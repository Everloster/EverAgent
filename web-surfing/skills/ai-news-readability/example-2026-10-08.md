## 头条 1 · 📄 《Navier–Stokes lost in translation》：AI 数学的第一场公开方法论交锋

**三句话速读**：OpenAI 数学发布后约 1 小时，arXiv 收到对抗论文。论文论证「AI 把自然语言数学翻译成 Lean 再机械验证」在计算复杂度上不可达，并给出 OpenAI 的 Navier–Stokes 证明作为误翻实例。同一窗口 HN 主公告发酵至 1,226 分 / 1,402 评论，对抗论文获 245 分。

**关键事实**
- 论文编号 arXiv 2610.08144，提交 2026-10-06 10:58 UTC，比 OpenAI 主公告（10:00 UTC）仅晚约 1 小时
- 作者 Bastounis / Circelli / Hansen，分类 math.AP + cs.AI + math.LO，25 页 4 图
- 核心主张：语义忠实的 autoformalisation 在 Solvability Complexity Index 层级中 SCI = ∞，比停机问题还难
- 实证层：论文指出 OpenAI 宣布的 Lean 证明「不对应」其 NL blow-up 证明

**细读与质疑**
- 论文 v1 未经同行评审
- OpenAI 侧回应口径在当前快照范围内未见
- HN 评论区已有反驳口径：论文只处理 proof 与 intermediate statement，未处理 final statement
- Wikipedia 已建「Navier–Stokes priority controversy」条目，但公开时间线仍无统一口径
- 作者团队以 SCI 层级为学术谱系，理论立场有出处

## 趋势总结

### 1. 📄 AI 做数学 24 小时走完「加冕 → 质疑」全程，验证链路本身成为战场

**时间线非常紧**：10-06 10:00 UTC OpenAI 发布带 IAS 顾问、引用协议、Lean 形式化、算力透明的数学成果 → 10-06 10:58 UTC 对抗论文提交，主张 autoformalisation 不可达 → 今日 HN 主公告发酵至 1,226 分、对抗论文获 245 分。

- 这场交锋的标的不是 Navier–Stokes 本身，而是「机械验证」能不能为「自然语言论证」背书
- OpenAI 发布协议把 Lean 形式化作为可信度支点，论文论证这个支点有计算复杂度层面的结构性裂缝
- 对整个 AI for Science 赛道，这是第一次有人系统性攻击**验证方法**而非个案结论
- 冷读：对抗论文未经同行评审 · OpenAI 未回应 · 第三方复核缺位 · 但「发布 1 小时内即有对抗研究」说明学术共同体响应速度已追平厂商发布速度

### 2. 🏢 模型层竞争从「发更好模型」转入「定价结构战」，供应商降价与大客户撤退同日显形

**三组动作同日发生**：Anthropic 价格三连动（Haiku 5.5 压到 $0.10 / Sonnet 缓存半价 / 订阅送 API 额度）、OpenAI 把 GPT-6 + Intelligent UI 推全量、The Information 曝 Meta 砍半 Microsoft 削三成。

- 「订阅送 API 额度」把 10-06 SemiAnalysis「订阅折算 API」的分析公式直接产品化
- 当最大的平台客户开始用自研替换你的内部部署，理性响应就是压价 + 把订阅用户改造为 API 用户
- 加上 10-07 的 DeepSeek 一级市场融资与 Anthropic 不可撤销承诺拆账，模型层正在同一周出现资本结构分化与客户迁移
- 冷读：Meta / Microsoft 数字均为 The Information 转述 · 降价与撤退的因果是时序推断 · 75% 成本下降为厂商口径

### 3. 🛠 agent 栈的「认领赛」扩散到全部基础设施阵营，并开始自带「可验证」标签

**一周四层落子**：容器层（Docker Agent Builder）、网络层（Cloudflare 搜索 API + cloudflare-os + security-audit-skill）、硬件层（NVIDIA / Microsoft Windows agent 硬件）、终端层（cmux、cua 开源）。

- Trending 的 skills 集群本日完成从「个人工作流打包」到「大厂官方职能 skill」的质变
- cloudflare/security-audit-skill 强调「independently verified、machine-readable」——「可验证性」正在从数学哲学问题变成 agent 产品的卖点标签
- 这条和头条 1 的「验证链路忠实性」之争在工程层同构
