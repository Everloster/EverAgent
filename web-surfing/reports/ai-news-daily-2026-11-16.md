## 《金融时报》：黄仁勋与亲信讨论重返首席执行官

据《金融时报》11月15日（周日）报道，并经 The Independent 和频道新闻亚洲（CNA，转述路透社）等转述：黄仁勋已与亲信讨论重返英伟达首席执行官的可能性。消息来自知情人士，不是英伟达或黄仁勋的公开声明。本期未能打开《金融时报》原文，以下转述以已读报道为准。

一名盟友对《金融时报》说，他们正在召集硅谷高管组成“作战室”，推动他重返，并试图争取白宫支持；该人还称这些努力得到黄仁勋的支持。此人对报纸说：“在前沿实验室之外，科技界真正要紧的人都喜欢黄仁勋。”这是个人判断，不是一项行业共识调查。

The Independent 写明已向英伟达求证。CNA 称，英伟达在正常工作时间之外未立即回应。决定权在董事会。报道还转述，一名参与推动回归的人士承认，与下属发生婚外关系本身就足以构成解雇理由。董事会的独立调查尚未结束。这是对 [11月13日日报](./ai-news-daily-2026-11-13.md) 所写辞职事件的后续，并不等于调查结论或人事安排已经改变。上期写过的请愿仍在继续，不能把它理解成董事会已改变决定。

## 贝森特主张从外部选CEO，并要求十天内答复

美国财政部长贝森特周日在福克斯新闻《Sunday Morning Futures》节目中说，董事会寻找新领导人时“需要把目光放到公司以外”，“他们需要一场剧烈调整”。据 CNBC、Axios 和半岛电视台（与路透社联合报道）引述，他还说：“我认为我们需要在未来10天内，从董事会和外部律师那里得到答复。”

贝森特同时提出一个尚未被独立证实的问题：英伟达是否曾推动“看起来不合法的销售”，以抬高营收和利润。Axios 和 CNBC 都写明，英伟达未立即就这些言论置评。官员的质疑不能当成已经查实的出口违规。

英伟达已定于美国时间 11月17日（周二）太平洋时间下午2点、东部时间下午5点召开 2027 财年第三季度财报电话会，对应北京时间 11月18日 06:00。这是黄仁勋辞职后的首次季报。日期来自公司 10月28日的[投资者关系公告](https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-Sets-Conference-Call-for-Third-Quarter-Financial-Results/default.aspx)，不是本期新宣布的日程。

## OpenAI 开设科学博客，首篇谈标准模型的候选格点定义

OpenAI 11月15日宣布[开设科学博客](https://openai.com/index/our-new-blog-for-science)，用于分享用人工智能做科学发现的方法和进展。同一天刊出的[首篇客座文章](https://openai.com/index/step-toward-defining-the-standard-model/)由 Nathaniel Craig 执笔。页面介绍他是加州大学圣巴巴拉分校粒子理论组负责人、卡弗里理论物理研究所常任成员，目前在 OpenAI 做访问科学家。

Craig 写道，标准模型虽然极为成功，但仍缺少不依赖微扰论的完整定义。把理论放到时空格子上是一条有希望的路，但弱相互作用的“手性”特点让这件事长期很难做。他 10月6日在 arXiv 提交的预印本《A gauge-invariant measure for lattice chiral fermions》（[2610.09093](https://arxiv.org/abs/2610.09093)）提出了一个候选做法。他称自己已有策略，但未能在所有需要覆盖的情形里完成证明；Astra 帮助把策略做成构造，并在详细证明中起了主要作用。

文章把结果称为“候选的非微扰格点定义”，并明说这更像开端而不是终点：还需要专家讨论它是否具备应有的性质，目前也远未达到可用于实际格点模拟的程度。作者正在考虑它在有限格子间距下是否满足反射正性。文中提到，格点场论研究者 Maarten Golterman、Andreas Kronfeld 和 Yigal Shamir 曾审看 Astra 的证明并提问。这是作者所述的专家讨论，不是已经完成的期刊同行评审。哥伦比亚大学的 Peter Woit 早在 10月8日就[写过](https://www.math.columbia.edu/~woit/wordpress/?p=15915)：他认为这是对 Lüscher 工作的有限推进，距离连续极限下的完整定义还很远，也还不能用于实际的电弱非微扰计算。

## Steve Blank：黄仁勋离开后，董事会要先决定还要不要创新

创业教育者 Steve Blank 11月15日在个人[博客](https://steveblank.com/2026/11/15/whats-next-for-nvidia/)写道，有愿景的首席执行官离开后，公司常常只会靠惯性和品牌滑行，创新逐渐停下来。他认为这是英伟达眼下要面对的风险。文章发布于北京时间 16日 06:15，属个人分析，不是公司或董事会的说明。

他回顾说，黄仁勋曾三次改写公司业务：2006 年推出 CUDA，2012 年转向深度学习，2020 年收购 Mellanox 后从卖板卡转到卖数据中心整机系统。Blank 还写，黄仁勋约有 60 名直接下属，并且不相信接班安排；下一任首席执行官几乎必然先增加管理层级。这些组织细节来自他的转述，本期未回英伟达原文核实。

Blank 认为，英伟达最大的客户正在变成竞争对手，因为谷歌、亚马逊、微软、Meta、OpenAI 和特斯拉都在做自己的人工智能芯片。他担心，若下一任更偏向执行已有业务，可能先收缩每年推出新一代芯片、加固 CUDA，以及对人工智能实验室的投入。他写道，订单和 CUDA 也许还能让未来两三年看起来不错，除非有相当一部分收入被认定与流向中国的受限芯片有关。是否存在这类收入，以及规模多大，仍待查证，不能从这篇文章直接推出。

**Ethan Mollick**，宾夕法尼亚大学沃顿商学院教授，研究人工智能。他[写道](https://x.com/emollick/status/2122092065890635873)，如果家里的中枢设备没有足够好的模型来驱动，会越来越成为负担；把装了 Codex、Claude Code 或 OpenClaw 的电脑，和 Siri 或 Alexa 比一下就能感觉到差别。帖发于北京时间 11月16日 06:19，属个人使用体验和判断，不是产品评测。

**Gary Marcus**，纽约大学名誉教授，长期主张把神经网络与符号方法结合起来。他[写道](https://x.com/GaryMarcus/status/2122095186004029670)，要理解眼下的人工智能，先要分清“模型”和“整个系统”：如果系统里既有神经网络又有符号，按定义就是神经符号系统；他认为 Claude Code 和用 Lean 检查模型证明，都说明符号工具已经回到工作系统的中心。帖发于北京时间 11月16日 06:31，属个人学术主张，不是一项新的实验结果。
