## 8. 附录

### 8.1 数据来源

- API:`GET /user/starred?per_page=100`
- 鉴权:`gh` CLI(token 存于 keyring,账号 `Everloster` / user_id `2820419`)
- 媒体类型:`Accept: application/vnd.github.star+json` —— 必需,否则响应不含 `starred_at`
- 拉取页数:全量共 9 页,合计 **867** 个 starred 仓库(全量,最早可追溯到 2012-11-17),本报告按 `3y` 过滤后剩 **482** 个

> 数据观测:全量 867 个 starred 仓库的时间分布存在两个活跃段(2015-2017 与 2025-2026),2023-2024 区间内无任何 star 记录。若非账号闲置,可能与当时的 GitHub 使用习惯/隐私设置变更有关,本报告仅如实反映 API 返回数据。

### 8.2 方法

- **过滤**:仅保留 `starred_at >= cutoff` 的项目
- **分类**:基于 repo `topics` 字段 + `description` 关键词的规则分类,见 `scripts/analyze.py` `CATEGORY_RULES`
- **统计**:Counter 计数,占比基于时间窗内子集
- **数据未做二次 enrich**:`/user/starred` 响应已包含 `topics` / `created_at` / `updated_at` / `license` / `stargazers_count` / `forks_count` / `language` 等字段,无需额外 API 调用

### 8.3 限制

- 分类为规则分类,无法归入任何规则的项目落入「其他/未分类」,可能掩盖真实兴趣
- GitHub API 返回的 `stargazers_count` 为拉取时刻的值,后续变化不在本报告反映
- `starred_at` 字段依赖 star+json 媒体类型,若 API 行为变更需同步脚本
- 公开/私有仓库均包含(token 鉴权读取)
