# 心理学学习与研究

## 几条阅读线索

- **记忆与信息加工**：[Miller 精读](./reports/paper_analyses/01_miller_magical_number_seven_1956.md)，同时关注原实验的测量对象与后续解释。
- **判断与决策**：[前景理论](./reports/paper_analyses/05_kahneman_tversky_prospect_theory_1979.md)与[认知偏差全景图](./reports/concept_reports/认知偏差全景图.md)，连接实验结果和理论模型。
- **情境与个体**：[Milgram 精读](./reports/paper_analyses/02_milgram_obedience_1963.md)与[关键人物图谱](./reports/concept_reports/心理学关键人物图谱_更新版.md)，兼顾方法、伦理与思想传承。

经典地位不等于证据无争议。阅读时关注样本、效应量、相关与因果、复现情况及 WEIRD 人群边界；行为发现不直接等于临床建议。意识与意义问题可衔接[哲学](../philosophy-learning/README.md)，睡眠和生理机制可衔接[生物学](../biology-learning/README.md)。
