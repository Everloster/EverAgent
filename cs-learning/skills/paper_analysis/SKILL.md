# CS 论文深度分析

> 用于单篇算法、系统或理论计算机论文。概念综述使用 `concept_deep_dive`。

## 路由

- 原文、证明、复杂度和工业采用：读 [guide：论文证据要求](./references/guide.md#-论文证据要求)。
- 按论文选择问题、方案、证明、实验、影响或关联：读 [guide：七个分析维度](./references/guide.md#七个可选分析维度)。
- 只有需要成稿骨架时读取 [guide：结构参考](./references/guide.md#结构参考)。

## 不变量

重构支撑核心 theorem 的证明思路和假设；复杂度口径准确；伪代码足以说明关键机制；工业采用与版本信息通过 eacli 核验。
