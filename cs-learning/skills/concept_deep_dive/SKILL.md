# CS 概念深挖

> 用于算法、系统、数据库、网络或编程语言概念。单篇论文用 `paper_analysis`。

## 路由

- 来源、真实实现和版本事实：读 [guide：领域证据要求](./references/guide.md#-领域证据要求)。
- 按问题选择直觉、定义、机制、实现或系统权衡：读 [guide：五个理解维度](./references/guide.md#五个可选理解维度)。
- 只有需要成稿骨架时读取 [guide：结构参考](./references/guide.md#结构参考)。

## 不变量

复杂度注明 worst、amortized 或 expected；真实系统结论核对源码或官方文档；示例代码应可运行；trade-off 给出具体条件和代价。
