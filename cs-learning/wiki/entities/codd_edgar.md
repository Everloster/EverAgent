# Edgar F. Codd

> **生卒**：1923-08-19 (Portland, Dorset, UK) – 2003-04-18 (Williams Island, FL)
> **领域**：关系模型、数据库理论
> **首次归档**：2026-06-21（ByteAgent · 数据库50年演化）

## 关键贡献

- **1970**：在 *Communications of the ACM* 13(6) 发表 *"A Relational Model of Data for Large Shared Data Banks"*，提出**关系模型**（基于集合论与谓词逻辑），用数学严格性替代了 IMS / DBTG 的导航式访问。
- **1970-72**：提出 **12 Rules (Codd's 12 Rules)**，作为判定"真"关系系统的准则。
- **1985**：与 C.J. Date 等人提出 **第三范式** 的修订版本（与 Boyce 合作的 BCNF）。
- **1993**：与同事及 Arbor Software 合作，提出 **OLAP 12 Rules**，奠定多维分析理论基础。
- **1981 Turing Award**："For his fundamental and continuing contributions to the theory and practice of database management systems."

## 主要著作

- *A Relational Model of Data for Large Shared Data Banks*, CACM 13(6), 1970
- *The Relational Model for Database Management: Version 2* (1990)
- *Providing OLAP to User-Analysts: An IT Mandate* (1993, Arbor Software)

## 在本项目 (cs-learning) 的影响

- 关系模型是本项目 **`reports/knowledge_reports/数据库50年演化_从层次到向量库_20260621.md`** 的核心节点之一。
- 通过 Ingres / System R / Oracle 间接孵化了本项目 **04_unix_1974** 的现实意义（关系型数据库成为 Unix 时代商业 IT 核心）。
- OLAP 12 Rules 是数据仓库范式 (Bill Inmon 1990, Ralph Kimball 1996) 的理论上游。
