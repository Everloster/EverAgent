# 版权与公开边界（podcast-learning）

本文件约束本领域的报告、Wiki、转写与润色稿。它不是对第三方作品的许可，
也不因标注“个人学习”、注明来源或提供下架渠道而取得公开复制权。

## 权利与引用

节目、音视频、字幕与其中受保护表达的权利归相应权利人所有；本项目不主张对这些
第三方资料的权利。平台可访问、可下载不等于已授权全文再传播。本仓其他许可不自动
覆盖被引用或转写的第三方作品。

公开报告以原创分析为主体，注明节目与公开来源链接，只引用理解论证所必要的少量
原文，避免连续重现章节或使摘录集合替代原作品。引用是否适当取决于目的、必要性、
作品性质、范围及适用规则，不能仅凭“几句话”“某个百分比”或权利人是否提出异议判定合法。
没有查明的权利依据不得写成授权事实；需要扩大复制范围时，先取得并记录适用许可。

## 后续新增资料的默认边界

| 资料 | 默认保存与公开方式 |
|---|---|
| 原创报告、概念分析 | 可公开；附来源链接、必要摘录和事实/推断边界 |
| 节目元数据与时间戳索引 | 只保留定位研究内容所需的信息 |
| 完整转写、完整润色稿、下载字幕与音频 | 默认私有/本地保存，不拉回公开仓，不公开链接私人绝对路径 |
| 机器审计回执 | 可发布经审阅的最小脱敏视图；只含公开来源、内容哈希与审计指标，不含原文样本或执行拓扑 |

私有保存本身也不免除获取方式、服务条款或适用法律的要求；本项目不绕过访问控制，
不把未公开材料、付费或加密内容当作可自由分发的来源。确需公开全文的例外，应逐项记录
可核验的权利依据及允许范围，并由维护者确认；审计通过不构成版权许可。

`transcript_path`，105 篇声明 `polished_transcript_path`（包含部分 `null` 声明）；历史目录有

这些数字是该次快照，不是持续更新的索引，也不表示每个引用都已完成版权或内容核验。

本次不批量搬走这些历史全文、不改报告正文、不重写证据/复核哈希回执。这是为避免
突然破坏已有引用和可复核链的过渡措施，**不代表已取得公开再传播授权**，也不消除现有
公开副本的版权问题。历史保留不是后续新增全文的先例。

若要处理具体历史来源，应先列出其报告、evidence、review 与链接依赖，明确适用权利
及处理要求；迁移需要建立新的 revision、更新合法的公开来源/ref、重新复核和最终判定，
不篡改旧回执。更改当前 tree 不等于移除 Git 历史或其他副本；需要改写历史或对外下架时，
由维护者另行授权并协调，不能以“哈希不能动”为理由拒绝必要的权利处理。

## 私有来源与可复核性

新报告可省略全文路径或填 `null`，同时提供公开 `source_url`、`transcript_source_ref:
sha256:<内容摘要>` 与仓内相对 `transcript_audit_path`。收据字段和只读命令见
[转写参考：私有默认与公开审计收据](./skills/transcription/references/pipeline-guide.md#私有默认与公开审计收据)。

公开收据不含私有绝对路径、设备/账号映射、运行态标识或原文样本。仅能读取收据时，
审计明确给出 `receipt_only`，不声称重新核验原文；缺少 source、收据或摘要不能假装成功。
report-v2 的本地 evidence 仍指向仓内普通文件；来源 URL 承载原始来源身份，审计收据只能
证明其自报的指标与绑定，不能替代原文语义证据或有权访问来源的 Reviewer。

本仓协议与检查不会自动调整外部 eacli worker、拉取脚本或其他生产器的默认落盘行为。
执行者仍需选择仓外私有输出并核对外部回执；不能把文档默认误称为外部服务已完成迁移。
