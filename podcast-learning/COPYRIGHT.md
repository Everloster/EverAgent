## 3. 法律依据（《中华人民共和国著作权法》）

### 合理使用（第 24 条）

以下情形属合理使用，**不构成侵权**：

> "为个人学习、研究或者欣赏，使用他人已经发表的作品"

### 本项目的使用定性

| 行为 | 定性 | 备注 |
|------|------|------|
| ✅ 个人听 + 写笔记 | 合理使用 | 100% 个人学习 |
| ✅ 报告里每条 ≤3 句原话引用 + 评价 | 合理使用 | 引用 + 评论属合理 |
| ✅ 书名 / 嘉宾名 / 章节时间戳 / 节目元数据 | 事实性引用 | 不构成复制 |
| ⚠️ 完整转录稿（35K+ 汉字）推到公开 repo | **灰色地带** | 超出通常"合理使用"5-10% 范围 |
| ⚠️ 完整润色稿（按章节重组）推到公开 repo | **灰色地带** | 同上 |

### 风险等级自评

- **报告 + wiki**：🟢 低风险
- **完整转录 / 润色稿**：🟡 灰色地带（合法与不合法之间，**取决于版权方是否追诉**）
- **音频文件**：本地保留，不公开传播

## 4. 引用边界

### 4.1 报告中允许的引用

- **金句引用**：每条 ≤ 3 句 + 我的评价/分析
- **章节时间戳**：作为索引引用（不复制原话）
- **书名 / 嘉宾 / 概念词**：作为事实信息引用

### 4.2 报告中避免的引用

- ❌ **连续 5 句以上**原话不评价
- ❌ **完整复制**原作品的某一章节（即使是"摘要"形式）
- ❌ **替代原作品**（不要让报告成为"代看"）

### 4.3 完整转录 / 润色稿的处理原则

- **不主动对外推广**（不在社交媒体/邮件等宣传）
- **不替代原作品消费**（不鼓励他人"看转录就够了"）
- **明示来源**（每次引用都注明节目 + 主理人 + 嘉宾 + 链接）
- **提供替代路径**（"想听完整节目请去小宇宙 / Apple Podcasts"）

## 6. 例外情况

- **嘉宾本人**的引用：**优先遵循嘉宾本人意愿**；若嘉宾明确反对引用某观点，删除该条
- **未公开发布**的节目（如仅在小范围分享的草稿）：**不在本项目范围内**
- **付费节目 / 加密内容**：**不在本项目范围内**
