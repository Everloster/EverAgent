# 芯片开卷计划（Chip Open Plan）

> 概念实体 · 首次引入：2026-09-16（此话当真对话张托肯）

## 定义

张托肯发起：一颗有广泛商业价值的芯片需要 99 分以上，但初学者大量精力耗在 0→60/80 分的教科书/研究生级内容上——**这部分应该被开卷（开源+AI 加速），让人从 60/80 甚至 90 分起步**，把精力留给真正创造价值的高分段。

## 配套判断

- **"封闭世界的胜利"**：数字芯片工具链完备、边界明确、易 verify → agent 渗透率 80-90%（模拟芯片预计饱和 40-50%）——封闭、可验证的工程领域是 agent 最先打穿的地方
- **验证要求反升**：芯片设计验证需要几百上千轮工具交互 → 对模型智能要求更高 → token 消耗想象空间巨大
- 配套实践：开源 EDA 桥接工具（4 个月阅读 4 万+）、Razavi Bench 50 题评测、"训模型=教书育人"（好任务本身就是训练数据）
