# Agent 元年（Chatbot 翻篇）

> 概念实体 · 首次引入：2026-07-17（屠龙之术《重估一切，文艺复兴——2026H1 AI行业观察》）

## 定义

庄明浩对 2026 年的定性：Agent 从聊天走向任务执行的转折之年，对应文艺复兴"从画匠到工坊"（1470 佛罗伦萨工坊制=产能来源：师傅构图、学徒分工执行）。核心判断："纯 Chatbot 已经到头了，这是不需要探讨的结论。"

## 标志性事件（2026H1，主播转述口径）

- **Codex = 新 ChatGPT**：OpenAI 把 Codex 更名为 ChatGPT（旧版→ChatGPT Classic[?]），新增 ChatGPT Work；周活 5 月 500 万 → 7/15 900 万，每天 +100 万
- **Claude Code 时刻**：类比 22 底 ChatGPT 时刻；Anthropic 内部人均代码提交量 ×8；"Code 吞噬一切"，Code 成为 AI 自主进化的 harness[?]
- **分工与多智能体**：规划/工具调用/执行/纠错/评判的角色分工 + 多智能体系统成为共识
- **软件生态去 UI 化**：软件给 agent 用不需要 UI → CLI/MCP/A2A；大语言工具链 → agent 执行工具链；agent infra 开源项目半年爆发
- **模型厂商下场做垂直**：Anthropic 连发 Claude Finance/Legal/Science/Design/Enterprise，"模型的边界"成悬案
- **国内同形态竞争**：字节 Trae/扣子、阿里 Qoder[?]/悟空、腾讯 WorkBuddy、智谱 Z Code[?]、Kimi Code/Work；豆包/千问下线旧"智能体"（提示词打包封装）；钉钉整合、腾讯 WorkBuddy 成"新太子"

## 关键判断

- 怎么做/做什么/找谁付钱/2B 还是 2C **都没有答案**；唯一有答案的是产品形态——"感谢 Codex 这个好师傅"定义了这一轮产品样式
- coding 是核心战场（Claude Code 异军突起 → Codex Q2 追 → Cursor 走弱被 X 收掉）；从 coding 扩展到 work（白领）使市场规模再加 2T
- 数字世界 4T（订阅+广告 0.3T、coding 2T、work 2T，Coatue[?]口径）之外还有物理世界——这是世界模型热的需求侧原因
