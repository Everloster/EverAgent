# GEO（生成引擎优化）

> 概念实体 · 首次建档：2026-10-02（AI炼金术 2026-09-23 期，鲁扬口径）

## 定义

**GEO = Generative Engine Optimization（生成引擎优化）**：面向生成式 AI 平台（豆包/千问/DeepSeek/ChatGPT 等 Chatbot）的品牌优化——让 AI 在用户问询时推荐你的品牌、位置靠前、描述准确客观。

## 与 SEO 的物种级差异

| | SEO | GEO |
|---|---|---|
| 对象 | 搜索引擎（有规则） | 大模型（黑盒） |
| 规则 | 网页权重可查（百度统计）、方法论公开（TDK/内外链）、算法迭代慢（百度 20 年大迭代就几次） | 无明文规则：同 query 今天推 A 明天推 C，不给原因（神经网络推理） |
| 操作 | 可手工，按教程 1234567 按图索骥 | 越来越难手工；人工做=每天写稿发稿碰运气 |
| 分水岭 | —— | **能不能手工操作**（技术流派分叉点） |

## 三阶段（清蓝 self-蹚路）

人工碰运气 → 数据驱动（AB 测仍不精准）→ **算法驱动：用一个模型去学习一个模型，用一套算法去解读一套算法**。

## AI 可解释性（核心研究对象）

GEO 研究的不是文章写法，而是"品牌为什么会被 AI 推荐"。AI 判断漏斗：意图理解（拆 query）→ 检索 → 只分析返回内容的一小部分（未入即出局）→ ranking（排前=出现概率高+篇幅多）→ 答案生成只引用极少数（思维链可见的引用只是一角，且有正门引用/过程引用之分、随版本漂移）。方法与量化交易同构：抛掉人工判断，算法对内容特征做因子挖掘（参见 [[concepts/ai-trading|AI Trading]] 的机器打机器直觉）。

## 采信来源的模型个性

- 国内模型：偏媒体内容；**豆包对抖音视频权重很高**（视频的长度/题材/真人/数字人/镜头语言/叙事结构都会成为因子）
- 海外模型：偏品牌官网、独立站、Reddit 社区，媒体权重反而低
- 同一品牌国内外 GEO 是两套活（国内：稿件结构+信任状+媒体渠道；海外：官网 GEO 化+社区运营）

## 意图电商与 prompt 货架

货架电商 → 信息电商 → **意图电商**：用户描述现状/痛点（"膝盖疼"）而非商品（"哪个氨糖好"），AI 识别意图完成推荐。货架演化：百货大楼 → 虚拟货架 → APP → **prompt（"一个 prompt 就是一个货架"）**。品牌策略：回归自身核心优势让 AI 认知到（二线冲锋衣优化"性价比高、质量好、抗造"而非"最好的冲锋衣"），"AI 是讲道理的，你得让它讲道理的时候有话说"。闭环信号：ChatGPT 电商跳转（2025-04-29）→ Instant Checkout（2025-10）→ 豆包站内下单+打通抖电后台+酒旅抽佣（常规 8 点/部分 12 点）。

## 科学 GEO 八环节

知识管理（建品牌知识库，可信心源起点）→ 意图挖掘（锁定值得优化的意图；含"不可优化意图"判断：联网率低/只出科普不推品牌的）→ 品牌诊断（呈现度/趋势/竞品/AI 怎么 talk 你）→ 内容管理 → 效果预估（Shadow[?] 环境模拟稿件提升概率）→ 发布 → 效果监控 → 效果调优。写稿发稿只占 2/8。
效果验证：单次抽样无意义；小时级（上限分钟级）采样、同 query 20-30 次/天、多平台多账号（上百个）多 IP、连续一个月取**月均**达标。常见 3-4 周见效。异构模型：通用底座+按客户 query 单独学习的小模型（约 1 周）。
