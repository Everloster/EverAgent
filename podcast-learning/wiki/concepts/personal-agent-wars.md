# Personal Agent 战争（2026 秋品类爆发）

> 概念页 · 2026-10-09 · 来源：[乱翻书275 报告](../../reports/2026-09-21_xiaoyuzhou-luanfanshu_personal-agent-wars.md)（含产品深研档案）

## 一句话
争夺"用户意图产生后的第一入口"的品类战争：Personal Agent 以**人**（而非任务）为中心组织 Context，替用户把事办完（订票/退款/账单/邮件），2026 年 1 月 OpenClaw 启发、2 月集体立项、9 月 Muse/Instinct $10B/Dots 三连爆，6 个月内从开源玩具变成巨头战场。

第三极：OpenAI Dots（09-29，GPT-6 Astra，4000+ 应用）；中国变量：微信小微/豆包（×抖音打通）/千问（调淘宝支付宝）/Today 中国版（09-24）。

## 核心分界（vs 前三波）
- 不是 Siri/Alexa（语音指令）、不是 chatbot（问答）、不是办公 Agent（任务维度 Context）
- **以人为中心的长程理解 + 主观能动性**（理解目标后主动提方案，非 prompt 驱动的自动化）+ **把事办完**（Instinct 接信用卡/屏幕/麦克风才病毒传播；Poke 只推送准没做执行→被收购）
- 先烈教训（OpenClaw 一代）：追热点太糙；云上 agent 三套环境（设备/云服务/执行环境）状态一致极难（Today 花 2 个月）；门槛太高+不敢出错

## 关键判断（乱翻书275 嘉宾）
- **GUI = 地图论**（Suki）：GUI 不再承载操作，是探索 agent 能力的地图
- **真实需求排序**：行政杂事 > 旅行 > 省钱理财 > 购物（Today 数据，前四 >70%）——"帮你买东西"不在 top 场景，小扎购物叙事存疑
- **意图经济**：收藏="没有兑现的意图"；商业模式应是订阅/抽佣，绝不能是广告
- **无网络效应叙事**（Vanessa）：无双边锁定，谁好用第二天切换——创业公司比上一波更好打
- **最值钱位置 = 信任和习惯**（context 只是入门）；光有 context 不够，从 context 构建画像的 memory 工程极难
