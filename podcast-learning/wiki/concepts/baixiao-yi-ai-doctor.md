# 百小一（AI 家庭医生）

> 概念实体 · 首次引入：2026-06-18（小宇宙 Vol.29）

## 产品形态

百川智能推出的 C 端 AI 家庭医生 Agent。**底层是 Agentic 架构，对外封装为 AI 家庭医生**。

## 两个核心能力

1. **C 端体验**："能够帮你去管家庭"（家庭医生属性，最强用户感知）
2. **专业医疗资源对接**：需要"医学大家"的背书 + 医疗资源对接（不能只靠公开数据自训）

## 商业逻辑（与豆包/ChatGPT 的关键差异）

| 维度 | 百小一 | 豆包 / ChatGPT |
|------|--------|----------------|
| 驱动指标 | 医疗机构/保险/药厂付费 | DAU + Token 消耗 |
| 收费方 | C 端付费 + 机构付费 + 药厂 | C 端订阅为主 |
| 故事版本 | 类似智谱上市前的"项目化定制" | 标准化 DAU |
| 估值逻辑 | 供给侧付费 | 用户规模 |

> 王小川："**它不是 token 消耗的逻辑，它不是单一的个体去 subscribe 的逻辑。**"

## 三类买单方

1. **C 端个人付费**（订阅/单次问诊）
2. **医疗机构**（医院、诊所）购买服务
3. **保险 + 商保 + 药厂**（真实世界数据 / 干预预后 / 保险控费）

## 与"好大夫"的差异

王小川强调：百小一**不是把好大夫搬到 AI 上**，而是对现有医疗体系做**结构性补充**。
