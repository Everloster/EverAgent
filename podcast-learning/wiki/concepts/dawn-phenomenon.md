# 黎明现象（Dawn Phenomenon）

> 清晨（约 4–8 点）体内激素变化导致的生理性血糖升高现象。
> 是理解「糖尿病人为什么怕早餐碳水」的机制钥匙；健康人受此影响甚微。

## 机制

天没亮、人未醒时，身体已开始用激素「叫床」：

1. **夜间生长激素 + 清晨皮质醇 + 肾上腺素** 协同作用
2. **肝脏放糖**：把储存的糖原释放一批进血液 → 空腹血糖自然升高（为起床供能）
3. **细胞暂时性胰岛素抵抗**：让这批糖留在血液里供能，而非被细胞储存

```
夜间激素（生长激素/皮质醇/肾上腺素）
        │
        ├─→ 肝脏释放糖原 → 血糖升高（供起床用能）
        │
        └─→ 细胞暂时胰岛素抵抗 → 糖留在血中
                        │
        健康人：胰腺追加胰岛素 → 压回正常 ✓
        糖尿病人：胰岛素不足 → 压不住 ✗
                        │
        此时再灌一碗碳水（燕麦粥）→ 血糖冲天
```

## 人群差异（关键）

| 人群 | 黎明现象的影响 |
|------|--------------|
| 健康人 | 人人都有，胰腺压得回去，无感无事 |
| 二型糖尿病人 | 胰岛素不足压不住，清晨血糖已高；此时吃碳水早餐 = 雪上加霜 |
| 用胰岛素/降糖药者 | 反过来有低血糖风险，**不能**随意跳餐，须遵医嘱 |

## 关联研究

- **丹麦 Parkner 团队 2011**（*Eur J Clin Nutr*，PMID 21346717，N=13 二型糖尿病，随机交叉 4 天，早餐热量再分配到其他餐）：早餐日全天血糖 SD 高 32%（P<0.0001），平均血糖仅高 0.24 mmol/L（趋势）。视频原称「克里斯蒂安森团队」，Christiansen 为资深作者
- **以色列 Jakubowicz 团队 2015**（*Diabetes Care* 38(10)，PMID 26220945，N=22 交叉，午晚餐固定各 700 kcal、早餐热量不补偿）：禁食至中午日午餐后血糖 AUC +36.8%、晚餐后 +26.6%；机制链 = GLP-1↓、胰岛素峰值延迟约 30 min、FFA↑41%
- **两项研究的关系（2026-07-18 查证）**：看似相反、实则互补——前者测全天变异度+等热量再分配，后者测单餐峰值+热量赤字。糖尿病人减早餐的正确姿势是「缩小再分配」而非「简单删除」
- **Leproult & Van Cauter 2001**（*JCEM*，8 名健康男性 36 小时清醒）：清晨 5–8 点强光使皮质醇立刻升高 >50%，下午同等光照无反应 → 启动生理时钟的是**晨光**而非早餐
- **蛋白质 preload（2026-07-18 查证）**：餐前 10–30 min 摄入 15–50g 乳清可削平餐后峰值（meta：−1.4 mmol/L，Smedegaard 2023 *AJCN*）；机制为 incretin priming；「提前 1 小时」无文献依据；长期 HbA1c 获益未证实
