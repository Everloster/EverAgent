# 黎明现象（Dawn Phenomenon）

> 清晨（约 4–8 点）体内激素变化导致的生理性血糖升高现象。
> 是理解「糖尿病人为什么怕早餐碳水」的机制钥匙；健康人受此影响甚微。

## 机制

天没亮、人未醒时，身体已开始用激素「叫床」：

1. **夜间生长激素 + 清晨皮质醇 + 肾上腺素** 协同作用
2. **肝脏放糖**：把储存的糖原释放一批进血液 → 空腹血糖自然升高（为起床供能）
3. **细胞暂时性胰岛素抵抗**：让这批糖留在血液里供能，而非被细胞储存

```
夜间激素（生长激素/皮质醇/肾上腺素）
        │
        ├─→ 肝脏释放糖原 → 血糖升高（供起床用能）
        │
        └─→ 细胞暂时胰岛素抵抗 → 糖留在血中
                        │
        健康人：胰腺追加胰岛素 → 压回正常 ✓
        糖尿病人：胰岛素不足 → 压不住 ✗
                        │
        此时再灌一碗碳水（燕麦粥）→ 血糖冲天
```

## 人群差异（关键）

| 人群 | 黎明现象的影响 |
|------|--------------|
| 健康人 | 人人都有，胰腺压得回去，无感无事 |
| 二型糖尿病人 | 胰岛素不足压不住，清晨血糖已高；此时吃碳水早餐 = 雪上加霜 |
| 用胰岛素/降糖药者 | 反过来有低血糖风险，**不能**随意跳餐，须遵医嘱 |

## 关联研究

- **丹麦 克里斯蒂安森团队 2011**（N=13 二型糖尿病）：不吃早餐日全天血糖波动小约三成
- **以色列 雅各布维兹团队 2015**（N=22 交叉试验）：不吃早餐日午餐后血糖 +37%、晚餐后 +27% —— 结论相反，尚无定论
- **Leproult & Van Cauter 2001**（*JCEM*，8 名健康男性 36 小时清醒）：清晨 5–8 点强光使皮质醇立刻升高 >50%，下午同等光照无反应 → 启动生理时钟的是**晨光**而非早餐
