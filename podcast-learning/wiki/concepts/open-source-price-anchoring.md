# 开源价格锚定（Open-Source Price Anchoring）

> 概念 · 首次出现：2026-07-24（涌现 EmergenceHK×Bill It Up S01E01 / 所长林超 B 站视频版，蒋涛提出）

## 定义

当开源模型能力逼近闭源（长程任务完成度 90-95%）时，**中国厂商把同等能力的价格锚定在闭源的 1/10**（DeepSeek 再往下压到约 1/30）——闭源巨头"要维持市值就得维持收入，而收入的价格被锚定，就没法增长"。模型差距越小，价格锚定对闭源估值的杀伤越大。

## 论证链（蒋涛）

1. **Linux 类比**：微软互联网时代因 Windows Server 被 Linux 替换而股价长期下跌——闭源巨头进企业级市场会重演（B 端不敢用投喂数据的模型 + 开发者分层用模型："最难的用 Opus，其余 DeepSeek 干"）
2. **企业算 ROI**：只要算 ROI 就不会全用最贵模型 → 闭源 2B 收入增长天然受限
3. **中国制造类比**：二十年前德日货十年不坏 vs 中国货两年坏但 1/10 价格——最终全部被打败
4. **IPO 考验**：OpenAI/Anthropic 上市后财务曝光，第三四个季度"curve 没那么陡了"→ 市梦率被报表戳破 → 估值回到微软式 ~10 倍水平

## 与相关概念的张力

- 与 [[ai-capex-bubble-debate]]（庄明浩"美第奇的账本"）互补：庄论"债是导火索、收入只够折旧"从供给侧；本论从需求侧价格端掐闭源收入曲线。两者共同指向同一时点窗口（2027）。
- Bill Qian 的对冲：若 AI 增长够快（3 年 1000 亿美元收入），"增长能解决一切"；变数恰是中国把它做成"社会总福利大增、财务增长没有"——价值捕获问题。
- 反驳条件：闭源重新拉开代差（如 Fable 5 级跃迁）则锚定失效——观察指标是上市后"每 token 均价 × 收入增速"剪刀。
