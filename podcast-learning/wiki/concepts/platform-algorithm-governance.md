# 平台算法治理（Platform Algorithm Governance）

## 定义

指政府 / 监管机构 / 平台自身对社交媒体 / 内容平台的推荐算法进行透明化、可问责化的治理努力。是 2020 年后全球范围的核心数字治理议题。

## 三大治理路径

### 1. 政府监管
- **欧盟**：Digital Services Act（DSA）2024 年生效，要求平台算法透明
- **中国**：2022 年起施行《互联网信息服务算法推荐管理规定》
- **美国**：2024 年开始推动算法问责立法（参议院多次听证）

### 2. 平台自治
- **X / Twitter**：算法调整后用户可选择"按时间线 / 按推荐"
- **TikTok**：定期发布算法透明度报告
- **Meta**：2023 年起部分开放算法研究 API

### 3. 第三方监督
- **学术机构**：研究算法对青少年心理健康的影响
- **NGO**：电子前线基金会（EFF）等推动算法可解释性
- **媒体**：报道算法偏见案例

## 关键观察（来自 Vol.32）

庄表伟在历期节目中反复讨论：
- 算法调整后 6-12 个月才能看到生态稳定态
- 平台规则变化 → 内容供给侧变化 → 公众认知变化的传导链条
- "X 平台新生态不等于'言论更自由'" — 算法调整影响流量分布
