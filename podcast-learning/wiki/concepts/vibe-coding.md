# vibe coding

## 定义

"vibe coding"是 2025-2026 年间在 AI 编程社区兴起的非正式术语，指**不依赖严格语法和工程规范，而是凭直觉 + AI 辅助快速产出可运行代码**的编程方式。Andrej Karpathy 在 2025 年 2 月的推文中首次大量使用这个术语，随后被广泛传播。

## 关键特征

- **build 成本归零**：任何人在一个周末可以做出可演示的 app
- **不强调代码质量**：追求"能跑 + 能演示"而非"可维护"
- **AI 是默认协作者**：LLM 负责补全、纠错、重构
- **快速迭代**：从"想到"到"可演示"的时间从几周缩短到几小时

## 与"传统编程"的对比

| 维度 | 传统编程 | vibe coding |
|------|---------|-------------|
| 学习曲线 | 陡（语法 + 工程） | 平（自然语言 + AI） |
| 产出速度 | 周/月级 | 小时/天级 |
| 代码质量 | 可维护优先 | 能跑优先 |
| 适用场景 | 长期项目 / 团队协作 | 原型 / 个人项目 / MVP |

## 关键观点（来自 Vol.30）

Sahil Lavingia 强调：vibe coding 让"造得出"变得容易，但"卖得出去"是另一个完全不同的能力。技术稀缺已从"造得出"转向"卖得掉"。
