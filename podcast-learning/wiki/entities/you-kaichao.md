# 游凯超（Kaichao You）

> 人物实体 · 首次出现：2026-07-28（小宇宙《张小珺Jùn｜商业访谈录》Vol.148，3h 对谈）

## 身份

- **Inferact 联合创始人兼首席科学家**；**vLLM 核心维护者**（第四个主要成员，决策层「仁慈的独裁者」之一）
- 清华大学本博（2019 年清华特等奖学金；主持人引述老历史：36 门课 4.0、论文精读笔记在校史馆展出）
- 2019 暑假赴 UC Berkeley Michael Jordan 组暑研（结识李卓翰）；2024 赴 SkyLab 交流时加入 vLLM；2025 年 7 月博士毕业，为等 vLLM 创业接了 SkyLab 博士后
- 研究轨迹：数据稀缺场景高效学习（LogMe, 2021）→ 大模型微调 → 博士后半段转系统
- 2016 年起写知乎；本期由 Manus 季逸超（Peak）2025-12 介绍（当时 Manus 尚未被 Meta 收购）

## 核心观点

- **系统的确定性**：「你可以说我的东西不 novel，但是你不可以说我的东西没有用」；系统工作的衡量标准是 GitHub star 与 issue 里的感谢信，论文是系统做好后的副产品
- **开源治理**：仁慈的独裁者分级制；「要做什么，更重要的是不做什么」（他亲自删掉 Beam Search）；coding agent 打破开源社区善意假设 → 社区二分为维护者 + 用户
- **co-design 时代**：模型结构决定推理效率上界；[[hardware-lottery|硬件彩票]]；算法 × infra 双料人才（DeepSeek 模式）
- **开源模型最后会赢**：token 带着模型的烙印 → 藏不住 → 护城河只在快速迭代
- **方法论**：第一性原理屏蔽噪音；「如果你没有办法清晰的写下来，说明你对它还不够了解」；「大胆猜想，小心求证」
