# 播客报告写作

> 把已取得的转写、润色稿和 shownotes 写成学习报告。下载与转写使用 `transcription`；只需要问答链时再读 `qa_chain`。

## 路由

- 选择普通总结、问答链或跨期综合：先读 [episode_analysis](../episode_analysis/SKILL.md)，需要问答链时再读 [qa_chain](../qa_chain/SKILL.md)。
- 需要日报式速览、章节模板、数字表或润色契约时，读取 [report-guide §二–§三](./references/report-guide.md#二润色产物契约2026-10-09-修订)。
- 核验引用、数字、`[?]` 和修辞强度时，读取 [report-guide §五](./references/report-guide.md#五纪律红线2026-10-14-全库-review-后立违反即返工)。
- 只有遇到对应来源或管线故障时，读取 [report-guide §六](./references/report-guide.md#六已知坑速查持续追加)。

## 完成条件

按根写作指南完成用户要求，明确来源、范围与未验证项。统计和来源检查只处理实际变化，可信且未变的结果可复用；独立Review与质量附件按需，不是提交前置。索引需要更新时再生成；只把跨节目可复用的新发现写回资料，节目特例留在报告。
