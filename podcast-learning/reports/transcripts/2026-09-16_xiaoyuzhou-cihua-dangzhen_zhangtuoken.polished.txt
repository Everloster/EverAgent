## Token Grant 与「芯片开卷计划」

（开场金句剪辑）

张托肯：题目写的是三天从零到流片，AI 带我设计一颗 attention 计算芯片。这个题目里面最重要的两个字是「带我」，都不是我用 AI，我觉得完全是 AI 带我飞。

张托肯：我之前在学校的时候也拿过清华大学优秀助教。这些问题在现代还需要浪费这么多优秀人才的时间和精力再来从零学起，我们不如有一些整理好的 knowledge 直接吸收走。我觉得比我写一个教程去教人，效率更高的就是直接教模型。

张托肯：从去年年底的时候，我就发现数字电路部分几乎没有一行代码是手写的，全部都是 agent 写的。我从 AI 的「加一」变成「加二」了，我会去派一些其他的 agent 去审查中间的过程。我相信以后所有人都可以升职。

（正片开始）

Cindy：欢迎大家收听此话当真，真格基金团队将在此和各领域的领军人物一起分享最新热点和行业洞察。真格，你的创业第一站。我是真格基金品牌团队的 Cindy。本期我们邀请到了真格基金与十字路口联合发起的项目 Token Grant 得主张托肯。Token Grant 为每位获奖者提供 5 万元人民币 Token 费用，从最早开始支持大家 build 下一代 AI 原生产品。欢迎托肯，请先跟大家介绍一下自己以及目前正在做的事情。

张托肯：好，谢谢 Cindy。我叫张托肯，托肯是 Token，它也是托举与肯定的意思。我自己是 2026 年从清华电子工程系博士毕业，现在正在瑞士的苏黎世联邦理工学院做博后，是在集成系统的实验室和人工智能中心。我拿 Token Grant 这个项目的项目名字叫做「芯片开卷计划」，这个名字是我第一次提出的，我非常喜欢。它是出于这样的一个认识：芯片行业通常给人一种高度封闭的印象，但我认为其实有很多部分是可以开放的，也应该开放的。因为一颗芯片它具有商业价值，或者说具有广泛的商业价值，可能需要 99 分以上，甚至 99.99 分以上；但培养芯片工程师非常的慢，行业长期缺少人才，相当多的人，特别是初学者入门者，他花了大量的时间精力在处理一些 0 到 60 分、0 到 80 分的东西。那这些部分我觉得都是一些教科书 level 或者研究生 level 的，这些部分应该被开卷，应该被通过 AI 的方法极大加速。大家就可以直接从 60 分，甚至 80 分，甚至在以后直接从 90 分开始，再做到具有生意价值，这样大家的整体技术水平可以更加的繁荣，把精力留给真正具有价值创造的部分。

Cindy：开卷这个词特别有意思，就看到不管是咱们公众号还是 B 站也更了很多具体真的在做的事情。比如说咱们最开始有哪些灵感来源的场景，或者说做了哪些比较有意思的尝试，可以跟大家分享一下吗？

张托肯：灵感来源就是做一系列的公众号讲 AI 故事。这一系列本质动机和触发点在于，我去年的时候就已经在尝试拿 agent 来帮我做芯片，也就是 2025 年的 11 月、12 月到 26 年的 1 月这三个月。当时就发现，哇，原来 agent 已经能帮我这么多了，但是我身边的很多人都完全不能够理解。在这样的巨大反差和认知差之下，我决定站出来，拿着大喇叭跟大家吼：大家可以用 agent 来帮助自己，大家可以开卷，已经到了可以开卷的时候了。

Cindy：当时大家表示不理解的时候，会有哪些具体的反馈吗？

张托肯：不理解的话主要就是几个问题。第一是幻觉，因为大家对大语言模型，特别是当时吧，停留在网页上 chatbot 的时代，当时 agent 可能还不是那么的火，大家无法理解一个对话的大语言模型怎么就能够调 EDA 工具了，怎么就能够去处理文件了，大家对此表示高度的怀疑和不信任，认为这个中间有巨大的幻觉和潜在错误的可能性。另外的质疑点就是模型本身能力不行，因为或多或少有很多人在网上跟各种大语言模型去聊过关于芯片的问题，但是在一些很早期的时候，模型给出的回答都是很差的；到了今年初以后，才开始逐渐步入正轨，到达可用的状态。

Cindy：那是怎么了解到整个 Token Grant 这个项目的？这个过程里面有没有哪些印象深刻的瞬间？

张托肯：这个契机其实是今年大概三月到五月份，当时我自媒体这个炸火之后，就有很多投资人联系我，希望出资让我创业。但其实当时有一个非常大的 concern：我在今年一月就已经答应了我现在瑞士的导师，毕业之后会来瑞士做博后，这也是我当时个人发展规划和时间节奏的重要一部分，我个人是非常看重已经做出的承诺的，所以说就没有把它割掉，回绝了这些投资人的邀请。那这个时候，真格的 Debi[?] 就给我提供了一种新的思路，一种不以立即创业为前提的 Token Grant，我就以这个契机申请了。最打动我的瞬间其实就是这个项目本身，它的愿景和诚意，就是不做任何的前置绑定而直接给予资助，我认为这是一种需要很大格局和魄力才能做出的决策，我非常欣赏这一点，这也非常触动我。

Cindy：明白。最近每几个月或者说每段时间的变化都很快，从咱们的这些视频和文章里面看到，这个工作的状态或是流程也是在有变化的。从咱们最早开始接触 AI 或者 agent 工作流到现在，对比更之前还在更传统的工作模式下，就咱们个体体感上觉得有什么变化吗？

张托肯：体感上的变化，我觉得就不断地在用「惊叹」和「震撼」两个字，不断地被 AI 的能力、被 AI 的进步所震撼。去年演出之前[?]，所有的操作基本都是手工的，手动点点点，不同的文件之间需要手动搬移来搬移去；但是后来在 agent 普及之后，这些工作都可以被更加智能化的方法给托管，负担从我的心智中卸下来了，这个是一个很大的变化。

## 一根 USB，让 Codex 从聊天窗口走进物理世界

Cindy：你觉得给你带来最惊叹的一个瞬间会是什么吗？

张托肯：最惊叹的一个瞬间可能是近期做的几个尝试。最近的话就是尝试拿 Codex 去接上真实的测试仪器，就是物理世界的硬件，就是在电脑之外的，拿一根 USB 插上，然后让 Codex 去读取那些端口，再去控制这些电压电流激励信号，再拿另外的仪器去测。发现我跟 Codex 说话，那边就能够出来像样[?]的波形。我觉得这个是之前人们很难想象的事情，在芯片设计领域也属于一个很难想象、刷新认知的事情。当时我就把这个过程录了下来，还发了几个文章，当时我起的名字叫做「听说你还在手拧 LDO？我用 AI 控制芯片测试的供电和参考源」。这件事情我认为是比较震撼的，因为真正的打通了从 chat window 到物理世界的 hardware。

Cindy：那像刚才这种更 specific、更专有的这些场景，当时想到做这些的目的会是什么吗？或者有哪些契机吗？

张托肯：契机很明确，就是因为我真的在用，来自于我的真实需求，因为我真的需要用这一套设备去测试我的芯片，所以说我就用 AI 来帮我做，这个事情是非常自然的。这个事情也是我认为 agent 所解放的一种 possibility：其实大家的末端需求都是高度碎片化的，有 agent 之前，可能有一个第三方来帮我们满足这种需求，然后再把满足需求的产品再卖给你，那它肯定很难去满足所有人的碎片化需求，它只能满足一些大面上的共识性的需求；但是除此之外，我们还有最后一公里，无数的最后一公里。那像现在，我们每个人都可以用 agent 帮我们自己完成最后一公里。

## Agent 能参与芯片设计的哪些环节：从 30% 到 80-90%

Cindy：你第一个 B 站视频其实也说，现在有 agent 可以帮你替代一个流程里 30% 的工作。这 30% 更多的是像这种末端更碎片化的这些需求吗？

张托肯：都有。30% 的话，当时我是这么划分的：在芯片设计流程中，它有数字芯片，有模拟芯片，然后我的博士方向主要是做数模混合芯片——一种以模拟为中心、但是也有很多数字电路辅助它的混合芯片，在其中模拟算是核心，数字算是辅助。但是数字跟模拟混在一起之后，中间是有大量的接口问题，很容易出错，所以需要大量的验证，所以又加一个验证部分，我是分成了这三大部分。在这三大部分中，agent 可以有不同的侵入程度：从去年年底的时候，我就发现数字电路部分几乎没有一行代码是手写的，全部都是 agent 写的，所以侵入程度非常高；在模拟设计的话，可能还显著的低很多，所以当时是只给了 10% 左右；在验证部分，我认为虽然说很多 debug 还是通过我自己读博多年积累的经验人工去判断的，但是还是有很多 labor work、trivial work、大规模认知劳动的 work、大规模数据处理的 work 是 agent 完成的，所以我认为它也做了可观的贡献。最后加权换算下来，我给了一个 30% 左右的比例，我认为是比较客观和公允的。

Cindy：那现在这个比例有变吗？

张托肯：我相信这个比例是可以提高的，当然了这个比例也随着芯片本身的特点而有变化。比如说对于纯数字的芯片，现在无疑可以达到 80% 到 90% 以上，对于所有人我相信都是可以的；但是对于模拟芯片，可能它会一个缓慢的过程，从 10% 到 20%、30% 左右，我觉得它可能在未来会饱和在 40% 到 50% 左右。那么对于整体的芯片系统，它肯定有数字部分，它也有模拟部分，最后 agent 到底能侵入多少，就取决于这个系统是怎么定义。

Cindy：刚才提到这一切开始的契机是今年自媒体上的一些文章爆火，那在做这个自媒体的过程中，你觉得最大的 learning 或者收获会是什么吗？

张托肯：最大的 learning 我觉得就是输出反补输入，也靠这些来让自己急速地成长，不断地去探索前沿，不断地去探索前人没太做过的事情，并且以一种更容易被受众所接受的方式表现出来、展示出来。

Cindy：你觉得像这个火的契机，是因为它真的打中了一个很强的需求，还是因为别的什么原因？

张托肯：我觉得这个有天时地利，也有人和吧。因为我们正在一个巨大的智能化改革的浪潮里面，我们非常有幸又遇到这么大的一个时代契机，这个就是时代整体的 beta。那在这样的一个大环境下，肯定对于 agent 在每个行业中有怎样的应用，大家是有一个起步的兴趣的。

Cindy：单说芯片在这个整个 AI 或者 agent 这个浪潮下，针对于这个领域，你觉得还有什么独有或者说不同的地方吗？

张托肯：应该说 AI for 芯片设计有一大部分是封闭世界的胜利，这个事情也是我跟 Fable 一起提出的一个名字。就是说数字芯片设计的工具链其实是非常完备、非常多样的，而且它是具有明确的边界条件，非常容易刻画，所以它在很多层面上都很像编程。很多人都问做芯片跟编程有多大的区别，那我的回答一直是：区别有，但没有想象的那么大。而且我们不能够拿 AI 做芯片做一个整体来做，因为设计芯片范畴实在是太大了，芯片设计的整体是非常复杂的，但是拆开之后并没有那么神秘，有至少几类任务是很容易能让 agent 介入的：包括大规模的信息提取和加工、各种代码脚本命令行任务，还有就是数值的建模分析计算。这些你拆开来看，它其实跟我们现在用于训练 agent 能力的这些 Terminal-Bench 高度相似的。对于这些任务，通用 AI 其实已经具有了足够的能力和泛化性，可以做出可观的贡献。

## 为什么数字芯片设计是 AI 落地的最佳场景之一

Cindy：那像你之前也提到，数字芯片设计是 AI 落地的最佳场景之一，这个是为什么？

张托肯：就是因为刚才说的，它容易验证，比其他很多领域更加容易 verify，技术层面它是可行的；还有一个是商业层面，就是它是具有高价值的，因为数字芯片的市场足够广阔，需求量也会很大，未来还会更大，会出现大量的定制需求。这里有两方面的原因：一方面对数字芯片产品的需求会越来越多，因为以后在不同的领域、在不同的地方都会有自己的定制芯片、定制 AI 芯片、定制推理芯片、定制这个通信转包芯片等等；同时国内的产能也会急速的上升，就之前我们国家的芯片产能一直受限，一直比较紧张的状态，但是在未来的两年、三年或者更久，它一定会得到解决。那当供给上升、价格下降、周转周期下降之后，就有更多的公司、更多的人有动力去做自己的芯片。那么这两边结合起来，自然会让 AI 辅助做数字芯片的需求急剧上升，很容易地转换成商业价值。

Cindy：那像在 AI 进行芯片设计的辅助过程中，整个过程它跟目前我们去调用 agent 做一些日常任务有什么区别吗？

张托肯：至少两点。第一点是用的工具不一样，很多模型在最开始的时候，比如说在去年的时候，他们说的进入[?]到生产力生活，是面向 Word、PPT、Excel 等这些常用的办公工具，还有那些常用的编程工具去做特化训练；那我们做芯片呢，基本上完全是另外的一套基础栈，虽然说接口很多时候它也是能用编程的方法来理解，但是训练过和用通用能力泛化出来的能力去应用，它还是有一定差距的，这就是工具链的区别。那更大的一个区别在这个验证上面：就是对于一些场景，这个准确率它其实要求不是非常的高，就是它大面上看得过去，就像现在我拿 AI 去写一些文章或者写一些 code，也是经常需要返工，那返工就返工吧，也可以接受；但是对于芯片的话，它对于验证的多样性、全面性、准确性要求非常多，因此需要更多的测试轮数、工具调用和工具交互的轮数。那在这样的情况下，对于模型的智能要求其实是更高的，如果说处于一个很笨的状态去交互几百轮甚至上千轮，那这个其实没有人能够承受。我们都希望它更像人类工程师一样，用很敏锐的观察和具有经验的思考来迅速的找到有效的信息。这个事情我认为对 agent、对所有的模型来说其实是一个很大的利好，因为我们对准确性、全面性、多样性的要求越高，其实 agent 的轮次不可避免的会很多，所以当这个技术更大规模的落地和推广之后，这个 token 的消耗量我觉得还能够大幅上升，我认为这中间有巨大的想象空间，它也有巨大的商业价值。其实这个过程也是需要包括模型更高的智能，以及很多经验的输入。

## 三天从零到流片：不是我用 AI，是 AI 带我飞

Cindy：所以这也是为什么那篇《三天从零到流片》这篇文章就觉得很有兴趣。就是你花了三天时间，可以用 AI 设计了一颗 attention 的计算芯片，能不能跟大家分享一下一开始的过程？

张托肯：这个其实也是一种机缘巧合。当时我们课题组恰好是要去做芯片，就是要做一个拼版[?]的、一个 MPW 的芯片，然后其中有一块面积恰好因为某种原因而空出来了，如果没有人用上这块面积，这块面积就会被浪费掉。这就是为什么我说这是一次临危受命：就是在最终 deadline 的前三天接到这么一个任务，在有 agent 之前是完全不可想象的，所有懂相关数字芯片设计的人都认为这个工作至少得做一个月或者一个半月以上。那在这样的情况下，我也是从零开始，现场让 agent、让 AI 帮我构思这个芯片的架构定义，帮我构思每一步应该怎么做，帮我去想。我把全过程也在公众号文章中做了记录，题目写的是《三天从零到流片，AI 带我设计一颗 attention 计算芯片》。这个题目里面最重要的两个字是「带我」，都不是我用 AI，我觉得完全是 AI 带我飞。因为我在之前对于 attention 在芯片上面的硬件实现其实理解并不是非常的多，每一个细节都是我跟 AI 不断的沟通，它教给我，我去想办法验证，验证好了之后再搬到芯片里面去实现，再一步一步地把它堆起来，堆成了一个可以送去流片的状态。我其实只提了一些比较模糊的方向，我真正感觉到了一种当领导的感觉，具体的任务都是 AI 实现完成的。

Cindy：感觉 AI 让大家都学会了怎么当好老板。这篇文章也是 5 月 2 号到 5 月 5 号，也是最高效的一个五一假期的度过的方式了。

张托肯：对对，是的是的是的。刚才这个三天被 AI 带了流片，其实也是我对于未来 AI for 芯片设计的一种期望，就是我心目中的未来 AI for 芯片设计可能也就长这样，当然比较更好。就是说类似的模式：我作为一个芯片设计师，不一定所有的我都懂，我可能懂一些大面上的，我懂一些方向，在 AI 的加持下，它能够帮我赋能，增大我的大脑，延长我的双手，让我的能力边界达到扩大，我觉得这样是我对于未来 AI for 芯片的一种预期和盼望。

Cindy：对，包括像那篇文章下面最高赞就说，这种程度在未来的使用会是常态。

张托肯：是的，是的，我相信。

Cindy：那比如说在你感受包括日常的这些工作流程里面，现在 AI 能完成什么？

张托肯：我觉得能完成非常多，包括刚才说的这种做一个 attention 芯片，其实类似的活我最近又做了非常多，虽然说没怎么发表，但是这个是完全可以的。特别是经常看到一些 SOTA 模型做得已经非常好了，他们已经能够非常熟练地运用一些三大家的 EDA 工具，然后很快地就做出来较为合理的芯片模块，并且过一些比较全面的验证，这个我认为还是在飞速进步中。这个是我认为现在 AI 能做的以及正在做的。

Cindy：就是在这个大背景下，其实很多人就问，什么时候 AI 能够 one button 做出一颗芯片？

张托肯：其实我非常不喜欢这个说法。像现在大家都知道 AI 编程能力很强，但以我的使用经验来看，我没有任何一个软件是 one button 做出来的，没有任何一个我满意的软件、网页或者小工具是一键做出来的，或者一句话 one prompt 做出来的，还是每一个都通过了大量人工的校正、参与，或者说是沟通协调。我认为这个事情跟人类社会是很一样的：就是在任何一个公司，你招过来一个能力非常强的员工，也很难说给他一句话，他哼哧哼哧干两个月，也不需要跟大家开会，就把所有事情干完了，因为这个是很困难的。所以我认为对于 AI 能做什么，这个我们需要不断地根据客观实际情况，以及我们对于一些类似事物的理解，来对它做一个预期的校正。

Cindy：是说 one button 不太实际这件事，其实更多还是在于它有缺失的 context，或者有很多隐性经验没有办法放进来吗？

张托肯：我觉得一是 context，二其实是人的需求都是不断在变的，特别是芯片，每个芯片在设计最开始的时候跟它最终做成的样子很可能差很多，因为很多设计的指标、很多内部的决策都是在一边做、一边开会一边改。

Cindy：你跟 AI 也一起协作很长时间了，你觉得在这个过程里面，你作为人的决策有发生什么变化吗？

张托肯：我觉得我升职了，我从 AI 的「加一」变成「加二」了。当时在用 Claude Sonnet 4.6 的时候，可能还需要微操一些细节；到了今年的时候，微操的细节越来越少，我跟它的交互越来越是 high level 的、大面上的、方向性的，或者说我就只需要看交付的结果，以及我会去派一些其他的 agent 去审查中间的过程等等。我觉得我升职了，我相信以后所有人都可以升职。

Cindy：那这会也意味着，加尔[?]——或者说能跟 agent 更好地传递好需求的人——得是他先有能力去进行这些更框架性的总结和给 agent 的指导？

张托肯：对，我认为这个能力很重要的，就像人也是需要所谓的领导力、组织力，公司越大这种能力越重要，也越困难，对 agent 肯定也是的。

Cindy：你今天消耗了多少 token？

张托肯：就我现在的话是中午，在大概 24 个小时，就上一次重置之后，大约消耗了 Claude Max 20 的 30% 左右，不管是 Fable 还是 Opus 5 都消耗了 30% 左右；然后这个 GPT 那边也是一个顶配的 GPT 20 Pro 20[?]，也消耗了这么多。今天的话可能还在做我最近在做的模拟电路画板，这个是消耗比较多的部分，在具体的优化用户体验。

## 用 Agent 重做模拟电路画板与开源工具反馈

Cindy：你能介绍一下这个模拟电路画板吗？因为看到这也是你最新的一个更新，视频的呈现效果真的特别好。

张托肯：谢谢。这个的话其实也是来自于我自己的痛点需求，因为我之前尝试在百分之百用编程的方法来做模拟电路，也去跟我的很多朋友去收集他们的 data 或者说任务，来一起做一个模拟电路的评测集。在这个过程中我就发现，让芯片设计师来直接用编程的方法来做模拟电路，其实对很多人是很痛苦的，那效率是不够高的。那有没有办法来把那个拓扑原理图再给画出来？然后我就尝试用一些既有的工具去画，但是这个时候就发现，过去的工具已经不能够满足我的心意需求。那这个情况下，我就调研了几乎市面上所有已存的工具，要么是不好用，要么是不好看——因为我知道自己对于审美还是有较高的要求。那在这个情况下，我就想干脆重新 vibe 一个算了，所以就重新 vibe 了一个。那这个既然要干，那目标就是要做世界上最好用的原理图画板。在这样的愿景下，我也招了几个朋友跟我一起干，干了半个月左右，在三天之前我去在线上做了宣传，到今天才刚刚三天或者两天半的时间里，在全球范围内已经获得了超过 7000 人的访问量和超过 2 万次的访问量。我认为这个还是在所有的画板里面非常好的一个效果，而且我相信现在只是它的第一阶段形态，在未来还会有更多的工作超出现在很多人的想象。

Cindy：它解决了很多你调研过的市面上工具没有的一些东西，包括你提到的审美，你觉得是怎么做到让这个项目可以实现你要求的审美的水平的呢？

张托肯：审美的话，这个就完全是一个艺术设计的范畴了。在用户体验上，我觉得用 agent 来开发跟传统开发最大的几个区别，是它的开发节奏要比之前快上百倍。在这样的一个前提之下，量变是引起质变的：也就是传统上我们做任何的代码改动都有非常长的流程，而且要瞻前顾后，考虑这个向后的兼容性等等，一考虑到这些就很容易堆积成历史的屎山版本。那如果说我们现在为了去考虑兼容性、为了兼容一些不好的 feature 而做出的妥协，它所付出的代价很大；那另一方面，我们直接干脆重写一遍的代价很小，那我们就更倾向于：我但凡发现有什么问题、不符合 best practice，那我就干脆重写，每个部分都在不断的重写，就是每个小模块都在不断重写。最近的话也发现有另外的引擎可能会有一些重构，那这个的话还没有尘埃落定，但是我觉得这种重构在现在无非就是多消耗一些 token，而你们又给了 token 的资助，所以我就更加敞开了让 Fable 重写。那在这样的情况下，我就可以一直保持在最佳状态，轻装上阵、轻装前行，那我肯定比过去的那种要好很多很多，所以这个是从第一性原理上来讲就会变好。

Cindy：敞开了之后，会感觉自己在这个项目的过程中也会少更多掣肘？

张托肯：对，是的，是的。我相信这也是 Token Grant 的一个初衷，然后 Token Grant 给我们的一些可能性。

Cindy：你在复盘的工作的时候有感受到，现在整个项目的节奏推进的更快了之后，原本被替代的这些时间会用来做什么新的事情吗？

张托肯：对于我个人来说，可能就是多个项目并行推进，就比如说这个画板是推进的一部分，但其实我自己还有别的，包括 benchmark 的建设，然后包括其他的科研工作，这都是多个并行在推进，有很多个 agent 在背后正在工作中。

Cindy：包括这个画板的项目在内，你也有很多开源的项目和尝试，你觉得在这些项目已经运行了这样一段时间之后，有什么印象深刻的反馈吗？

张托肯：这个反馈还是很多的，各种声音都有。印象最深刻的、也是反响比较热烈的，其实是一个桥接工具，就是让 agent 去接上这个商用的 EDA 软件——是一个但凡做模拟芯片设计就无法绕开的一个软件——我写了一套桥接的工具，让 agent 可以更好的去操作这个软件。那这个是我今年四月份开源的，至今就已经有大概四个多月的时间，可能也是迭代过超过大几百次，这个是收到了相当多的反馈。印象比较深刻的可以说是有两类：第一类是数字上的，从这个项目发布出去之后，我看到了很多数字，这些数字让我深刻的感受到了 agent 所解锁的可能性，以及 agent 所能够带来的代码平权、开发平权。包括在 GitHub 上面，阅读量就超过了 4 万次，然后下载量超过了 1.6 万次，然后 star 数量超过 680，fork 150。还有一个数字是比较重要的，就是明确用我这个项目再做二次开发的项目，这种项目就有超过十几个，在这种情况下，就说明是有较大的反馈了。另外一类反馈是从各种社交媒体上的四面八方的反馈，包括 B 站，包括小红书，或者是口口相传的等等。举两个例子吧：第一个例子是说，有一个 B 站的粉丝，他直接把我和这个开源项目写到了他的本科毕设论文的致谢里面，我觉得这是一种非常高的赞誉；第二个是有若干家公司的人跟我说，他们把我这个工具做了某些改版，然后直接放到了他们公司内网的环境里面，作为他们生产环境的一部分，这个也是一个非常高的认可。因为所有工程师的最高梦想都是自己做的产品、或者说自己做的技术能够被用上，尤其是能够被商用，这些都是令人印象非常深刻的反馈。

Cindy：那像刚才提到的有很多也是在进行这种二创或者二次开发的，他们都是有做了什么改动吗？

张托肯：有的让它计算效率更快，有的让它接上了 RAG、接上了知识库、接上了优化算法、接上了这个版图设计等等，各自根据自己的需求去加，就更加的展示出了 agent 所解锁的这种多样性和可能性，每个人都可以根据自己的需求去定制最后的一公里，至少得让自己用的顺手。

## Benchmark：不只比较谁更强，还要测出 AI 能替代哪些任务

Cindy：刚才聊了很多，包括大家都是怎么在解决这些最后一公里的事情。你也提到你还花了很多时间在做这种评测集，能跟大家分享一下，比如说当时是怎么想到去建立这些评测集，或者说建立这些 benchmark 的？

张托肯：我觉得这个跟最后一公里是互补的两个方面，这个真的属于地基。就是我们现代化的 AI Native 的应用，几乎它的能力引擎都是来自于基座大模型，我们如果说要提高在一切应用上的使用体验，那最直接的方案还是去提高基座模型的能力。那这个情况下，评测集就非常重要，因为它可以刻画基座模型在不同领域的能力。我认为 benchmark 它其实是两把尺子：第一把尺子叫做相对比较，我们可以通过 benchmark 来比较不同模型的能力差异，那现在其实大部分 benchmark 都是这个状态，包括什么 SWE-bench、Terminal-Bench，或者别的 Artificial Analysis 等等，基本上它给人的作用就是说比较一下这个模型比那个模型又强了一些、新出的模型又进了一步之类的，这个是一个相对比较。那我认为对于芯片设计领域，还有一把尺子非常的重要，叫做绝对能力的定标：现在大家都知道模型能做一些事情，但是到底能做哪些事情、能做到什么程度，很少有人能够量化出来，并且以一种更容易被大家接受的方法让更多人知道。那我就非常愿意告诉大家，现在模型的能力到了什么程度，哪些任务是现在的模型能解的，哪些任务是解不了的，哪些任务是被很多模型都能解出来的、以后就不应该人干了。那像有了 benchmark 之后，我们就能够对这些问题进行一个非常定量、相对客观的回答。那我更喜欢的一些描述就是说，它可以认为是一些考试，或者说就是它非常像教育学：我们说一个人他会做芯片，那这个「会做」有非常大的区别，你是本科生水平、硕士生水平、硕士毕业的校招生水平，还是说你这个刚入职一年的水平、三年工程师经验、五年经验、十年经验，这都是完全不一样的能力刻度。那现在 AI 到底发展到哪一步了，是几年级了，那这个事情其实没太有人具体的知道，每个人都说我能做得很好了，但是我觉得不是很客观，那我就希望做出来这样一个绝对的定标来告诉大家。

Cindy：有了这个定标，包括这些过程的测评下来，有得到什么结论吗？

张托肯：最直观的一个结论是，现在 AI 的能力其实已经超过了很多人的想象、很多人之前的理解，特别是芯片行业的很多人的理解。一个例子是这个 Razavi Bench，它是由 50 道模拟电路题目的问答测试。这个测试里面，在前年发布的模型，这个 GPT-4o 时代，它的表现是非常糟糕的，几乎就是完全不可用；今年 6 月之后的模型已经到了不亚于中上水平的研究生人类的水平了。那这里有一个非常陡峭的上升曲线，这些人们可能意识的比较少，那我就把这个给刻画出来，所以也是一种结论。还有一个呢，就是对于测评本身，尤其是 agentic 任务，就明确地发现了包括 test time scaling 非常有效，还发现这个模型本身的能力对于最终效果的影响是远大于 harness 的影响等等，所以说就是更加地凸显和强调了基座模型能力的重要性。具体的信息我还在准备写一些论文的过程中。

Cindy：怎么得到「模型能力本身是要大过 harness 的影响」呢？包括你怎么看最近大家对于 harness 的这个意义和讨论呢？

张托肯：这个的话我是做了一系列实验，比如说用同一个模型换五个不同的 harness，在同一个 50 道题上面去做三遍，然后做出来分数差不太多，那就说明没什么区别；然后换不同的模型，比如说你就换 GPT 5.6 的 Soul、Terra 和 Luna[?]，横坐标是时间，纵坐标是分数，那它就是泾渭分明。

Cindy：那像现在模型的更新速度同样也很快，怎么避免说刚才咱们定的这些标准、这些评测集不会过一两个月就过时了？

张托肯：是一个好问题。这其实也是一个具有两面性的：一方面我们看到它过时了，实际上过时的这些任务或者说题目，它反而可以更好的告诉整个行业的人，这些问题就是被大模型斩杀掉了，以后我们可以花更少的人力来做这些事情，可以想办法让 AI 接管——但是这也是个好事，模型斩杀的越多，对于芯片行业越是利好。那另一方面，在持续建设这个 benchmark 的过程中，我觉得我是有信心能够在较长的一段时间，可能两年到三年的时间里面，一直领先于模型的能力。因为我认为这个芯片设计的难度它可能是没有上限的，现在我去让 AI 能够做出一些分数，都是处于一个我们在故意放水的程度，我们在 baby sitting。那这个还有一个比喻，就是说我们从小读书到大，每个年级都有每个年级的考题，我作为一个研究生毕业或者博士毕业的老师，我可以出出来一年级的题目、二年级的题目，出六年级的题目、出中考的题目，我可以一直至少出到他本科或者说接近到硕士水平，所以我认为这个还有非常大的空间。如果说让很多基座模型都已经在我以及跟我一起合作的人出的题目已经完全难不倒他了，那我觉得这个 AI for 芯片设计这整个 topic 已经到了一个非常高的水平。

Cindy：baby sitting 这个词很有意思。你现在在给他出的这些题，或者就是你跟他设置的这些流程里面，目前有让你意外的部分吗？

张托肯：我觉得是有的，经常会感叹「这都能做出来」。比如说最近的一个版本的 benchmark 是这个 release 了 50 道题，但其实是测了可能至少 80 道题，就发现有一些题是几乎所有模型都做得出来，我就把它给砍掉了。我们让 AI 学习的效果最大的一部分，可能是那个模型之间有差异的部分，这样就让它一步一步地向前，然后我们一步一步地培养它，升级打怪。

Cindy：你会说它是一个好的学生吗？

张托肯：我觉得是的。

Cindy：模型做到什么程度，你才会说它具备了芯片设计的能力呢？

张托肯：我觉得它做到什么程度其实都有一部分能力，就像一个学生一样，实习生有实习生的搞法，十年经验的工程师有十年经验工程师的用法。所以理论上在一个公司里面，每一个大型的芯片项目可能都是几十上百个人，那么在这样的团队里面什么水平的人都有，能对他的能力有客观清醒的认识，然后把它合理的用起来，我觉得就够了。

## 训模型就是教书育人：「会用 Agent」与数据基建缺口

Cindy：那你是现在怎么理解训模型这件事呢？

张托肯：我觉得就是教书育人。包括我之前在学校的时候也拿过清华大学优秀助教，我是教过很多课，然后在网上也写过很多教程去教过很多小白。当时我写过的一个教程是叫做《混合信号电路设计师的入门之旅》，然后做了一个非常经典的芯片小模块。我当时写那一系列的课程的原动力就是，太多人问我一些非常小白的问题，我觉得非常的痛苦。当时可能 2024 年开始写的，我觉得这些问题在这个现代还需要浪费这么多优秀人才的时间和精力再来从零学起，那我们不如有一些整理好的 knowledge，让大家以最快的方案、最容易吸收消化的方案直接吸收走，就不再需要走这些重复的坑了。所以我就不断的去做这种教育也好，或者说是宣传也好。那现在对于 AI 时代，我觉得比我写一个教程去教人、一个人一个人的让他去看课程，效率更高的就是直接教模型。那我教了模型之后，所有人他需要用到的时候就从模型中直接获得，不需要用到的时候那就把时间精力省下来干别的事情，那对于整个人类的知识水平和整体的效率肯定是更高的，这也是我比较相信的一个愿景。

Cindy：这个很有意思，感觉不管是每个领域其实都是在做某种程度上去总结这些经验然后传达的事。就像那个机器人的 RoboMaster，其实就是每一代的学长留下来一些东西给下一代。不管是在芯片还是在很多这种应用的行业，很多价值反而就是在这些 tacit knowledge，或者说这些很难被写下来的经验里面。作为一个助教，包括在作为 AI 的老板这个过程中，你觉得怎么更好地把这些经验传递给他呢？

张托肯：经验传递给他，其实现在我非常认同的就是正经的模型训练的方案，就是数据。其实现在所有的模型核心评价就是数据，那我认为这个事情也是正常的，就像我们所有的人，他可能有预训练阶段——这个义务教育到高考；预训练之后他有各种后训练——就上本科了，上本科了他就开始去进入各个专业、各个学院去学每个方向的内容，每个方向呢再往后到研究生 level 的一些项目或者说这个 research，那他有更细的经验。那每往前走一步都会面临缺少数据、缺少信息。那人的这些数据和信息都是通过学长、学姐、导师，然后学校的各种内容，或者说实习而获得的。我举一个非常好的比喻，就是说一个学生从零开始一直到他有所事业的成就，最大的变量就是他做过哪些项目，那项目本身好不好——他做过很多好的项目、获得了好的引导，他就可以变得成功。那很多不同学校之间的差异，很多时候我们仔细去看，也是这些项目制，他这些项目落到每个学生身上，他的培养效果到底差多少。放在实习也是，我们不同的人去了不同公司实习，那为什么后面他们能力的成长不同，那就是他们去实习拿到的项目到底好不好。所以这个项目、这个任务本身非常重要，这个环境非常重要，这些内容我认为可以非常好的迁移到训模型角度，那我们其实也是通过类似的项目、实习来教模型，也就是大家所说的后训练。

Cindy：说到这个比喻也很有意思。那像回到比如说你在这一两年跟 AI 很密集的协作，包括这些项目的完成的过程中，你觉得 AI 时代最容易被低估的一种能力会是什么吗？

张托肯：我觉得这个挺反直觉的，我觉得最容易被低估的能力是用 agent 的能力。因为很多人处于一种被动的状态，他们可能会期待这个 agent 或者说 AI 的发展，自己就能够按照自己既有的方案去 one button 的调用，或者说就 AI 说什么就是什么之类的，现在很多人会有一点变成 AI 中转站的感觉，这是不对的。我认为不管 agent、不管 AI 怎么发展，人作为 agent 驾驶员，这个能力还是非常重要，甚至说越来越重要的。就像汽车出现之后，层出不穷的新车，那其实也都需要司机有足够的驾驶水平、驾驶技术；飞机出现了，也需要飞行员的驾驶技术。我觉得现在非常重要，我是高度的 appreciate、高度欣赏这种优秀的 vibe coder，我一直都在不断地寻找优秀的 vibe coder 作为我的合作者，一起去做我的各种项目。

Cindy：擅长驾驭 agent，或者是擅长会用这些 agent 的人，你观察到他们具备哪些特质吗？

张托肯：最大的几个特质，第一个是熟悉车性，就像每个老司机都是熟悉车性，知道这个车在怎样的情况下是有异常的，怎样的情况下是可以高速跑的；熟悉车性之后能够开得快，又能够刹得住，最终还能够有效地把人或者货物送到目的地。

Cindy：拿一个三到五年的时间下来看的话，大家是会减少需要驾驶 agent 的时间吗？或者说驾驶 agent 这个过程会一直存在吗？

张托肯：肯定会减少的，你看之前大家都是手动挡、自动挡到自动驾驶，现在很多人买一些自动驾驶程度比较高的车，你可能 90% 都是车自己在开，这个事情是必然发生的。

Cindy：那像在这个很快的改变的过程中，你感受到最大的变化会是什么吗？

张托肯：我感受到的就是认知在不断地刷新，太快了，对我来说年度汉字就是「快」。怎么说这个快？就是我们的很多判断要不断地与时俱进，比如说 AI 不能做什么、AI 能做什么了，这几个事情是需要不断刷新的，我觉得能力边界在不断地前移，然后我在不断地尝试用到这些能力边界的部分，这个是一个非常大的感受，这个遍地都是机会。

Cindy：那我觉得现在其实能够再碰上一个如此大的浪潮，也是一代人的幸运。现在你感觉 AI 还不能做什么？

张托肯：那可多了。最主要的，我觉得它还不能够完全担负起一个员工级别的责任。

Cindy：在你的这个定标里面，真的可能有几年经验的一个工程师、这样真正懂芯片的一个 agent，你觉得他最重要的一点会是什么？

张托肯：如果说要到具有一到三年经验的话，我觉得最重要的还是数据和基建，这个还是万变不离其宗，这个重剑无锋[?]。

Cindy：刚才你提到有了更多的 token 其实可以少掉很多掣肘和限制，那假如有一天有了无限的 token 的话，你觉得你会做什么？

张托肯：我希望大规模合成有效数据，以及做更好的基建，为训练模型，或者说为整个 AI for 芯片添一把燃料，更大的扩大规模。

Cindy：那你会预想一年之后这个目标会有什么进展？

张托肯：我觉得一年之后，这个数据获取和合成的效率肯定会比现在高很多很多倍，这个事情是我非常愿意做的。

Cindy：你觉得过程中你会有什么变化吗？你会期待自己的一年后会是什么样吗？

张托肯：我觉得一年之后可以通过一些方法来证明自己真正的推动了 AI 在芯片设计领域的能力提升，我觉得能有办法来证明 difference 就非常好，这也是需要一定时间的。另一方面我希望继续去做宣传和布道工作，让更多的行业同仁——不管是工程师、学生，不管是实验室还是公司——都更充分更多的认识到 agent 在芯片设计中的能力，并且真正的用起来。以上两点吧，一年之内既为 AI for 芯片的能力建设做出贡献，也为行业扩散做出贡献。

Cindy：那刚才像提到其实行业扩散，或者说走向这些在公司内部或者说这些商用，其实还是蛮重要的一步。那现在的这些进展里面有得到哪些反馈吗？比如说就是往这一步走的时候，会需要先克服什么吗？

张托肯：我觉得现在还没有克服的，其实还是基座模型的能力。芯片厂商跟其他公司一个很显著很显著的区别是对于信息安全的重视程度，这也是为什么我一直在说合成数据非常重要，因为以目前的各种沟通和广泛的交流下来，几乎是完全不可能从真实的芯片厂商那边获取大量真实数据的，所以可能只能想办法来合成数据。那在这个大背景和基础认知之下，大家对于云模型的接受程度是非常低的，如果要用到各个芯片厂里面，大家最愿意的还是本地模型；而现在的本地模型，或者说能够担负得起的本地模型，距离能有大规模的效果我认为还是有一点距离的，所以还需要一些发展的时间，还是需要等待模型的一些进展。

张托肯：希望大家把 Token 变成行动，做一点前人没有见过的东西出来。
