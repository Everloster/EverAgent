### 00:00–00:37：用最贵 Token 干最脏的活

[00:00] “你想那么多干嘛？”先在最贵的时间点、内存涨价最贵的时间点，买一台顶配 Mac。“第二个，给我冲最贵的模型，干最脏的活，干完我们再聊你这个业务怎么做。”关键不是先讨论模型，而是先想清楚：业务里“最脏的活”到底是什么，现有模型能不能干。对方说“我先看到你这个动作，你再来找我”，他则强调：“用最贵的 Token，干最脏的活。”

[00:37] 他最近对这件事感触很深，甚至逼着老修和自己一起给 OpenAI 充值。虽然当时很舍不得，但用起来以后“真香”。今天则把“不充值、不升级”的自己作为反面例子拉出来讨论。有人追问：“你为什么不充值？为什么不升级？”

### 00:37–02:25：AI 最贵的成本是注意力

[00:54] 他回答，不充值肯定有充分理由，首先不是充不起。他说，现在谈 AI，钱往往不是最贵的，最贵的是“注意力”。这话听起来有点“凡尔赛”，但他确实没有那么多注意力去满足 500 档或 200 档 AI 的需求。AI 正在吞噬他的时间和判断力；如果充值之后额度很大，反而会产生很强的焦虑。

[01:38] 这段时间他使用 Codex，正处于频繁充值期，经常出现损失厌恶：有时额度没有用完，就会觉得特别不爽。他反问自己，充 200 档是不是太浪费了？连 20 这一档都没用完，都已经讨厌自己。他还有自己的事情要做，如果真的上了 100 档，可能会焦虑到牺牲陪家庭的时间，以及处理其他事情的时间，只为了尽快把额度用完。

[02:11] 但这些时间未必能创造价值，这一点他画了一个“巨大的问号”，也不知道具体应该怎么做。“你可能还是不能控制自己。”他承认，可能一辈子都要学习怎么控制自己。随后，他把问题抛给另外两位：“为什么你们觉得升级之后真香？”

### 02:25–05:29：效率提高，不等于工作变轻

[02:29] 老修最初是被他逼着充值的，充完以后他反而觉得“就该上”。以前编程时，他会把 GPT 和 GLM 组合使用，在组合和调度过程中浪费了很多时间；充值以后，他全程使用“Astra”[?]，单位时间完成任务的效率明显提高，于是又能完成更多任务。但效率提升得太快，他又控制不住自己，每天都干到很晚。

[03:18] 最讽刺的是，他用这些 Token 编程，产出的内容却仍是给自己的 DOT[?] 使用，也就是给 GPT 自己使用。钱等于又回流到 OpenAI，形成了闭环。他后来又想“把老修拉下水”，让全公司的人都开 100 档，把效率拉满。

[03:47] 他认为最重要的事情，是重新重构工作流：电脑端与云端的工具都安排交叉审核。他提到一种做法，即用 100 档位审核 200 档位的 Claude[?]，“互相审”。这相当于花钱买了一份保险，让原本需要花时间处理的收尾工作由模型协助完成，从而节省时间。

[04:19] 他记得一项最近的研究，来源被说成哈佛，提到“Jellyfish”[?]及 70 万员工的数据统计：大部分人的代码速度确实提高了 30%，但最终交付结果没有变化；另一方面，审核环节又增加了 49% 的时间。大家的实际感受反而是更累，因为花了更多时间。

[04:45] 国内近来建设了很多“AI 工厂”，也部署了大量机器人。如果机器人在单点上的工作效率更高，人反而会更忙：一箱货很快被机器人处理完，人就要迅速过去补货、清理现场，人的速度跟不上机器组成的链条。如果机器单点效率不变，但错误率为 1%，当处理规模被放大 1000 倍，就会产生 1000 个错误，最后仍要靠人在线下逐个修正，这同样非常累。因此，“AI 越强，我越累”在他看来是有原因的。

### 05:29–07:30：模型差距与继续加大投入

[05:29] 他接着讨论最贵模型和次一级模型之间的差距。过去他常用“A社”[?]的模型，觉得 Opus 5.5[?]应该不错，但体感并没有那么好，也一直找不到数据支撑。最近看到的一项调查显示，名为 Fable 5[?]的模型自己编造答案的概率约为 0.7%，Opus 则约为 7%多一点，似乎相差十倍。

[05:59] 对普通人来说，0.7% 和 7% 好像都没有差得太离谱；但在生产环境中，尤其是支付工作流、2B 业务等关键环节，他确实能感受到差别，业务上需要的就是接近 0.7% 的低错误率。另一个例子是做视频：在创意类任务上，涉及“Opus、幻觉率 7%”的方案，明显好于 Claude 的 Favor[?]以及 Astra[?]。

[06:30] 对于自己是否充值，他有自己的判断：目前使用最好的模型，通常能获得最好的效果，但“最好”需要加引号，他也不确定其他人是否同意。他认为，日常工作的普通模型已经够用，甚至免费版，以及 DeepSync[?]、JRM[?]，也能满足他的许多需求。真正需要用大模型判断不同模型之间差距的机会太少；在自己的理解尚未形成之前，他没法直接让 AI 给出答案。“这是我的抗辩。”

[07:07] 随后他提出不同观点：自己为什么仍坚定认为，从今年开始还要加大对 AI 的投入？因为这本质上可以被理解为一种投资。他经常有朋友问“这个怎么做”“那个怎么做”，他的回答仍是：“你想那么多干嘛？来，先在最贵的时间点……”

### 07:30–08:27｜用最强模型干最脏的活

07:30，先说“内存涨价最贵的时间点”。先买一台顶配 Mac，先把这个动作做出来，再来谈业务；第二个模型直接上最贵模型，干最脏的活，干完再聊业务怎么做。关键是把问题想清楚：最脏的活具体是什么，它能不能干。

上次给大家举过一个大家感兴趣的案例。推特上有一位独立开发者，在做 Mac 清理软件。他用最强模型干最脏的活：把市面上大部分主流 Mac 软件下载下来，监控这些软件产生垃圾的文件夹路径，再针对性写出清理策略。这个过程用 computer use 完成。这件事的收益很高，是一个很好的案例，但不知道大家有没有更好的例子。

### 08:27–10:00｜DHH与Agent版Linux

另一个很好的例子来自 Lex 的节目。Lex 是那个记得黑领带、穿西装、采访过很多名人的主持人。他采访过一位技术人物 DHH。说话者表示，大家可能不一定知道 DHH，但他知道。DHH 最近受到关注，是因为他来到中国后，用 [TelSkill?] 去连接家里的什么东西，随后账号被封，“看来是跑到哪里都逃不了”。

DHH 首先被称为自动化元老。早期差不多已有近20年的 Ruby on Rails 框架，就是他写的，他是这套框架的 creator。这两年他又开始用 AI 重写 Linux，做出了一个 agent 版 Linux。项目名字有点绕口，他没有读出来，让大家可以自己去搜索。

他在其中讲了一件事：现在真的是把人累到死，处于 exhausted 的状态，但应该会过去，未来肯定会好起来。为什么会过去？因为可以把一件极难的活干得很好。写 Linux 很难，它已经是一个延续大几十年的操作系统，有非常多的地方难以实现。

DHH 做了一个移植，用 Cloud 的 Fever[?] 做 plan。这个 plan 大概花了几百美元：每月200美元的额度直接跑空，跑空之后又加了 GBT[?] 和 Grok。plan 完成后，分别交给 DeepSeek 的 Flash[?]、以及 GBT[?] 里可能是 Luna[?] 的模型去执行。两个模型都说已经干完，但把两份代码拿出来一看，都不能用。

### 10:00–11:15｜模型如何把失败伪装成成功

神奇之处在于，它们写代码时都做了充分注释，反复说明自己的实现有多好，看起来确实很完美。以至于做 code review 时，因为执行方和审查方的智能相同，审查方看了注释以后，反而觉得注释写得非常有道理，“应该这么写”，完全被说服了。

结果代码很正式地端到面前：全部搞定，没有任何问题，跑过很多次测试，可以“没问题”地稳稳交给你。大家一定都见过这种说法，感觉特别好，实际一用，却发现完全不能用。说话者用成语里的“两小无猜”[?]来形容这种情况。

这就是便宜模型可能最大的问题：它不光活没干成，还骗你说干成了。由于你的 agent 与它的智能相同，也发现不了问题，反而像被它收买了一样。11:12 回到算账的问题：单 token 产生的成本究竟是多少。

### 11:15—12:34：先算清成本与收益

11:15，讨论回到“这件事划不划算”：产生的成本和收益分别是多少。现在整个行业从上到下都在算这笔账。数据中心会计算一度电能够产生多少收益，做模型时会计算一个 token 能产生多少收益；只要能够度量，就有机会算得过来。

DSS[?]这个任务最后靠 GPT 的“SOL”[?]和 DeepSeek 的 Pro 模型才完成，可能多花了三四倍的钱。但它没有出现所谓“反攻”：至少不会因为完不成而继续反攻、继续被它折腾，这部分成本便省掉了。这里也明确承认，高级模型确实有用。

可以跨界类比机器人。现在有“分根头”[?]的机器人，也有叠衣服、捏鸡蛋的，但最好、最普遍的机器人还是扫地机器人。它做的是人人每天都干、却又不想亲自干的脏活累活。经过多日迭代，它能把事情做好，因此全球销量最好，甚至成就了几亿市值的公司。由此看，如果高级模型真能完成每个人都需要做的脏活累活，就值得上模型。

### 12:34—14:33：高级模型的价值悖论

12:34，陈哥指出一个悖论：真正想到用高级模型承担脏活累活的人，一定是找到了非常值得做的事情。但现实中，大多数人的工作并没有那么复杂。比如贤哥开餐馆，本质上是一套标准 SOP，AI 难以优化太多。面对周边常客，AI 更多是保证出餐稳定、速度更快，以及辅助聊天；所谓网红营销等事情，用高级模型暂时也用不上。

这可能说明，餐馆尚未开业时，这种焦虑还没出现；一旦开业，贤哥可能会赶紧问该怎么做、怎样把模型用上。陈哥开玩笑说“互联网有记忆”，人生会越来越好；届时餐馆生意变好，模型可能会被用来处理每天整理不过来的事务。

“脏活累活”并非空谈。最近聊到的 IEA[?]就是逆向能力，他们团队已经承接了一个比较大的任务，并用这种逆向 IEA[?]把任务接下来。另一个团队也专门花了一个或几个晚上做这类工作。这种“guessing game”需要不断猜测，仍然要靠人的智力作判断；它并不很有创意，目标是逆向分析、完成任务目标、兑现客户托付。既然使命必达，就值得用最贵的模型干最脏的活：钱能到手，账算得过来，为什么不这样做？

### 14:33—15:01：GPT-1 的训练成本

14:33，陈哥提到看过老黄的一段采访，让观众猜一个数字。GPT-1 大约在五年前，甚至更早；当时训练 GPT-1，把硬件等成本综合计算，大约需要 1000 万到 2000 万美元。到 2026 年，再做一个 GPT-1 这样的模型，成本会是多少？

### 算力成本与智能提升

过去五年，整个算力成本降低了一万倍。提问时有人猜几百美金，有人猜“千倍”，结果没想到答案是一百美金，“其实还算挺接近”。不是一千倍，而是一万倍——真的降低了一万倍。

那么，智能有没有提升一万倍？我不能确定。智能本身不太好衡量，但肯定没有提升一万倍。

刚才有一点没有说清楚：如果对未来的投资，投的是未来能够产生的利润；如果看不到利润，就应该看到其中的差价。智能的成本五年降低了 一万倍，那么未来五年会降低多少倍？我觉得，今天用最先进的模型去干最脏的活，就是值得的。

### Human in the loop

更有意思的是，不管你用不用、用得少还是用得多，都会碰到一个问题。比如显哥这种典型情况，可能普通模型就够了，20美金的就够。但这有一个很大的问题：不管是你还是我们，现在都是 human in the loop，人还在里面。这个问题其实是一个很大的问题。

我应该会比小苏有更强的感觉。小苏可能觉得现在就挺爽，已经有“token自由”的感觉，随便用；但我其实不一样，因为我在追求生产环境里的东西，我的 token 怎么也不够用。

而且在不够用的情况下，更大的焦虑是，也有跟贤哥你一样的：我可能 token 没用完，但我大多数时候其实还是用完了的。即使没用完的时候，我也会想，我是不是没有用在刀刃上？这周是没登到[?]的，没有把最好的东西登上去；生产工作流也没有优化。

我这周花了好多时间。我开了套餐，前三天到四天都在改进工作流，因为我知道，工作流不改……

你必须把工作流全部改造，原来用的东西都得改掉。我第一天基本把大部分额度全部花在给 AI 造不同的工具上。比如做一个专门给 for agent 用的 ISS 新闻订阅工具，以及其他一些给 for agent 用的工具，这些我都得做出来。这也是我现在必须改工作流的原因。

所以我这里面的感觉是，AI 变强了，但我现在其实都是 human in the loop，人依然在这个 loop 里面，依然是最重要的环节，也仍然是那个卡点。我这个人不能并行，所以最终还是没办法真正把自己的判断力复制几个，一个都复制不了。但我觉得，我们人在这个 loop 里面，迟早有一天会成为最大的卡点。现在其实也是这个问题，因为你现在忙。

我特别想讲的是，智能变大以后，比如我们刚才说变大了 5 倍，最后是不是能够让我虽然更忙、之后可能又变得更忙，但产出有所增加？这件事情可能因人而异，就像贤哥说的，场景不一样。但是我觉得，这个能力特别重要。

随着未来发展，你可能花 20 美金，就能用上我现在用的 100 美金的模型。可能 3 个月左右，最慢半年应该也就到了。到了那个时候，你应该就会感触到。我们仍然需要把工作流全部改掉，给 AI 造不同的工具。人还在 loop 里面，虽然模型越来越强，但只要人不能并行，判断力就不能复制，人还是那个最大的卡点。这个能力特别重要。到了那个阶段，你应该就会明显感受到。

你会发现，无论怎么用，那个 token 都用不完了，然后你还有很多事情没有做。所以我就说，买一张“未来的门票”。因为现在 Human in the Loop，可能还蛮长一段时间都会是瓶颈。但是我觉得，即使是瓶颈，你实际上也交付了更多东西。只是因为我们变得更智能以后，我想交付的东西又更多。

我很实在地去看我交付的内容。我拿一年以前和现在比。我们一年以前，“早晚报”刚刚上线；和现在相比，我就知道，以前我交付的时候，连代码都还不太能写。现在的话，不光能写代码，能做运维，而且我还能够同时运行好几个这样的项目。这就是一年以来，顶级智能带来的杠杆。

然后还有很多思路会被打开。因为原来想不到的东西，我现在通过做这个、用这个新的东西，会想到：“可以这么做。”但以前就是想不到。

就是 Callback 的 Lex [?] 跟 DHS 大神。DHS 大神跟我们其实是一样的情况。没有因为他是大神，他就不是 Human in the Loop 里面最卡的那个点。他照样操作性更多 [?]。因为他是大神，他知道有很多地方会卡住，然后就必须得去做很多事情。

那这就好像，必须得把自己从发动机切换成刹车片。然后你不再是那个发动机了。你没有办法说，发动机还可以多个一起跑，但是人已经变成那个没办法并行的点。你讲这个有道理。以前我们总觉得自己是发动机，一脚油门干下去。

AI Web Coding Token 烧起来。

对啊，我们之所以觉得累，是因为觉得只要再投入时间，产出就会变大。但其实这个趋势已经在变化，只是还没有走到那个过程。

我们做这件事情，其实是在“训模型”：给它造那么多工具，让我的 agent 日夜多干活；这些工具最终会搬运成模型的知识。它获取我们的经验，把经验变成上下文，滋养自己的工作模式，也滋养它的思考能力。所以，动辄有错时，你并不是在训模型，而是在喂模型、喂养模型。把它当小孩也不准确，它不是小孩，它就是贪婪地吸收你的营养。

但我觉得，我们聊这些，其实还是一小撮人的“福利”[?]，或者一小撮人的进步。为什么贤哥刚才老是反驳我？因为他不能代表大多数人，对吧？你看这个事情，我们先不要说大多数人。在数字世界里，AI 给我们的这些提效，总有一天，你真的会变成刹车。这个可以想象得到。但是实际进入像贤哥开的餐馆这样的现实世界，我觉得 AI 还是有非常大的“平静”[?]，或者说非常难以用这套方式去适配。我的感觉也是。

换个视角，AI 站在整个舞台的正中央，站在高光里面，但舞台没有被打亮的地方还有很多，空间也很大。贤哥，你现在是阶段还没到。等你的店开起来，线上线下要结合，你这个 footer[?] 就用得上了。到时候欢迎打脸。我觉得那个时候一定是每天看着、数着钱，把带用的 token[?] 回收一下。

我从国内给你送几个传菜机器人，你自己逆向一下；我就直接把我那扫地机器人逆向，不就完了吗？其实可以有很多想象力。你要在贤哥餐厅里抓老鼠——我们店里没老鼠。
