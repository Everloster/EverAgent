## 开场：榜单 99 分，用户没感觉

Yiwen：之前我们聊过大模型的训练数据和榜单——每次新模型发布，各种榜单成绩都在刷新，但这种进步对我们用户来说，很多时候并没有变成工作中的进步。以电商为例：从一个产品创意到把它做出来卖到全世界，中间要研究市场、找工厂、比较报价、安排物流，还要在不同平台上开店发布商品，最后算清楚这笔生意到底赚不赚钱——这些工作 AI 现在能接手多少，又会在哪一步卡住呢？半年前我们请到阿里国际站总裁张阔聊了他们刚发布的 Accio Work；半年过去，Agent 产品不断更新，我们再次请到他。张阔分享了一个观察：**很多模型的通用评测成绩已经接近满分，但团队在真实经营中并没有感受到同样幅度的提升**。于是他们从实际业务中整理了 107 个任务，测试 AI 在无人干预的情况下能不能把工作做完。

## 一、AI 同事市场：coding 渗透 99%，商务 Agent 刚开始

张阔：Agent 最开始解决的第一个问题是 coding，这个市场的渗透率我估计 99%——身边很难找到一个不用 AI 写代码的研发，绝大多数代码应该都是 AI 产生的。第二个垂直赛道的渗透远小于这个数字。Cowork 类产品目前能交付的内容还比较有限：文案、计算类工作；但对于商业尤其电商这种需要更复杂判断、更长程任务、结果不是当下可验证的场景，整个 agent 还是一个刚刚开始的状态。

**为什么 coding 容易**：一是 coding 百分之百数字化，所有 code 在 GitHub/code base 里容易被 AI 广泛学习；二是结果天然可验证——能不能编译、结果对不对。商业场景就复杂得多：数据多元、没有通用流程、不同企业对经营结果好坏的判断有差异性、验证不是以单次计而是以天/周/月/年计，反馈闭环周期很长。

**Accio Work 的三段演进**：一年前核心是 AI 搜索（alibaba.com 的 AI mode）——现在整体搜索涨 20%，**多模态搜索涨 130%**，越来越多用户用自己的方式表达需求。第二阶段 sourcing 向前后延展：从 query 向前做市场调研、产品 Design Pack 设计，向后把设计交给供应商推进沟通直到完成交易（Agentic Trade）。第三阶段是今年 4 月推出 Accio Work：基于 alibaba.com 和 1688（全球最大供应链平台），帮用户管理所有电商后台——一站式理解多平台经营情况、管理供应链、管理员工日常经营表现。

## 二、商家案例：从"花养死了"的 idea 到全球生意

Edward 的例子（CoCreate 大会讲的）：他喜欢种植物但经常把花养死，就想做一个产品让植物告诉他现在什么状态。从 idea 到做出消费级电子产品，光 Design Pack 就能拦住很多创业者——用什么检测设备、读取设备、怎么把成本压到最低。Accio Work：①帮你做 Design Pack 设计（供应商反馈"没见过这么专业的 Design Pack"——一般买家纸上画一画就要花很多精力交流，拿到手发现跟想的不一样，大量 dispute 的 back and forth）；②找到广州深圳做电子产品最厉害的厂商制造；③解决跨境问题：订船期、HS code 过海关、当地物流；④多平台销售：Amazon/eBay/Shopify/TikTok 管理多个店铺、符合不同平台规则的 social 内容、不同 pricing 计划、买家 feedback 迭代产品——完整周期在一个 agent 里跨端管理一本生意。

**找工厂对比**：没有 agent 时，从 query 关键词开始，管理一个 20 列的 Excel——十几个供应商的生产制造能力、资质、工厂水平、拿货价格、账期、物流方案——选出两三个厂家，back and forth 以月计，最后拿到样品。有 agent 周期缩短到**一天**计：帮你把 idea 分解成可制造的产品和所需能力，基于平台商家详情和企业知识库匹配最合适的商家，在授权下跟若干商家沟通推进拿报表——**花一个月维护的 Excel，现在 24 小时内达成结果**（含到手价和零售 margin 的计算）。

## 三、中美 Agent 生态：SaaS 与平台的路径差

办公角度中美差异相对小，但与两地企业延续性有关：美国 SaaS 是大生意且垂直化（CRM/广告/法律/医疗各有成熟 SaaS 体系）；中国是平台侧集成大量垂直功能，AI 进来时有惯性差异。**AI 会替代 SaaS 吗**：如果 SaaS 做的内容比较简单，确实会被削弱；但 SaaS 跟工作流集成紧密，对企业的上下文理解（现在流行叫 Ontology）——就算请个大学生来，也搞不清企业各数据意味着什么、经营目标是什么。交易成交了不代表好——是为了 margin 还是市场份额？budget 用法、库存、广告打法都不一样。这些没法扔一个通用 AI 进企业就完成；SaaS 自己也可以用 AI 升级。现在是两边互相集成。每个时代有这个时代的公司（Harvey、Open Evidence 这类 AI native 产品做得好）——技术转折节点总有新公司冒出来。

**独立站 vs 平台**：中国企业第一想法不是做独立站；美国 Shopify/独立站还是大生意——Amazon FBA 你接触不到客户，想要自有品牌和客户关系就选 Shopify；国内淘宝天猫是中间态。最终交付的价值项一样，形态不同。**Accio 第一天就是 global 的**：AI 天生没有语言问题，交互门槛大幅降低（LUI：把工作描述清楚就能交付）；但 harness 和 context 分区域有差别（美国接的工具平台与中国不同）。以前国内 1688、跨境 alibaba.com 是两个平台做了 20 几年；Accio 从第一天起就是全球产品——**这可能是 AI agent 时代新的产品设计范式**。

## 四、Agent 公式：Model × Harness × Context

agent = model × harness × context，是乘法——**任何一项是 0，整个结果就是 0**。

- **Harness（工程框架）**：连接不同 tools、管理 memory、用户授权……保证系统持续运行。做电商天生是长程任务，连续几个月不停执行经营，harness 上要花非常多的精力。
- **Context**：Accio 天生有优势——20 多年跨境电商/Sourcing 积累的沟通信息、行业属性、平台趋势，还有你与供应商的交流本身也是 context。
- **Model**：现在花很多时间——**model 跟 harness 要一起优化**，不是只优化一个另一个用通用 frontier 模型就行。不是简单做 FT，而是基于一定尺寸的模型做后训练，在 model/serving/harness 三者上精细打磨，才能拿到最好的效果：最低成本达到一样结果、cache 率、准确率新水准。

## 五、107 个真实任务：最前沿模型无人干预通过率 61%

为什么要自己做 bench：模型发布频次更快（在硅谷待一周，光个人助理就发了好几个），每个模型都说自己各角度更好、榜单打到 99 分满分，但日常使用没有感觉那么好。**发现：coding/数学/通用 agentic 得分高，与电商领域能完成更多工作没有很大相关性**——通用智能水平变好确实能提高一些通过率，但本质水位没有发布时说的那么大。

于是基于 alibaba.com 上百万真实经营数据和 Accio 里真实问答数据，总结了 **107 个 task（开源）**，以 Accio 作为统一 harness 评测各模型。**最 frontier 的模型在这个 bench 下通过率 61% 多一点**——达到及格水平都有点费劲。61% 不代表工具不能用——是"完全无人干预"下不能完成的比率；任务难度不同，分 L1-L4，越长程、结果越开放，能通过的模型越少。

**任务举例**：①买家给商家发 quotation，从大量回复里选最合适供应商——回复含生产工艺、价格、到手价、物流方案，中间掺杂几个**钓鱼邮件**要识别有害信息，把工厂价到含税到手价每一个算清楚选正确答案，任何环节 fail 或算错都算未完成；②给定期限起止点在船公司网站上 book 一艘船，book 成功才算完成；③平台 dispute——判断买家对卖家的投诉信息是否完整、赔或不赔、需要更多信息还是能下结论。107 个涵盖七大类：有的监测计算结果，有的监测执行成功，有的监测商业判断（开环/闭环）。

**商业 AGI 的定义**：给定边界（budget、供应链一样），agent 做日常操作和判断比一个人赚到更多的钱——就是商业领域的 AGI。

## 六、成本：用得起的 AI 才是有价值的 AI

**帕累托最优路由**：把所有模型放在一起形成帕累托最优曲线——最终目标是最好的结果用最低成本，不是模型升级了都跑最贵的模型。L1-L2 简单工作路由到小尺寸/高性价比模型（中国出很多高性价比模型）；对多模态/视频要求强的路由到特定模型。**同样任务全跑完 107 个：Accio 成本 3.69 美元 vs Codex/Claude Code 9 美元以上——约三分之一**。而且自己绑定模型（Codex/Claude Cowork 是 agent 跟自己模型绑定）没法做路由——美国市场 OpenRouter、Fireworks 这类 hosting 大量模型帮你优化的生意很受欢迎，因为模型越来越成为 commodity。给客户建议直接选 **Auto 模型**：帮你帕累托优化所有工作该用什么模型。用千问最新小尺寸模型做 post-train，效果已非常接近 frontier top 模型——大量简单工作路由过去，更快更高效率。

**"用得起的 AI 才是有价值的 AI"**：这是日常经营使用的产品，不是解一个数学难题用一次就不管的。

（谈 GPT-6 Astra 刚发布）：再过两天可以直接去我们 bench 上看 Astra 的评分。**"它 3D 模型做得不错、computer use 有突破，不代表它在通用商业里的 agentic 能力强。说它是 AGI，我现在给你打保票肯定不是 AGI。**最终还是以最高性价比完成任务是第一要义。"

## 七、商家的新工作方式 + 老板仍要做的判断

张阔曾 2011-2016 在淘系做商家平台，现在站在另一视角看 AI 商家经营，发现有意思的 use case：①**多平台经营**：抖音/淘系/京东/多多——哪个平台今天挣到钱有大量流水，但不代表有利润；跨平台投入/收益/退换货形成完整报表，以前人工多平台来回切换整理 Excel 还不一定算对，AI 随时给跨平台实时经营结论；②**发布商品**：多平台规则和受众有差异，统一 update、大促大折操作是大工作量，AI 做完 repetitive work 放草稿箱由人发布或授权直接发布；③**客服经营**：以前经营会一条条看谁答对答错，现在 AI 分析所有经营结果告诉你什么是更好的回答方式；2B 客户出现问题的提前预警、下一步最重要的判断。

任务难度随时间从 L1 推到 L4（问问题→交任务→复杂任务→经营判断）。**留给人的决策**：支付/采购按钮一定交给人判断（对经营结果负责）。还有太多：idea 靠不靠谱、是不是真问题、目标客户群体是否感兴趣且技术足够大、产品 taste、对市场的预测判断（经营直觉）、同样 budget 要更多广告还是更多库存、铺更多渠道还是更大 margin——**AI 帮做大量分析调研，但最终商业判断是人按这个按钮**。

多 Agent 建议冲突怎么办：不同 agent 给不同建议非常正常。最核心是**老板要有整体经营目标**——以毛利为结果还是规模、速度；这次交易成功了也可能最终导致商业失败。Accio 站在商家自己"一本账"的角度做整体优化，与其他围绕单一平台优化的定位不同。"统一所有 agent 意见给用户反馈"不是产品设计的初衷。

## 八、上云 ≠ 长程；CoCreate 现场与中小企业放大器

上云是 basic 需求（PC 版几天后就有云端——本地 memory 放云端换机器可操作；"今天你说没上云，就是你功能还没做完"）。**长程是另一个概念**：让 AI 推哥德巴赫猜想推俩月也叫长程，但从商业角度分几种范式：①**定时任务**——每天店铺经营报告、员工表现；②**事件驱动**——跟多个供应商沟通过程中基于更新信息推进结果；③**季度级复盘**——这盘生意最终赚没赚钱。"你要追求模型 7×24 跑一个礼拜不挂——不挂 means nothing，如果没有解决你的问题的话。"

**CoCreate 现场**（洛杉矶）：最惊讶的是来的人太多了——注册到场约 15000 人，booth 搞小了，排队排到中午。美国用户对 AI/agent 的教育领先。CoCreate Pitch（类似 Shark Tank）：去年英国冠军是 15 岁初中生，用 Accio 找供应商做自动降温毛巾/宠物降温产品系列，**年销售额约 100 万英镑**；美国冠军 Christian Reed（MIT 毕业、穿着工地化），做很酷炫的测量设备，从 idea 到供应链全基于 alibaba.com/Accio Work，客户包括施耐德电气和 SpaceX，**今年生意做到几千万美金以上**。

结语：全球中小企业是各区域经济和就业的主力，原来的问题不是"AI 取不取代工作"，而是没有那么多资源和经验，又想把生意做大、利用全球供应链。今天正好有 AI 和 alibaba.com 的能力，帮助更多中小企业从一个 idea 开始，实现商业价值的放大。
