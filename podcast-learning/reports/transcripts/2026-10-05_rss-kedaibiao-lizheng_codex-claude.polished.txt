## 开场：Claude 重做网站，新旧版本差在哪

真正的高手他能找到事物之间的本质联系，化繁为简，然后去找到最有效的那个方案。

事情是这样的：昨天一早我收到有超[?]给我发的信息，他说 Opus 5.5 做网站的水平非常好。尤其我频道的观众知道有超，他是一个创业公司的 Founder，平时非常忙，他既然跟我说了，那我就一定应该去照做一下。于是我起来以后就照做了，结果真的大出我意料：我用 Opus 5.5 做的网站在这里，之前 Codex/GPT 做的网站在这里，大家可以看到完全天差地别的感觉。我这个（Codex）网站其实已经打磨了几十轮了，可能经过了好几次大的迭代，迭代成这个样子，但是跟 Opus 5.5 做的这个网站感觉就是有代差。

我做完了以后，也马上感受到了个人网站在 AI 时代的巨大价值，所以赶紧在社区里面发了个帖，并且来录这个视频，跟大家讲一讲这个网站做了什么、怎么做出来的、和我们为什么要做这些——也就是在那么一堆看上去很 fancy 或者说各种信息里面，什么才是真正有价值的点。如果让我一句话去总结为什么要做这件事的话，那就是**掌握自己的叙事主权**——无论你是面对其他人，还是面对 AI，都是这样的。信息泛滥和整个平台算法统治的年代，这件事尤为重要。

## 从 Cowork 到 Code：先写文档，再做网站

我们先去看一下 Opus 5.5 到底给我们做了什么。这里是我发的帖，大家还可以看到我之前拆 GPT 做的版本——GPT 做的版本我觉得其实已经不错了，挺整齐的，该放上去的资料全都放上去了；可是你一打开这个 5.5 的版本，你就会感觉到审美上确实是有代差的。

我也可以给大家看我具体的 prompt 是什么。我昨天开始做的：我首先打开了 Claude，然后让它在我的 Cowork 上去做。大概就是这么一句话："我个人主页，主页的所有的历史我全都是放到 GitHub 上"——我相信我跟我的 AI 说一下这样的一个项目，他就可以整体地去看到。然后我跟他说：你系统审核一下，给一下 update 建议，要大胆暴击。他给的这个建议其实不太好，说实话一上来他给了一些文字版，然后我跟他说我面向的不是那种真正的极客们，我面向的还是大众们，所以我又跟他讲了一些 I can force[?]，他又做。做到后面我发现，因为我其实要在里面添加很多个性化的组件，我就让他把一个文档写好，我还是去交给 Code 来做。这个是我在 Code 里说：你就读一下这个文档。

这其实是我们在课程里面教的一个很重要的点，就是 **Document first**：我们在做什么东西，到最后要形成一个 document，然后这个 document 你就可以拿到各种地方去用。我现在是从 Claude Cowork 变成 Claude Code，我把这个文档去交给 Codex，或者交给 Grok，也是一样可以去做的。所以这个 document 其实非常重要。这个 document 给了他以后他就开始做，做了这么一天，我就得到了我现在的这样的一个版本，大家可以看，它还是有不少的内容的。

## 两万多人的社区，怎么变成一张可探索的地图

在这个版本里边，我做出了一个特别特别有意思的东西——不是上面这些"我干了啥、我有什么对话"，而是这个**超线性学院：我们在建一座城**。你看这里有 2 万多个点，每一个都是可以点开的：比如说你点立正，然后它就到了我的主页，这就是我的内容；这是我们社区里的所有的人，全都在这里。

大家知道我是做 AI 社区的。很多人会把自己的一个 newsletter 就叫做社区，或者说一个微信群叫做社区——微信群确实是个社区，但是 newsletter 肯定不是社区。社区的意思就是说，我们每一个人跟每一个人都可以产生链接。在这里边有两万人，万万万的链接就可以产生两亿条的链接——就是 n 乘以 n 减 1 除以 2 的那个方程。所以说这些链接才是一个社区真正的价值和真正的意义。我在做这个超线性实验的时候就跟大家说：我不是要一个中心的分发的东西，而是要一个希望人和人之间能产生链接的东西。那这个地图其实就非常好地具象化了这件事情。

我在我的文章里边也告诉了大家这件事情到底是怎么做的：其实每个月我会用一个 GitHub Action，把这个 Circle 上的资料调用我的 API 去抓下来，然后放到一个 Vercel 的 Blob 上，再去把这个更新，它每个月都会自动更新，不需要我去做任何事情。然后在审美上我也去跟 AI 说——你看它现在的聚光灯是在变的——我去说"你要高级，但是不要 busy"，它就真的给我做出来了一个高级不 busy 的。包括我鼠标在这移动，大家看到吗，这个光也会随着我的鼠标去移动，我觉得就很有范儿。这个审美是真的很好，我自己是想不出来的；我能跟他说你要什么东西，但是具体怎么实现，他很好地实现了，比我想的要厉害得多。

## 问问立正：用我的文章和判断回答你的问题

再往下看，还有一个很有意思的点。关注我的话你会知道，我很早就把我的所有的 context 全都给公开了——大家完全可以去调用我的 context，我也有很多朋友在下面留言说他们用了我的 context 效果还挺不错的。可是我后来去想：你要去调用这个 context，虽然说起来简单——就是你在 Codex 里面说句话就行了，或者 Claude Code 里面说句话就行了——可是很多人还是不具备这个点。那我就把它又做出来了一个大家可以**直接免费去调用**的东西（"问问立正" ask.lizheng.ai）。

比如说我说：DS（数据科学）在 AI 时代还有前途吗、会被取代吗、怎么转型？随便说一个，然后试一下——它背后是这个 Grok 4.5 的模型，然后就可以查找原文去做。

这个东西是怎么做的？其实我是昨天下午的时候开始做，就用手机这样去跟他说"你用我的 context"。但是这里边比较难的呢，是你怎么把这个模型部署给其他人。好在我们有我们自己的这个 Builder Space——就是我们讲过很多次、在社区的 ToolBox[?] 里边就有——给大家提供了这么一个基建。这个基建就可以让你登录了之后去调用很多很多不同的 API，然后你还可以直接去部署你调用的这些内核，所以说它不是一个前端界面。你在这里面，它首先先把我的所有的相关的文章给智能地调用出来——这虽然是个所谓的 RAG，但是一个 **Agentic RAG**：它把我所有的文章调出来，然后再去综合，最后再去形成答案。

你看在这里边"还有前途吗"这个回答——大家感兴趣的话可以暂停然后自己去看一下这个回答的质量：被取代的是哪一层 DS，材料里的判断并不温和——"我认为就是会消亡的、是浪费时间的"，所以说它真的是我说的：它不是一个片断话，它真的是一个很有态度的话。然后"什么决定转型：要改什么而不是换什么标签；进攻性[?]岗位更接近任务结果"——这些都是我说的话，我觉得还是挺好的，大家可以去看一下。

我能很快地做出来，就是依赖了我们背后有这么一套基建。所以我真的是昨天晚上这么说一下，然后他去做，做完了以后我就发——就其实已经发了——然后我再说"速度有点慢"或者说"改一下域名、换一下模型、思考过程尽量给用户"，都是很少的话，他就可以做出来这么多东西。

## 真正的 AI 高手，为什么不用花哨技巧

这也是一个很重要的点：一个 AI 高手，他到底怎么样子才能看作是 AI 高手？在我看来，我们没有教任何翻写的东西，我们所有的方法都是跟 AI 直接说话就好了，可是背后那个东西其实是很厉害的。

这个道理其实我第一次看到是在《禅与摩托车维修艺术》里面讲了一个故事：他同行的那些人骑的是一个宝马的摩托车，什么坏了都去店里修。它中间有一个垫片掉了，需要找那个垫片，作者就说：这个易拉罐上的拉环的那个垫片特别好，你直接用它就行了。他的朋友就说：我这个宝马摩托车怎么能用这么便宜的一个垫片呢？我要去店里找一个特别好的垫片替换上。然后这个作者就说：他其实根本不知道，这个易拉罐上的垫片比他店里找到的那个垫片要好得多——因为易拉罐的垫片其实背后是非常非常贵的机器做出来的，质量是非常高的；虽然它常见、虽然它便宜，但是它背后的功夫是很深的。这个作者不光有能力知道这个垫片是能用，而且能知道背后这个垫片的质量其实是很高的；但是一个菜鸟——他朋友——不了解这个机械也不了解工业，他就会觉得我要去店里边找一个很 fancy 的东西才是符合我的做法的。

这其实就是我们平时看到的：很多那些教的人会说，我们要用什么 fancy 的 prompting technique，或者说一堆 fancy 的工具去做。其实真正的高手他能找到事物之间的本质联系，化繁为简，然后去找到最有效的那个方案。还包括比如说其他的例子：我看到宋亚东去打一个叫曹岩的 UP 主，稍稍用了点力，那个 UP 主就在那疼了半天起不来。你让宋亚东这样的一个搏击冠军去说你的搏击的厉害是厉害在哪？是在这一拳快速有力、只打要害，是打得准、打得快、打得用力，而不是去搞什么花拳绣腿。哪有什么[?]降龙十八掌——降龙十八掌、独孤九剑这些东西呢，是在武侠小说里边大家看着厉害，真正的实战派用的是这一拳。你看梅西的动作也看到了：真正厉害的人是不搞踩单车这种 fancy 的东西的，它是每一个动作都最简单有效。这边稍微跑题。

总之这是我的个人主页：除了把我的这些东西放上来以外，还有两个很厉害的模块。这两个模块的意义就在于，它们其实是我长期积累下来的结果被一个直观的方式给呈现出来了。就是我之前说我的这个社区两万多人，它就是一个数字，大家听了没有概念；但是在这儿能呈现出来每一个人是什么样子的，这个背后的 substance（实质）就更凸显。希望这样就讲清楚了。

怎么做？其实就是你去跟 AI 说：把我的东西给沉淀下来，把我的东西给总结下来，然后把这个网站给做出来。你可以抄我的提示词，你甚至可以让他说"课代表这个网站不错，你抄一下"，或者你喜欢什么其他的人的个人网站去抄一下，我相信 AI 都可以抄得很好；**但是真正的那个实质，是需要我们自己自己去构建的。**

## 为什么做个人网站：拿回自己的叙事主权

这就是我们说的第三点：为什么要去做这么一个个人网站？基本上有三个原因，就像我帖子里面说的一样。

第一个，就是你要**控制自己的叙事主权**。大家可以想一想，你对我的印象是什么？你可以先在脑子里面想一个印象，然后你可能会想到你看到我的几期视频，或者我说过的一些话，但是你脑子中的那个印象大概率不是我想呈现的这个印象。我是没有办法控制你脑子中的印象的，我也没有办法控制我在每个平台上大家对我的印象是什么；但是我能控制的，是我给大家一个确定性的入口。我把我的故事放在那里，然后大家想了解我的话，大家可以来我的个人主页，看我是怎么讲我的故事的、我对我自己的叙事是什么样子、我到底关心的是什么。所以在我的个人网站里边，你会看到我是怎么样子去讲的：我真正 care 的东西是什么、我把什么信息放到前面、我过去的判断、以及我最近在想的事情——这些都是我在构建我自己的叙事。

并且这些叙事不光可以给人看，也可以给 AI 看。现在大家就可以去试一下，你去问你的 AI"课代表立正"[?]的话，大概率它会索引到我的这个主页——因为我在背后也让 AI 去把整个 SEO[?]和这个站点图（sitemap）给做好了，AI 在搜我的时候就会很靠前地搜到我的个人主页，那它也会去看这里面是什么。所以无论是对人还是对 AI：掌握我自己的叙事主权。

## 给自己留一个不靠平台推送的入口

第二，这个个人主页你可以说是一个我的**自留地**。今天你可以看到这些视频，是因为平台的算法决定把我的视频推送给你；不然的话，我上传那么多视频，其实大多数你是刷不到的。我每个周都会上传很多视频，我那天看了一下，我光在 YouTube 上平均一周会发七条视频，这些视频里面绝大多数你是看不到的。你想到了某位 UP 主[?]的时候，你会好好去搜；但是你会在这个小红书或者说 YouTube 上搜一个 UP 主吗？大概率不会。所以说我们缺乏一个别人确定性地找到我们的渠道。那个人主页——我们为什么要用立正.ai 买一个这样的域名呢——就是大家可以想到我的时候，可以确定性地找到我，然后在这里边通过我的这个叙事主权去形成信任。

我也把我真正关心的东西和我的合作方式放到这里。举个例子：我在这里边的合作，就是您想要邀请我上节目、或者说是机构咨询、长期合作、定制，都是可以在这里边找到的；我的过往的演讲、我过往分享的东西，也都是可以在这里找到的——减少了我的很多解释成本，也能把我过去积累的东西用这种免费的形式分享给大家。还有像比如说我的周边店什么的，在这里边都是可以看见。这个是我让那个 AI 刚刚改的图，有点搞笑，但 anyway，想要去跟我有关的事情在这里边你都可以找到。

## 注意力、信任，以及长期积累的价值

这件事在我们这个时代就尤为重要：因为算法的分发、因为信息的泛滥，所以说**注意力**这件事和**信任**这件事是很难构建的。你如果没有一个自留地，你哪怕在一个平台上再多的粉丝，平台明天不给你流量，那你这些粉丝就没有用——这些粉丝是没有办法真的找到你的，他们刷不到你，他们就会忘记的。就不要觉得有人会真的去点自己的关注列表然后去找到你，不会的：大家忘了就忘了，刷不到就把你忘掉了。所以说有这么一个自留地是非常非常重要的。

其实我在做这个社区一开始，也是给大家提供了这么一个空间。我在自我介绍的时候就是说：你在社区里自我介绍也可以是你的互联网名片。在这就可以看出来了吧：我们点开一个人，是可以看到他之前发了什么、他留言了什么、包括他的各种 profile 是什么样子，就能知道他的过往。他就在我们的网站上形成了一些他的留痕，或者说他的 context——这些 context 他未来也都是可以去使用和帮助他形成信任的。这也是所谓的两万个乘以两万个的链接，它的意义所在。

那好，希望到这就跟大家讲清楚了：这个网站是什么样子、它是怎么做出来的、它的亮点是什么、和我们为什么要这么做、这个个人网站在 AI 时代的价值所在是什么。如果大家有进一步的兴趣，在 Share Your Projects 里边就能找到我的这个帖子；如果大家想知道我具体使用的提示词是什么，在这个帖子下面留言，我也可以都分享出来。希望这期视频对大家有用，我们下次再见，拜拜。
