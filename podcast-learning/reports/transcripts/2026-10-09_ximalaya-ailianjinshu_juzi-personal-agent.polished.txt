## 一、时代追上了橘子：个人 Agent 为什么现在火

半年前 ColaOS（爬你电脑的个人 agent）发布时任鑫杠他"太宽泛、要不要找细分"；半年后 Instinct 融资爆火、Muse 带飞 Meta 股价、Grok Bot、OpenAI 临时出 Dot、Manus 出 Q——**"时代终于追上了橘子"**，而他打了转向灯（转向垂直+本地）。为什么是现在：

1. **Agent 上云**：以前本地电脑有门槛；云端="跟豆包一样说句话就能做事"+agent runtime 多 10-100 倍能力。
2. **扎克伯格撒币大法**：Muse/Dot/Instinct 全免费——免费+补贴云成本把摩擦力降到极低（中国互联网最爱的免费策略回来了）。
3. **便宜模型的 agent 能力质变**（最实质）：半年前要 Opus 级（Sonnet 都不一定好）；今天 DeepSeek Flash / Haiku 5.5 就能完成"看邮件、订机票酒店、操作软件"——**token 成本是半年前的几十倍便宜**：Opus 4.6 内测每用户补贴几百美元 → 今天 DeepSeek Flash 每用户每月约十美元 ≈ SaaS 订阅价。**"烧 token 补贴用户的成本已低于获客成本"——滴滴打车大战式的互联网免费打法可以再来一次**（"投资人你们的钱终于有用了"）。Ben Thompson：2C 打到大市场必须广告模型——"靠 token 卖 revenue 要给'接近免费下的新商业模式'（竞价排名/信息流广告？）让路"；曾鸣的书同理（"都说每次不一样，按周期拉长看都一样"）。

**产品完成度也到了**：Muse 若小龙虾是 30 分，它接近 90 分。

## 二、ColaOS 半年踩坑实录（一线的冷水）

- **99% 的人没有日历**：线下专科发传单没人看一眼——"AI 圈在自己的信息茧房里"；Instinct 切入点是日历+邮件，没有日历怎么定行程？跟 agent 说半天 context 的输入成本很高（这也是当初选做电脑端的原因——电脑上有很多现成信息）。
- **大部分人没有"支使别人干活"的肌肉**：当领导是能力；大部分人不想 build 东西、只想刷短视频——"我们是一帮变态在研究正常人类，变态的小众需求"。
- **Agent 之间协作**（Instinct 讲的故事）实测"使用率低得吓人"。
- **Context 输入很烦**：同事关系等信息不存在任何文档里（除了 GitHub）。
- **手机端做东西不成立**：移动状态无法专心——上月决策重投本地。
- **程序员用户极少**（极致性价比→Codex/中转站）；但代码是通用能力——非程序员做项目都需要，只是不以程序员身份写代码。

**真实受益者画像**：十几人的小公司（产业配置不全、老板亲自上）——**30-35 岁+有社会/人脉/业务积累+以前没团队把想法做成产品**的人最如鱼得水；年轻人以自媒体为主。

## 三、转向：垂直 + "965 之外"

- **办公赛道放弃卷**：managed agents 是基建不是产品（"所有要做 AI 产品的公司都必须有这套基建"——做云端/Lovable/Vercel 都需要它）——可以把它当 infra 卖给所有人，也可以在垂直领域用它解决行业问题。
- **Product Hunt 发布**（在美国做的）：本地生活商户的 AI 运营。
- **个人 agent = "965 之外"**：帮用户发现**人生第二资产曲线**（副业/摆摊/淘宝店——part-time 不只 creator）。判断依据："YouTube/推特上无数人教赚钱=注意力层有真实需求；而没有一个 YouTuber 在讲'你应该学习 personal assistant'"；短视频平台已经在给用户发钱（农村老人月入上千="UBI 的一种形式"）；**AI 没有身份（发内容被平台干掉）→人的身份本身值钱**（宝岛眼镜大几千员工写点评的案例）。
- **教练式 AI 优于秘书式 AI**：会的事（订机票要靠走廊）用户会挑毛病；不会的事（如何开抖音副业）你是老师/教练角度**不易错**——"身灵/self-help/coach 都包进去的细分切口"。
- 推荐系统的反思：他们做的是**推盲区**（每天最多 3 个"你可能 miss 掉的"，用户很喜欢）vs 消费推荐（推新东西让你不停点）。

## 四、商业模式与融资的微妙时刻

- 中国 personal agent 创业不成立：邮件/日历/机酒中国不用+大厂一两周全都会发+平台封闭。
- 美国：创业公司能跑出一两家，但**以 5-10 年为单位算 ROI**的烧钱游戏——Muse 免费+分发好+产品好+模型差点但"这个赛道模型没那么重要"，"你说产品比人家好，Meta 说我免费"——这个故事很难讲。
- **投资人悖论**："想听非共识，但最好等它成为共识时再给钱"——《让子弹飞》："发枪没用发钱没用，要让黄四郎被打死了、我是来分享胜利果实的。"上半年给所有投资人讲过个人 agent，没人投；现在共识了，但 100 个竞争对手都是大厂。
- Instinct 讲交易额不讲 DAU（"帮十万人管理日历融不到钱"；佣金 story：Shopify 2.5% 到 boutique 酒店 30%）；**豆包的战略尴尬**：做机酒电商抽佣一直 make sense（=免费版 Muse 前身），但跑去搞 cloud code 办公，现在海外火的又是"纯豆包"。
- ColaOS 今年目标：**盈亏平衡**（创业第二年；达成=runtime 无限，可以去找新机会）。"又要梦想又要现实：现在既要有一个梦想，又要验证出你能赚到钱。"

## 五、"产品和技术今天没有任何壁垒"（十月拷问）

- Instinct 火后 Manus/Dot 不到一个月赶工出基本一样的东西。**软件本身没有红利了**：红利=①提供一个小但很多人需要、服务得不错的东西（留存→获客成本降→绕起来）——能到 ARR 好几百万美金；千万/亿级要出圈，拼的不是产品技术。②**爆款+两周窗口**：Jev 案例——一个月全行业做完，融 100 亿估值=**"币圈玩法：领先一天炒到顶端，不考虑下一轮考虑下十轮，把钱融到位，之后换方向都行"**。爆款只给你两周曝光，要用来搞钱/渠道/大厂合作。
- **模型吞噬一切**：Opus 5.5 从头到尾做完知识类视频=一类产品被吞；**下载 3A 大作让 AI 破解随便改**——"游戏软件硬件一切终将开源"（AI 猜你的架构重写=cleanroom 没法告；当着 Adobe CEO 面复刻 Photoshop；相机固件/Apple Watch/遥控器都是 vibe coding 设备；Meta glasses 出 SDK 直接改固件）；**世界模型赛道被"干脆了"**（上半年中国投资人最爱投的东西打水漂）；短剧案例：领先 20 分的 harness 被 Seedance 升级瞬间拉平；模型公司也被卡半空——"**做个小细分，老老实实赚点辛苦钱，晚上才睡得好觉。**"
- **那什么增值**：生产端过剩→**需求端控流量/信任/渠道更值钱**——"老登资产"（茅台搞不掉；资源 owner 大多连智能手机都不太会用，靠线下喝茶闻味道）——"多出去跟大佬喝茶，可能比对着电脑敲字重要（敲字也敲不过你们）；线下 connection AI 帮不上忙；脏活累活 AI 做不了（但用 AI 做脏活累活，资本给的估值倍数还行——没把你当外包公司）。"

## 六、彩蛋

橘子新播客 **Next Token** 四期上了八次小宇宙新星榜、单期 1.2 万播放——秘诀=官方推流（"认识平台的人+每期发链接给小宇宙老板说推一下"）——"老登最后都是靠平台扶持。" Gemini 被 Nano Banana 2.1 比下去（"谷歌这条大腿不行"）；GPT 100 美金用不完（Astra 打不过 Opus 5.5）vs Opus 200 美金花得完。结尾橘子读了自己的诗："假如我重新开始写诗，从自己的小模型找下一个字……"
