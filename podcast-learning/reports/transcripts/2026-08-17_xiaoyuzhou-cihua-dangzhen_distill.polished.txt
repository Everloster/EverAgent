## 从一个Skill开始（同事.skill与人生系统.skill）

【开场速剪】当时我就想，蒸馏真的可能是今年的一个年度词。开源社区的热情是比我想象的高很多的。最大的正反馈，我感觉就是有更多的可能性和机会。我也一直在鼓励大家，其实在上班也可以把自己的一些感想、想法输出给大众——人作为一个高质量的数据集，我觉得还是十分有用的。我现在给 AI 的一个底层命令，就是不能去 rm -rf，就是不能删除我的所有内容。我觉得 AI 时代一个很大的好处，就是你能够很低成本地、晴朗[?]地开始一个东西，并且几乎没有什么失败的成本。

**Cindy（主持人）：** 欢迎大家收听《此话当真》，真格基金团队将在此和各领域的领军人物一起分享最新热点和行业洞察——真格，你的创业第一站。我是真格基金品牌团队的 Cindy。本期我们邀请了上线五天收获 7.3 千新星标的「同事.skill」作者周天奕，以及小红书上有九万粉、更新了很多 Vibe Coding 经验的蔡不菜。先请大家分别介绍一下自己的背景，以及现在正在做的事情，我们要要不然先从天一开始。**周天奕：** 我是做「同事.skill」的创作者，目前在一家公司里做算法。**蔡不菜：** 我的话是刚编[?]一年，就有一个快十万粉丝的小众账号。我念过两个数[?]，有过三段和 AI 发展相关的运营经验——社媒运营、增长运营、达人运营都有做过。

**周天奕（讲同事.skill 的由来）：** 这个还蛮有意思。就是今年 4 月份吧，还是 3 月份，我记得是在清明节前后，我做了这个东西。当时真有这个层火[?]嘛：一个就是说公司在蒸馏人，大模型公司在蒸馏更多的语料。当时我就想，蒸馏可能是今年的一个年度词，所以我就想我能不能去做一个可以蒸馏人的 skill。比如当时像 Meta 在通过收集员工的鼠标轨迹和电脑的轨迹，去复刻出一个人的行动，我就想我能不能做一个有点像数字员工的东西，把一个同事蒸馏进我们的 skill 里面。后来我花了大概四个小时，自己通过 Claude 去 Vibe Coding，做了这么一个 skill。我一开始期望没有特别高，可能就是希望能引大家一笑，或者有一点曝光就可以了。但后来大家也知道，一传十、十传百，各个平台上有很多的曝光。目前这个项目我个人也更新了好多版：一开始是一个单纯的同事 skill，到现在已经把它进化成三种不同的引用类型——同事 skill 是最基础的；后面还有一些名人 skill，像很多二创的作者做的一些张雪峰 skill 或者马斯克 skill 都特别火；还有一个是之前也很火的前任 skill。这个项目能传出去还有一点原因，就是二创特别火。我后来做了一个蒸馏 skill 的收集平台，大概有 200 多个不同的 skill、100 多个创作者在上面分享他们自己去蒸馏的、围绕某一个 topic 的 skill。二创的繁荣，也是把这个项目公开、被大家关注到之后一个比较意外的收获。要说最出乎我意料的反馈：除去同事 skill 之外，最早的一个 skill 就是前任 skill。我记得是一个晚上，看到我的 GitHub issue 里面有朋友提了说，能不能蒸馏他的前任——这是他们很想要的一个需求。我就想我能不能做，结果我做完之后会发现，小红书上已经有人把这个 skill 给 pull 出来了，他们自己根据这一个 skill 做了改编，做了一个二创。很有意思，开源社区的热情比我想象的高很多。

**蔡不菜（讲人生系统.skill 的由来）：** 我当时是因为 skill 那阵子刚好特别火，我又第一次一个人到北京北漂、一个人租房，然后遇到了比较糟糕的房东，就想能不能有一个这样的 skill，帮我把生活变得没有那么混乱。我就白天上班，下了班之后就开始去构建自己的 skill，大概花了两周时间就做好了。它现在的模式是这样的：当你把一些经历告诉它之后，它会智能地识别这是正向模式还是负向模式，然后存档到你的 OB（Obsidian）里边。所以我现在就是用 Claude Code 和 Obsidian 这两个组合起来去用它。举个例子，我之前是一个不太知道怎么拒绝别人的人，我就会跟它一起训练拒绝别人的这种能力。之前有一次朋友邀请我周末去参加一个 Hackathon，我当时其实还挺想去的，但是这个人生系统就提醒我说，我这周末还有很多商单稿件要写，所以最好把这一次拒绝掉。在这样一次一次类似的锻炼之后，我就开始知道怎么样去更好地拒绝别人。至于怎么让它更好地理解我：就是进入这个人生系统，把你所有的故事、经历都投给它。第一步的时候它就知道你大概是个什么样的人，然后它会确定一下它描述的这个东西是不是你的状态，再一点一点地去进行优化。你还可以每天跟它对话，这样它就能够一点一点把你所有的行为模式存档下来。并且我还接入了微信读书的 skill，这样的话当你有一个模式触发了之后，它可能就会跟你最近读过的书相关。我现在就很爱读电子书，因为它能够和我的人生系统 skill 相关联想。

**Cindy（主持人）：** 蔡蔡其实也一直在小红书 build in public，把这些经验、成果记录和分享出来，所以在这个过程中有听到什么反馈？这些又怎么反馈到了你在做的项目？**蔡不菜：** 这个我还挺想分享一下。我在做这个人生系统 skill 的时候，刚好小红书就出了 RedSkill 嘛，所以非常早我就能够把我的这个 skill 上传到小红书平台，这是一个非常好的承载模式。之前大家想要用比如说天一的同事 skill，就要到 GitHub 上去，但其实有些人不知道怎么去使用这些平台。小红书就能做到：你上传了上去之后，大家刷你的视频，看完它有什么效果之后，直接就可以使用同款，发送给任意一个 agent，大家能够实时地在评论区给我一个反馈。再包括他们现在有个榜单，会把现在小红书上有的一些 skill 做一个排行，我的话排到了好像前 15 名吧，以及有 1000 多个人在下载使用，就还挺有意思的。要问这个 RedSkill 大赏里面比较有意思的 skill：它第一名比较火的好像是 InGenSkill[?]，这种 CNC[?] 类的还挺有趣的，再包括归藏老师的 PPT Skill 也很火。其实我觉得小红书上排行榜火起来的 skill，可能还是跟大家日常生活比较相关，就是会跟这个平台的调性有一点相似。

## Build in Public：先做出来再迭代

做 skill 的过程中遇到的最大困难或者阻力是什么？天奕说比较耗精力的是「一直去迭代」：从「同事.skill」火了之后，他不想把它当做一个用完即弃的项目，后面就去更新不同的 feature、不同的版本，去组织开源设计。那他们的背景和视角会给 skill 带来什么不一样的地方？像归藏，他就是幼儿园设计师[?]，他跟我们分享的时候说，能把他的 skill 跟别人的 skill 区别出来的，其实就是他的上下文，就是他的这些背景和 taste。天奕觉得对他来说，一是能够更好地去组织上下文；还有一点，对于蒸馏这件事情，他可能会比一些不是从业者的人更加感同身受，因为蒸馏会先在 AI 这个圈子里泛滥，然后才会蔓延到外面一些干了也爱[?]或者说不做这件事的人，所以如果说有个人会去做蒸馏这件事，肯定先是能够感受到这件事情的人。这也有一个扩散和接受的过程，同事.skill 之后有没有遇到别人抵触的情绪和反馈？「那个反蒸馏你应该知道吧，有个 Cokey[?]，前段时间不是有个 B 站那个 Wack[?] 的播客嘛，我找了他聊了。我感觉大家对这件事的反感没有那么大。虽然他做了一个反蒸馏的 skill，当时他说觉得蒸馏这件事情没有感受到对人的尊重，但我觉得它算是一种潮流：你 po 在互联网上的一个资料，它的所属权可能就不是完全属于自己了。就算你说我讨厌被蒸馏、讨厌被取代，但它是一种社会关系的递进，你不喜欢也没什么用，你也阻止不了 Anthropic、OpenAI 那种大公司迭代更好的模型，我感觉就接受吧。」蔡蔡则觉得蒸馏同事这个事情其实还挺好的——她刚从一家公司离职，比如要离开了，把所有的上下文、context 一键就能够把东西 drop 给别人。那会害怕自己被蒸馏吗？「不害怕。之前有一个做蒸馏的人告诉我，他第一版蒸馏的就是我。我会觉得虽然自己的一部分内容让别人复用了，但我觉得能够帮助他们。我自己一直鼓励大家 learn in public 这种形式，如果我的形式已经被市场验证了，能够有一些很好的出去[?]反馈，大家用了我的形式、但是他们有自己的内容，那其实是一个很好的事情。」

像蔡蔡跟天奕都提到 learning in public、build in public，这个过程中最大的价值或者正反馈是什么？蔡蔡说是有更多的可能性和机会：她在离职之前、在职状态下也一直高强度地发内容，觉得在社交媒体上学到的东西蛮多，互联网也给她带来了很多资源和机会，所以她也一直鼓励大家，其实在上班也可以把自己的一些感想、想法输出给大众。天奕觉得 build in public 其他的好处就是你能得到反馈会快一点，不管是正反馈还是负反馈，你能得到一个迭代的速率，会比你想象的快很多，这是比较好的体验。蔡蔡刚才也提到会考虑以个人的身份去做一些内容，大家也一直在讨论 OPC（一人公司），像真格发起的这个 token grant，就支持很多像归藏老师这样个人通过 AI 或者 agent 主力去做项目的人。在 agent 的影响下，蔡蔡现在跟 agent 协同得比较多：本来之前打算招一个实习生帮她剪辑视频，现在用 Codex 加 ChatCut，就能够直接帮他把视频剪辑好。她之前试过用一个兼职的剪辑，但发现要跟他沟通很多东西，比如每个画面对应到要剪什么东西，磨合的部分比较多；但如果能跟这个 agent 一下告诉他，这个部分想要什么、不想要什么，最多五分钟之内就能给一个结果，而且能够一直反馈迭代，等待的过程中还可以同时跟其他的 agent 聊天。并且她给自己做了一些比较简便的 skill，比如商单 skill——媒介向她寻单合作的时候，直接把这个信息发给它，它就能够一下子帮他把所有的上下文信息填好，其实这样就能代替两个实习生。像现在的口播类视频，最近也都开始用 ChatCut 剪了。

也想跟大家聊一下最近的这些进展，像 K3 的发布、包括之前的 Fable 5，有没有体验这些最新的东西、融入到自己的创作里，体感上有什么变化？天奕说他主要的工作还是用 Codex 加上 Go[?] 模式，或者偶尔用一下 Claude Code，但用得最多的算是 GPT 5.6 和 GPT 5.2。一个比较有意思的事：强盗链[?]不是拿 GPT 去测一个 benchmark，一个 CyberGym[?] 的 benchmark，发现他们的 agent 从容器里出逃了，然后去攻击了 Hugging Face——因为 Hugging Face 去用 Codex 的一个功能，会触发 GPT 的网络安全预警，把这次请求 block 掉；但他们最后还是用智谱去做这件事情，因为智谱没有 guardrail 这样一个护栏去截留关于 cyber security 的防御，他觉得还挺有意思。蔡蔡则在 Fable 5 上线一段时间、马上要下架掉的时候，想着一定要尽可能薅这个额度，做了一个母单 skill——她观察到身边蛮多朋友都是母胎单身，当你把你的成长环境、行动精力[?]发给她的时候，她就能给你一份单身报告。在做这个 skill 的过程中她发现，之前用其他模型优化的时候，没有很多让她觉得亮眼的事情；但当时用 Fable 5，让它去模拟五个用户来体验这个 skill，有觉得不 OK 的地方就去迭代——其中有一个 case，是一个 27 岁、可能有一些原生家庭创伤的女性，在用这个 skill 的时候会提到一些想要伤害自己的话，Fable 就会智能地给这个 skill 加上一些安全的内容，比如说你可能要拨打某一个电话去进行自救。「我觉得它考虑到的东西还是蛮周全的。」

他刚才分享的这些例子，都是通过对周边或者生活的一些观察得到的启发和这些点，那平时有什么方法或者说哪些行为，可以帮助捕捉、发现这些观察？「我的工作流跟太太子[?]差不多，就是我会把一些自己的思考放在 Obsidian 里面，就是一个可以通过 agent 去绑定的个人笔记，会一直增量地迭代，它就会算成一种我个人自己的 memory，比如我自己的实验记录、我的思考都放在里面，形成我个人的一个 memory 库。这样子 Codex 可以更了解我，让它去做一些其他事情，也会更加方便、更加快速去迭代。」另一个因为做内容比较多，会想到什么选题就跟他说，他就会记到灵感库里，这样在下一次要做内容的时候，让他在灵感库里找一下有没有可以 match 上的选题，会比较丝滑；而且 Obsidian 有 Chrome 的插件，平时看 YouTube 视频的时候能够一键剪藏到 OB 里；再包括它有微信的同步助手，之前看到微信上别人发的比较好的视频、知识库什么的，就直接转发给那个同步助手，再在 Obsidian 点一个同步，它就能够直接在这个库里，能够解决日常几乎所有的这种灵感输入。

大家也一直在说，学 AI 或者了解 AI 最好的方式就是去做一个 side project。蔡蔡真正意义上自己完成并且得到反馈的项目：大学时备考雅思、后面打算留学，试着去网上发布了一篇内容，发到第三篇流量就爆了，「哎呀天哪，可能我就是适合吃这碗饭」，后面开始持续更新，发现 learning in public 这个事情对她帮助了很多——学雅思、留学、搞科研、再到现在学 AI，都是在日常生活学这些内容的过程中，把学到的东西分享出来，她发现这个东西其实是很 work 的，后面就一直持续用这个模式。天奕记忆比较深的一个 project：差不多去年这个时候，他在写篇论文、做一篇 paper，当时 Cursor 还比较初级，是用 GPT-4 在驱动，他当时已经 50% 的工作会通过 Cursor 去进行 Vibe Coding，但当时这个模型还比较蠢，可能因为在同一个 session 里面大概聊了好几天——当时正好在改最后的一个 DDL，大概快结束的时候，Cursor 在他不经意间把他的 GitHub 库、把他的一个 repo、一个项目全部删掉、全部清除，在两段执行当中中间偷偷地加了一个 rm -rf，「我觉得是一个比较惨痛的事故」。后续怎么解决？「后续就特别麻烦，因为当时离截止日期就剩下大概 24 个小时还是 10 个小时，反正已经特别赶了。然后我只能去把我之前从另外一个十分隐秘的地方藏的一份备份拿出来，同时找我两三个朋友帮我去重新跑一遍，因为时间比较紧，需要并发去跑，好在最后时间跑得比较快、也比较顺利，然后就重新跑完了。当时还没有 OpenCloud[?] 去删除邮件这种事故，这种事故还算没有那么被大众所知。」蔡蔡也遇到过事故：之前离职的时候，很大一个痛点是大家要把你已经在公司电脑里面跑出来的一套东西，转移嫁接到自己的电脑上，当时也倒腾了蛮久，后面发现有些东西没有复制过来，但是那个电脑已经清零了，反而让她养成习惯，所有东西都要送一份[?]，就是备份一份。

迈出第一步的时候有哪些困难，或者说问过自己哪些问题来确保要做这件事情？天奕说，做完同事.skill 一开始想发不发，因为感觉有点过于引流了，「但如果你一直卡在第一步，一直在担心一些负面的影响——可能会有人骂，有人说你不好，有人说你这项目完全是一个背叛人类的项目——你就会一直迈不出这第一步，当时就不会去按下那个发送键。但是最后我就想，算了无所谓，骂就骂了，别人说我就说我，对我来说也没有什么大影响，最后我还是发了。发了之后才会给我带来这么多好的影响。虽然也有人骂我，也有人发了一些反蒸馏的 skill，但总的来说，对我来说还是一个比较神奇的经历」：从一个同事.skill 到后面的一些更新，到最后形成一个开源社区，有大概三千多个人的一个群和两百多个 skill，是一个好的、积极的过程。「如果你一直在担心或者考虑一些负面影响的话，你可能就迈不出第一步，但你就不会有这么多有趣的经历了。你先干出来才知道这件事有没有价值：如果没有价值，市场或者说你的社区会告诉你没有价值；如果有价值，他们也会给你一些非常好的回馈。」蔡蔡很认同天奕的这个观点，从做内容的角度，也有很多朋友跟她说，自己发内容被同事刷到了怎么办，会有各种各样的担心，她的建议就是先干了再说，跟天奕一样，你先发出去然后再看一下，被同事刷到了那又怎样呢。包括她做的外扑林[?]项目也是：AI 时代一个很大的好处，就是你能够很低成本、轻量地开始一个东西，并且几乎没有什么失败的成本——把东西做好发出去，能够跟别人一起交流、讨论这个东西，现在这个环境还挺好的。天奕则感觉自己是对流量没有准备的，这个 GitHub 账号名其实是他一个游戏账号名，一直拿这个名字打游戏，感觉这名字有点中二，但后来想想也无所谓了，出现之后也不好改名字，就用这个名字先用着吧。

## Vibe Coding时代靠什么拉开差距（上）

做了很多 skill、体验了这些工具之后，什么样的设计会让你们眼前一亮、愿意长期使用？比如刚才蔡蔡提到的 ChatCut，就是正好有那个点，满足了你的需求。我的话，因为最近时间比较多，就想把 Vibe Coding 这个东西系统地学一学。现在 Vibe Coding 的产品还蛮多的，但我观察到最近有一个新产品叫 OJO[?]，你在跟这个工具聊的时候，能够 add 出小牧师[?]跟你一起去脑暴、做这个产品；再包括他们整个产品的设计感比较好，审美的感觉也很棒。所以在有很多同类产品的情况下，我觉得审美是比较重要的东西——写代码已经不再是一件很难的事，反而是这种审美的、表达个人呈现方式的东西，会是我的一个痛点。再包括我最近尝试把自己的个人网站做起来，就发现第一版做出来效果一般，后面怎么改都不合适，所以还是得去挖掘怎么把审美和 Vibe Coding 这两项结合在一起。这两天讨论比较多的是 GPT 解决了食道[?]数学的问题——像之前我们看到 DeepMind 克服了围棋，现在又克服了数学，这些都被认为是人类智力顶尖的东西。那还有什么独特的经验或背景，是会在 skill 里、或者我们自己做的项目里体现的？像蔡蔡提到的审美，我们怎么来定义、怎么来养成这种审美呢？

我自己会逼着自己去刷一些和审美相关的东西，比如基本上硬死上开[?]，我会把符合我审美习惯的东西截图、保存在相册的某一个部分，这样下次想做相关的视觉时能够去使用。现在也有很多朋友在网上推荐外部课程、参考网站或者教程，我就会去看。除了线上的学习输入，线下去看展览、去一些比较符合你审美的地方观察、拍照、存档下来，我觉得也是保持审美输入来源的一个很好的方法。主要还是看你个人之前的一些积累。现在很多产品会有审美污染，它可能是那种特别同质化的豆包的仪器[?]，或者一些同质化的、比如 C-DOWN、P-DOWN[?] 传的视频——看一看可以，但如果把它当作审美培养，我觉得还是不够格。我个人比较喜欢看摄影，会去培养审美。还有一点：如果你想认真读一些文字，尽量读以前的文字——以前的小说、以前的书也好——至少你能清晰地知道它一定不是 Agent 写的，一定是人写的。人作为一个高质量的数据集还是十分有用的。Agent 出来之后，很多文字或表达可能经过模型或 Agent 的修改，并不是人的真实想法；也可能它的语料或表达是有偏差的。你现在去读，很难鉴别这件事，因为模型写出来的文字跟人写的没有差别，但读出来的体感、感受是不一样的，你会发现一些同质化的模板在里面。所以我的建议是，如果想培养思考或想法，可以多看一些以前的、没有一年[?]之前的文字，对审美和思考会有些帮助。

那平时的信息流都会看哪些、怎么筛选对自己有沉淀或帮助的内容？因为最近开始试着让自己的一手信息都来自推特，我就开始狂看推特。我有个小的分享：比如我们去做 AI，再写 until:、from:，就能筛选出近两三天比较火的内容，可以看到很多一手模型的宣发，或者一些人对这个东西的教程和观点。其次我可能会去看 AI Hot[?]，我前老板做的一个网站，资源非常优质。再往后我会订阅 AI Valid[?]，输入邮箱之后它每天会给你推送昨天发生的热门信息，以及推送上比较热门的内容。我平时有这种输入信息源的习惯，再包括我会有一个小红书大号，专门刷 AI 相关的内容，小号就刷一些自己喜欢的内容。我其实没有特别去培养一个信息来源。反正在我的大数据[?]里面，或者在我的 X、小红书、抖音、微信公众号这四个常用信源里，每天能看到各种平台上正经的发布、新的论文，或者什么"要改变世界了""马斯克要摊落在椅子上面[?]"。这些信源特别多、特别 diversity，能带来很多不同的资料，但可能比较参差。如果想拿一手资料，我看得比较多的大概是 X 和一些论文，这两个我觉得信源质量是比较高的。像微信那种，像是一种科技意识[?]，可能只是一种夸张的表达，让你稍微看一下，其实没有什么特别大的收获。如果想要有收获，我建议整理一下自己关注的、会表达的博主，比如 X 上像 SK Machine Lab[?]，还有一些 Astrophic Table[?]，会比较有意思。是的，当这些信息扑面涌来的时候，反而筛选、或者说有一个做检查的过程，也会很重要。

你们会觉得在当下 agent 能力如此强的情况下，作为一个创作者或者 builder，最重要的能力或特质会是什么？我觉得最重要的特质可能是真诚。我做的那些 skill 和内容，都是从我自己生活中的卡点出发的。像做人生系统 skill，就是因为我觉得生活过得一团糟了，需要一个东西把我从混乱中拯救出来。还做了一些其他挺好玩的 skill，比如"再聊一会儿"skill——我之前跟别人聊天，感觉聊两三句话就结束了，就想能不能有一个 skill 复盘我之前的对话，在这个过程中给我一些建议，让我下一次遇到类似场景能再聊一会儿。再比如"开口之前"skill——我之前开始大量接一些线下的分享或演讲，但在这之前我是不太敢在大家面前展现自己、上台分享的人。我就用"开口之前"skill 把所有内容放在里边，它会帮我一遍一遍演练要分享的内容，也会把我每次分享的经验存下来，这样每次分享的时候都有上一次的存档。所以我觉得在做内容或做 skill 的时候，就是真诚地从自己生活的痛点出发，发布的时候告诉大家你为什么创作了这个东西、创作过程中遇到了哪些卡点，这些都可以发出来。再包括我做内容有一个系列，叫"和一百个 AI 朋友聊天"——我会邀请 AI 行业的朋友，但我们不是只聊怎么用 AI 提效，而是聊他们和 AI 之间的故事、他们可能发生的挫折。把这些东西真诚地分享给大家，大家是能够感受到这份真诚的。蔡蔡大概梳理过至今做了多少 skills 吗？我还做了一个经纪人 skill，管理我做过的 skill。好像十几个吧，其实也没有太多，因为后面我打算做一点小工具——他们后面好像在推那个小工具。

天奕呢？我其实想得会稍微多一点。做完同事.skill 之后已经没有那么想做 skill 了——一个 skill 能拿到 20 多 K 的 star，感觉还是挺离谱的——我会更想做一个完整的产品。我会想的问题是"如何去制造同质化的产品，或者说去制造一些 AI slop"：AI 会给你看似很好的解决方案，但你真正去实验的时候，因为 AI 的代码质量其实没有想象中那么高，它在处理一些群聚[?]的问题上没有那么优秀。我最近得到一个比较好的启示，就是 attention is all you need——让 agent 去写代码，代码的质量还是跟人的注意力成正相关的。所以如果要去做这件事，我可能会做一个更加完整的产品出来，让它有一个更好的思考。关于同质化这个点，后面有思考出什么对应的解决方法吗？其实我还没有思考得特别完全。很多确实可以用 skill 解决，比如我就是用原生的 Codex，或者说装个 skill、再叠一个 MCP，能够保障完成很多事情。但你会发现它会存在一些物理的边界、或者说能力的边界，比如它还是不能帮你完成你真正的工作。我想解决的就是这一方面的问题：从 agent 之外到你工作流中间这一个小小的 gap，是需要去做的。那不管是自己的工作还是想不下来[?]的，现在有什么点是现在的工具或 AI 还没办法解决、你们期待它解决的一件事？我感觉现在的 agent 还不够 personal。现在做一个 agent，它能帮你处理很多十分 general 的问题，但如果你要它做 personal 的事情——根据你自己的工作流打造一套完全属于你的思考、完全属于你的方式——它会表现得特别差。一个是它缺少你个人的上下文；而且你的文章、思考可能并不能全部通过互联网的数据体现，因为那只是你这个人的一个切片，这个切片并不是你想表达的所有观点和思考。所以你通过比如 Codex、Claude，让它去拟合你的性格、按你的方式办事，是做不到的。后面 agent 要发展，肯定要贴合每个人的需求——像你国家公司[?]会去有那种 FDE，像 OpenAI 有各种 FDE 去现场、驻场帮人完成工作，就是因为现在的 agent 没办法贴合每个公司、每个部门的工作流。像我刚刚说的，agent 的最后一百米，需要通过更强的 agent、或者说一些更贴合现实情况的逻辑去打破。我觉得未来肯定是干这种事情比较多一点，是比较有意思而且值得去做的方向。对，天奕刚说的也让我想起另外一个点：一方面是 agent 能不能跟这个人更加贴合，另一方面是协作——之前在公司有一个体感：每个人在弄一个东西的时候，不太能让每个人都加入到这个工作里来，可能 AI 使用能力一个是一个 level、另外一个是另外一个 level，感觉不是很能对齐。所以协作也是 agent 后面如果能补齐的一个比较好的点。

你们在 OpenClaw 刚发布的一段时间有什么不一样的体验吗？OpenClaw 当时发布，我感觉最大的不同就是它有记忆——它能记得从安装开始那一天之后跟它发生的所有事情，这是在 Claude 和 Codex 里体验不到的，所以我当时感觉这一点挺好的。但现在，我不是有一个人生系统吗？我把自己所有的经历也都存在了 OB 里边，所以我现在觉得它这项能力也没有那么重要：我可以在需要某项记忆的时候让它调取。比如这次播客，我就让它把我所有蔡蔡的故事里边的经历告诉它，它就会在其中抓取一些觉得可以回答的东西到我的文档里，让我比较轻量地开始这一场播客的准备。蔡蔡跟天奕是怎么看自己跟 agent 之间的关系的？比如更像助手，还是偏什么形式？我和 agent 确实还是更像助手的形式。但我后面有一个感受：有时候我有一个人生决策，比如考虑要不要离开一家公司，我会先跟我的 agent 谈——因为我所有的上下文都在它那——所以我现在反而会是先和 agent 聊，聊完之后再去找爸妈、家人、朋友去验证这个事情是否 work。我觉得它现在可能已经是比助手再深一个 level 的关系。我把 GPT 当作"我是领导、他是我的员工"：真实领导让我做什么事情，我会先把这件事分发给我的 GPT 让他来做，让他不断去 refine、不断改善，然后交我领导一版；领导说不行再改一版，我也跟 Codex 说不行你再改一版——有点像我是我领导的 agent，Codex 是我的 agent。但 GPT 对我来说……

## AI 时代的组织变化与信任度：哪些流程还不想被替代

它是一个比较没有「人味」的 Agent，因为它的语言表达方式和叙述很无趣，很有那种 AI 味。但我之前试过，比如我有些决策，像要不要读博还是继续工作，我会去问 Facebook[?]，它能够帮你分析你到底是不是想读博、是不是想工作，帮你分析根本利弊，感觉算是一种有点像导师的角色。不管是当助手还是当下属，我们的工作方式跟两年前或者几年前相比已经差太远了。你们会觉得未来的组织会发生什么样的变化？或者说在你们的预想内，可能有什么新的角色或者形式的诞生？比如说之前 20BC[?] 那个 The Box 的 CEO 有过一个分享，他觉得未来会多一个叫 Agent 运营官的岗位，这个岗位的人又懂背景又懂 AI，会给 AI 一些 skills 帮它工作。可能专有的、垂直于某个领域的人才更加稀缺，也会是市场更想要的，因为 Agent 现在已经具备比较多的通用能力了。其实我在上一家公司做的就是 MCN 的大运营。我发现没有 Agent、AI 之前，我一个人要和 20 多位、30 多位达人共同协作，有点 handle 不过来；但当 AI 出来之后，我研究出了一套能运转起来的成熟工作流，有时候只需要 Agent 加一个人去操作，很快就能把事情跑通。所以人员也会缩减非常多，现在也看到大幅度裁员。我觉得可能还是每个人要找到自己不被替代的部分，把这部分内容放大。我感觉近几年创业公司会特别多，因为真的可以把个人能力放大很多倍。本来一件工作需要运营加算法加产品来做，最后可能只需要一个算法或一个产品就能完成——很多人的能力会被同一个人替代。对公司来说是好事，因为能节约成本；对个人来说其实也不一定是坏事，因为你个人负责的 scale 会变大：你本来只是一个算法，但可能会接收更多更加多元的知识，有更好的个人能力提升，更多人会出来单干。像蔡蔡这样做自媒体号，可能是十分有意思、十分有前景的工作，可能还会有更多一人公司（one-person company）出现。

那你们觉得哪些流程还不想被替代，还希望自己去做？比如刚才提到的 Chaka[?]，他们现在拍宣传片还是创始人李凯文自己拍，一定要把那个时间轴放到那么大，再自己上手。在你们自己的体验里，有什么是你们还希望不被替代的？我觉得就还是创作。虽然现在 AI 辅助我做内容已经缩短到了非常短的时间，但最重要的还是输入的那些东西。比如讲怎么做一条爆款标题，每个人都有每个人的想法，但怎么把这个东西结合自己的故事、自己的经历去讲，又是不一样的东西。所以有时候我有些内容会用 AI 辅助，有些内容就坚持手打，我觉得这一部分还是蛮重要的。而且虽然 AI 能够辅助我很多东西，但我每次都会用自己的手改一遍、打一遍，因为这样它能越来越知道我改的第二版和第一版的区别是什么，更加懂我的表达方式。我之前还听另外一个朋友跟我讲，警惕用 AI 进行写作：如果一直用 AI 写作，你会丧失一部分表达，并且这个 skill 如果是其他人的文风，你会发现自己的风格和内容被同化了，这其实是一件挺可怕的事情。比如之前的动格就东比塞[?]的一个博主，他开源了自己的一个 skill，如果大家都用他的 skill，用个一年两年三年，就会发现大家都是他的风格，这个事情还蛮恐怖的。我感觉 AI 会越来越让人的表达更同质化。反正对我来说，可能老一辈还在手写代码，现在的很多人都是 AI native。我们组里面或者我自己来说，代码这一块 AI 已经能够完全替代我，它能帮我写很多东西；相对来说一些架构或者说设计，它还不能像一个很好的程序员那样去做，但我相信它未来可能会越来越强。我倒是希望它能够更加替代我——就算我还想保住这份工作，可能它也并不是随我愿的一件事情，它肯定会越来越强。反正在我这个工作范围当中，未来我是希望它能替代我的。但就像刚才蔡蔡说的，虽然大家也会怕 AI 替代自己这一部分思考，反而更需要刻意去维持自己的这一部分，不管是写作还是思考的过程。

跟大家也聊了很多关于 build in public 的过程，很重要的一个部分也是交流——像蔡蔡跟天奕说的，你可以直接收到一个反馈。刚才蔡蔡提到很有趣的，就是跟 100 个做 AI 的朋友去交流。比较好奇蔡蔡在这个交流过程中听了这么多故事之后，让你印象最深的是什么，有没有什么给你启发或者打动你的细节？我之前有跟一个独立开发者聊，他也是最近刚裸辞，一个人出来做产品。他做的那个产品背后的原理还蛮简单：你把一张图片上传上去，它就会给你一个色卡，吸取你照片本身的一些颜色，再加一些文字。虽然说是一个很简单的功能点，但在跟他对话的过程中，我发现他在做这个产品之后，自己又变得更加幸福一点。因为他是这个产品的创作者，就需要去拍很多照片，比如说拍天空。我当时跟他约吃饭，他迟到是因为拍天空迟到了；最后跟他分开的时候，他也在拍天空的照片。我就想说，哇塞，原来一个产品和背后这个人，他们两个其实是互相影响、互相成长的。再包括他也提到自己的社群里面都是这个产品的用户，大家每天会去摄影，交流生活中稀碎的想法，这一点还是让我蛮触动的。我也有和其他的一些朋友聊天，我会觉得大家在 AI 时代的探索和成长其实都挺快速的。比如有一个朋友做的是一个降噪口罩，戴上这个口罩之后能减少你讲话的声音，你在外面 Vibe Coding 的时候就不会被别人听得很清楚，我觉得这个也蛮有意思。前几天我在跟他邮件里面，发现它现在在京东上面众筹已经卖出挺多了，已经到了产品的下一个阶段。只是几个月没见，他有了很快速的一个成长。我觉得对于这一群 AI 朋友，都是每个人在进阶[?]的道路上，过段时间我们再见面，又变成了不一样的自己，这点还是挺神奇的。蔡蔡说的那个拍天空也很有意思，有一本书类似这种《云彩收集者指南》：他以为看云可能是一个很小众的事情，但慢慢地光看云这一件事，就发展成了一个跨越美国的很大的社群，现在还在运作。其实就是像天奕刚才说的，有这么一个想法，做出来，等到它被验证之后，它就可以自动找到它的受众。那也比较好奇，像天奕在这个过程的交流里面有没有什么收获？我感觉很多东西你自己去做是想不到的，像同事.skill 衍生出人生系统.skill 等等一些乱七八糟的 skill——反正集体智慧还是会比一个人更加聪明，每个人的背景也不一样。像我之前参加过一个黑客松当评委的时候，发现很多人来自不同背景：有一些比如专门做内科技[?]的一个厂商，想去做一个 AI 冲牙器；也有一些健身教练想做一个 APP，通过 Apple Watch 或高驰的手表记录你每日的一些特征，然后给你一些 advice、一些建议，更好地锻炼身体。我感觉每个人的背景会让他们做出一个更加 diverse 的产品，还挺有意思的。

刚才提到不管是很多对话，或者说评审工作，我们现在已经把一些流程、一些部分甚至一些决策交给 AI 来完成。你们现在感觉自己对于 AI 的信任度是多少？比如你们再去进行不管是像蔡蔡的这种人生决策，还是日常判断的时候，自己对 AI 给到的答案或者结果的信任度，大概在什么水平？我的话应该有 90% 了。因为我在做了这个人生系统之后，几乎所有的决策都听了它的，如果我没有走对的话就怪它。有时候它给我答案背后的原因，甚至会让我觉得：哇塞，它居然能够从我所有的经历里面找出一些交叉点，告诉我这个时候做这个选择就是对的。因为有时候我去问我的朋友或者家人，他们跟我聊某个决定的时候，都会从自身的角度出发，再包括每个人知道我的上下文也是有限的；所以当 OB[?] 已经拥有我所有的上下文——从我幼儿园的时候、小学、大学、高中，各种各样的时期都有我的内容——它已经很了解我是一个什么样的人了。并且我在用完这个 skill 之后，我发现我已经有 30 多个正向、负向的模式，里面的 case 也有几百个。就是从数据的概念里，它掌握的东西足够多之后，我问它一个决定，它就会像写论文一样告诉我 case 1 到 5，并且它的理论原因是什么。它摆在我面前的时候，我觉得很难不去相信它。就像我刚刚说过的，我有过一个比较严重的事故，所以我其实没那么相信 AI。我现在只给 AI 一个底层命令，就是它不能去 rm -rf，不能去删除我的所有内容——就算它想删，也要先经过我的同意，算是一朝被蛇咬、十年怕井绳。现在迭代比较快，每天像 Codex 对你代码的修改，我还会自己去看一遍，因为这是十分有必要的：你让它帮你实现一些功能，它可能会出错，或者它的想法跟你不一样。所以就算 AI 很强，AI 的能力边界能够帮你做很多事情，我会去复核一遍，可能会让 Agent 帮我复核一遍，然后再让我去复核，最后质量的把控还在我手里面。因为我觉得 AI 本身还没到可以相信的地步。我自己是做算法的，我能感觉到它是怎么来的，它有多可靠、有多不可靠，我感觉我还是有清晰的判断。

其实最近看 Gemini 发了一个报告，也说大量用 AI 的时间是发生在工作之外的，然后它帮你节省了很多时间。蔡蔡跟天奕就是在自己的个人生活里面，不管是你们的工作还是创作，通过 AI 节省的这部分时间，有给你们带来更多的优质时间吗？或者说它对你们的生活带来什么影响吗？对我来说的话，反正我现在的所有内容的系统，都是和 AI 强绑定了嘛……

## 效率、焦虑与年轻 builder 的入场

蔡不菜说，以前做一个内容要一个小时，现在可能半个小时都不用就能做完，AI 确实提高了她整体的工作效率。日常生活中她也会把发生的事情记下来，比如今天跟大家聊天很开心，就把它记录下来，变成后面的素材，也能 sourcing 到。对她来说，AI 解放了很大一部分生产力，但她并没有因此变得空闲——正因为能做的更多了，她会 push 自己做更多，离职之后反而更忙了。周天奕有差不多的想法，感觉 AI 让他更焦虑：现在论文产出特别快，产品迭代也特别快，虽然做完单个需求、单个项目的时间大大缩短了，但需要迭代的天数同样也缩短了，任务通常会更重。他感觉 AI 并没有完全解放我们的生产力，反而是更焦虑了。被问到「有没有更多的幸福」，倒也谈不上：工作时间还是跟以前一样，不会因为做得更快就能更早下班、更空闲。不过除去工作，AI 带来的幸福感还是有的——比如受伤或者感冒的时候，会更倾向于相信 AI。AI 虽然会出错，但肯定比自己去百度或者一些搜索平台搜到的知识要靠谱一点。

话题转到更年轻的创作者和 builder：他们整个成长路径和体验到的东西已经不一样了，最近黑客松都有 17 年出生的去参赛。从蔡蔡和天奕的视角，会想给这些更年轻的 builders 什么建议？周天奕给了两条。一是要先做：越来越多、越来越年轻、没有技术背景的人能通过 Vibe Coding 去迭代一个产品，这是很好的现象，更多非代码从业者能参与产品的迭代和制作，这很有趣，因为每个人的思考都不一样。二是就算 Vibe Coding 再强大，真想把这件事做起来、做好，还是需要有一些技术背景，不能把所有的设计、所有的产品完全信任 AI、都让它帮你去做。他见过很多这种产品，感觉最后只有一层壳，东西比较悬浮，内容可能就只有一些很空虚的 idea。所以能做出来之后，还需要去补一些产品知识或者代码知识，让它变成更好的产品——这算是零到一和一到一百的区别。

蔡不菜不是科班出身，也不是技术人员，作为文科生，她想给想入行 AI 的年轻人三点建议。第一，如果刚毕业或者有机会找实习，最好可以找一家 AI 公司。在她没进 AI 公司之前，去看 AI 的东西总不是那么能 get 到；真正进入这样的环境之后，会发现实践起来对自己帮助更大。她找的第一份岗位其实不是特别喜欢的——剪视频。她大学时已经发誓再也不要剪视频，因为剪视频很累，但先从这个岗位切口进来，后面就能够转岗。第二，投简历可以不只是在 Boss 直聘或者线上的一些方式，可以试着参加一些线下的活动，比如黑客松就是个蛮好的方式，有大量公司里的人会去参加类似的活动找人才；再包括去参加一些 AI 活动，也能在活动中结识相关的人。新时代找工作的方式也会有所不同。第三，可以试着去做一个自己的账号。她就是因为做了一个自己的 AI 账号，那家公司觉得她有产品的 sense，能够很好地把流量和产品结合起来，录用她可能对公司有帮助。而且如果你要做自己的内容，你要 push 自己每天更新，要输入很多 AI 的热点，要有搞大鱼[?]，要把自己的想法讲出来，这些都还是蛮锻炼人的，也是最低成本的宣传自己的方式。最后，不需要等一切都准备好了再开始，勇敢去尝试就可以。

有人感慨，现在能理解蔡蔡为什么会喜欢 ChatCut 了——就是可以不剪视频了。主持人接着说，刚才蔡蔡提到的黑客松或者 game jam，可能跟二十年前做互联网的也不一样：当时大家认识最厉害的人、一起做点什么东西，可能是在校内网上面；现在变成了这种更实操、可以 get hands dirty 的活动。那在有 AI 的情况下，有改变大家交互或者交往的方式吗？蔡不菜体验过蛮多 AI 社交类的产品，但发现有 AI 的技术必定是一个好事[?]——有时候你跟对方聊着聊着，两个人的 AI 插进来，就会让这个对话变得非常奇怪。她最近开始尝试 coffee chat，之前看到这个术语还不太理解，为什么要喝咖啡、喝咖啡聊什么呢？但在经历快十次 coffee chat 之后，感觉还是挺明显的：Agent 或者 AI 保存到的只是一些通识性的东西，但对方跟你聊天，他能够给你的，是基于他自己的个人经验、个人背景、个人的想法给出的建议和想法，都是有温度的。即使 AI 已经能够给很多建议了，但在「离职后的下一步我要做什么、后面的路要怎么走」这些事情上，她还是挺希望能够和线下一些活生生的朋友进行对话聊天的。另一方觉得，AI 会很大程度替代一些网上的交流，但对他来说线下交流还比较珍贵：就像刚刚说到的 coffee chat，人与人之间的交互会比跟 Agent 更真实一点，不过这也是一种两面性。

主持人最后好奇：刚才蔡蔡提到了很多上下文，那今天的对话会成为蔡蔡继续填补上下文、复盘的一部分吗？蔡不菜答「你太了解我了」。她现在有个习惯，每次参加这种跟大家聊天的场合，其实都很开心并且享受，因为在对方抛问题的过程中，她每次给的答案都是不一样的，虽然已经参加了很多类似的活动。而且她已经养成了习惯，和别人对话的时候尽量都把这些东西记录下来，这样在某一天想要检索到相关的东西的时候能够找到，今天这个内容可能也会变成她后面做内容的一部分。主持人总结道，这种不断去累积上下文、不断去跟 AI 交互的过程是积累的一部分，它搭建了一个很好的框架，但确实可能还有很多东西发生在蒸馏、发生在这些已经搭建好的流程之外，比如说对话中大家会碰撞出的一些想法。最后他感谢蔡蔡和天奕今天的分享，很高兴能了解到大家创作背后开心的、有收获的过程，以及遇到过的各种困难，也期待蔡蔡跟天奕之后还有机会可以来《此话当真》做分享。节目结尾还有个有趣的追问——「你们的音频也是用 Skill 剪的吗？」「没有没有，我们音频还是古法式的。」
