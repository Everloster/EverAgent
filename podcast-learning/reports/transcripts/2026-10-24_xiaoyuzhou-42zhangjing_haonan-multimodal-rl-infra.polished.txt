【00:09:12】做 Agent 和做多模态「有点围城」：做 agent 的天天洗数据没劲；做 video 的觉得 video 不体现智力；年初 GUI agent 都快黄了，「是不是都 CLI-anything 了」。职业发展上：做 agent 的人在主线上，公司做不好可以换下一家但还在主线上；做多模态工作体验更有意思（review data 像看视频而不是读 trace），但如果公司不做这条线就没什么好的发展方向。

## 二、为什么放弃视频生成、转向具身

【00:11:33】大厂不太能做具身：具身「不太够赚钱」，相对大厂主线业务更像车或手机这种产业链很长的行业，大厂对产业链的控制能力也弱（华为这类更了解产业链）；软件那种「天然更暴力」的打法在具身上不成立。所以要真做具身就得扎根基层、上手摇操作；在大厂天然做不成，大厂能做模型研究。

【00:12:47】两条延伸路径：继续 Diffusion 做视频生成，或用 Diffusion 做 Action（world action model）。Action 逻辑与视频/音频生成非常相近，可以用原来的 codebase 试一把，技术门槛没那么高，天然就能转。

【00:13:54】视频有没有「R1 时刻」：他们年初认为有，做了半年发现不行——不存在比较 efficient 的 scaling law，现在视频生成更拼 pre-training 的能力提升。他区分了两类 scaling：训练期的 scaling law（跟模型结构更相关，例如 curve 的 K 值）与 test-time scaling（堆数据能往前推，但纯堆训练数据不 efficient）。Seedance 做得好的核心是数据质量。

【00:15:36】多模态的竞争「没那么激烈，更巨头效应」：更多数据 + training infra；infra 很便宜，「弄个十来个比较有经验的同学，两个月的时间，都能推到一个相对 reasonable 的水平」，而且 infra 圈开源做得好；data 纯看自己的积累，走不了捷径——要么花钱，要么有产品帮你做数据回流。所以「得在那种有产品的地方做这东西才能做得成」。

【00:16:13】具身方向「更吃资本、更吃大团队、更吃公司，而非一拨比较厉害的人就能干起来」。

## 三、视频生成：能力分、抽卡与 Harness

【00:16:53】AI 短剧已经「几乎达到了 Netflix 的水平」；嘉宾认为这些能力没有到头，做到 Netflix 水平「没什么问题」。他提到《无敌超人》，认为里面加了很多专业的人为因素。

【00:17:20】创作中人的参与方式变了：不再像以前 heavy 地做很多事，而是更多希望你的 taste 去影响它的导向。这跟 code 有小差异——code 有公认的最优解（又快又好又整洁又好读），影片很多时候希望自己施加影响。所以多模态/具身里做 harness 或 agent「非常有必要」，「交互体验的成分其实是大于 code」。

【00:18:12】下一步：目前这个圈子还停留在「搞视频或玩视频的哥们会用这些工具」，还不够编辑；模型能力还没到电影质感，交互侧也还没有一套成熟产品让大家都用得上电影质感。嘉宾判断「未来一定得有一款这样的 Harness 出现，或者用交互式的中间层出现，套在能有电影质感的模型上边」，并认为这是多模态生成和 agent 接下来半年要推进到的水平。

【00:18:49】能力分口径：如果最强的那批（口播指 Seedance 2.5）能做到 100 分，「那他们现在应该做到了 60 分差不多」，后面空间很大。

【00:19:20】抽卡会长期存在，但含义会变：现在抽到的是很差的 clip；未来的抽卡「并不是质量的问题，它都很好，只是你和我的偏好不一样」，即对「什么叫好影片」的 taste 不一样。类比线下拍摄拍几段最后给导演选一段。未来可能要选「刘德华还是陈道明」、要不要用某种镜头语言。精细控制可以通过 rich caption / rich description 做到，但要让人在手机或电脑上敲非常丰富的描述「你也累啊」，所以还是机器根据前面的影片 propose 几个、你再选——「这个我觉得就是所谓 taste 了」。

【00:21:12】复制热门视频的能力会被包进模型：「这就是所谓的生成的一体化」，他用了一个 [?] 的词来表达，意思是「理解能帮助生成，生成虽然不一定能帮助，但理解一定能帮助生成」——比如换人，需要非常好的影片理解能力，才能生成得好。

【00:21:53】影视方向的门槛：现在消费的人远多于创作的人，创作依然麻烦、成本高。未来半年到一年要把门槛和成本全拉下来，让更多人生成，形成「既是生成者又是消费者」的平台。

## 四、H3 与实时互动：伪实时、真实时与「一致性」

【00:22:26】实时互动真正进入大众视野「应该是 H3 出来以后」——H3 做了一个实时互动的模型，在外网有点火。

【00:22:45】H3 的水平：嘉宾把 H3 的模型能力对标 Seedance 系列，口播在「3.0」与「2.0」之间摇摆（[?]），同时说它「还是会生成不少废的 clip」。Seedance 2.5 精细控制能力更强——能加很多 reference image / reference video，可以像 storyboard 一样插很多小图（人物正面背面、发型等物料），控制能力非常好，「H3 就不具备这个」，他认为字节在这一块有非常强的优势。

【00:23:55】实时互动分两类：伪实时（生成速度快于消费速度，但还是你打完它生成，只是快到像实时）与真实时（真的能跟你的对话做反应）。他认为大家都在第一条路线，而第一条现在也没有很成熟；第二条更像世界模型。

【00:24:34】「崩」指的是一致性问题。加速有很多 trick：scheduler 与降噪技术、infra 层的 T-Cache 跳层（不必每层都做降噪）、蒸馏、宋阳等人做的 consistency 一步生成——但这些东西整体来说「容易让它更容易崩」：镜头转回来后边的东西就变了、人脸就变了。

【00:25:21】「保质量比保 real time 更好」，real time 是一个阶段，两者一起往前走。他对真 real time「有一点点悲观」：模型越来越大，为了 consistency 更好把更多能力堆进去，天然就更慢。现在大家先保质量、保落地实用，主线没有在追求实时互动；但如果哪天做到足够好，「突然会出现一个视频领域的 [?] 的感觉」，舍弃很多东西但速度更快、成本更低。

【00:26:19】他强调自己「还在 60 分，还没到能力溢出的」，离那个点还有很大距离。

【00:26:31】关于 H3 外网/直播平台上的实时生成演示：他用过 H3，也训过它的后训练，体感是「没有那么容易，还是很慢」；现在「OK 我生个视频，我等半天我才做完这一圈，然后再去做二奥（创作）」，与宣传中的实时差得挺远。

## 五、世界模型与具身的两条路线

【00:27:05】视频 world model：两拨人在玩，一拨做 VSD/coscotral 式的生成——给定一个 action 往下生成；最早是 Google 发的 demo。最近有些结果很像塞尔达在地图上瞎闲逛、跑图那种感觉，但视频质量还不太行；这个圈子最近「又不太火又不太好」。

【00:27:46】为什么世界模型圈「有点迷茫」：不知道这东西 for what；另一波冲击是 Astra 这种大模型加上更小的「地球人」去做渲染——直接出一个巨大模型仿真整个世界，然后你在里面逛，看起来更 [?]；而且「老大还卖了」，讲了好几年故事最后不做了。嘉宾反问：如果世界模型真能做好、交互真的能做好，「李飞飞他为啥要买公司？他缺钱？肯定不缺」。

【00:28:38】嘉宾的判断：做 research 的同学一直都知道这件事非常难、短期做不出来，是市场情绪把大家架在了那上面。很多小厂商都做过 video world model，做出来其实是为了具身——「你要做具身，为啥不直接做具身呢」。后来发现具身没有必要完全走这条路。

【00:30:05】路线之变：具身后来发现并不需要先理解完整个世界再做 action，「我就理解我当前，然后就 action 一步，然后再理解下一个，再往下做就结束了」。像 LeCun 那样不需要把草啊、叶子啊、树叶都做光线建模得很好；不需要这样，「你可能就是理解加做 action，这个就做具身就足够了」。real-to-sim-to-real 那条路慢慢变味了。

【00:30:55】具身的两条正确路线：第一波是想做巨大模型——国内国外都有；市场上一直有种传闻说国内具身公司融了非常多钱，但真正花钱的少；几个大厂的组说「我这么的大模型、好的模型能不能调一下做具身」，逻辑类似 Astra。初创公司基本不做这条——没有技术积累、没有基金、没有卡、没有钱。

【00:31:54】数字口径：国内具身公司现在最高的估值大概在 200 亿人民币左右，账上一共五六十亿，走不到十亿美金，跟真做模型的公司没法比。

【00:32:18】结论：具身公司讲道理最终会变成两个系统——一个直接操控本体的（System 1），一个语言与思考能力非常强的大脑（System 2）。

## 六、Astra 为什么让具身圈震动

【00:32:37】具身需要什么模型：能看懂世界，然后给自己的硬件下一个指令，最后输出一个低维 vector（「可能二十多维」），每一维都有准确意义（表示关节角等），而非大模型常规理解上的那种 latent（口播举例「4 乘 9、6」）。图式化理解：就是机械手或机械臂每个电机怎么动多少度。模型结构是输入 video（可能多角度）→ video tokenize → latent 进来 → transformer/diffuser → 输出这样一个小 vector，是「高维到低维」的 input-output 结构。

【00:33:53】为什么以前没有震动：让 language model 输出一个 vector 很正常但没意义——让 LM「写一串数字」再解析成关节角度去操控，不正常；一是觉得不成，二是即使做出来也不 work，它输出的是文本 token prediction（口播举例「0.96、0.96」这样一串文字），「这有点有点变态」。

【00:34:33】这次震动的原因：Astra 有非常好的 3D 理解能力，并且能按你的指令真的输出一段序列，这段序列真的有意义、真的就能操控。（他自认对 OAI 内部只有「粗浅的理解」，并说「应该是」专门基于具身训的。）

【00:34:48】他转述的内部情况：OAI 做具身的团队「有点不知道怎么做」；他们做数据、做能力提升其实是为了给 VLM 帮着提升，而 VLM 发现能力的主要提升来自 LM；最后所有数据还是回滚到主线 language 模型上。据他听说 OAI 里有两条线，一条类似通用 LM 线、只是把具身当作其中一部分来泛化，另一条专门做具身。

【00:35:41】嘉宾自己的解释：Astra 的做法「其实也是一种泛化」，就像它做 3D（口播提到 Blender）那样最后也是这么推过去的。这个泛化里比较核心的两点：多模态理解做得非常强；真的有大量具身数据（「这波是真的训了具身数据了」，之前即便有也非常少）。

【00:36:31】本体差异：每家的本体和设备参数都不一样，所以每家还得自己做 transfer。机械臂是大家都在用的；而对人形/复杂本体（如 [?] 提到的某家）来说是有困难的——「它其实不准，是通过它动一个关节之后的效果、视觉效果，然后猜出来它的一个变量的变化代表你的哪个关节，会带来什么样的效果」，相当于输出一段、看一段视频，在多轮交互里看明白了视觉和输出的关系，「所以它能动得非常好」。

【00:37:27】Reward：他觉得不像真的对着具身 train reward，而是「通过其他的领域迁移过来的」——Blender 里操作一下，视觉上的 3D 效果会怎么变，它其实是能形成关系的。

【00:38:02】数据两条线：实体的真机（ego-centric）数据 vs 虚拟仿真数据。仿真数据对大模型很有价值，它是一个很好的 environment、像个 game；但对具身厂商不一定——他们 care 的是能不能落地、能不能操控他家机器，所以要用 exactly 他的机型去采各种 trace，失败的成功都要，失败的加 dagger 让人类接管继续成功。

【00:39:05】真机数据的价值会不会下降？他的回答是不会：对于真正的操控成功性，尤其在复杂本体的情况下，「你还是得拿真正 exactly 的数据去 train、去调」。举例：抓东西用两个手指也能捏起来，但真正想要的抓是五个手指非常贴合地抓住瓶子；全是仿真环境，可能最后用中指和食指捏起来了，但不符合你想要的效果——「这是我觉得最后仿真环境那个 gap」。

【00:39:45】如果仿真环境做得足够好，real-to-sim-to-real 确实能够 scaling up，具身厂商和大厂厂商都会走那条路；但目前 simulation 环境非常难做——物理仿真仿不好，各种物理的摩擦系数这些都很难做。

【00:40:56】「大脑」会不会变成大模型厂商的竞争：很多公司讲大脑是为了估值。嘉宾提到某个主页上写过 SYSM0、SYSM1、SYSM2（主人与出处 [?]），是 Astra 出来之前画的；现在他觉得「那就可能不要 0 了，就是 0 和 1 是一个，然后 2 是一个」——2 就是 exactly 那个最大最大的模型。所以趋势是「1、2 直接操控本体的那个，和一个贼大个的、语言 thinker 能力都非常强的上面的大脑，2、1 两个组合」。

【00:41:39】卡：具身厂商的卡「远远不够远远不够」，与大模型厂商的卡的差距「可能你后边加俩零」；大模型是五六家（六小龙之类）在分卡，具身是上百家在分那些卡，而且还得是 LM 剩下的。

【00:42:02】估值：去年他们就觉得具身估值怎么这么高、有泡沫，「结果今年没想到更上一层楼」；Astra 这件事出来对整个具身的「大脑故事」有非常大的影响。

## 七、为什么此时入局：个人志趣与生产力

【00:42:35】他被问「做视频不好吗、做那个是没机会吗」时的回答：不是没机会，确实可以去大厂做这个；但「这个东西它不是硬核生产力，它是付我精神享受的，我觉得我想做的」。他说如果要在这个行业干十几年、二十几年，「那我可能希望说能够更多的……如果说改变人类这个事大家可能觉得有点抽象，但这个哥们确实应该做点能够影响大家、更生产力方向的东西」。所以他最后想做 physical AI——把 AI 带到物理世界、以各种形式真正进入生活，「你到 Physical 领域，你才能改变大家的生活」，他对此非常坚定，所以转的；「所以它不是一个短期的选择、纯好奇」。

【00:43:28】短期驱动的最理想选择是当年就做 agent：「TikTok 给了一个还是相当可观的 package」，按他的说法现在可能就在美国做 agent（口播提到今年美国 TikTok 给 package 去做 agent）；对方现在也是套在当时的 [?] 视频上的一套 agent。

【00:43:57】AI for science 没考虑过，但他相对了解：两拨人在玩，一拨搞 science 的哥们搞 AI（他老板 PHD 是 MIT 物理系，解 PDE/ODE；应用场景例如 WiFi 信号覆盖怎么布置最好、流体力学）；另一拨是 AI for 化学帮做实验。他强调 AI for 化学还是需要有一个实验工厂去做真实实验，「而非纯干实验」——「就跟具身线下的那些素材什么有点像，素材也是工厂」。

## 八、Agent / 多模态 / 具身三点总结与小厂的活法

【00:45:32】Agent：智力水平「完全 OK」，问题是怎么让大家更好用；现在大家主线推的 GUI/CLI，核心还是「你怎么让大家用得上」。他判断 Personal AI 就是 agent 这条线最终的终点。现在开发的场景还是不够多（比如 Game Agent 少），下一个爆点是什么他想不到，「这可能还是得看 Astra」。关于 coding：能力提升已经很难准确说出从哪一点变好了，因为大部分情况下它已经超过 AI Infra 人的平均水平，「我不觉得谁能自信地搞 AI Infra 说他能觉得它不好」。

【00:46:42】多模态（他自称「悲观说」）：图片没什么可做的了，主要就是做视频，方向是提升视频可控性以及视频里的 harness 交互；「未来半年肯定有更好的交互的 studio，或者交互的 harness 产生」。模型层面，大厂竞争「据我了解也没有什么重头再来 pre-train 自己的 video model」，因为视频很贵：早年间做视频的都要爬 YouTube，24 年底 25 年初还能爬，「现在咋爬，根本爬不动，一爬就封号」，各个平台的反爬机制都非常好了。

【00:47:38】具身「玩法不一样」：大厂有大厂的玩法（做上面那一套）；小厂要有壁垒——要有自己的硬件，「要不然怎么跟大厂做差异化呢」。硬件指：大家都有自己的本体，谁的硬件做得更好、谁能把自己的硬件和那个 System 1 绑定着做得更好，「就是 co-design 的逻辑」，然后上面再套一个 Astra，「我个人认为小厂的核心的壁垒」，「要不然变成制造业了」。小厂的具体逻辑是：做好自己的本体/产品，绑定自己的 7B 到 16B 小模型调得更好，对接外边的一个大模型，把这一套跑通，尽快落地——「就像估值这么高，你想要让它更高，你只能是真的落地、真的能够有场景」。

【00:48:26】落地场景举例：酒店叠被子。酒店地面是平的，可以用轮式而非双足机器人；酒店「既不是纯标准化也不是非标准化的场景，它是某种程度上固定的场景，但又不太一样」，所以这类场景是能做一做的。

【00:48:55】GPT-3 时刻：Astra「确实有点算」。它甚至能替代部分素材源：模型成功率只有 50%–60% 时，在没训过的场景泛化到 50% 已经非常不错；出问题就及时让 GPT 接管（看视频判断要接管，然后把后面的操作 route 给 GPT），而这条遥操数据非常有价值，被留存下来，再迭代把自家 7B/8B 模型的成功率从 60 拉到 80；这样就可以在没有人的情况下遥操，再出问题再 route 给机器人；再不行由数台人盯（不是一个人盯一个）及时接管——形成一套比较优秀的数据管线：成功率提高 → GPT 调用量变少 → 人的负担减小，「你 scale-off 的逻辑可能才能真的成型」。

【00:50:23】最终可能是「大模型管制的 speculative decoding」：小模型先 draft 一遍，大模型只是 pull 或者不 pull。落到具身里就是小模型先一顿操作，快 fail 了才接管；「这条接管数据……也叫 recovery，其实是数据里非常有价值的，就是失败了情况下怎么回来」，然后再回流，形成真正意义上能赚起来的管线。因为具身很难家用的情况下你很难回流这些数据，不像 GPT 你用一用它就给你回流数据。

【00:51:06】蒸馏分两种：硬蒸馏（真的让模型学出来，像 language 里那样蒸馏）——「具体上你蒸不了，这个东西实在是成本过高，就是没必要」；软蒸馏（就是刚才讲的接管 trace 回流）——量小很多，而且可能把机器人带回正常的轨迹或正常的行为模式，自己的模型还能继续操作，相当于只争了这一两步，「这个我觉得是大家能接受、也能成本 cover 住的，而且很有价值的数据」。这种软性蒸馏「大概率不是大厂在做，是具身厂在做，因为具身厂好布设备、好在场景里布这个东西」。

【00:52:24】收尾：具身在国内从 23 年开始到现在三年多，故事变了好几波，估值都很高，但 Astra 出来以后「大家又拉到同一起跑线」，而且解锁了非常多新的可做的事情。未来几年估值与市场怎么变化他不知道，但从具身本身的发展落地来讲会解锁新的各种可能性，「我是兴奋的」。他说 Astra 让他第一次感觉到「我靠，我这东西真的能落地、真的能做，方法能力这么强」，「它们还都不是 3.5 呢」，但对整个具身领域是一个非常重要的节点。
