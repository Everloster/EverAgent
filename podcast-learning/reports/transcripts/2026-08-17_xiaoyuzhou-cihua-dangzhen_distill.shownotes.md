今年 4 月，「蒸馏」意外出圈。
大模型在蒸馏语料，公司也开始把人的经验变成 AI 可以学习的数据。周天奕想到：人，能不能也被「蒸馏」进一个 skill？
他花了四个小时，用 Claude 做出第一版「同事.skill」。上线 5 天，它就在 GitHub 收获了 7.3k 星标，如今已经累计 23k。更出乎意料的是二创：「前任.skill」「名人.skill」陆续出现，这个原本没有被抱太高期望的项目，最后聚起 100 多位创作者，衍生出 200 多个 skills。
小红书上拥有近 10 万粉丝的 AI 博主 @蔡不菜（AI 版）则从自己的生活开始。第一次一个人到北京，租房、上班、遇见糟糕的房东，她用了两周做出「人生系统.skill」，把经历和每天发生的事存进 Obsidian，让 Agent 一点点理解自己。她和它练习拒绝、演讲，也会一起讨论要不要离开一家公司。
先做出第一版，再把它发出去。
Vibe Coding 让开始一件事的成本越来越低，一个想法可以在几个小时、几天里变成产品。但当所有人都能拥有最强的工具，真正拉开 builders 差距的是什么？
本期节目，我们和周天奕、蔡不菜从两个 skills 聊起：你怕被蒸馏吗？什么可以交给 Agent，什么还要自己亲手完成？当 AI 可以学习越来越多人的经验，我们还能靠什么保持自己的 context、taste 和表达？

同事.skill
由周天奕创作，它可以读取聊天记录、会议纪要、项目材料等内容，支持导入飞书、钉钉、Slack、微信聊天记录及 Markdown 文档，将一个人的技术能力、沟通风格和决策习惯「蒸馏」成可调用的 AI 技能包，实现工作代办。
人生系统 skill
蔡不菜用 Claude Code 和 Obsidian 搭建的个人系统。它会记录使用者过去的经历和每天发生的事，识别反复出现的行为模式，并结合读书记录提供建议。人生系统.skill 的使用说明已在小红书获得万次观看。
