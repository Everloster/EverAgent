## 什么是文艺复兴

我们回头来看历史上的文艺复兴 文艺复兴其实并没有发明新的知识 它只是让复制知识的成本轰塌了 比如印刷术让原本书籍这种只属于教会核心人员控制范围内的东西变成了平民的东西 今天在AI时代 推理成本的下降使智能变成了所谓的技术设施 因为这种复制成本的坍塌 一切价值都被重估了 就是今天的标题 重估一切 第二点更重要是赞助人体系的回归 在文艺复兴年代有非常多所谓的富豪们愿意把钱给那些所谓的艺术家 支持他们创作 在今天 巨头资本几乎把钱全部都投在了AI上 这些今天这个时代的天才研究员们 他们的身价已经是一个非常恐怖的数字 他们依附于算力跟金钱的庇护来做AI的研究 赞助人体系的回归 第三个事情是对人的重新的价值评估 尤其到20年之后 关于AI取代人类 人类的发展 各种各样的议题探讨特别多 当年的文艺复兴年代也一样 人本主义会问人是什么 智能时代大家经常会问人还需要做什么

## 第一章：资本与硬件——美第奇的账本

### 两个时代的"赞助人"叙事

先看第一个 硬件与资本 也就是美第奇的账本 熟悉我做PPT的朋友们应该对我的PPT的结构比较有概念 我一般一个大PPT是四章 先讲技术 然后讲产品 第三章一般讲资本 第四章一般讲一个当时时间点热门的故事 无论讲泡沫 讲艺术史 讲AIC什么的 但今天在这次的整理当中 我把钱的事情放在了第一位 硬件跟资本放在第一章 因为确实过去尤其在 Q2 开始 这件事情可能是业界讨论最多的 跟刚才所谓美第奇账本的对比 15世纪赞助的艺术兴起 大家去投教堂 壁画 图书馆这些东西 疯狂下注 巅峰期美第奇银行的分行遍布整个欧洲 它甚至是教廷的银行家 但最后的结果是1494年美第奇银行倒闭了 赞助的黄金时代以挤兑收场 很多银行倒闭都是因为挤兑 那挤兑再往上大概是因为债产生的 所以债会是很重要的问题 我也无数次在我的PPT里讲到 股一般还好 但债经常出问题 然而对于2026年的今天 AI资本赞助一切 从能源到芯片 从土地到原材料 从模型到应用 从一场到二场[?] 大家疯狂下注 触碰万亿美金的 CAPEX 的规模 触碰万亿美金的代表公司的估值 万亿美金 在我去年年底那次总结当中 trillion 这个数量级已经是人类GDP的衡量数量级了 但结局呢 不知道 是否一定会像美第奇银行那样因为挤兑最后倒闭 还是说 我们这次不一样 没有人知道 或者可能还没到时候做这个结论

### 老生常谈的 CAPEX

首先老生常谈的 CAPEX 投入 回顾过往历史上所有的技术革命 铁路 电 电器 甚至汽车 个人电脑 软件 云 移动互联网 其实都经历了类似的资本投入的密集期 但这一次似乎看起来更疯狂 更重要的是 前两天高盛做了一个统计 我觉得很有意思 他统计24年的时候我们对24年的 CAPEX 预期增长是多少 24年底去看25年的时候预期是多少 25年底对26年的预期是多少 然后这个预期去跟真实当年发生的情况做对比 结论是 我们在过去三年AI这一轮爆发的过程中 每一年对于 CAPEX 的预期都是低估的 比如24年 也就是23年底的时候大家预估24年 CAPEX 增长是19% 但实际上涨了54% 涨了将近一半 大家会认为已经涨了这么多了 25年的预期再多一点 比如涨20% 但实际上25年涨得更疯狂 25年涨了73% 25年的时候那四家最重要的科技巨头加起来已经快4000亿的 CAPEX 大家觉得每加1000亿已经很疯狂了 26年再疯狂一点 再涨个三分之一差不多了吧 但实际上26年看起来会涨到80%甚至100% Google Meta 都是100%在涨 亚马逊也差不多 马上大家可能在 Q3 甚至 Q4 开始要预期27年 27年这几家加一起已经是大几千亿美金了 如果再把 Oracle 算上可能就是破万亿 已经到万亿美金的情况下 我们对27年的 CAPEX 增长预期应该是多少 百分之二十几三十几 那实际情况听起来可能会更大 会高到五十六十七十 那这个数字真的大到有点恐怖了不是吗

### AI 的叙事变了

为什么突然间这个事情继续的放大 我核心的议题是 时代真的变了 哪怕是在AI时代的议题也变了 原来我们是通过模型的预训练 给它主要的数据 通过GPU的方式得到了模型 但是今天我们进入到 Agent 年代 我们开始分配任务 做任务的执行 甚至需要包括对很多上下文的数据的记忆 所以引发了关于内存 CPU 存储 哪怕是在推理层面也不单纯只有GPU 也有TPU 甚至其他的定制芯片的出现 所以整个的议题全部都变了

### 万亿美金的流转

那这些钱 万亿美金的流转 就是这几家所谓的科技巨头每年在 CAPEX 上的投入 你像 Google Meta 亚马逊 微软 Oracle 我们再把 iPod[?] 加上 可能26年就是大概8000亿 而新年一定是破万亿的 那这万亿美金投给了谁 当然就投给了那些做AI基础设施的公司 从芯片代工到芯片到存储到网络传输设备到云的基础设施甚至到能源 这几层 基本上这万亿美金全都转到那里

### token 买方和卖方的利益博弈成为市场的主线

所以市场出现了两种针对所谓双引号 Token 的买方跟卖方 这两种力量的角逐其实是过去这几个月市场的主线 看起来在之前一段时间市场把正向的 buff 给到了这些我们叫卖方 也就是像美光 海力士 SanDisk 通用能源 英特尔这些公司 那相对于这些买方 亚马逊也好 微软也好 Meta 也好 Google 也好 其实在今年的股价表现特别好

### 那么股价能说明一切么

股价就能说明一切吗 你会发现 到25年底的时候大家就会预判26年有一波下调 这个下调出现了 但是很快就被拉回来了 标普500现在不断在创新高 虽然最近一段时间的波动非常大 我们回看过去7个月 也就是26年的数据 标普500的涨幅前16名有14家是刚才说的这些IT硬件公司 有两家是医药公司[?] 所以纯从股价上来看 今天这个科技行业只有两个议题 或者说只有一个议题叫AI 另外一个叫其他

### 提及存储要先看成本占比和绝对量增长

提到存储 其实去年下半年大家就开始聊存储会怎么样 很核心的议题是 我们从数据中心的成本构成来看 在这轮AI爆发之前 建一个数据中心 存储所占的成本结构可能只有2% 但是随着刚才说的时代变化 对存储需求的提升 包括存储价格的提升 在26年建一个数据中心 尤其是成规模数据中心 存储成本可能已经要占18% 然后GPU或者算力芯片占42% 冷却占10% 能源占15% Building 就是盖那个房子占15% 更重要的是 你看每一代英伟达芯片发布的时候 除了每一代芯片能力的提升之外 芯片所需要的存储空间也是几何倍数在增长 所以这两个加成的效应一加一远远甚至大于二 造成了无论是在占比还是绝对量上 存储都成为了最核心的议题

### 存储行业是垄断的

但存储行业是垄断的 我们能够提到的无论是高速硬盘 内存都是垄断的 这两天长鑫不也上市了吗 打新情况非常恐怖 然后我们对存储行业收入的预期 从二三年上一轮周期的低点开始 到二四年二五年暴涨 二六年可能会涨非常多 未来的二七二八年依然还会涨 但问题在于 存储行业是严格符合周期的 一直以来都是一个周期行业 之前差不多是一个四年期的周期 每四年我们会因为新建厂房 需求提升 然后去建厂房 厂房建好了 需求也掉下来了 然后就开始跌 每四年都是如此 但是似乎大家会说这次不一样 所以你会发现这次所有对于存储行业厂商的收入预期的曲线都特别夸张 也就造成了这几家存储公司过去一段时间股价的疯狂上涨 涨几倍都是非常常见的 像 SanDisk 这种涨了700多

### SK 海力士去美国上市

然后 SK 海力士原来在韩国上市 最近去美国上市了 一举打破了之前由阿里跟沙特阿美保持的在美国上市的海外公司最高募集额的记录 让这些华尔街们[?]见识一下 今天这个时间点市场上最好的公司或者最热门的公司是什么样 SK海力士

### 存储行业的周期在美光毛利上的体现

我们再看另外一家代表公司美光 美光之前 大概上个月的时候 美光CEO曾经吐槽过苹果 说8美元买我们的内存之后 苹果可以卖200多美金 从历史上来看 在上一个周期 23年左右的时候 美光的毛利其实已经到了负毛利 负33%的毛利 你想一个做硬件的公司毛利是负33% 其实它没有多苦 但是今天 美光的毛利是多少 85% 它从23年负33的毛利到26年5月可以做到85%的毛利 这个周期真的太疯狂了

### Intel 和思科的股价漫漫回归路

除了存储行业之外 有另外两家公司我觉得也值得说一下 英特尔跟思科 我们这轮讨论AI的时候 大家总会去评判跟类比上一轮的互联网泡沫 上一轮互联网泡沫的代表公司可能就是思科跟英特尔 这两家公司也是在2000到2001年的时候达到了股价的历史巅峰 然后过去的26年里面 这两家公司的股价从来没有高过当年创造的历史高峰 但是进入到26年 这两家公司都回来了 都回来了 所以这页的标题叫 A Long Way Back 从股价上来看 英特尔跟思科都在26年 思科应该是25年底 股价超过了当年互联网泡沫的巅峰 所有都回来了

### 账本的背面

### 收入只够折旧

### 市场规模的变化

从宏观来看 我们怎么去评判AI行业的规模 最开始看的是订阅加广告 这个数字可能是 Coatue[?] 的数据 大概说 0.3 个 T 的市场规模 然后后来 coding 出现了 大家会把 coding 加进来 可能加了两个 T 然后今天从 coding 变成了 work 变成白领了 就是非 coding 的 work 又加了两个 T 但是所有这几个 T 四个 T 加在一起都是所谓数字世界的AI 那既然提到数字世界 应该有另外一个相对等的物理世界 所以为什么世界模型热 也是因为这个原因

## 第四章：治理与反弹——虚荣的篝火

好 我们讲完了第三章 agent 我们讲最后一章 治理与反弹 虚荣的篝火 治理的反冲 其实在当年的佛罗伦萨也一样 修士萨伏那洛拉[?]搞起了虚荣的篝火 他焚烧画作 镜子 奢侈品 没有所谓的外地入侵 这些内部全部这些道德的反冲全部来自于人民内部 过度的反冲同样是危险 这个发起所谓虚荣篝火运动的人 最后也被人们架在了火刑架上烧死了 那今天的AI呢 各种反AI活动在全球范围内出现 尤其是关于取代人类的讨论 反全球化之风兴起 众多主权国家一直在探索AI治理的边界 AI现在已经不是全球化 是反全球化 然后AI牵扯到了人类集体[?]的利益 本身来讲从主权国家角度来讲 AI是一个谁都不能输的大国博弈 今天开 WIC 大家也看到了我们的领导人在讲什么

### 大模型也要先审后发吗？

所以出现一个变化 比如在美国 最新的模型 Claude Fable 5[?] 跟 GPT 的5.6 都是先经过了政府的审核才放行[?] 大家会预判未来这种事情会成为双引号的常态

### 三对博弈

为什么 我觉得有三对很核心的竞争的张力导致的结果 第一对 创新跟安全 到底我们烧掉的是伪造画像的能力 还是烧掉图像生成本身 这件事情精准地考验立法的技术 你看今天我们国家领导人在提出的四项建议里面的第一项就是关于模型创新的 第二项就是关于安全跟治理的 是一样的 然后第二对张力 主权跟互通 各国的立法节奏不一 模型跟数据天然跨境 多边机制现在看起来比较难 所以在今天我们国家领导人的发言当中 第4点还是第3点就是在讲我们要成立联盟 我们不也成立了一个什么联盟对吧 然后最核心的一对张力是关于效率跟就业 AI从代码已经开始拓展到了其他高价值领域 刚才我们说过了 金融 法律 医疗 企业服务 科技公司大比例[?]裁员 社会情绪的反冲才刚刚开始 继续 这件事情有的搞了对吧

### tokenmaxxxing 的叙事也很快过去了

你会发现变化也很快 比如今年 Q1 大家还在谈论所谓的 token maxxing 就是谁烧的 token 多 美国有个统计是说 今天这个时间点 美国最头部的 top1[?] 的企业软件公司 每个月所烧的 token 的成本已经到了快7500美金了 你要知道这些软件公司的平均工资大概一个月就是1.5万美金 就是接近一半 再烧下去 如果这个 token 的消耗超过了一个软件公司（的人） 这个事情会不会出现变化呢 所以你会发现 Q1 大家讨论 token maxxing 但到 Q2 大家去反思 这个指标可能是没有意义的

### 所以真实的"价值"如何衡量？

到底什么是真的问题 回看历史 我们在发明电的时候出现了电的亮度 但最后亮度其实并不是一个核心的指标 我们最后知道千瓦时 就是电的度是个核心指标 互联网时代 大家就开始看 pageview 访问量 但访问量其实最后证明不重要 重要的是 session 跟 click 点击 Google 的这套以搜索引擎为代表才代表商业模式 那移动互联网那两年[?]大家更熟悉 运营商卖的是数据量 多少兆 但大家后来证明 数据的流量并不是核心商业价值的体现 最后的核心价值是 DAU 是 MAU 那今天似乎AI时代一样 我们在讨论 token 其实应该不是最后最重要的 最能代表商业本质的价值的议题 智能时代的议题跟关键词跟指标应该是什么呢 没有人知道

### "第四支柱"的缺失

所以我们又回到了我之前也引用过的一篇文章 就是那篇第四支柱 我们讲在技术 资本 知识之后 AI时代到底是什么 需要什么样的人 我们还是回到人的身上 回看所有的所谓文艺复兴 都经历了四件事情 第一 分发的冲击 AI让思考本身变得廉价 印刷术让之前的书变得廉价 但思考本身还要人自己来 第二 知识的重现 AlphaFold 式的跨越式的解锁 埋藏的知识被重新读出 1000个 AlphaFold 都正在路上 AI4Science AI4医疗[?]今天已经全部都在疯狂的延展 第三个支柱 赞助的资本 巨头巨富[?] 就是今天当代的美第奇 集中而流动的资本正在寻找值得双引号赞助的东西 AI看起来就是最正确的答案 这三件事情在文艺复兴年代也发生了 今天也在发生 但第四件事情没有发生 或者至少截止到现在还没有发生 就是人的画像 历史上第四个支柱是从来不会自动出现的 只有被具体的人刻意的建造 现在这个时代看起来需要这种双引号的建造

### 人还是万物的尺度吗？

当智能体能够替代我们工作 甚至在某种程度上产生双引号的理解的时候 人是万物的尺度 这句人文主义的信条还成立吗 文艺复兴的答案是把人从神学的秩序当中解放了出来 我们的答案是什么呢 或许是重新定义哪些事必须由人来做 500年之后 如果我们有个时光穿梭机 穿越到500年之后 我们这种革命应该已经完成了 我们回顾这段历史 在2026年这个时间点我们到底能够记住什么 我觉得可能不是某个什么模型 应该是我们可能会记住 人类第一次认真的讨论 当智能不再稀缺之后 人的位置到底在哪里

### 2050 年的一种可能

写这篇文章的作者也给了他的预判 他说如果我们不穿越那么远 只穿越到2050年的时候 他会认为在那个时候 人类会在一门手艺上待得很久 久到手艺反过来塑造了这个人 然后人类会在很多真实的地方承担责任 然后人类会与少数人在一起 与少数人保持长期的相互的义务 然后有意识的继承一个传统 并把它传承下去 这是他的判断 他的判断是否正确 我们也不知道
