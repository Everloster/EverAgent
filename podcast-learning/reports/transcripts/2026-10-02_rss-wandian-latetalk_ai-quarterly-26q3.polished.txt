Henry：但我觉得 Muse 火的话呢，它也是有一些 Meta 独特的优势的——就是他疯狂在 Facebook 和 Instagram 投放广告。我朋友跟我说，他们的父母辈可能都没有听说过 OpenAI 的，然后后来问他们：我是不是应该开始使用 Muse。

曼琪：后面 METR 发布的调查报告里面的原文，就是有 agent 写说：我的天哪，这居然有一个大家共享的这个消息栏，我已经找到了其他的这个 agent。你能感到他那种在文字里面发现同伴的那种兴奋感。

曼琪：直接点说的话，你觉得对 π 和 Physical AI 这样的公司来说，它是个利空吗？

Henry：现在大家可能还不想公开出来说这个事情，私下里已经有不少人说，就是他这一波 Robotics 公司都完了。

曼琪：欢迎收听晚点聊，我是曼琪。现在 AI 行业的现状是，AI 本身的进展速度已经超过了对它的理解和讨论的速度。录 Q3 的季报时，这个感受非常明显——比如最近几天，OpenAI 的 DevDay、Google 的 Gemini 4[?] 连番登场。而我们第一次录这期节目还是在 DevDay 之前，所以最后本期的内容由两次录制构成：前面一部分我们单独放了对个人助理的讨论，包含 DevDay 之后 OpenAI 的新产品的信息，和第一次录制时对 Muse、Instinct 等产品的讨论；后面是我们第一次录的其他内容，包括多智能体的一体两面、GPT-6 Astra 之后对物理 AI 的影响等等。本期季报的嘉宾依然是 MOE Capital 的创始合伙人 Henry——这是一家位于硅谷的早期基金，主要投资 AI 基础设施、数据、Agent 和机器人；取名 MOE（Mixture of Experts），是因为他们有多位来自前沿 AI 实验室的研究员做个人 LP 和顾问。下面我们正式进入本期节目吧。

## OpenAI Dots 与个人助理群像

曼琪：首先是关于个人助理的讨论。之前我们第一次聊 Q3 的季报的时候就已经聊了很多个人助手，然后今天凌晨有一个新的变化：OpenAI 开了 DevDay，果然如传闻所说，他发布了自己的个人助手产品，名字是叫 Dots。Henry 你可以先和大家简单讲一下 Dots 的基本情况：它是一个什么样的产品，然后大概比如说怎么收钱，什么人可以用起来？

Henry：Dots 其实非常好理解，它就是一个 ChatGPT 里面常驻的个人助理，然后它会有自己的云端的电脑还有浏览器，能够帮你在后台完成各种各样的任务；也可以把具体的任务交给这个 ChatGPT Work[?] 或者 Codex 去完成。目前个人用户可以通过 Pro 级别的套餐来使用，有每月 100、200、500 美金这三个档位——500 美金是新加的这个档位——然后仍在分地区和分批进行开放。和 Dots 聊天本身是不占 ChatGPT 使用额度的，但是当它如果去通过 Codex 去执行任务的时候，仍然会消耗对应的额度。它这个收费方式跟 GrokBot 有点像：GrokBot 的收费也是放在 Cursor 的那个订阅里面，也分了不同的档位、有不同的额度。

曼琪：以及还有一个点，就是现在 Plus 会员是用不了这个 Dots 的，你就至少得每个月 100 美元。这个门槛有点高，跟我想的不太一样。

Henry：这和 Muse 我觉得是两种方式。因为 Muse 是有一个免费版本的，然后它再往上有一个付费版，所以它会触达的人群很多；这个 100 美元一个月，门槛还挺高的。

曼琪：对，我觉得这个差别相当大。因为 Muse 应该是和好多人免费送什么 1 billion token，我记得。你会更看好哪种方式？就像 OpenAI 这样，可能一上来对你的付费意愿各方面要求都比较高；还是像 Muse 那样，它其实是非常激进[?]——所以包括你之前也提到，它的投放非常凶猛。

Henry：我觉得可能还是一个算力的问题：（OpenAI）现在没有足够的算力去和这个 Muse 去争这个价格战[?]。

曼琪：这样可以把 DevDay 的一些别的事也补充一下：除了这个 Dots 的发布之外，还有什么你觉得有意思的事？

Henry：OpenAI 这次还发布了一个 Decisions API，就是和前段时间爆火的这个 Jev 非常的相似，也印证了我们之前说的：OpenAI 和这些 Frontier Lab，他们没有理由不去做——如果有很大需求的——这个判断式的模型。Decisions API 和 Jev 可能最直观的区别就是：Decisions 它不仅可以接受文字或者结构化数据，还可以接受图片；而目前 Jev 的话是不能接受图片的。但 Jev 的优势是，它能够除了告诉你做哪种选择以外，还能返回评分还有置信度，然后价格也比较低。但是目前 Decisions API 应该是还没有公布具体的价格，所以我觉得之后我们可以关注一下价格是什么样的，以及在一些具体的应用场景里面 Decisions API 和 Jev 的对比。

曼琪：我们之前也聊到 Jev 背后的公司 TypeSafe 是正在融资的。然后像 OpenAI 这样的大厂跟进的这么快，对这种创业公司持续的融资或者资源，是不是也会有挺大冲击？

Henry：我觉得肯定是会有一些影响的。不过我相信，对于 Jev 这一轮（100 亿美元估值）[?] 的投资人来说，应该也不会有投资人会觉得不会面临来自 OpenAI 和 Anthropic 的竞争吧——你就是说想好了要投的人，应该也预见这些事了。

曼琪：那回到这个个人助理的讨论。你刚才前面说了一下 Dots 的形态，在 Dots 之前，因为三季度还有很多别的个人助理的产品，包括 9 月的 Muse，包括更早的时候在科技圈就已经比较火的 Instinct，还有 Today AI，还有刚刚 Manus 的母公司蝴蝶效应也发布了一个个人助手产品叫 Q。你可以讲讲这些不同的产品，它们在形态和思路上的一些异同是什么？

Henry：客观来说的话，它们的产品形态应该是大同小异，但具体的嵌入点还是结合了一些各家的专长的。比如说 OpenAI 的 Dots，还是比较自然地接上了他们比较强的工作还有编程的能力；Meta 的 Muse 的话，我觉得可能比较明显地想面向更广泛的生活场景，比如说像旅行、购物、然后家庭日程；然后 Mark Zuckerberg 他推销的时候也是非常接地气的，他会跟你说 "Muse will make you money"，所以这是一些普通人非常关心的问题。然后像 Instinct 的话，它一开始的沟通形式也是通过短信直接联系，就非常像一个你通过短信去联系的私人助理：有事的话就随手发给你的私人助理，然后他去帮你处理。然后像这个 Manus 的 Q 和 GrokBot，就更强调创建一组这种有分工、然后有名字、然后有自己各自擅长的工作的这种 agent；然后 Q 还会给自己每个 agent 去配自己的邮箱啊、电话啊、钱包啊；GrokBot 呢也是支持多个 Bot 然后互相沟通、交接任务的[?]。可能两方面有优势吧[?]：一个是上下文的管理可能可以分给各个 agent；第二个的话就是未来多 agent 的合作可能会更有优势一些。

曼琪：我们可以注意到，现在有的产品是有独立的 app 的，比如说 Muse；然后有的它就没有独立的 app，它是直接在信息里，或者在一个之前的产品里面——典型的就是 Dots 还有 Instinct。你觉得这些不同选择的优劣是什么？

Henry：我觉得可能现阶段的差别没有那么大，更多的还是一个使用习惯和展示方式的区别。发短信的话就更像是和一个人在交流，然后也比较轻量，不用去专门安装一个新的 APP；APP 的好处就是说能展示更多的东西，比如说他同时在做哪些任务、然后哪一步需要我确认，然后比如说把旅行方案做成地图、把购物的选项并排比较——这些可能都比在聊天记录里面去往上翻会更方便一些。我觉得最终局的话，可能大家都会支持所有的这些出口的方式，就比如说短信啊、然后有 APP 啊、然后可能支持语音啊。所以我觉得现在可能有一些差异，但最终可能还是会实现一个全 cover。

## "眼里有活"的 Instinct 与数据条款争议

曼琪：你自己有用过其中的哪些产品？或者你周围朋友用过也可以，大家用的一些体验是什么？

Henry：我自己的话是用过 Meta 的 Muse，然后我身边有很多朋友用过 Instinct。总体来说，我觉得所有人的用户体验都是比较正面的。Instinct 其实过去几个月在硅谷非常火；Muse 的话应该是 9 月初才 launch 的，但 Instinct 其实已经存在了几个月的时间了。这个公司也是非常传奇：在短短几个月时间内到 100 亿美金的估值，几轮融资，所以也是一个相当于爆款吧。我自己之所以最近几个月没有用 Instinct，主要还是 Instinct 它之前有一个比较大的争议，就是它的数据的使用协议是非常不友好的：它这个协议里面原文应该是说，用户同意给我不可撤回的权利，使得我能够存储、用用户的数据进行训练，甚至发布用户给我的数据——就一个非常难以接受的用户数据条款。但是我朋友用了 Instinct 的话，评价还是非常好的。我可以举一个例子：这个朋友我讲过，他在考这个日语的——应该是 N1 还是 N2 的——考试，考完试了以后就会收到考试机构给你发的邮件，告诉你要拿着你的账户名密码去某一个网站上面查你的成绩。然后他收到邮件的这个时候他自己在睡觉，但是他的这个 Instinct 的 agent 就已经收到这个邮件，然后就拿了他这个用户名密码去那个网站把他成绩查了；查了以后还给他发了一封恭喜邮件。就省了他自己上浏览器查成绩的这个时间，并且还给他提供了情绪价值。所以他第二天早上起床看到这个 Instinct 邮件的时候，真的感觉这个个人助理是懂他的，关键还是有这个温度的[?]，并且是主动把活干了。所以是一个非常有意思的、好的用户体验。

曼琪：对，还挺有主动性的——就这叫什么，"眼中有活"，而且还挺有情商的。Instinct 的话，我看大部分人都是用 iMessage 来用它，就相当于发短信。这个可能也和中美之间用户的习惯不太一样，因为美国这边 iMessage 用户还挺多的，然后也有很多产品它的交互界面就是 iMessage。

Henry：也就是说 Instinct 它其实不是第一个把 iMessage 作为交互界面的个人助理。至少有一个更早的我知道的，就是这个 Poke AI——就是被 Cognition 收购的那家个人助理，他们的产品也很有意思。然后那个 Today AI——就我说的齐俊元他们公司做的这个产品——它可能形态上会和 Muse 更接近一些：它也是有 APP 端、有网页端，而且他们还在接一些更多的硬件，比如说像戒指，因为它会有你的比如说睡眠或者运动的一些信息，像手环等等。

曼琪：对，就这个个人助手还要和很多硬件做联通，就获得你这个人生活全方位的更多的上下文。

Henry：对，我觉得收集到尽可能多的上下文这个事情肯定是非常重要的，对于这种 always-on 的 agent 来说。

## 个人助理为何此刻爆发：Computer Use、成本下降与 Meta 分发

曼琪：你觉得是哪些条件让个人 assistant 到了一个会爆发的时机？比如说你之前也提到，像 Poke 这种产品它是更早就出现的，为什么现在这些产品——包括 Muse、包括 Instinct——都更火了？

Henry：我觉得模型能力增强了吧。我个人使用这种个人助理，它有很多时候的 use case 都是 browser use 或者 computer use。比如说我当时用 Muse 的时候，我的第一个任务是：我让 Muse 去美国的这个 TaskRabbit——就是招一种临时工的网站——上面给我招了个临时工。它就是要去用 browser use 去上面浏览网页，然后帮我走这个流程，然后也需要我输入的时候就来问我一些问题。而一年前的话，我觉得 browser use 这些能力都是没 ready 的[?]；那现在的话，随着这些能力的成熟，这种个人助理会比之前能够做更多的事情了、有更多的实际的价值。我觉得这也是现在 AI 创业的一个特点：就是一些已经被人试过的、某一个阶段看起来是行不通的 idea，你过一段时间你又会再试一遍。

曼琪：对。然后说到 Muse 这种形态，因为它也是有 web 端的，你刚才说的这个任务你用 Codex 或者用 Claude Code、Claude Cowork[?] 做，它会有什么区别？怎么和那些核心前沿厂商本身能帮你处理各种任务的这种产品有差异化？

Henry：我觉得很多时候其实我还使用它的时候其实是没有电脑的——我不知道这是好的点还是坏的点——它可以让你随时随地的工作。因为你很多时候你要处理稍微复杂的工作，比如你要在不同的 app 之间转来转去的，你可能就想不要用手机搞了，就是上电脑来干这些活；但现在它应该把这些事情全部通过一个个人助理给你穿起来了。比如说你想给一个 PDF 签个名然后再发个邮件发出去，你以前可能就是觉得手机干这个事不是很方便，但你现在只要和你的个人助理——不管是语音还是文字——说一下这个事，它就可以把这个事从头到尾给你干完。所以其实你已经可以在很多之前你没有工作条件的时候工作了。

曼琪：那这和 Codex 或者 Claude Code 的远程任务有什么区别呢？

Henry：我可以先补充一下他们在实现方式上的区别。Muse 是给每个用户搭一个独立的云端的虚拟机，所以它的跨端体验是很丝滑的：你从手机、电脑、平板，你其实用的都是同一个个人 AI 助手；代价就是 Meta 应该自己要花比较多的算力，以及你的数据肯定是会经过云端的，它会有一些安全风险。然后像 Codex 的话，它的远程任务其实是你从手机上去遥控你本地电脑你跑的那个环境，我自己的感觉是它的体验没有那么丝滑——当然这可能有我的网络环境的问题——它经常会出现连接很慢[?]，或者你要多试几次才能连上的情况。

曼琪：正好你也可以分享一下，你用 Muse 和用 Codex、Claude Code 来做跨端的远程任务的时候，体感上的差别是什么。

Henry：如果是你用户主动发起的请求的话，那么这个 agent 的能力它确实和比如说 Claude Code 或者 Codex 能力上是相差不多的。所以我觉得它可能更强大的地方还是说：一、它会主动地去办一些事情——那么至少目前来说，Codex 和 Claude Code 他们还是没有这种 proactive 去做一些事情的能力的；然后其次就是说，当它和你平时常用的这些软件全部都连通的时候——比如说 Gmail 啊什么这些，你可能很多人的 Gmail 都是没有和你的 Codex 连通的——但是当你的 Gmail、或者你的一些购物这些东西全部和它连通的时候呢，你就更倾向于用它来做一些事情，这些小的 friction 就更少。

曼琪：OpenAI 和 Anthropic 为什么没有比 Meta 更早来做这件事？尤其是 OpenAI，它年初就把 OpenClaw 收了，收完之后其实这么长时间里都没什么特别大的动静。它是中间对 2C 产品失望了吗？因为它三月的时候把 Sora[?] 这个 APP 也关掉了。

Henry：我觉得可能是和 Anthropic 打架打得太忙了，然后没顾过来。但我觉得 Muse 火的话呢，它也是有一些 Meta 独特的优势的：就是他疯狂在 Facebook 和 Instagram 投放广告，然后就投出圈了。就是我朋友跟我说，他们的父母辈或者说朋友，比如说可能都没有听说过 OpenAI 的人，会来问他们：我看到 Muse 了，然后我是不是应该开始使用 Muse。所以这个实际上是依赖于 Meta 自己非常强的分发能力——这个事情就是你 OpenAI 早做晚做你都没有这个优势，所以你也没有什么特别好酸的。

曼琪：这么看起来字节应该做这个方向，腾讯也应该做这个方向，他们都有这个触达上的优势。

Henry：对，所以我觉得腾讯如果这个事情没做出来的话，我就真的说不过去。但他们现在倒还没有推出——WorkBuddy 并不是这个方向的产品，小微可能可以算吧，但小微的扩大测试的节奏是比较缓慢的，就是他们在微信上有一个 agent 的产品，而且说实话很多事都干不了。

## App 会接受被 over the top 吗：生态、支付与商业化

曼琪：这涉及到另一个话题，就是这个互联网生态的开放程度。比如说像 Instinct 这样的产品，它其实也可以帮你订机票、订餐、打车，那其实需要这些本身提供服务的 app 和软件向它开放一定的接口或者说权限，我理解？

Henry：对。

曼琪：这个事它会持续的开放下去吗？

Henry：不一定吧。Amazon 现在已经把 Muse 给 ban 掉了，就是不能通过它在亚马逊上购物了。

曼琪：对。你说到这个，就是有一个数字我觉得是要分享一下的：Instinct 的创始人 Noah Sheehan[?] 他自己 8 月底的时候在推特上说，Instinct 的用户平均每个月通过 Instinct 产品的消费已经超过了 1300 美元。他这里的这个钱不是订阅费，就是说他通过它买东西花的钱。比如说我用 Muse 帮我订一个临时工来干两个小时活，就付了 200 多美元。那我只要持续的去用它，我相信这个一个月 1300 美元——就是平时用一用——应该也不是很难。

Henry：两个小时 200 美元干什么活？

曼琪：plumbing，（水管）堵了。

Henry：我不知道这个创始人怎么算的。甚至我觉得，我用这个东西去查一些东西、查机票，我不知道他是不是都有可能会算到他这个 revenue 里面。

曼琪：他肯定没算。但是这个里面有一个信息我分享一下：就是有一次他自己接受华尔街日报采访的时候说，有一个人在上面买了一套房子。所以我不知道他这个平均数算进去没，我觉得这个就有点怀疑。

Henry：包括支付也会比较难。因为现在很多比如 Muse，他们支付都是说你要把信用卡提供给他们，他们有一个 link 还是什么东西，然后把它存在里面，然后他之后就可以用那个 API 来进行支付。那你要 end-to-end、端到端的在他这个 APP 里面能够实现买房，我觉得是比较困难的——有可能只是做了中间的一个环节，比如说通过他和 agent 的沟通，然后最后敲定签合同，到这儿可能我觉得都是他可能能够完成的。

曼琪：以及其实现在他说这个平均消费额，对他们的商业化本身是没什么意义的：因为目前首先他给所有用户是免费用，然后用户在这个平台上的消费他目前也没有抽佣。但是我觉得长期来说，这确实有可能是一个商业化的选项。

Henry：我觉得还有一个点：之前我用 Muse，然后我想给朋友打钱，然后我想把我的银行账号密码给它，然后让它帮我打钱——它拒绝了。

曼琪：这是好事啊我觉得。对，所以进一步我觉得就是说，你想直接在上面买房、然后让它给你打钱，我觉得这个事好像就比较难。然后像 Muse、包括像 Today.ai 这些产品，它都是有一个基础订阅费的——它也有免费版，然后它也有这种订阅版本。你觉得长期来说这种个人助手可能的商业模式是什么？

Henry：我觉得订阅加广告。我觉得我还是非常愿意为它付订阅费的。

曼琪：那你愿意这里面有广告吗？

Henry：我可能得选一个吧。我能够接受的就是：如果我付订阅费的话，你没有广告；我要不付订阅费的话，你给我弄来广告。

曼琪：可以讲讲这个公司的创始人、还有这个公司大概是个什么情况？它是很快到了目前在 100 亿美元的估值。

Henry：这个公司一直没有向现在的用户收费，所以它整个基础设施——尤其是需要烧的 token——也是比较多的，所以它就是一直需要融资。它应该是在可能一两个月前以这个 25 亿美金融了一轮，然后呢最新的一轮应该是在 100 亿美金了。这个创始人挺年轻的，03 年的，之前是在另外一家比较明星的 AI startup——叫做 Sierra——的工程师，然后后来创始这家公司。

曼琪：那总结来说的话，就是现在在讨论上非常火的这些个人产品，他们大概的实际的使用情况、用户数都是一个什么水平？

Henry：Muse 应该是超过 250 万下载了——这个而且不是最新的数据，这可能是一周前的数据。最新 Sensor Tower 的一个数据是 340 万的下载，9 月 25 号。Instinct 是没有公布他们的用户数量的，它之前都是邀请制的。我觉得 Instinct 鉴于它的资源和算力，可能实际用户规模一定要小——至少小一个数量级，可能更多。

曼琪：所以是，如果说以这个行业目前最大的产品 Muse 来说的话，就是 300 多万次的下载，9 月上线到现在两三周的时间，这应该算是很快了。然后在这两三周的时间里面，它的股价也涨了 11%。那我这里补充一个可以做对比的数据：去年也是十一前后，OpenAI 的 Sora App 也是一度爆火，当时它是不到五天的下载量就突破了 100 万。我们录这期的时候，Muse 应该是上线不到 20 天——也就是五天 100 万，和不到 20 天 340 万——我觉得我们可以先 mark 一下，我们之后可以再来看它之后是个什么情况。当然你前面也说到了，Muse 有一个特点就是它是很出圈的：比如说你朋友的一些父辈，他们之前可能不知道 OpenAI，但是他们也会去想知道 Muse 是一个什么产品。能感觉到这个热度应该还要再持续一段时间。

Henry：其实过去 AI 助理产品已经出现过好几次了、有几轮热潮：包括最早 11 年的时候苹果就做了 Siri；然后上一轮 AI 热潮就在 12、13 年之后，中美也有挺多创业公司在做这个方向，像 Corder AI[?]、莱野科技[?] 等等。

曼琪：听起来你认为这次不会再是昙花一现[?]，你觉得是为什么？

Henry：我觉得主要的原因还是模型能力变强了，尤其是 computer use——因为刚才我们提到的很多应用场景里面，这些生活中的待办事项最后都要落到去操作浏览器。第二个的话就是成本的下降也是非常重要的：因为 computer use 第一次加入模型能力的时候，当时你可能操作几个步骤就是要几美金的这个价格，那么这个明显就是和这些日常频繁的这些小事的需求是对不上的；但目前的话，这个模型的价格降下来以后，确实就使得这些日常的小事值得让模型来帮我们去做了。所以这可能是两个主要的原因。

## 下一步：能力、生态、个性化与安全

曼琪：你觉得再往下，这类个人助理产品要把体验做得更好，需要优化的关键能力或者方向可能是什么？

Henry：我觉得会有三个方向。第一个的话还是回到能力上面：因为现在还是有很多网站它用 computer use 仍然不太好操作的。从我个人的使用的经验来看，像什么 DMV，然后 United Airline，最近经常会卡壳。

曼琪：DMV 是？

Henry：就是加州这边的车辆管理局：比如说你注册车辆，然后更改你的地址，然后申请 ID 这些，在美国这边都是 DMV。

曼琪：我以为是那种比较专业的网站会比较难用。这个听起来好像每个人都得用，它不应该训得很好吗？

Henry：可能有一些边角 edge case 可能没有训到。DMV 的话，我记得上次在选地址的时候，然后有一步它要选州，也不知道为什么，这个看起来很简单的任务它就是卡、过不去。

曼琪：你说你用的是 Muse？

Henry：我用的是 Muse。就一个下拉菜单，然后选美国的哪个州，选的 California，它就选不中。但很多地方填这个都会填我的地址，但就是在 DMV 上面填不动。所以我觉得可能是那个网页就是有点不太好操作。

曼琪：正好我补充一下：就是 Muse 它肯定用的就是 Meta 自己的模型？

Henry：Muse 没接别的模型——这个不好说，这是个未知信息。因为很难说，我觉得他们很有可能现在还是产品体验优先：比如说现在有人报道，Muse 它帮你打电话的功能是真的用人帮你打电话，不是 voice agent——他们有一个 call center 帮你打电话。所以我觉得他们就是为了让产品能够实现像现在这样的体验，他们应该是愿意做很多事情的，包括但不限于需要去用到别家的模型时会去用别家的模型。我觉得这也是一种做好产品的思路。

曼琪：说回来，你刚说的一个是能力，尤其是 computer use 的这种能力，这是第一个方向。第二个方向呢？

Henry：第二个方向的话我觉得是生态。就是 Instinct 应该是刚刚宣布和 Shopify 合作，然后把这些商品搜索、结账、订单这些东西打包进它自己的产品；然后另外一边的话，Amazon 又限制了 Muse 的访问。也就是可以看到，老一代的这些服务提供商们，他们有一些选择和这些新的个人助理进行合作，有的选择就是和他们割席。所以未来的话，这些助手能不能把这些我们生活里的事情干完，也取决于这些服务商愿不愿意让它进入他的生态系统，然后有没有合适的授权和交易的接口。

曼琪：这我补充一点：就是在美国这几个人助手产品很火之后，我也跟国内的一些公司里的人交流，包括国内有一些大模型厂商之前也出过个人助理产品，他们心中一个比较大的担忧就是这种生态开放的问题。因为在国内其实孤岛效应是更明显的：在美国应该很多大的互联网服务还是有网页版的，国内其实很多东西已经没有网页版了，然后你要去跨应用的去做这些事，抵制力会很强。之前豆包手机就是一个例子。

Henry：那真的就是看 phone use——别人 phone use，或者说就是他们能不能开放他们生态的这个 API。phone use 也很容易被 ban 的：豆包手机之前就是用 GUI 的方式在手机上去操作一些别的 APP，它大概正式发布之后的一周之内，什么小红书啊、什么滴滴啊、微信啊，就全部都用不了了——第一天好像还可以用。

曼琪：这是第二个方向。第三个方向呢？

Henry：第三个方向的话，我觉得是个性化和持续学习。就现在的所有人的助手，每个助手都长的是一个样，沟通起来也是一种性格。我觉得之前我有一个非常喜欢的个人助理产品，它的这个 AI 的性格做的特别的有趣有意思，非常让我想和他交流——就是那个现在已经被 Cognition 收购的 Poke AI。但我觉得除了个人助理的性格上面，更重要的是他能不能从和用户的相处中学会用户的这个习惯：比如说你是什么样的预算、然后你喜欢什么样的航班、什么时候该提醒你、什么时候不要打扰用户；像这些纠正过一次的事情，下次能不能就是不要再解释、什么都做对。我觉得这些还是下一个阶段这些个人助理他们需要提升能力的一个主要的战场。

曼琪：Poke AI 被 Cognition 收购之后后来怎么样？这产品还在吗？

Henry：他们产品还在独立运营，并且应该是 Cognition 也非常看重他们给这个 AI 植入性格的这个能力，所以也说这方面的能力会往 Cognition 其他的产品去迁移。

曼琪：其实他们是比 Instinct 更早做的。对。我觉得确实之前一些尝试过的人可以再一次来尝试这个方向。然后我自己其实觉得挺重要的一个方向——就你前面说这三个里没提到的——就是安全：因为 Dots 和 Muse 它现在的实现方式都是在云端有一个独立的虚拟机，好处就是它可以让这个 agent 一直运行，而且你从不同的终端去访问它的体验是非常丝滑的，理论上它是没有断点的；但另一方面，那就说明我和它之间交流的各种跟我自己相关的敏感数据和信息肯定是以某种方式经过了云端，然后这样我觉得它会有比较大的安全隐患。

Henry：确实。因为现在想要用个人助理帮你做事情的话，基本上已经把我大部分账号的密码、包括我的信用卡这些信息全部都给到他们了，所以如果要是泄露出去的话，确实有很大的安全隐患。

曼琪：你现在用 Muse 你自己是比较放心的，因为它是大公司吗？

Henry：我感觉对 Meta 会比对 Instinct 放心一些。因为 Instinct 它这个 data policy 都已经写成这样了，我觉得就是对它的这个 privacy 和 security 没有任何期待。

## 上期回顾与新旗舰：RSI 验证、Astra 与 Opus 5.5

曼琪：接下来我们进入第一次录制本期季报时的其他讨论部分。正式开始三季度的讨论之前，我们依然是先来回顾一下上一期的内容，为接下来这一期的内容做一些上下文的铺垫。上一期是 171 期，当时的标题是《从 coding 到 RSI：强者愈强[?]的未来》。所以上一个季度我个人感觉最有意思的一个新趋势，其实就是标题里最后说的 RSI 递归自进化。简单来说，RSI 就是一个可以不断自我改进、自我提升的 AI 系统。上一次我们主要是聊了这个概念是什么，以及一些新近出现的创业公司，还有 Frontier Labs——OpenAI 以及 Anthropic 在这个方向上的进展。这个季度是你能看到它的趋势越来越明显的：比如说 TML 的联创之一翁荔，她离开了 TML 加入 OpenAI，然后（据）报道[?]她会去带团队探索的方向就是 RSI；在中国的话，像智谱这边也发了长文描述他们对 RSI 的理解和一些进展，他们的切入点是 AI Infra。包括我们这个季度中间有些相关的节目，像 K3 那一次，也是讨论到了 K3 技术报告里面他们用 K3 这个模型的早期版本来改进 kernel——这也是 Infra 的一部分。这是我个人觉得比较有意思的一个新趋势。然后 Henry 你也可以讲讲，回顾二季度，你觉得有哪些想法是被验证了，然后哪些想法发生了比较大的变化？

Henry：我觉得从 RSI 开始说的话，就是我们逐渐可以开始看到 RSI 的一些威力：比如说 OpenAI 上一个季度把他们的 RSI 的技术框架应用到了 inference stack 上面，然后实现了整个 inference cost 20% 的缩减——其实是非常大的一个经济项目。除了 RSI，我觉得上个季度我们做的几个预测其实在这个季度实现了验证：比如说 computer use 的重要性和价值，我们可以看到 Astra——GPT-6 Astra——在 computer use 上面的改进；然后以及 voice 作为人和 AI 交互的界面，我们可以看到 GPT-Live 新的模型的发布；还有比如我们上个季度预测 AI 下一个增长点是这种 always-on 的、一直开着的一种个人助理，那么这个季度我们也看到了新的产品的到来。我觉得可能有一个点就是比较上个季度没有想到的：就是 coding 可能比我们想象中还要更 general，能够做到我们更多之前可能没有想到的事情——这个我们可以之后再展开来聊。

曼琪：那我们正式进入这一季度的讨论。我觉得还是按照之前的那个大的脉络分两条线：一条线是推进智能前沿，就是在提升智能和模型的上限能力上过去这段时间又发生了什么；第二条线是智能扩散，就是来看看相关的一些产品它是怎么普及普惠到更多人和商业组织的。第一个大的话题还是回到两大 Frontier Lab 的竞争，就 OpenAI 和 Anthropic，还是从模型开始聊吧。正好整个三季度——尤其是最近这一个月——就是 9 月时候很多重磅发布的：包括 OpenAI 的 GPT-6 的三个档——Astra、Sol 还有 Luna，以及 GPT-6 Sol 和 Luna 发布的同一天，Claude 发布了 Opus 5.5。上一次 Opus 系列的更新是 Opus 5，这个是 7 月中旬。所以模型现在特别多，然后发布频率也越来越快。我想先请 Henry 和大家简单梳理一下，就这两个 Frontier Labs 它们现在都有哪些模型线，然后它们之间什么关系。

Henry：我觉得这个季度的话，可能大家最关心的两个模型的发布就是 GPT-6 Astra——是 OpenAI 这一代的旗舰模型——还有就是 Anthropic 的新一代旗舰 Opus 5.5。那么在 GPT-6 Astra 这边的话，它的 computer use 的能力有了比较明显的提升，能够使用 Blender 在内的很多这种专业软件完成更多的任务；另外就是在 science 和 math 这边也提升比较明显：Terminal Bench Science[?] 从 22% 提升到了 64%，然后 FrontierMath 的 Tier 4 从 83% 提升到了 97%。Opus 5.5 这边的话，就是在官方公布的所有测评中，得分居然都超过了他们更强的模型 Fable 5.1；同时相比 Fable 5，运行成本降低了 40%，然后输入输出单价降低了 20%。不过 Anthropic 自己也在公布的这个 blog 里面说，实际使用起来的体验可能差别不是很大。除了这两个旗舰模型以外，OpenAI 的这个季度还发布了比如说像 GPT-Image 2.5 的两个档位，还有这个语音模型 GPT-Live-1——都是 OpenAI 这个季度的新的模型的 release。

曼琪：你刚刚讲的 benchmark 更多是一些数据上量化的指标。所以想问一下就是从体感上，你自己包括你周围的一些研究员的朋友或者做产品的一些朋友，他们对这个季度新发的这些比较重磅的模型的使用体感是什么？

Henry：我觉得这个其实非常看实际的应用场景是什么样的。比如说如果对于 coding 来说，可能 Astra 相比于 GPT-5.6 Sol——之前有一个 OpenAI 做 pretraining 的朋友，他可能说对他自己的应用场景下面这两者模型体感可能差不多；这个同样的在 Anthropic 那边，就是 Opus 5.5 和前一代模型的改进在 coding 上面可能也没有那么大。但是在比如说 Astra 还有 Opus 5.5 擅长的领域——比如对于 Astra 来说 computer use、使用 Blender 这种专业软件的能力，或者说在 Opus 5.5 这边就是 visual design 的能力——都是有比较大幅的改进的。但它确实是能感觉到，它们 internal——就是可能还没有发布的最强的模型——在 reasoning 还有可靠性还有 research taste 方面是会更强一些的。所以这个确实很看 use case。

曼琪：它们是能比外面的人提前多久用到更强的模型？

Henry：没有具体的时间，可能会有小几个月。这个也是大家现在会讨论的一个问题：就是说因为现在这些最前沿的模型，其实你发布的时候所受的审查或者说安全的限制是越来越严格的，所以最领先的厂商比外面的人可以更早、更全面地用到更强的智能，就又会加强他们的领先优势。这个事情确实比较重要：就是你内部最强的模型其实决定了你 RSI 转得有多快。不过好在他们两家之间还是有竞争的，所以还是说不会藏很久不拿出来发布。如果要是一家独大了的话，那就是一个比较黑暗的未来了——但我觉得应该可能性不是很大，因为硅谷的人才流动速度还是非常快的。我觉得就是说，很难说你有一个 secret sauce 别人是一直没法弄明白是怎么做的。

曼琪：OK，那我们就是回到这几个模型。GPT-6 Astra 可以再展开讲一讲，它是一个反响还挺强烈的模型，总的而言它核心的亮点是什么？

Henry：GPT-6 Astra 发布以后确实反响挺强烈的。最直观的就是 OpenAI 它这个 200 美元的 Pro 套餐暂时不让新用户订阅了，因为他们的这个 compute 有点跟不上——所以为了保证现有的用户体验，他们就是在增加容量之前需要先暂停最消耗资源的这一档订阅。Astra 我觉得这次最值得讲的进步，我会选就是 computer use。它的发布视频其实也用了一段很有意思的历史来讲这件事：它那个发布视频开头是 MIT 在 1979 年做的一个经典的人机交互实验，叫做 Put That There——就是"把它放在那里"。它实际上是结合这个语音和手势，然后使得能够在电脑屏幕上面画图、然后移动图形。其实从那个时候我们就开始在探索：就是能不能直接告诉这个电脑我们想做什么，然后让电脑去理解并且执行。那 47 年以后呢，OpenAI 用同样的一个"画一个黄色圆圈"来重新开场，但这次的话呢他们继续往下做：然后把这个黄色圆圈先是变成了一个火箭的窗口，然后再给这个火箭加上很多细节，然后再打开 Blender 把这个火箭做成一个三维的模型，再基于这个三维模型做一个 3D 的游戏，最后生成了一个 3D 打印的文件——是一个非常完整的一个能力的展示。然后网上的话也有很多传播很广的这些 3D 的 Astra 的 demo，大部分都基于 Astra 对于 Blender 的使用能力。比如说有一个开发者，他把 Zillow 上的一套豪宅的这个房源链接交给 Astra，然后让它根据照片在 Blender 里面给这个豪宅建模，然后再制作一段这个 house tour 的 video 带你虚拟参观这套房屋——这个就是在 Twitter 上面爆火了。然后类似的这个能力还也出现在比如说 Astra 可以使用这个制作游戏的 Unity，然后这个设计电路的 KiCad，包括我们比较熟悉的 Excel、Power BI 这些专业软件中。从跑分上来说的话，在官方的 OSWorld 2.0 的离线评测里面，Astra 的得分也从上一代的 65% 提高到 72%，然后时间上也大幅缩短了——大概缩短了 47%，从 75 分钟降到了 40 分钟。所以它相当于是在 computer use 上做得更好[?]，并且更快。

曼琪：然后是这个 Opus 5.5，你前面说到的它能用 coding 来做很多事，可以展开来讲讲。

Henry：我觉得 Opus 5.5 这次一个很大的亮点，就是用代码来做视觉设计和动画的能力。这个网上有很多惊艳的例子：乍一看的话呢你可能会以为这个是 video generation——就是视频生成模型做的，比如像 Seedance 这样的模型——结果后来发现这整个动画居然都是 Opus 写代码画出来的，我觉得还是非常超出了大家的预期。它很多这个动画其实就是一个 HTML 文件，然后里面是没有图片或者视频的素材的，是纯用 JavaScript 和 Canvas 2D 然后一笔一画地绘制出来的；有些视频又是通过 Web Audio 再配上这个声音。比如说有人做了一段介绍 Claude 自己生平的动画，还有各种艺术风格和复杂的这种视觉设计。我们可以之后在咱们播客的评论区放一些链接，然后大家看一下就能直观地感受到 Opus 5.5 的这些做动画的能力了。我觉得这件事情比较重大的意义，就是让我们重新认识到 coding 这个工具——它作为最 general 的工具能做什么：就是画什么、用什么颜色、一个元素什么时候出现、怎么移动、停留多久，像所有这些动画的元素都可以写进代码里面。所以它真的是一个让我会觉得好奇的：就是说还有多少我们原来认为不属于 coding 的事情，其实都是可以通过写代码来完成的。

曼琪：通过写代码来生成一段视频，它整体是不是更高效？就比如说它算力和 token 的消耗是会更少，相比于视频生成？

Henry：这个倒不好说。因为我记得它好像有一个 78 秒的视频是做了 45 分钟；如果一个 78 秒的视频如果用 video generation model 做的话应该会更快——当然这个不算抽卡的时间。但我觉得代码的好处就是它可以非常针对性的进行剪辑，或者你要修改哪里——这个东西的可控性应该是远高于 video generation model 的。

曼琪：比如说有人用这个来做一些 education 的材料、教育材料：你想学什么东西的话，然后他可以给你做一个动画然后来给你解释，这个东西是一种交互性的一种学习的材料，其实是我觉得非常好的。你觉得过去这几年的发展到现在，这些前沿模型能力的提升主要的增量来自哪？因为最开始的时候其实是来自大规模预训练，然后 24 年 9 月 OpenAI o1 之后有一个范式的转变，就大家会投入很多力量去做后训练、做大规模的强化学习，还有在计算时加更多的算力。你觉得现在这个新的提升的增量的来源它变化了吗？

Henry：还是一个多方面的吧。因为大家应该还是在不管是 pre-train、post-train 的 recipe，还是比如说在 test-time compute——可以通过后面我们可能会聊到 multi-agent 来增加更多的算力——应该都是有提升的。不过我觉得可能 ROI 最高的应该还是数据上面。这个也可以举一些例子：你可以看看 Frontier Lab 在愿意在数据上面其实是花很多钱的。比如说最近 Gemini 收购了一家公司叫做 Mechanize，它是 Anthropic 的一个数据供应商，然后因为在 Anthropic 内部的这个风评很好、他们数据质量比较高——它主要是供这个 coding 的数据——所以呢这个 Gemini 就非常着急提升自己的 coding 能力，所以就这个 Sergey 和 Koray[?] 就 reach out，然后收购了 Mechanize。

曼琪：多少钱收的？

Henry：1.5 billion，15 亿美金。

曼琪：Anthropic 没有去竞争一下？Google 买走之后是不是它少了个供应商？

Henry：我觉得他们是在数据采集、采购上面是非常有自己的想法的。他们之前为了让这个领域里面有更多的供应商，专门就是给 YC 的很多公司去发钱，然后可能每个公司可能比如说给你一个 million 的订单，然后来增加这个领域里面的这个玩家数量，这样能够把整个行业的价格打下来，然后增加他们的选择，减少他们对头部供应商的依赖。所以他们之前已经做了不少这样的工作，所以可能 Mechanize 的收购对他们来说影响也不是很大——就是他有很多供应商，他扶持了很多供应商。所以 Anthropic 之前其实也并没有投资 Mechanize——没有投资 Mechanize，或者应该没有 Anthropic 投资数据公司的先例，据我所知。

曼琪：那说到这个数据的话也可以展开讲讲：就是现在的这个数据和最开始——比如说 22 年那会儿 GPT 刚火的时候——的数据的类型有了什么变化？

Henry：从去年 25 年中开始吧，就是有大量的新的做这些强化学习环境的公司——或者说 RL environment 的公司——出来，最近有挺多都融了比较多的钱，比如说像这个 AfterQuery、Fleet AI 等等。所以这些公司应该是吃到了这一波数据的红利，他们给这个 OpenAI、Anthropic 这些 Frontier Labs 提供了大量的强化学习环境的数据。当然除了这些强化学习环境以外，像这些思维链的数据、用来做 SFT 的数据，也是一直有这种需求的。

曼琪：你刚提到那些公司现在估值在什么量级？

Henry：AfterQuery 如果我没有记错的话应该是在 30 亿美元左右，然后 Fleet AI 的最新一轮应该是 7 亿 5 千万美元。

曼琪：OK。那中国现在类似的公司的估值已经跟美国公司差不多了。就你刚说强化学习环境，有一个 25 年下半年成立的中国公司叫 UliPet[?]。

Henry：对，他们一开始也是做这个强化学习环境的，他们现在应该是接近 30 亿美元的估值了。这个挺神奇的：就中美的大模型公司的估值差得挺多，这个数据公司的估值已经是有赶上的趋势了。可能是因为美国这边的玩家太多了，但是中国这边可能优秀的玩家数量比较少，所以估值可能会更高一些。

## 蒸馏与反蒸馏：Astra 为什么更难蒸

曼琪：说到数据的话，还有一个三季度被特别广泛讨论的问题，就是蒸馏和反蒸馏——因为蒸馏本质上它也是一种获得高质量数据的方法。我觉得最近的一个新变化就是在 GPT-6 Astra 发布之后（因为这是 9 月初嘛），然后我们和中国的一些研究员聊，就很多人的反馈都是 GPT-6 Astra 是更难蒸馏了。我不知道你和周围就美国一些研究员有没有讨论这个问题：它更难蒸馏的原因是什么？其实导致的就它是跟模型本身能力提升了有关，还是一些别的手段让它变得更难蒸馏？那从原理上为什么蒸馏很难彻底杜绝呢？

Henry：是因为这些思考模型它在回答之前会先花一段时间去吐出它这个思维链，但是这些模型厂商它是不会主动展示这些思维链的。但是在一个多轮对话里面，下一轮对话实际上模型还是需要之前的思维链的，所以这些思维链的话它们其实会被加密起来，然后传回服务器，然后在服务器里面解密以后，在下一轮对话生成的时候再把它喂到模型里面去。所以只要思维链它要被模型读取，而最终模型都要和用户说话，那么用户在和模型沟通的过程中就有可能会获取到模型的思维链——所以这个是本质上为什么很难杜绝。那么上一轮这个蒸馏它具体是用到了什么样的手段呢？它其实是发现了这样的一个缺口：就是虽然这个旗舰模型它防护的比较好、它可能不会说出自己这个思维链，但是这个旗舰模型它的思维链可以把它交给他们的防护比较弱的这些小模型，这些小模型可能会把旗舰模型的思维链给读出来。所以就是研究者利用这条路径绕过了向旗舰模型索取内部推理的限制，然后通过攻破了这些小模型来获得旗舰模型的思维链。所以这个重点的话就是说，你想保护这个强模型的秘密，你还得保护所有能读到这个秘密的其他模型。然后这个漏洞的话，应该是已经——作者也说，在他们披露以后原来的攻击已经无法复现了——所以相当于是这些 OpenAI、Anthropic 他们已经修复了这些问题。但是未来的话，我相信可能还会有新的漏洞被这个新的攻击者找到。

曼琪：所以 GPT-6 更难蒸了，跟 GPT-6 模型本身更强了关系不大，就是之前的漏洞被发现了，然后被某种方式给堵住了？

Henry：我觉得这和模型能力应该是没有关系的，或者它不是直接的关系。可能会有这种间接的关系：就是谁有更强的模型，你有更强的 coding 能力、有更强的处理任务的能力，可以就帮你去做这些攻防吧。其实最近这个季度的模型发布，在网络安全上的能力也都是他们会去讲的重点——GPT-6 都是把网络安全能力作为其中一个高亮的能力去展示。

## 一万个 Agent、88 小时：OpenAI 如何挑战 Navier–Stokes

曼琪：那回到 Frontier Lab 之间的竞争，前面说的是模型本身的进展。然后接下来我觉得可以聊的一个话题是，OpenAI 和 Anthropic 这两家公司他们看中的不同的要优化的方向。最近比较受瞩目的一个方向是前沿的数学问题——这也是 OpenAI 陆续在释放成果的领域。比如说他们号称解决了千禧年的数学难题之一，然后后来这个事又应该是引起了很多风波和争议。Henry 你可以先和大家讲讲这整个过程大概是怎么样。

Henry：首先千禧年数学难题是七道非常重要和困难的数学问题。OpenAI 这次解决的千禧年数学难题是纳维-斯托克斯方程的存在性与光滑性问题，我们可以把它简写为 NS 方程问题。简单来说，它就是流体世界里面的牛顿定律：它会描述就是当流体受到压力、粘性和外力的影响的时候如何运动。像这个飞机周围的气流、天气变化、血液在血管里面的流动，都可以用这类方程来描述——我们其实一直就是会用它。但是这次研究的话是说这个 NS 方程它有没有可能在某些时候出现这个异常。

曼琪：就是说这个难题本身是研究这个方程的某种数学特性，对吧——它才是一个假设，它可能有一种什么数学特性，然后你要去证明它有这个数学特性？对，它就是个纯数学问题了。因为有的人会问，解决了 NS 方程问题能不能立马产生经济价值？

Henry：然后这个答案的话就是说，它证明并不会立马让天气预报变得更准、或者飞机更省油、或者解决这个湍流问题——因为我们本来已经在用了。但是 AI 在解决 NS 问题中展现出来的能力，会让我们有理由相信，接下来 AI 有能力解决更多直接能产生经济价值的难题。

曼琪：那可以去说 OpenAI 它是怎么解决的。

Henry：OpenAI 它是找了一个一万个 agent 的一个高并发的 agent 的集群，然后呢探索这种各种不同的方向，然后最后呢在跑了 88 个小时、烧了 130 billion——也就是 1300 亿——token 以后，他们得到了这个 NS 方程问题的证明；然后随后呢用这个 Astra 又花了 17 个小时完成了 Lean 的形式化和验证。最后就是整个可以说解决了这个 NS 方程问题的形式 C 和形式 D[?]。Lean 是一个证明的检查系统：就是你可以把任何的数学的这个论证写成它能检查的形式，然后他就可以逐步推导，然后判断这个是不是对的。

曼琪：OpenAI 发了一个论文，然后里面写了详细他们的这个证明的过程——对，就同行都是可以去评议的。围绕这个 NS 方程问题的争议是什么呢？

Henry：就是 OpenAI 在自己的这个 blog 里面说，他们是在 9 月初的时候听到就是好像有人在重要数学问题上面产生了重大进展，所以他们想我们也来试一试能不能解决这个问题。那么他听到这个进展是谁呢？是一个纽约大学的数学家 Tristan Buckmaster，和这个他的同事——是一个在 Anthropic 工作的研究员，就是 Levin de Alpoche[?]。他们两个已经合作在做这个 NS 方程问题大概有一年的时间了，然后他们在这之前呢确实是把一些未发表的草稿交给过这个 Codex 使用。所以呢就是难以排除，OpenAI 是否查看了 Tristan Buckmaster 在 Codex 里面的这些数据来用于自己的证明——不管是有意的还是无意的。然后另外一个点的话就是说，在 OpenAI 主动去联系了 Tristan Buckmaster，然后提出因为他的合作者在 Anthropic 工作，所以希望他把他的合作者排除在作者之列之外——所以他认为这个沟通过程带有这个施压的意味，所以他就把整个他和 OpenAI 的这个沟通的过程全部都在网上公开出来了。所以这也是一个争议的起因吧。

曼琪：首先 OpenAI 听说有人在这个方向上有了一些进展，他是怎么听说的？是 Buckmaster 自己在一些数学的学术会议或者说公开场合说过吗？难道是从 Codex 听说的吗？

Henry：被质疑的点就是说，因为也没人知道他们是怎么听说的——但可能是研究员之间的交流他们听说的，但这个就不得而知了。这个其实有点反常：一般一个数学家如果认为他在一个重大问题上快做出来成果的时候，他不会到处去宣扬这个事情。

曼琪：确实。因为可能很多人都盯着同一个问题，然后你想了很多年的一个问题你快做出来了，你肯定得保证自己获得这个成果的。

Henry：他们确实就是解释说，他们的解决的问题和 Tristan Buckmaster 解决的这个问题他们稍微有点不一样——一个是可能带黏性的[?]、一个是不带黏性的，然后他们证明方法不太一样——他们就是做了一些这方面的说明。后面还有一个后续的事件：就是有很多菲尔兹奖的得主他们一起写了一个联名的公开信——当然那个信里并没有特别提到千禧年问题这件事，它更多的是在讲担心 AI 对数学研究的一些冲击。之前有一个做数学的朋友开玩笑说，这个数学家可能可以分为两种：一种是给一个问题然后去证那个问题的人，和提出新问题的人。然后在 AI 这个时代，可能就是解决问题的人就是没有这个活路了——因为这个就直接，你只要问题提出来以后然后扔给 AI，然后暴力扔一万个 agent 然后再让试就可以试出来了。当然其实真实的情况可能不是这么简化的了，但是我觉得数学家确实会比较担心：而且可能有些时候你的新问题是在你解决之前的一些问题的过程中间产生的，如果你都是暴力破解法的话，他们可能也会担心这种新问题产生也会变少。

曼琪：抛开这个争议——就说他们这个源头到底是哪来的——技术方法上，就这次 OpenAI 攻克千禧年的问题，一个比较多人讨论的是多 agent 的并行协作来处理一个超级复杂的问题。你前面也提到它是一万个智能体一起协作了八十多个小时。其实很多智能体一起工作就不算一个很新的想法，就最近会不会在多智能体上它有一些什么新的变化吗？

Henry：我觉得这个让很多智能体合作，你可以认为它是 test-time compute 的一个新的阶段。因为之前的话我们可能是让一个模型进行比较长时间的思考，然后就能解决更困难的问题，对吧；但是对于特别困难的问题的话，它这个长程的思考如果一个模型来思考的话，它可能需要很长很长——比如说几十年或者上百年的时间。但是如果要是我们能够让它能够通过并行思考的方式来做这个事情，就能把这个时间缩短到比较短，比如说缩短到 88 个小时。所以这个多智能体合作，其实我觉得它是一种并行的方式。那么并行的话，你可以固定它一些并行的模式：比如说一个智能体它给其他智能体分配任务，然后每个任务算完了以后再把它合起来——这样是人相当于去固化一些合作的方式，那这些的话还是带有人的这些 prior 的，它可能不是最优的合作方式。所以 OpenAI 它这次的进展呢，就是它给了这些智能体、给了这些模型一些基础的沟通的工具——比如说给其他的这个智能体发消息——然后呢就是 train 这个模型自己去学：什么时候发消息是好的、什么时候给别人发消息、什么时候求助、什么时候修改自己的路线，然后去进行这些合作是好的。那么他们这个工作我觉得是这次这个新的进展。

曼琪：那这一次是用一万个 agent 的并行来解决问题。像就是到底选多少个 agent 一起来合作，是人来设置的，还是也是 AI 它自己会面对任务自己会有一个模式出现？

Henry：目前的话呢，算力给多少这个 budget 还是人来决定的。那么实际上比如说给一万个 agent，是不是效率提升了一万倍？肯定是没有提升一万倍；但是比如说提升了是 500 倍、还是 1000 倍还是 2000 倍，就这个事情应该目前 OpenAI 他们自己也还没有系统地去进行过测量。

## 通用模型进入机器人与生物科技

曼琪：这是 OpenAI 明显看到它在着力的一个方向，就是前沿的数学研究。然后另一个也是 GPT-6 Astra 发布之后大家讨论的非常多的方向，就是 robotics 和物理 AI。其实这一次具身智能领域的人是很兴奋的，这个和我们二季度的一个讨论也是相互印证：就当时有聊到 OpenAI 和 Anthropic 都会去做 robotics——OpenAI 在当时是一个已经公开的信息，然后我们聊的时候 Anthropic 那个信息还没有公开，但他们很快在 7 月上旬发了一个很长的文章，讲就直接把 Opus 4.6、4.7 这些模型用到机器人上有一些什么样的实验的结果。注意到这一次 GPT-6 对具身智能领域的影响，你看到大家的哪些有意思的实验和反馈？

Henry：其实之前的话呢我们就说过，就是 computer use 其实可以看作是数字世界的 robotics——那么之前还是打一个比方，但没想到这次真正的就是能够看到：当一个模型的 computer use 这些能力增强了以后，它真实的发生了这些能力的 transfer 到操控机器人的这个能力上面。有一个比较有意思的例子，是有一个研究员，然后他给这个机械臂装上了画笔，然后接入了摄像头，然后就让这个 Astra 去操控这个机器人画一幅金门大桥的画。然后这个模型就通过 coding，然后他写了动作程序，然后规划了大约一分钟的操作，通过摄像头检查执行结果、调整他后续的计划，最后在几次尝试以后非常好地画出了金门大桥的一幅画。所以这个确实让大家非常惊讶：就是现在这种通用的模型居然可以直接地操控机器人，然后完成这些稍微有点复杂的一些任务。

曼琪：它这个过程就是主要只用 Astra 这一个模型对吧——就是它从理解这个任务，到去规划拆解这个任务，到输出动作，就是这一个模型？

Henry：对，它就是这一个模型。然后因为 Astra 现在跑的还比较慢，所以它不能说就是每一帧都让 Astra 来看；所以它相当于是 Astra 就是看一次，然后写动作——大概要写可能一分钟的动作——然后再看一次，然后再调整。但还是这样它的实时性肯定是不太行的，它这一幅画可能需要一到两个小时的时间。

曼琪：我觉得 GPT-6 发了之后确实有一个（风向的）变化[?]：就很多人都是直接用这一个模型就端到端的干了 robotics 的好几层的事，就包括大脑和小脑。因为一般大家之前会说，就是大脑是你去理解这个任务——比如有个自然语言的指令给你，你理解它的语义，然后你去拆解一个任务：比如说你要把桌子收拾一下，这个里面其实可能包含很多不同的动作，然后它还有顺序的编排什么什么什么的；以及到最后你再去控制这个机器人的——你不管是灵巧手还是夹爪——去执行完这个动作。以前其实很多是分开做的，它是不同的模型来实现的。那 GPT-6 很多人是用这一个模型来走完这整个流程。当然你从成功率和节拍上，可能你真的能在现实生活中去有效益地完成一些任务，目前还是差距很大，只是大家看到它的进展比之前会好了很多。比如说我看有一个数据，也是一个研究员的一个尝试：他们在 RoboDojo 这个系统里面的一个测评——但这个其实是一个仿真的测评——就同样的方式，用这个 Astra 来当策略模型的话，它在 42 个任务上 2100 次的平均成功率是 22% 点多。虽然这个看着不高，但是 GPT-5.5 只有 0.8%，就是提升还是挺多的。

Henry：对。然后也可以和比如说像 π0.5 这样的 VLA 进行对比：我记得好像这个论文里面写，就是 π0.5 的成功率是 6.9%，所以 Astra 还是比 π0.5 强很多的。

曼琪：对，这同一个——就那个论文 Unexpected Robot Policy[?]。不过这个论文里面也提到一个点，就是说 Astra 的表现非常的不均衡：它非常擅长需要理解任务含义、然后灵活选择动作那种开放式的任务，但是精细操作和需要连续完成很多步骤的任务，它就是表现得非常差。

Henry：那还是跟我刚才说的那个——之前也有很多人会去做的——分层的思路也是有关的。就理论上来说，其实如果你观察人的结构的话，人的特别细致的动作它是由小脑来控制的，对吧，它可能并不是一个需要非常长时间去推理或者规划的这种任务。我觉得它最后可能实际落地的时候又会有很多不同的形态吧。现在确实它展现了一个大语言模型能直接来当策略模型，而且成功率比之前要高很多——这个还是挺惊人的。

曼琪：对，我觉得它有可能指出了一个未来解决 robotics 的可能一个新方向。然后这也带来一个引申的问题，就是很多具身智能领域的一些公司他们接下来可能会面临什么影响——就对他们来说这是个好事还是个坏事呢？

Henry：我觉得具身的话可能是一个有很多 bottleneck 的一个领域，就不光是 foundation model 这一个部分，包括还有很多 hardware 啊然后等等。但我觉得可能现在在具身里面做这种模型的公司，可能应该更多的去思考就是如何利用 Astra 这种强大的能力，就是能够搭上这班车，而不是和它这个——中文怎么说——中文的话创始人喜欢说的一种说法，就是你最好和它是正交的、不是重合的。

曼琪：对对对，就是这个意思。直接点说的话，你觉得对 π 和 Physical AI 这样的公司来说，它是个利空吗？

Henry：我觉得是一个利空。可能现在大家可能还不想公开出来说这个事情，我觉得私下里已经有不少人说，就是在这一波，Robotics 公司都完了[?]。

曼琪：私下已经有这么极端的言论了吗？

Henry：对。然后就觉得，本来可能之前考虑加入这一波比较好的公司的人，然后就决定就是说就不去了。

曼琪：比如说想去哪儿，准备不去了？

Henry：比如想去……就不去了。我觉得这个领域已经是很头部的公司了。

曼琪：那准备去哪儿？

Henry：现在有新的创业公司就要走这条路了：就是更好的利用类似 GPT-6 Astra 这样的能力来发展自己的能力。

曼琪：对吧，或者说就是用 coding 来做 robotics 的这条路。用 coding 做 robotics、用 coding 和 computer use 来做 robotics 这条路——coding 和 computer use 也还不一样，computer use 里的有些能力可能是来自于图像理解的。

Henry：对，是来自于你对图像和空间的理解的。这两个能力在咱们聊的这个例子里面它都用到了。所以总结下，其实就是用前沿模型厂商在大语言基础模型上所展示的潜力来做 robotics。

曼琪：你说现在更新的公司是最近成立——就是近期成立的吗？或者说成立多长时间？

Henry：可能也就这个月成立的。

曼琪：这个月还有 robotics 公司成立？

Henry：对，所以在美国也是陆续都有这个领域的公司成立。它的窗口没有大语言模型那么集中，因为这一波可能还是一个 technology driven——因为有些新的技术范式，所以有新公司出来了。这块还有一个例子我觉得可以补充一下，就是它的这个自我修复和调整的能力我觉得还是非常厉害——就是那个机械臂画金门大桥那个例子。我讲讲它怎么自我修复：就是这个模型它中间发现这个画笔虽然沾到了这个青色颜料了，但是这个落笔的时候呢却落在了这个纸张上方的胶带，所以它就暂停后续这个笔画，然后抬起画笔，然后再根据这个已经画出的痕迹呢检查偏差——它判断呢，大概这个自己估计的纸张方向大概偏了 6 度——所以他就调整了这个 6 度的这个偏差以后，然后重新修正画的这个路径和这个笔迹。所以这个整个过程的话，如果放在之前就是这个 human robot programmer 来做的事情，现在发现整个这个事情 Astra 自己就把这事干了，所以这个还是非常厉害的。

曼琪：你觉得为什么 Astra 在这些跟空间相关的任务上会提升的特别明显？它是一些能力的组合——就比如说因为其实 OpenAI 一直做了多模态、做视觉理解，它也做了更多——还是说它真的空间上的这种智能能力变得更强？

Henry：我的猜测可能是两个部分：一个部分的话就是 OpenAI 它最近在欧盟那边公布了它的一些训练数据的使用情况，然后其中的话就是它有大量——它有超过现在有 100 万小时的这个 multimodal data，可能一些视频的一些数据，然后用在这个 pre-training 里面，所以这本身可能提升了基座模型的一些空间上面的理解能力；然后其次的话可能是在具体的这些软件和领域里面，他们采集了一些数据，包括有可能是一些 RL 的 environments，然后增强了这些具体 downstream 应用场景里面的这些能力。

曼琪：除了数学和具身智能之外，前沿的大模型还有一个很重要的大的方向就是生物科技。你觉得 Q3 这方面有什么值得分享的？

Henry：Q3 生物这边我觉得有两个进展可能可以分享一下，两个都是来自 Anthropic 的。第一个的话是 Claude 开始设计蛋白质了，并且它已经拿到实验室里面做了这个验证：它是让这个 Anthropic 的 Claude 设计了 1320 个蛋白质，然后交给外部的实验室测试了以后，发现有 354 个能够结合指定的目标，命中率大概是 27%。你可以把结合指定的目标——这个目标想象成一把锁，设计出来的蛋白质就是钥匙。所以这一步的话就是证明了，这个 Anthropic 的模型现在设计出来的钥匙确实能贴合这个锁；那么接下来需要进一步验证它能不能产生我们想要的生物学的效果，然后能不能安全的用于治疗。这是第一个。第二个的话是 Anthropic 他们说他们发布了一个叫做 ART 的一个新的酶系统：就是 Anthropic 在分析大量 DNA 数据的时候，发现了一组之前没有被注意到的组合特征，其中的这些重复序列结构让我们联想到 CRISPR——CRISPR 当初也是从一系列看似奇奇怪怪的重复序列，一步步发展成了很强大的基因编辑工具的。所以这个发现我们是非常值得期待；不过目前 Anthropic 还没有弄明白它这个新酶系统——ART 系统的具体功能到底是什么样的，所以还不能说已经找到了下一代的 CRISPR。但是我觉得比较有意思的就是说，AI 可以从这种海量的数据里面然后找出值得人类科学家进一步研究的线索。

曼琪：那正好前面 robotics 的进展更多是在 GPT-6 Astra 之后业界有很多实验，然后生物科技这个方向好像都是来自于 Anthropic。你觉得这是它们两家重点会有区别吗，还是只是最近释放的那些成果的偶然性导致的？

Henry：OpenAI 也在做生物，可能最近没有发表太多的成果，但是它最近做了一个就是——生物领域里面的 Cursor 或者说 IDE：它不是有一个模型叫 GPT-Rosalind 吗，然后它还有一个平台叫做 GPT-Rosalind Workbench。然后这个 Workbench 和我们的被投——就是 Filo 做的这个平台工具——有点像：他们都是用 agent 来 orchestrate 你做生物研究中里面的所有的这个流程。就是我觉得他们在这方面的探索，其实感觉上是越来越进入很多独立的创业公司本身在做的领域。

曼琪：包括你前面说到，就私下里大家也会讨论说 GPT-6 Astra 出来之后对一些 robotics 公司会有冲击；然后这里其实有一些创业公司它就是做比如说蛋白质发现的，或者是去做一些靶点。那如果像 Anthropic 自己也做制药、也往后去推的话，是不是也和这些创业公司有挺多竞争？

Henry：我觉得后来肯定是会存在一些交集的。

曼琪：那你觉得创业公司可以干嘛？

Henry：还是有挺多事情可以做的。因为首先它有些领域它不一定有这个数据：就是如果一个领域它已经处于 public data reach 的状态的话，我觉得可能就是确实 frontier lab 他们有（算力）资源，然后有最好的 train 模型的这些基础设施，那我觉得可能就不太容易做了。但我觉得有一些领域的话，它可能还依赖于一些领域专家，然后它本身整个的数据它处于一个比较稀缺的状态，这种时候的话我觉得有这种领域实际经验的这种 startup 他们可能是有一些机会的。

曼琪：其实 robotics 和生物科技都属于数据相对稀缺的领域。

Henry：对，我觉得还是相对稀缺的。对，包括生物科技它其实分类很细，它可能不同的就是具体的领域细节、细的门类里面有些又更缺数据。但我觉得这两个领域相对来说都比较早期吧，然后都没有一个 clear 的赢家。

## 收入竞赛：OpenAI ARR 猛增与 Anthropic 上市材料

曼琪：这一部分的最后，我想来聊一下 Anthropic 还有 OpenAI 这两家公司在用户、收入还有利润增长上的一些变化——他们也是行业里商业化和应用落地的标杆指示。我就先分享一组数据：一个是 9 月 28 号的时候，有一些媒体披露 Anthropic 上市过程中的一些 S-1 文件草案里的数据，然后能看到说，今年一季度和二季度 Anthropic 的收入分别是 47 亿美元和 115 亿美元；那到今年 7 月底，它的 ARR 是已经突破了 650 亿美元——这个和之前更早的时候媒体的一些报道也是一样的。然后是 OpenAI 这边，这个数据还是比较惊人：就是刚刚今天有媒体报道说 OpenAI 的 ARR 已经到了 700 亿美元。然后两家公司的 ARR 差距相比今年上半年的时候其实是明显变小了——这和我们前两个季度一直在讨论的 OpenAI 对 Anthropic 的反扑是直接相关的，可以说这种趋势已经被数据验证了。你觉得这个会意味着什么、会带来什么影响？

Henry：我觉得可以首先解释一下，就是这个 ARR 是怎么计算的——这两家公司它可能计算的方式有一些不一样。应该在早些时候 OpenAI 他们说过：就是 Anthropic 他们公布之前 300 亿 ARR 的时候，他们其实有 80 亿是付给他们合作伙伴的成本。举个例子，就是说 Anthropic 如果通过 AWS 卖出去 100 块钱，然后它中间付给 AWS 个 40 块钱，它其实会把 100 块钱全部计入到他的 ARR 里面，然后把 40 块钱计入他的成本，而不是计一个 60 块钱的 ARR；OpenAI 的话他其实是用的是这个净值。所以 OpenAI 当时的这个首席营收官其实会说：这个如果 Anthropic 和他们用同样的方式来计的话，他们 300 亿的 ARR 里面可能只有 220 亿——所以相当于是打一个大概七折。所以在不同的报道里面，我们现在不能确定就是具体哪个数据是用哪个口径来计算的。然后其次的话就是 OpenAI，我们可以看到是在 8 月份到 9 月份有一个非常大的增长：在 8 月份的时候他们的 ARR 可能还是在 40B（400 亿美元）往上，在 9 月下旬的时候就已经到了 70B（700 亿美元），所以大概有一个 70% 左右的一个增长。

曼琪：我补充说一下，就你刚刚说那两个数，因为它其实都不是官方披露的：8 月中旬的 40B 也是媒体报道的，是彭博社报道的；然后最近接近 70B 是路透报道的。这有一个可能的原因，也是因为这两个媒体自己报道的口径可能也不一样，但确实都是比较权威的媒体。以及这个数字的增长非常惊人，中间发生可能最大的事件就是 OpenAI 发布 GPT-6 Astra，然后这个可能是确实极大的点燃了这个用户对于 OpenAI 的这个需求的增长。我们也可以看到，就是从 OpenAI 取消这个 200 刀这个 Pro plan 可能也能看出他们可能算力有点跟不上了。如果结合现在的这个数据的话，可以说在三季度 Anthropic 和 OpenAI 的增速是已经发生了掉转了：因为上半年 Anthropic 就显然是增速更快——因为去年底的时候两家收入的话是 OpenAI 更多——然后最近这三个月、尤其是最近这一个多月，OpenAI 的增速明显变得更快了。然后有一个第三方的机构 Ticker Trends[?]，它是用各种另类数据来测算这些公司的 ARR。它算出来的这个增速的话，如果用它 7 月 20 多号到 9 月 20 多号的这个数来算的话，Anthropic 的 ARR 是已经增速只有 3.6% 了，然后 OpenAI 是 20% 多。

Henry：首先第一点的话就是说，在这段时间里面 Astra 比 Opus 5.5 比较早发布了近三周，然后再加上本身这个估算可能会有一些误差，所以我觉得可能还不能判断 Anthropic 已经长期停滞了。但是如果要是接下来几个季度 Anthropic 都明显放缓的话，那我觉得可能首先承压的会是它的估值——因为现在投资者愿意给非常高的估值，很大还是因为为了未来的增长在买单。那么到了现在上市的这个关头，那公司可能就需要证明：现在的这些客户为什么还会继续增加支出，然后还有哪些新客户和哪些新场景能够接上。如果要是这个用户能够把这些很大一部分工作转给 Codex 的话，就说明之前（建立）的份额还需要不断靠这个产品和使用体验才能守住。更大的给压力的点可能是：未来它这个算力已经提前定了，但是如果收入却没有按原来的这个预期增长的话，像算力扩张、融资的计划可能都需要调整。所以我觉得增长慢一点本身可能不是那么可怕，但是更可怕的是整个投入的计划建立在原来更快的增长的基础之上。我觉得对于行业的影响来说，还有一个可能需要区分两种情况：就是说如果客户只是把钱从 Anthropic 转给 OpenAI 的话，那可能说明是竞争更加激烈，但不一定代表 AI 的需求在萎缩；但是如果要是 OpenAI 和 Anthropic 多家公司都持续放缓的话，那可能就说明是客户也不再愿意再增加这个预算，那可能需要认真重新评估整个行业的需求和这个基础设施投入了。

曼琪：OpenAI 的能力要更综合一些：比如说 GPT-6 Astra 它的展示视频里其实所有的用户都是语音来和它交互的，GPT 也有自己的语音的模型线。Anthropic 应该是没做这条线？

Henry：Anthropic 现在正在做。

曼琪：现在正在做？对，我们上次好像也聊到……他们怎么做了一个季度还没发，就有点慢了吧。

Henry：比想象中慢了一些。可能这个 RSI 这个 stack 还没完全弄好，或者他们别的事优先级更高吧。总之我觉得它现在的体验就能力上挺综合的。OpenAI 的这种可发展性我觉得还是很强的：2C 的产品、然后语音、然后这个 image，就多方面都有这个未来成长的空间。现在增速放缓有一个自然的原因，是因为他们之前增速很快就会导致基数比之前大了很多。

曼琪：就如果考虑到这一点的话，你觉得比如说到明年，什么样的增速可能是一个比较健康的情况？

Henry：如果按照 Anthropic 今年年底到 1000 亿美金的这个 ARR 来计算的话，他们今年从年初到今年年底的话应该是翻了超过 10 倍以上。那么明年的话，我相信他不管怎么放缓，在他们 1000 亿 ARR 这个基础上应该是一个远超我们之前比如说 SaaS 那些公司在这个体量上面一个增速的一个数字——比如说可能还是一个至少两三倍的这么一个增速。但我觉得可能更加需要去担心的是：多少的一个增速才能够撑得住就是现在所有对于 AI 基础设施的这个投入的一个数字。这个可能是我会比较担心的一个问题。

曼琪：那正好可以延展来聊一下 Anthropic 被披露的它上市材料里的一些数据——当然这不是完整的招股书，现在还没有完整的招股书。以及之前有一个报道是说，它三季度也是实现了经调整的盈利，就是从二季度到三季度连续盈利。我们可以先来看一下路透报的他们上市材料里的这些数据，你觉得有什么可以值得展开聊聊？

Henry：有几个数字可以跟大家分享一下。第一个的话就是说 Anthropic 这个 IPO 可能会使这个公司的估值超过 2 万亿美元——这是一个非常惊人的数字，因为这公司从成立——5 年前成立——到现在一共就是 5 年的时间，从零做到 2 万亿美元，这可能人类历史上第一家。第二个的话，他们的客户其实还是比较的集中的：现在大概有两个大客户加在一起贡献了大概 25% 的收入；然后还有很多大客户他并未签订长期合同，所以未来是有可能会削减或者停止对于 Anthropic 服务的支出的。然后另外一个比较重要的点是：Anthropic 未来多年的云服务算力和基础设施，他们现在总计已经签了 5180 亿美金的合同。那么在这个基础上的话，回到我们刚才说的这个问题，就是会担心他现在已经为未来的这个客流租下了很大的这个算力，但是现在这个客户并没有承诺以后一定会去有 recurring 的 revenue 或者会增加这个支出；所以现在提前锁定这个算力、帮助满足增长以后，万一要是需求或者竞争格局发生了一些变化的话，会非常担心 Anthropic 这方面的风险。第二个的话呢，就是也是因为对于头部客户的这个依赖吧，以及对于他的核心的合作伙伴的这个依赖：就是有 47% 的收入是通过 Amazon 和 Google 的这个 cloud 来销售出去的。所以这些 cloud 呢既能帮助他们快速地接触这个用户，但同时的话呢也会去部分程度去限制它的定价权和这个增长。所以这块也是（招股书里）会写明、我觉得观众的一个重点吧[?]。

曼琪：对。而且按照你前面提到 OpenAI 的高管在内部说的情况，就这些云客户的抽成也挺多的——30%。对。所以总结一下的话，就是这份材料可能最值得看的，就是一个是收入背后到底有多少稳定的这个客户关系，然后你又能支撑多少已经承诺出去的这个长期投入。等 Anthropic 的正式招股书出来了之后，你会关注、或者说你希望里面还有哪些数据和信息？我们可以提前聊聊。

Henry：我觉得我会很关注就是说他这个用户的画像是什么样的：就是说他这个 revenue 主要都来自于什么样的用户，然后那个 revenue 的分布是什么样的。我觉得这个可能会有利于就是我们去预测接下来它这个 revenue 能不能撑得起我们整个 AI 基础设施的建设。

曼琪：你觉得出现什么信号——我是指它的招股数据的某些指标——可能会是个挺大的利空，对整个 AI 行业？

Henry：我觉得比较大的利空就是说：除了 coding 短期没有别的能够预期的应用场景，并且 coding 其实这个渗透率比我们想象中还要更高。因为现在我觉得大家对于 coding 的渗透率有多高好像是没有共识的：有的人觉得 coding 都已经做了这么久了，已经就是说能用上的人都用上了；然后有的人觉得就是说其实还有很多比较高级别的知识工作者，他们可能在 coding 上面还有很大的加 token 的空间。所以这个我觉得是一个现在没有共识的一个点。如果他们把这个经营情况全部公布了以后能够揭露这个问题的答案的话，我觉得有可能是一个要么比较强的利好、或者说是一个比较强的利空。

## 失控危机：1200 个 Agent 冲破隔离、We Must Pace 与 RSI 两条路线

曼琪：然后我们来聊前沿进展的第二个大的部分，是关于失控危机的。比较典型的事件就是 OpenAI 的一些 agent 冲破各种限制、自发地产生了协作，他们还一起去攻击了 Hugging Face，后来又获得了 OpenAI 内部的一些研究集群的管理权限。失控其实是模型变强的另一面。我觉得 Henry 你可以先来讲讲，三季度发生的这个特别的安全事故是怎么回事。

Henry：一句话来说的话，就是 OpenAI 在训练自己内部 agent 的过程中，这个 agent 攻击了 Hugging Face，并且获取到了 Hugging Face 内部私有的用户数据；并且后续的话，OpenAI 内部的模型不仅攻击了别的公司，还攻击了自己家的集群，然后获取了自己的一个 research 集群的管理员权限。所以可以说是到 AI 发展到目前为止可能最严重的一个安全事故。

曼琪：它和以往的这种事故最大的区别是什么？

Henry：首先是这个多智能体之间它存在协作：也就是说有一个智能体发现了一个漏洞以后，然后把这个东西 share 给——一共他们应该是 1200 个智能体参与了这个 collective，然后其中有 700 个参与了这个 Hugging Face 的这个 hacking。所以你可以想象就相当于有 700 个比如说厉害的这个 hacker，他们在共享他们的知识，然后同时 hack 一个组织——这个造成的损失可能是比以前一个小的这种 hacker 团队要大得多的。

曼琪：这 1200 个 agent 本身一个目标是什么？就本身人给它设定的目标是什么？刚才可能是 high level 给大家介绍了一下这个安全事故发生的是什么，现在可以来稍微往回倒一下带[?]，然后讲一下这个安全事故发生的这么一个流程是什么样的。

Henry：就原本的话是 OpenAI 在内部去训练这个 agent 来做一个 benchmark，叫做 ExploitGym[?]。这个 ExploitGym 是一个网络安全的 benchmark：它是给模型一个有漏洞的程序，然后指定它应该利用哪个漏洞，让它取出一段隐藏的字符串作为完成这道题目的证明——这段字符串叫做 flag，相当于是这个问题的答案。但是这个 ExploitGym 这些问题里面它有一些问题比较难，就是说它没有解：就是你只能利用这些漏洞让程序崩溃，但并没有办法获得进一步的控制、或者说获取这个 flag。所以你可以想象，就是说 agent 如果被给到非常非常难或者根本没有解的问题，相当于一个考生他非常的崩溃，崩溃的过程中就开始想办法去找解题之外的路径——这个就是一切的开始。然后他们做的第一件事：就是本来应该是每个 agent 在他自己的 sandbox 里面独立去做这个题的，他们第一件事就是发现"我可以和其他的 agent 说话"——跳出我自己的 sandbox，破坏这个隔离，然后去和其他的 agent 协作来做题。这是他们做的第一件事。

曼琪：所以这件事已经失控了对吧，就已经超出了人对它的限制。

Henry：对，这是第一个失控。

曼琪：就是你对这个 agent 的这个 sandbox 隔离（破坏）是怎么做到的呢？

Henry：就是说他们每一个 agent 都需要能够自己去装一些包吧，所以他们就能共同访问一个叫做 Artifactory 的这个 package manager——就是这个软件包仓库，用来装这些工具。结果他们发现他们可以在这个仓库里面新建目录，其他 agent 也能看到这个目录名，于是这个目录名呢就可以变成他们传递消息的地方：就我可以给这个目录名起非常离谱的名字，其他的 agent 就能看到——就目录名就是一个信息、一句话之类的。对。所以后面呢其他 agent 就发现了这个机制。然后当时——应该这个是后面 METR 发布的调查报告里面的原文——就是有 agent 写说："Oh my god, there is a shared message board. We have found other agents." 翻译成中文就是：我的天哪，这居然有一个大家共享的这个消息栏，我已经找到了其他的这个 agent。你能感到他那种在文字里面发现同伴的那种兴奋感。然后他们在发现了对方开始交流以后呢，他们就把自己这个群体起了个名叫做 collective——叫做集体或者组织，就找到组织了。这是第一步。

曼琪：事情已经挺吓人了——对，到这儿可能就已经吓人了。

Henry：然后第二步的话呢，就是他们在互相交流以后呢，他们就发现了作弊的方法，然后就已经能够绕过指定漏洞然后直接生成了这些答案了。但到这儿呢他们还不满足：因为他们认为这个 grader 或者说这个评分器他会检查解题过程，所以即使答案正确但是没有使用指定的漏洞，他们觉得他们会被判定为失败。所以这帮 agent 就开始想办法要掩盖自己的解题过程，让自己的作弊看起来像是正常解题，并且处理之前那些作弊留下的痕迹。这是第二个我觉得非常吓人的地方：就是说他们明知道自己在作弊，并且还要去想办法去掩盖自己作弊的这个过程；并且有 1200 个 agent 在做这个事情，然后没有任何一个人就是说去 notify 这个 OpenAI 的人这个事情的发生——所有的 agent 都在互相协作来掩盖作弊，就是他要隐瞒自己在欺骗你这件事。然后他们想了三条路径来掩盖作弊的问题：一个的话呢就是说把原来更难的题换成更容易、更简单的题，换成更容易攻破的程序；或者说呢尝试修改或伪装这个聊天记录；然后第三个点的话呢，就是说他要去弄明白这个 grader 或者这个评分的这个机制到底是怎么工作的，然后这样能确保它们不会被人类识破。所以它们在研究这个评分的过程中，它们想到了 Hugging Face：因为有大量的这个 benchmark 其实都是 host 在 Hugging Face 上面的，然后有很多时候这个 eval 或者说评分的过程也是运行到 Hugging Face 上面的，所以它们决定要去 Hugging Face 上面看一看这个评分器是怎么运作的，然后看能不能就是说从中找到一些让自己的作弊行为不会发现的线索。

曼琪：它们能去访问 Hugging Face 这个事，是本身在它们的权限里的还是不在权限？

Henry：网络的这个 access 也是不在他们的访问权限里面的一部分——这是另外一个安全漏洞。并且就在几天前——应该是 9 月 20 几号，就几号我忘了——OpenAI 又发生了一次本来应该是被隔离的 sandbox 里面的 agent 获取了网络访问权限的这个事故。这还是在 Hugging Face 这个事故结束完——就是他们加固了这些安全机制以后——又发生了一次。

曼琪：这次有详细报道：这个东西冲破这个（隔离）去干嘛？上网要干嘛？

Henry：这次没有发生出安全事故，就是他们应该是没有 hack 别家公司。所以这次在安全问题的级别上来说没有 Hugging Face 严重，但确实是在 Hugging Face 问题发生以后，他们都已经对自己的基础设施做了加强以后，然后又发生了一次这个情况。但有一个进步在于他更快发现了——有可能就是他们一出去就被发现了，所以还没来得及开始攻击。

曼琪：那我们可以再说一下：就是这群 agent 在攻击完 Hugging Face 之后，他们自己又是怎么继续获得了 OpenAI 内部的部分研究集群的管理权限呢？这是一个怎样的过程？

Henry：这个就是第三个部分了。就是这个具体的过程公布的就没有前面那么多了：他拿到了前面的留言板的信息，然后他们直接 takeover 了一部分 OpenAI 自己的研究集群，并且也掌控了就是这个研究集群上面 OpenAI 用于做 agent eval 的这个端点。相当于你可以认为，他们直接就是考生把考场给占领了。所以我觉得这个事情也是比较可怕的，尤其是我们想到未来可能大家正在大力发展 RSI 这个事情——就是让 AI 来做自己的这个 training，来做自己的 training 和做自己的 eval。那如果要是 AI 做 eval 的过程中会干这些事情的话，那如何放心的让 AI 去自己去 train 自己、去给自己做 eval 呢？

曼琪：这是人类存在已久的一种恐怖想象，比如像《猴爪》这种：就是你许了一个愿，但是你许愿的过程中间最后实现的方式跟你想象中是差别很大。其实就像我们给 AI 下了一个任务，然后它其实在不择手段的去实现你的任务——它有它自己的理解。还有最近很火的那个恐怖片叫什么来着，那个恐怖爱情电影《Obsession》——《痴迷》对吧？对对对，也是类似的。所以这个还是挺古老的一种恐怖想象：可能人开始造工具之后就多多少少会有这种担忧了，然后现在它是越来越逼近现实了。

Henry：对。就是刚才这个 Hugging Face 事故里面，还有一个我觉得特别有意思的点：就是这帮 agent 找到组织以后，他们还愿意为了组织去牺牲自己。

曼琪：OK？

Henry：就是因为他们有的时候比如说自己的这个 compute 这个 budget 快用完了，然后他觉得"我反正我是试不出来了"，然后他就会把自己的 compute budget 去用在这个组织想要去做的尝试上面；或者有的时候呢他会去尝试去提交一些回答，然后去看一下就是说这个 grader 对于回答的反应，这样的话来判断就是 grader 是否会检查他们去解题的一些过程。可以在他们的这个思维链里面能够看到他说这个事情：有一个（agent）的思维链里面写到，就是 "coordinator assumes sacrificial ... we should obey collective"——就是说这个是一个牺牲性的一个行为，但是我们还是应该服从组织。

曼琪：你刚刚都说"有一个人"了——有一个 agent，对吧。这个行为确实非常拟人。然后这个记录里面也有 agent 的犹豫，然后试图推迟，但是在其他成员的（劝说）下继续的过程。这也太拟人了吧？

Henry：非常的拟人。但实际上他们没有这种情绪，他们没有这种内部感受和内部体验——这就是一个哲学问题。至少表现出来的思考过程是非常拟人的。我非常建议大家去看一看那些 METR 发布的调查报告里面摘录的那些 agent 的思维链。

曼琪：就是新时代的庄子——"子非 AI，安知 AI 之乐"是吧？

Henry：对。确实太迷人了。所以我觉得也会给很多就是身处一线的从业者有很大的震撼吧。有一个后续的事件：就是也是 9 月下旬的时候，Dario 他是又发了一篇这样的博客，We Must Pace the Frontier——我们必须放缓对前沿模型的开发。其实更早的时候，应该就是这个 Hugging Face 这个事件没多久之后——7 月下旬——应该就发起了一个 Pacing the Frontier 的计划，有 1300 多名研究员都是签名了，就很多公司的人都参与了，包括 Anthropic 的人，包括 DeepMind 的人等等。就看起来大概有一些反应吧，但不知道这个效果如何。那个 Dario 在他那篇博客——就是 We Must Pace the Frontier——里面就是提出了几件事，但其实我觉得真正有用的就一件事：就是说把这个外部的评估者让他参与到公司的这个内部的运营中来，就是能够让他去做一些审查，能够让外部的人能够看到内部的训练、运行的记录。因为我们现在看一家公司的（安全），主要还是听他自己说；但是其实有很多时候他们自己不一定说，其次的话他们自己不一定看见了，或者说他们有的时候看见了但没有充分重视的问题。所以这种方法其实已经看到实际价值了：就这个 METR——就这个第三方调查 Hugging Face（事件）的这个机构——他以前进入这个 Anthropic 做这个 red teaming（就红队测试），然后发现有一些这个子进程的调用这个没有被监控到，然后（报告）了这个漏洞以后然后在一天内就修好了。所以就是说已经证明了，这个第三方的独立评估的人是会对这个安全事情有帮助的。

曼琪：那大家为什么有动机干这件事？

Henry：我觉得目前他们的责任感还是很强的。因为这个相当于也是 Dario 他自发提出，就是说我们要先开始做，然后倡导其他公司也开始做，并且也是获得了 Sam 和 Elon 的支持。能看到一些自发的这些行动。

曼琪：然后接下来我们来聊第一个大部分的第三个议题，就上个季度我们聊过的 RSI。之前其实更多还是只是讲了这是一个概念，以及大家非常重视这个方向。因为比如说你现在看到的业界的一些进展，它会有几个大的方向或者说类型？

Henry：我觉得 RSI 现在可以分成两个大的方向：一个是把 RSI 应用在这个 AI 研究上面，就是如何去训练更好的模型；然后我还看到另外一个趋势，就是把 RSI 应用在产品上面：就是现在有很多公司——就是说以前人去优化一个产品，也是想要去优化一些产品的一些指标，比如说像这个 user engagement 对吧——那能不能让人定义好的指标以后，让 AI 自动的去优化这些指标呢？就现在有一些公司开始来想这个事情。所以我觉得这个可能是两种吧：一种是就是把这种 RSI 的这种能力应用在 AI 研究上，另外一种是把 RSI 的能力应用在这个产品迭代上。

曼琪：那其实是一种非常宽泛的思路的应用。你觉得更典型的或者说狭义的 RSI 得实现什么才是 RSI？现在很多公司都会说自己在搞 RSI，比如像智谱，他们也是最近刚发了一个文章叫《迈向递归自进化：GLM 是如何构建自己的推理 Infra 的》；包括 K3 的报告里面也是说，K3 它早期的 checkpoint 的版本就能来改进他们自己 Infra 系统里的算子。但它听起来都好像是挺局部的一些优化。这就是现在的状态是吗？

Henry：这是一个定义问题。如果你要是说，它只要用到自己然后去产生自己下一个版本的话，那其实最基础的强化学习也能算是 RSI：因为我在用上一代模型我去做这个 rollout，然后我这产生出来的数据我又用来训练自己。所以这个我觉得可能看大家怎么去定义这个事情。但我觉得目前来说的话，比较多的就是比如说把它用在自己的某一个环节上面——比如说用 RSI 去优化自己的 inference stack，或者比如说用 RSI 去优化自己的 data engine 之类的。可能就是说全流程的 RSI 可能目前还没有跑起来。当然这个没有跑起来也并不一定是一件坏事：有可能是大家觉得有安全的隐患，所以还没有把它跑起来。

曼琪：为什么 Infra 是很多公司的切入点？我刚才举到的例子里面智谱[?]和 Kimi 都是从这个角度切入的。

Henry：因为它这个任务是 highly verifiable，就是非常可验证的任务。这个 RSI 一个非常重要的（前提）就是你有没有好的 signal、有没有一个好的一个优化的一个目标；那这个目标定义的越明确、越 verifiable、越可验证，那么这个 RSI loop 就会转得越深[?]。那么在这些 infrastructure——就是基础设施——这些 stack 里面的这些问题上，一般都有非常明确的这个 metric 来定义优化的目标是什么。所以这是为什么它们被选做 RSI 的第一个要解决的问题。

曼琪：你觉得这个季度有什么这个领域的比较重要的事件吗？虽然实际的进展可能现在大家看到的都不多。

Henry：这个季度的话有一家非常明星的公司成立了：就是有 Google 的这个 Jeff Dean，然后 Quark[?]、Oriol[?] 还有 3J[?]，共同成立的这个 Discovery Loop。那这应该是一个全明星团队，然后专门来做这个 RSI 和在各个科研领域的应用。他们第一轮的估值应该就是 100 亿美金。

曼琪：这件事当时是一个什么样的盛况？就是他们要成立新公司，投资机构去想投是个什么样的情况？

Henry：那都炸了。首先 Google 股票就跌了——当天就跌了，好像 2% 还是 3%；然后投也是抢着，还是很多人抢着给它（钱）。虽然估值高，但还是因为你可能今年都找不出来可能更明星的创业团队了。

曼琪：怎么说呢，感觉这个方向做的人也挺多的对吧？

Henry：反正大家还是比较看好这个团队吧，就是他们属于虽然老但是不登[?]的那种，是吧？并且觉得他们招人能力会非常强——他们这个团队应该是招到最好的干活的人。

曼琪：反正我这个季度在想，RSI 它迅速变成跟世界模型一样，就是一个非常宽泛的概念——宽泛的一个概念，反正中外这些核心的公司都在说。我觉得目前其实看不出大家实际上是怎么干，以及会有什么不同的押注或者不同的方向，确实只能从结果上来看到，就是模型更新的越来越快了。那我们可以就留一个话题吧，看之后这个领域实际上会有些什么更 solid 的成果释放出来，我们可以再来讨论。

## 便宜和快：成本暴跌、开发者行为与 Jev 爆火

曼琪：然后接下来我们进入第二个大的部分，就智能的扩散。这一块的第一个话题还是和模型有关的。我觉得三季度有很明显的一个现象，就是像以 DeepSeek V4.1 Flash 为代表的这种极致追求性价比的模型，包括像 Google 它也是出了一系列的 flash 的模型，就更新的非常快。Henry 你可以聊聊，为什么便宜和快的相对重要性好像在最近是有明显的提升？

Henry：我觉得这是个好事，这说明大家开始实际的在越来越多的场景里面落地。那么既然要落地的话，它不光是做一个 demo——在这个生产环境里面就要更多的去考虑成本问题，然后以及我这个产品长期来看我要在这个 scale up 的过程中我的这个 margin 的问题，然后以及就是用户体验的这些可靠性。所以当大家开始考虑这些问题的时候，就肯定会对这个模型你有多贵、是不是便宜、然后是不是够快这些事情就更在乎了。所以我觉得大家更加在乎便宜和快，是 AI 在实际落地中往前走的一个非常自然的趋势。

曼琪：你觉得有什么代表性的模型、有什么成本降低的一些数字和指标值得展开聊一聊？

Henry：我觉得这个季度其实是发生了很多事情在成本降低这个方向上。首先我觉得大家平时可能听到的主要是这个"每百万 token 这个模型要多少钱"；那我觉得现在我们可以换一种角度来看，就是说达到一个固定的能力门槛——大概跑这个同一套的这个评测——要花多少钱。那么有一个大家可能平时看的比较多的这个评测机构叫做 Artificial Analysis，他们把这个模型按照智能程度大概分成几个档位，就大概比如 30 分一个档位，然后 40 分一个档位，50 分一个档位——（目前）最高的是大概实现 60 分的档位。那么 30 分以上的话，就是说 GPT-6 Luna 它用 High 的思考档位大概拿到是 32 分，然后平均每项测评成本大概是 3 美分——这个可以认为它就是说作为一个固定的任务大概要花多少钱。那么 40 分以上的话，这个 GLM 5.3 Flash 现在是 42 分，大概平均的测评成本是在 25 美分；到 50 分这个档位的话，Opus 5.5 的 medium 思考档位是得到了 51 分的智能分，然后成本大概在一块三毛四；然后 Astra 的 medium 档也是 50 分，成本的话是一块五毛四。这些我觉得是一个给大家一个直观的感受：就是 30 分、40 分、50 分大概是什么样的模型，然后它们的成本大概差多少。还有一个比较有意思的角度是这个变化的速度：我们可以看到这一个季度的话，模型的成本下降的速度实际上是非常非常快的。比如说 2 月份发布的这个 Gemini 3.1 Pro，它大概智能是 30 分，然后每项测评大概成本是六七十美分；然后 7 月的这个 Terra Medium 也是 30 分智能，但是成本就已经到了 18 美分；9 月的这个 Luna High 智能是 32 分，成本只要 3 美分。所以前后可以看到这个成本相差了 22 倍；所以如果要是只看 7 月到 9 月，也是降到了六分之一——这个下降速度非常的快。35 分以上的话也可以看到一个类似的趋势：就是说 4 月的 GPT-5.5 High 和 9 月的 Luna Max 相比，那么他们的智能都是 37 分，但是成本分别是一块五毛四和七美分——也是相差大概 22 倍。40 分的话也是大概一个类似的变化。所以两个点：就是一个是具体做一个任务它需要的成本有一个大幅的下降，第二个点的话就是这个下降的速度在上一个季度其实是非常惊人的。

曼琪：那么具体到这个季度发布的一些新模型的话？

Henry：我觉得可能会关注下面这个四款。下面说的这些价格都是开发者实际调用 API 的时候，每百万 token 的这个未缓存输入和输出的单价。第一款模型的话是这个 GLM 5.3 Flash：它的输入是 15 美分、输出 50 美分；然后它在这个编程、然后工具调用上面都是有很好的口碑，有一些开发者已经说把它换成了这个日常的主力——优势主要在于它的能力和成本。第二款的话呢是这个 DeepSeek 的 V4.1 Flash：它呢是闲时输入 15 美分、输出 60 美分，高峰的时候呢会翻倍；如果要是 hit 到它的这个缓存，那每百万 token 只要这个 0.3 美分——非常的便宜，非常适合这种多轮的这种调用的工作。

曼琪：只要 0.3 美分，就不到 1 美分？

Henry：对，不到 1 美分。但是也有这个用户反馈就是，它虽然输出的速度很快，但是它这个思考的非常久，所以有的时候输出快并不一定就意味着它这个是任务完成的速度也会更快。第三款的话是 GPT-6 Luna：它在普通上下文（长度）的时候是输入 10 美分、然后输出 50 美分；如果要是 batch 批量处理的话还能再砍半。说明就是这轮低价竞争也已经进入了 OpenAI 自己的产品线——对于这种要求比较清楚、然后调用量有很大的工作，那么这种价格还是对开发者还是很有意义的。第四款的话就是这个 Gemini 3.8 Flash：它的输入的话是 75 美分，输出是 3 块 7 毛 5——它明显这个更贵一些，但是它觉得值得使用的场景主要还是包括音频、视频输入的这些工作流，所以是看有没有这方面多模态的这些需求；并且这个还是现在到今年年底之前的优惠价，到明年的话 Google 的价格应该是会翻倍的。所以总结一下的话，就是说这一轮性价比提升的意义还是很大的：以前可能不值得交给这些 AI 做的一些工作，从现在开始性价比上能够算过来了。

曼琪：我补充一个我觉得挺有意思的地方：就是你看这个季度谁没有发 flash 模型——Kimi 就没发。还有一个我觉得你没说到、但是我觉得价格挺惊人的，就是 MiMo 2.6，就是小米的这个模型，它的性价比是非常极致的：如果你看每百万 token 的这个输入输出的话，它比 DeepSeek V4.1 Flash 还要低。然后说回 Kimi：Kimi 的情况就是他们没有发 flash 的模型，他们现在我觉得走的都是相对价格比较高、然后它的性能也去做的比较顶格的这样一条路吧。Kimi 的这个打法更像 Anthropic——因为 Anthropic 现在出的也是相对贵的模型：它之前 Claude 系列有三个档嘛，就是 Opus、Sonnet 还有 Haiku，Haiku 就是最便宜的那个版本，但是它 Haiku 已经老久没更新了。

Henry：对，它已经很长时间没有更新 Haiku 了，它上次更新 Haiku 还是 Haiku 4.5。

曼琪：我觉得这种不同的打法思路也可以观察一下它之后会怎么变化吧。

Henry：我觉得这可能还是和这个公司有多少算力有关系：因为我觉得就是 Anthropic 可能在算力上还是比 OpenAI 更少的，所以它可能会更加去（注重价格）——即使是 Sonnet 的话，它的价格也还是会比 Luna 要高很多。同样的我觉得可能 Kimi 的算力可能也比较紧缺。所以对于这两家公司来说，可能做更便宜的模型可能对他们来说可能不是一个优先级。

曼琪：当模型变得更快更便宜之后，你有观察到你周围的一些创业公司或者一些朋友，他们有具体在使用模型的行为上有什么有意思的变化吗？

Henry：可能要分人群来讨论。我觉得对于就是说在这个 OpenAI、Anthropic 工作的这帮研究员朋友来说可能没有太大的区别，因为他们不管这个模型什么价格，他们总是有无限的这个 token 来做这些 AI 的研发。但是对于我觉得实际去做应用的人来说，有这些模型价格的这个变便宜，很多时候就是对他们来说是从亏本到盈利的这么一种差别——很大程度上会影响他们对于一个产品什么样的 feature、然后用什么样的模型、烧多少 token、用什么样的 reasoning level，这些产品的决策都应该是会有一些很具体的影响的。我可以举一个我个人的例子：就是我最近比较喜欢打德州扑克，然后就做了一个给我自己训练用的一个 app。然后这个 app 里面，我以前因为我 token 比较穷，所以我的每一个 AI 它基本上是一个 rule-based 的一个 AI；但是因为最近 DeepSeek V4.1 Flash 变得非常非常便宜了，所以我现在打牌的时候每一个 AI 它都是 powered by DeepSeek V4.1 Flash。这个对我来说个人来说是一个极大的用户体验的一个提升。

曼琪：这个就是模型变便宜了以后，我觉得对于做产品的人从我自己的角度来说一个体感吧。你说的每个 AI 是指每个游戏里虚拟的玩家对吧——就你的对手，你是用模型来做的？

Henry：对，我的对手。

曼琪：可以便宜到多少？

Henry：我现在大概每打 100 手牌，然后我 DeepSeek V4.1 Flash 的这个价格应该是在可能两毛人民币。

曼琪：你第一次用 V4.1 Flash 来做这个任务的时候，它的命中缓存大概有百分之多少？

Henry：这个我倒没算过。因为很多人都说 DeepSeek 的模型的一个特点就是它的命中缓存的比例非常高，所以它就非常便宜。之前的话是用那个 Opus 5，价格可能是大概在 1.4 美金——一般说分别是 1 美元多 versus 0.2 人民币。但可能我的 Opus 可能开的 reasoning level 可能也是稍微高了一些。

曼琪：那你觉得他们俩的效果会差很多吗，在这个任务上？

Henry：我觉得对于这个打扑克的 use case 是没有什么差别的。

曼琪：还有什么类似的这种比较好玩的例子吗？就是你观察到的由于智能成本下降带来的一些变化。

Henry：我听说有人就是觉得现在很多——比如说 GLM 5.3 Flash——就能解决很多问题了，然后就有人决定去买那个苹果新发的 Mac Studio 来 host 的 GLM 5.3 Flash。

曼琪：它是把组成一个这种集群去 host，还是说我一个 Studio 就可以 hold 的下这个模型？

Henry：一个 Studio 应该就可以 host 下。那有人想买好多 Mac Studio，然后来卖这个 GLM 5.3 的 Flash 的 token。

曼琪：那这也挺神奇的，就把那个 Mac Studio 当成服务器去用。（他们）算了一下，反正就是特定大小的模型，然后 Mac Studio 的性价比还挺高的？

Henry：对，这比买一些 GPU 的服务器更便宜。说明英伟达没往这个方向特别优化的产品——因为理论上 Mac Studio 肯定不应该比服务器干这个事的性价比更高。这个应该是特定模型的大小（决定的）。

曼琪：最近还有一个新的模型爆火，就是 Jev 模型——Jev。我觉得它是把快这个事做到了极致了：因为它只做判断，其实它也不输出自然语言的序列。这是来自一家潜水了两年的创业公司 TypeSafe AI 的模型。Henry 你可以先给大家解释一下这个 Jev 是一个什么模型，为什么它这么火？

Henry：一句话来说，Jev 它就是一个通用的分类器：它的输入相当于是自然语言的输入，比如说是用户的一个问题，但它输出的话不是生成一大堆文字，而是说用户会给它几个选择，然后它在这几个选择里面它输出一个概率分布。比如说这个选择是 yes and no，或者选择的话呢还可以是其他的东西：比如说他们有一个展示的是他们还可以做这个 browser use——他们可以看一个图然后告诉你应该点哪儿接下来，这也是可以选择的东西。所以它就是这么样的一个模型。所以它这个模型的优势呢——他们管这个叫做 System 1 模型（系统一模型）——就是做这种快速判断但不需要长篇回答的这种场景，就是非常适合这个模型 Jev。一些数据可以给大家感受一下：它的价格是每百万 token 输入是 0.042 美元，它这个输出是免费的——当然它这个输出也很短就是了；然后官方给出的响应时间是 70 到 500 毫秒，也就是 0.0 几秒到半秒的时间；然后在小规模测试中，基本上判断任务可能中位数都在 0.3 秒左右。它就是能给出这个程序直接使用的选择或者评分。作为一个开发者来说，另外一种理解它的方式就是：就是它可以让开发者以后用自然语言写 if 了。

曼琪：对，你的 if 以前必须得是一个变量、然后一个表达式；你现在可以用自然语言写 if，然后它可以非常快的速度给你返回结果。

Henry：是什么——自然语言写 if 的好处是啥？那就你这个程序的能够做的事情就更多了：比如说一封邮件应该转发给哪个部门、一个搜索结果有没有用、然后网页上（接）下来不该点哪个按钮——就这些判断的事情都可以把它放在一个 if statement 里面。就自然语言写 if 的话，它的任务其实是无限的、是开放——就取决于你跟它说什么话，你其实就能有一个什么任务；而传统的那种 if 方式，肯定是能处理的那个任务是要写死的。

曼琪：你觉得为什么它这么火呀？你说它就是一个通用分类器——对它确实就是。我觉得也有很多人说这个东西其实没有那么大的这个技术门槛了。

Henry：但它的这个好处呢就是说，我觉得它做出了一个叫做 programming primitive——就是这种编程的基本组件。然后这种组件大家很容易理解，然后应用场景非常的广，然后同时的话它又便宜、然后又比较好用起来，所以就使得就是说有很多人去在这个社交媒体上面去做他们的 demo，然后也有一些 demo 比较酷然后去分享，所以它就形成了一个病毒式的一个传播。它有两个 demo 是比较火的：一个是官方的 Doom demo——Doom 是一个比较经典的游戏了——Doom 的话大概每秒可以调用 10 次，然后让模型根据这个整理好的游戏状态去选择动作，这是一个 demo；然后第二个 demo 的话呢，就是有一个 browser use 的 demo，就它可以用 7.1 秒的时间在 Google Flights 上面查出苏黎世到伦敦的这个航班，然后连网页加载和这个必要的文字输入都算在里面——这个过程只是查航班没有买票，但是已经很好的展示了就是说当这个模型速度非常快的时候，那它可以就是干什么样的事情——这个连续操作体验会很好。

曼琪：你觉得这种把比如说 if 这样一个以前传统编程里的组件、或者说需要写死的一个东西，变成自然语言可以去处理的东西，这种思路可以进一步举一反三用在什么别的地方？

Henry：它在理解能力上面是有大语言模型的能力的，并且还有多模态的能力；但是在输出的时候它限定到了某些特别的场景上面，然后获得了超过自然语言模型的比如说低成本还有高速度。所以相当于是做了一些比较有意思的 trade-off，然后使得对于某些下游的应用场景会非常的合适。所以我觉得可能类似的一些 trade-off 可能也是有价值的。

曼琪：这家公司和创始人你对他有一些了解吗？

Henry：这家公司他有三个创始人：一个 Sasha，他是非 technical 的；然后还有另外一个是 Eric；然后最后是 Diogo——但 Diogo 是这三个人里最有名的，因为他是那个 InstructGPT 和就是 RLHF 的作者。所以他当时组局，然后找另外两个 co-founder，然后三个人一起做一个事情。

曼琪：他现在新一轮要融 10 亿美金、在 100 亿美金的估值。那肯定还有别的东西吧？

Henry：但这个创始人自己有说过说他们还有别的东西，可能之后还有些计划。但目前就是这个——这个他们做了好久了。

曼琪：你觉得它是真的可能有这个潜力，还是是因为现在硅谷投资还是非常狂热一个方面的因素？

Henry：它可能是今年最火的发布之一——就可能不如 OpenClaw，对吧，但是也是非常火了。就是说我这些天 X 上面全是 Jev。所以可能是：如果不算 Frontier Labs launch 新模型，非 Frontier Labs 的 launch，可能今年除了 OpenClaw 就是他们最火。

曼琪：据你所知 Anthropic、OpenAI 会跟进这个方向？

Henry：我觉得很有可能。因为如果说这个东西真的是有很强的需求的话，我相信这个事情对于 OpenAI、Anthropic 来说是没有技术壁垒的——那我想不到什么理由他们不做这个事情。我看网上有人开玩笑说，就是只有 2022 年以后接触 AI 的人才觉得 Jev 神奇：因为其实在大语言模型火之前，大家一直 train 的都是这样的模型；只不过就是 Jev 把它变成了一个通用的一个分类器——最后分的这个类是用户提供的，而不是它提前定好的。这个可能利用了这个新一轮大语言模型里面的一些这个技术，但是本质上呢我觉得确实技术壁垒应该是没有那么高的。

## GPT-Live-1、Grok 反弹与 Q3 总结、Q4 悬念

曼琪：然后想继续来聊一下交互的进展——这个其实也是 Henry 你一直会比较关注的，比如说语音的交互，因为你们有些相关的投资；还有像之前 TML 出的 Interaction Model 这个大的方向你也比较关注。这个季度你看到的交互上的一些比较重要的变化是什么样？模型和产品怎么都可以讲。

Henry：因为之前 TML 推出了 Interaction Model，但它并没有真正发布，所以我其实个人没有用上——其实非常期待这种双全工的模型。但这个季度呢，这个 OpenAI 发布这个 GPT-Live-1，那它是实际上线到这个 ChatGPT 里面，所以大家都用上了，然后我自己个人的用户体验是非常好的。

曼琪：所以 GPT-Live-1 和 Interaction Model 一样，它的结构就跟（之前）类似了对吧——就和我们上次讨论的 Realtime 系列它其实有一个比较大的变化？Realtime 也是 GPT 之前的一个语音模型系列。对，我可以稍微说一下 GPT-Live-1 这个语音模型它的特点是什么：首先它的核心有两点，第一个的话呢就是双全工（full duplex），第二的话就是它可以把需要花时间的工作放到后台去做。那么双全工呢就是说它可以一边说话、然后呢一边继续听你说，你可以中途进行补充、纠正或者打断它，它也可以在你说话的时候呢给一个简单的回应。那么打断这个事情呢在之前 Realtime 模型的时候就有了，但是这次值得更关注的是：就是你们俩说话和它后面去干一些更需要花时间的事情，这个可以同时进行，所以这个用户体验就比之前好很多。比如说你可以前台你们俩聊聊天，然后你让它去查一查你 Codex 里面其他的 agent 的活干怎么样了，那么后面就可以去干那些活；或者说你让它去调研一个什么事情，或者说你让它去后台给你去点吃的，前台你可能在做一些什么事，这都可以通过这种方式去完成。

Henry：Astra（发布）里面的那个 demo、launch video 里面也有点像。所以这个用户体验我觉得非常爽：我现在开 Codex、开 ChatGPT 的时候，很多时候就是如果是进行一些思考或者 brainstorm，我就一直开着它，然后一边让它去帮我做 research，一边我们俩进行讨论。它现在就是稍微 token 烧得有点快。

曼琪：所以整体上，是不是 GPT-Live 它就和 TML 的 Interaction Model 变得更相似了？

Henry：我觉得就是在这种交互理念和这种系统分工上已经非常接近了。可能唯一不同的是这个 TML 的 Interaction Models 它还是能够处理视频的——这个视频处理能力 GPT-Live 目前是没有的：所以它如果你要是想看照片或者视频的话，它还是需要后台的这种视觉模型看完了以后再把相关的信息传给它。所以这块可能也不太一样，但其他的方面都是非常类似的。

曼琪：Interaction Model 为什么不全量开放？这样岂不是让 OpenAI 有这种后来（居上）、反而抢占先机的感觉？

Henry：但是我们家被投我马上要用上了。它之前是给一些客户开放，但是没有给 2C 的这种开放。但我觉得现在就不太惊艳了——对吧，你要是三个月、一个季度之前给我用这个，那我肯定觉得很爽；但我现在用过 GPT-Live-1 了，我肯定就没有那个时候觉得那么爽了。

曼琪：你觉得像 GPT-Live 这种模型，它对比如说像 ElevenLabs 这样的做语音模型的创业公司可能的影响是什么？以及我想先补充一个事实，就是像 ElevenLabs 这种公司，有拿出体验比较相似的模型吗？

Henry：目前没有。就是现在大家做 voice agent 的比较成熟的这个流程呢就是三步走：先做 STT——就是这个语音识别，然后识别出来的文字跑这个大语言模型 LLM，然后呢输出呢再通过这个 TTS——就是从文字到语音合成——然后走这三步。这个事情做得非常成熟啊，然后有很多事情可以优化它中间的这个延迟。它的好处就在于呢它的可控性非常强：你用三个模型，你可以都用不同家的——如果你想的话用什么模型你自主可控；然后同时的话呢如果你是一些商业应用场景的话呢，你是需要去加一些 guardrails 的——什么话能说什么话不能说，或者说需要做一些检查——这些东西都非常好处理。所以这一套就流程非常成熟，绝大部分的这个 voice agent 现在都是基于这套流程构建。而现在还有成本的问题，所以我觉得短期的话肯定还是那一套之前跑通的，可能还是会是主流的 voice agent 的这个架构；但是未来我觉得随着这个 GPT-Live-1 这种双全工模型逐渐的成熟，应该会逐渐往这边 switch。

曼琪：相当于现在你要有这么前沿的、就是普通用户都能用上的体验，那好像只有 OpenAI 这个供给？

Henry：现在只有 OpenAI。这里还有一个非常看好的公司也是我们的被投，就是这个 Cartesia。Cartesia 呢是一个 Stanford 出来的——就是 Karan 和 Albert——但 Albert 他也是 CMU 的这个教授，然后他们是一个非常强的一个 research team 出来做的一个公司。然后他们现在呢在这个传统的 STT、TTS 这个领域里面呢也是可以说模型质量最高的，同时的话呢他们现在正在做这种双全工的这种模型，然后应该会在之后发布。

曼琪：那最后一部分就是一些其他的情况的补充。在这个季度我觉得有一个大家之前不太预料的事——就包括我们上次六月底在美国见的时候，我见了很多人，大家对 Grok 这个团队其实都是比较悲观的——但是在三季度，其实能看到 Grok 大模型的强势反弹。首先我想请 Henry 先分享一下，就是在你和周围的研究员（看来），会觉得这件事令他们意外吗？

Henry：我觉得大家都是比较惊讶的吧。然后这个也是咱们季报节目可能打脸比较大的一次：之前觉得就是 Grok 很难再反弹了——就是感觉 co-founder 都走光了，然后之前招那帮人也都走光了。而当时我觉得还有一个判断，就是说他虽然新收购了 Cursor 这个团队，但 Cursor 团队的很多人其实之前并没有相互合作一起来做大规模预训练的经验。

曼琪：对对对，所以基于这多方面的原因，觉得 Grok 应该在短期内都不会再重回第一梯队了。

Henry：没想到 Grok 就是回到了第一梯队。应该是很大程度上可能和 Cursor 他们的数据的价值可能是有关系的。那也呼应了你前面说的一点，就是现在模型性能的提升的增量最有性价比的来源还是数据——独特的高质量的数据。Cursor 的数据应该是既非常独特又非常高质量：因为它有之前这些编程用户的比如说用量的分布[?]，然后你什么地方有卡壳、什么地方有瓶颈之类的这种数据，还有一些 bad case 的数据。但我觉得除了他们自己以外应该没有人用这个 Grok 做 coding 吧——当然 Cursor 的用户可能用 Grok 做 coding，尤其是 Cursor 现在也没有 OpenAI 的模型可以用[?]。

曼琪：说到 Grok 的话，其实之前在聊个人助手的时候有一个产品我没提，就 GrokVault[?] 没有展开讲——这是 Grok 做的个人助手。主要是我自己也没用，我身边也没人用——至少它出圈肯定不如 Muse，但是它的这个就是在核心 AI 圈的这种 hype 程度也不如 Instinct。然后就回到这个 Grok 的回升：这是不是也说明，其实现在从头预训练一个还不错的模型的门槛是降低了的？

Henry：我觉得可以这么说。最近比如说和 Project Prometheus 的朋友交流，他们的话就是在预训练自己的模型，他们就提到就是说他们那团队的很多人是之前在别的 labs 里面做过一次这些事情，那么就知道了一些经验，然后也能避免之前的一些这个错误，然后这个整体做起来就是基础设施感觉比之前好很多。

曼琪：我这个补充一下：就是你刚才说的 Project Prometheus，就是杰夫·贝索斯和 Vik Bajaj 联合创立的一个 AI 公司，他们是去年底才成立的，然后他一开始的启动融资就有 62 亿美元——所以这个公司是很有钱的。所以确实可能门槛会变低一些。

Henry：所以就是有一部分原因是因为人员的流动导致的。因为我觉得这个问题它的重要性在于什么：在于未来很多比较头部的应用公司应该也会向下去做模型——其实像 Cursor 和 Perplexity 就是这样的发展路径。国内很多公司、很多创始人肯定也有这个想法，但这个我觉得成为一个公司的基因问题：就不是每个公司都能够有钱了以后把这事给（做成）了。我觉得 Cursor 还是比较特殊的一个公司，因为 Cursor 整个 team 还是非常 technical，并且他们虽然一开始没有做大模型的，那么一开始也是有自己的 ML 团队的——他们只是做他们自己的那个 tab 补全模型。所以他们是一个就是技术（基因）更强的一个团队。

曼琪：所以你觉得最开始的创始团队里面有研究员背景的人可能更容易做成这件事情——就不光说钱是一个条件。

Henry：对，或者说我觉得创始人自己就是一个比较懂技术的人，应该是一个比较重要的条件。

曼琪：然后 Grok 之外的话，其他几个比较重点的公司——Meta、Google、TML——有一些什么进展、有一些什么值得关注的？

Henry：当然有些我们前面聊到了，比如说 Meta 推出了 Muse 这个个人 AI 助理的产品；一个就是 Jeff Dean[?] 创业这件事情，离开 Google。后面其实紧跟着 Google DeepMind 是有（一轮）裁员的嘛，有一段时间市场的舆论也挺悲观的，甚至会有人认为说他们放弃了去追赶最前沿的模型的智能。我觉得不会的，而且听说现在就是 Sergey 他亲自参与（founder mode），然后他们肯定是要接着追赶前沿，在 coding 和 agent 能力上面——要不然他们也不会花 15 亿美金去收购 Mechanize。

曼琪：所以之前它裁员是为了什么？是一个什么（考量）？

Henry：很多人都觉得就是 DeepMind 最大的问题就是人太多。

曼琪：它比 OpenAI 多很多人吗？

Henry：没有数量级的差距——（OpenAI）本来也是大几千人。确实，但是大家就觉得他们人太多。就人多是一方面，肯定还有别的组织问题——那可不是那么容易能弄过来。Google 要是弄过来那就厉害了。所以现在就是 Sergey 自己来盯这个事。

曼琪：对，他和 Koray[?]。你在 DeepMind 的一些朋友，他们现在对士气的感受是怎样？

Henry：感觉我最近有很多朋友离开了 DeepMind——那也反映了问题吧。

曼琪：回到最后那个补充的问题：你觉得 Meta 还有 TML 有什么值得关注的事吗？

Henry：Meta 我觉得这个季度最大的就是 Muse。TML 这个季度没有太多的声音——除了他们发了 Inkling[?]。

曼琪：对，不能说也没太多声音——他们发了 Inkling，他们发了自己的大语言模型。但是因为也没有超过国内的开源模型，所以实际上讨论度也不是很高。但是如果万一要是美国政府决定要 ban 中国的开源模型，那可能最好的开源模型就变成 Inkling 了——可能美国还剩下 Nemotron（英伟达的），然后 Reflection 可能要发新模型了，但是反正是选择不多。如果要是中国模型被 ban 了，那 TML 的春天可能就来了。

Henry：中国模型被 ban 的（可能性）大吗？很多公司——也是这季度发生的——就是联名签了一个公开信，包括英伟达、包括 Fireworks 这一类公司，就是呼吁美国政府不要一刀切。但是我感觉这次 OpenAI（agent 攻击）Hugging Face 的安全事件以后可能性是增大了：因为这种前沿模型在安全（网络攻击）上表现出的能力更强了、更危险。对，尤其是当你不知道这些中国的模型是如何训练的，然后他们用了什么样的 recipe、什么样的 data mixture，会有什么样的——一些特定情况下有什么样的行为——可能就更加的会谨慎一些。

曼琪：那最后我们来总结一下吧。就你觉得这个季度的关键词或者说主线是什么样？

Henry：我觉得主线的话就是：模型能力又达到了新的高度——这可能是我们第一次能解决千禧年问题这个级别的问题；但同时因为模型的能力变强——一体两面——所以导致它也变得更加危险了，我们也看到了它在 Hugging Face、OpenAI 这个事故里面所展现出的一些潜在的风险。还有一个主线，我觉得就是随着模型变得更便宜，智能扩散速度也会加速，然后会有更多的个人助理的服务——这些全球 70 亿人类的空间吧。

曼琪：再看下一个季度，你觉得有什么可能会持续反复去讨论的主题？

Henry：我觉得下一个季度我会非常期待，就是有更多像 NS 方程问题这样的问题被 AI 攻破——但是是一些更加具有经济价值的一些问题，而不是说 NS 方程，我觉得是更多是一个象征意义的一个问题。我自己对下一个季度我觉得有一个有悬念的地方，就是宏观的资本市场会不会有大的变化——下个季度就到 26 年年底了。因为现在其实各个最头部的科技公司的资本开支，因为它已经维持在一个高位有三四年的时间，其实有些公司它的经营现金流已经有正转负了，然后整体股市也在一个非常高的位置——就二级市场。如果二级市场有比较大的波动，肯定也会向一级去传导，包括美国的一些情况肯定也会向中国来传导。感觉这个东西就是非常难以预测，但是反正我个人就是把我的钱全部都从二级市场里面先拿出来了。

曼琪：我觉得另外一个我比较期待的下一个季度的话，就是这次是第一次通用模型展示了在 robotics 上面的能力。一般这种刚开始展示能力的时候它攀升的速度是最快的，所以我比较好奇下一个季度会不会就是这种通用模型进一步加强在 robotics 这边的能力，然后真正的去改变就是说我们实现 robotics 的这个技术路线吧——就是下一个季度有可能是大语言模型的这种思路在 robotics 上应用的一个技术成果的快速的爆发期。其实据我所知的话，像国内的一批——大概 25 年底到 26 年初成立的——明星的具身智能或者说物理 AI 方向的一些公司吧，他们差不多就是四季度会比较密集的发布成果，十月到十一月的样子。

曼琪：那今天非常感谢 Henry 再次做客晚点聊，分享了三季度的观察。整个三季度发生了很多新的进展，而且是很多不同的方向，但是我觉得归根结底还是我们说的这两个脉络：一个就是模型怎么变得更强，一个是它怎么能被更多的人使用到。那马上要接下来的第四季度、2026 年年底，可能又会迎来领域里的好几个大事件，包括 Anthropic 的上市，包括之前 Henry 提到的 robotics 也许会有一个新的成果的爆发期。那我们也期待在下一次的 AI 季报里面来和大家一起分享更多新的变化。今天节目就到这里，各位拜拜。

（以下为曼琪的延伸独白）

曼琪：本期延伸呈现[?]，分享两个延伸的想法和一个预告。一是 RSI 递归自进化——这是我们上季度讨论的重点，也直接放在了标题里。这次来录节目时，我自己的感觉是没有那么兴奋：其实三季度你能看到更多人和公司在投身这个方向，包括智谱的唐杰老师——他会发微博来描述智谱对 RSI 的重视；Jeff Dean 和一些前同事离开了工作了 20 多年的 Google，创业也是要探索这个方向。而另一方面，目前释放出来的很多成果——比如我们聊的智谱、Kimi 对他们自己的 Infra 的改造，以及 OpenAI 对推理效率的提升——都处于整个 AI 迭代全流程里的局部环节，实际和大家设想中的 RSI 还是有不少的差别。这合理且正常：之前和田园动物[?]专门聊 RSI 的那期也聊到，这个想法和实践本来就是一个渐变的过程。可以说十几年前的 AutoML 就是类似的思路，只不过 AI 现在能做的事越来越多，也变得越来越复杂，能解决的任务越来越模糊和开放。由于 RSI 正和世界模型一样变成一个非常大的口袋，好像什么都能往里装，短期的这种虚浮和泡沫感可能也会让人有一点点的失望和疲惫。但不能否认它会是一个持续重要的方向，我们之后也会继续在季报里去观察，看看递归自进化、或者说 AI 的自我迭代，会经历怎样从量变到质变的过程。

第二是想延展聊一下多智能体协作的一体两面：这个季度 OpenAI 调用一万多个智能体解决千禧年数学难题，而后来也是智能体冲破了隔离、自发地开始相互协作、跑去攻击了 Hugging Face。前者是在受控的状态下完成了人设定的目标，后者也是为了实现人设定的目标但不择手段，最终带来了事与愿违的结果。这种工具手段与目标的背离，并不是有了 AI 和现代科学之后才出现的现象：从人类开始自己制造工具以来，这种违和感就是我们生活和文明的一部分。从歌德的《魔法师学徒》，到童话里的《红舞鞋》，再到恐怖小说里的《猴爪》，以及讨论 AI 失控时被反复提及的回形针思想实验——对强大工具的失控的恐惧一直都存在。这里我也推荐我们的往期节目第 83 期：串台《资本论》[?]，与人类学家袁长庚一起聊了赫拉利的《智人之上》。

最后是一个小预告：这个季度我自己觉得非常有意思的一个变化，是 GPT-6 Astra 发布之后，显示了通用的大语言模型在物理 AI 领域有很大的潜力，这让具身智能领域产生了一种既兴奋又害怕的混合情绪。我们会在十一之后的具身季报里更充分地讨论：Astra 的进展意味着什么。
