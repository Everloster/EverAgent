## 一、为什么榜单 99 分，商家没感觉（本集核心问题）

- **Coding 渗透率 ~99%，第二个垂直赛道都远远小于这个数**：coding 100% 数字化（GitHub 可学）+ 天然可验证（编译/对错）；商业场景数据多元、无通用流程、好坏判断因企业而异、反馈闭环以天/周/月/年计。
- **107-task benchmark 的由来**（开源）：模型发布"各个角度都更好、榜单 99 分+"，但日常使用没有同样幅度提升——"coding/数学/agentic 得分高，与电商领域能完成更多工作，没有那么大相关性"。基于 alibaba.com 上百万真实经营数据+Accio 真实问答整理 107 个任务（七大类、L1-L4 难度、snapshot 持续增加）；**最前沿模型无人干预通过率 ~61%**。任务例：从大量报价中选对供应商（掺钓鱼邮件、算含税到手价）/在船公司网站真实 book 到船/判断纠纷该赔不该赔需不需要更多信息。
- **"商业 AGI"的定义**：给定边界（budget/供应链相同），**agent 经营一定比人赚到更多的钱**——这就是商业领域的 AGI。
- **Agent = Model × Harness × Context（乘法）**：任何一项为 0 结果为 0。Harness 上精力最多（连 tools/管 memory/授权，电商天生长程——连续几个月执行经营）；Context 天生优势（20 多年平台数据）；Model 现在也花非常多时间——**Model 与 Harness 要一起优化**：基于一定尺寸模型做后训练+serving+harness 同时精细打磨（千问最新小尺寸 post-train 已非常接近 frontier top）。

## 二、用得起：帕累托路由

- **"必须是一个用得起的 AI 才是一个有价值的 AI"**——日常经营产品≠一次性解数学题。
- 107 任务全跑完：**Accio 3.69 美元 vs Codex/Claude Code 9 美元+（约 1/3）**。L3 以下简单任务路由到小尺寸/高性价比模型；多模态/视频路由特定模型；auto 模式帮用户帕累托路由。**绑定自家模型的 agent 没法做路由**（对照美国 OpenRouter/Fireworks 生意——模型成为 commodity，每段时间都有更好的开源模型出现）。
- 防腐化：模型/agent 迭代一段时间后原 case 会变差——每个版本都要 eval。

## 三、商家真实用法：难度爬坡 + 高频 use case

- **任务难度持续上移**（发布第一天到今天的截图）：L1 问问题→L2 交任务→L3 复杂任务→L4 经营判断级——"商家侧每一段时间都会 push 产品解决更复杂的问题"。
- **五大高频场景**（B2C 商家）：①跨平台利润核算（多平台流水≠利润，以前人肉切平台整理 Excel 还不一定算对；现在任意时点给跨平台实时经营结论）②多平台商品发布/统一 update/大促打折（插程叠加起来工作量巨大，AI 做完给判断，放草稿箱或授权发布）③客服经营复盘（AI 分析全部回答谁更好，以前开经营会一条条看）④2B 交易预警（单子要黄了提前预警+下一步最重要判断）⑤供应链全周期（见 Edward 案例）。
- **Edward 案例**：养死花→想让植物告诉自己状态→Accio 做 Design Pack（"供应商说没见过这么专业的 design pack，一般买家纸上画一画"）→匹配广深最厉害厂商→HS code/船期/物流→多平台（Amazon/eBay/Shopify/TikTok）销售管理——**完整生意周期一个 agent 跨端完成；Excel 月级流程压缩到 24 小时**（20 列×十几个供应商×以月计 → 一天）。

## 四、多 agent 冲突与人的判断

- 各平台 agent 建议不同很正常：**Accio 站在商家"一本账"角度整体优化**（各平台怎么投入）；老板要有整体经营目标（毛利/规模/速度）——"不做统一 agent 统一所有意见"。同一笔交易成功了也可能导致商业失败。
- **永远留给人的**：支付/采购按钮、idea 靠不靠谱（真问题？客户群体？支付溢价？）、产品 taste、市场预测、budget 分配（更多广告还是更多库存）——"AI 帮做分析调研竞对[?]判断，最终商业判断是人按按钮"。

## 五、上云 vs 长程（对"在场"论的正面回应）

- **上云是 basic 需求**（PC 版几天后就有云端；"今天没上云就是功能没做完"）；**长程是另一个概念**，分三类：①定时任务（每天店铺经营报告/员工表现）②事件驱动（买家与多供应商沟通中 AI 基于更新信息推进）③季度级复盘（这盘生意赚没赚钱）。
- **"追求模型 7×24 跑一周不挂，不挂 means nothing——核心是定义场景下完成什么目标"**。

## 六、SaaS、中美与全球化

- SaaS 与 AI 互相集成：SaaS 懂企业上下文（**ontology**：请个大学生也搞不清企业各数据意味着什么、老板要优化什么）；简单 SaaS 被 AI 削弱存在。每个时代有每个时代的公司（Harvey/Open Evidence 是 AI native）。
- 中美差异在 harness/context（工具平台不同），交付目标一样；美国垂直 SaaS 生态 vs 中国平台整合惯性；**AI 产品第一天就是 global**（无语言问题+LUI 交互门槛大降）——"AI agent 时代新的产品设计范式"，前提是需求本身接近（电商最大公约数接近）；Accio：供给侧中国企业多用、买家/经营侧海外用户多。
- **CoCreate 洛杉矶 15000 人到场**（booth 排队到中午）；CoCreate Pitch 冠军案例：**英国 15 岁初中生**（Accio 找供应商做自动降温宠物毛巾系列，**年销 100 万英镑**）；美国冠军 Christian Reed（MIT 毕业"工地化穿着"，酷炫测量设备，客户含**施耐德电气+SpaceX，年营收几千万美金**）——"中小企业不需要大公司也能把生意做大；AI+全球供应链=中小企业自我价值的放大期"。
