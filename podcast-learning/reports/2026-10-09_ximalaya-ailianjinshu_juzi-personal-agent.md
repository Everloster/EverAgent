# AI炼金术：橘子——先行者的转向

## ⚡ 速览

- 个人 Agent 火的三个真原因：**agent 上云×撒币补贴×便宜模型质变**（token 成本半年降几十倍，免费打法回归）。
- 一线踩坑：**99% 的人没有日历、没有"支使别人干活"的肌肉**——AI 圈在信息茧房里研究"变态的小众需求"。
- 十月拷问："**产品和技术今天没有任何壁垒**"——爆款只给你两周窗口；增值的是控流量/信任/渠道的"老登资产"。

## 概览

- **时机复盘**：半年前 ColaOS 被"杠太宽泛"；现在 Instinct（融资最猛）/Muse（带飞股价）/Grok Bot/Dot/Manus Q 全线爆发。为什么现在：①agent 上云（豆包式零门槛+runtime 能力×10-100）②撒币大法（全免费+补贴云成本）③**便宜模型 agent 质变**：DeepSeek Flash/Haiku 5.5 已能干"订机票操作软件"——每用户月成本从几百美元（Opus 4.6）降到约 10 美元≈SaaS 订阅价——**补贴 token 比获客便宜，滴滴大战可以再来**；下一步是"接近免费下的新商业模式"（广告模型，Ben Thompson/曾鸣同理）。
- **踩坑实录**：99% 没日历（线下发传单没人看）；没有支使肌肉（大部分人不 build 只刷短视频）；agent 协作使用率低得吓人；context 输入烦（关系不在文档里）；手机做东西不成立→重投本地；程序员用户极少（去 Codex/中转站）。**真实受益者=30-35 岁、有人脉业务积累、没团队的小公司老板**。
- **转向**：办公不卷（managed agents 是基建非产品）；做垂直（本地生活商户 AI 运营，Product Hunt 发布）；个人 agent 做"**965 之外**"——第二资产曲线（副业/摆摊/淘宝店）；判断依据：无数人教赚钱=真实注意力需求；**AI 无身份→人的身份值钱**（宝岛眼镜/农村老人刷视频月入千元的 UBI 雏形）；**教练式优于秘书式**（做不会的事不易被挑毛病）。
- **融资悖论**：投资人"想听非共识但等它成共识再给钱"（《让子弹飞》比喻）；中国 personal agent 创业不成立（无邮件日历习惯+大厂两周全发+平台封闭）；美国=5-10 年烧钱游戏（"你说产品好，Meta 说我免费"）；豆包的战略尴尬（机酒抽佣 make sense 却去搞办公，海外火的又是纯豆包）；ColaOS 今年目标**盈亏平衡**（达成=runtime 无限）。
- **壁垒消失**：Manus/Dot 一个月赶工复刻；软件无红利（小而美服务→ARR 数百万可以；出圈拼的不是产品）；**Jev 式"币圈玩法"**：领先一天炒到顶、考虑下十轮融到位、之后换方向都行——爆款=两周窗口。模型吞噬一切：Opus 5.5 做完知识视频/破解 3A 大作随便改（"一切终将开源"）/世界模型赛道"被干脆"/Seedance 拉平 20 分优势。**增值的=控流量/信任/渠道的"老登资产"**（茅台/线下喝茶/脏活累活）。
- **彩蛋**：Next Token 播客涨粉秘诀=平台官方推流（"认识人+让老板推一下"）；Gemini 不如 Nano Banana 2.1；GPT 100 刀用不完 vs Opus 200 刀花得完。

## 增量观点（polished 之外的连接与分析）

1. **个人 Agent 创业者三部曲在本周齐了**：[[2026-09-24_xiaoyuzhou-luanfanshu_today-personal-ai|Today 277]]（高策+Suki：技术成熟度前夜做通用）、[[2026-10-12_xiaoyuzhou-42zhangjing_zihao-ambi|Ambi 子皓]]（硬件结合）、本集橘子（先行者转向垂直+本地）——**三种路线选择恰好覆盖了该赛道的全部战略空间**。橘子独有的贡献是失败数据（agent 协作使用率、99% 没日历）——这是 Today/Ambi 都不会公开说的部分。
2. **"便宜模型 agent 质变"给梁琛奇的娱乐三要素补了第三块拼图**：[[2026-09-24_rss-wandian-latetalk_liangchenqi-ai-joy|梁]]说娱乐需要推理成本降（DeepSeek 后 ROI 打正），橘子给出 agent 侧同一现象的精确数字（每用户几百美元→10 美元=SaaS 价）——**"免费打法回归"是 token 成本曲线与获客成本曲线的交叉点**，这个交叉点同时解释了娱乐、个人 agent、云端电脑三条赛道的爆发时序。
3. **"教练式优于秘书式"是于红/孙宇晨决策框架的 AI 应用版**：[[2026-09-27_xiaoyuzhou-crossing_yuhong-sel|于红]]"画叉叉"（信息优势方不易错）、[[2026-10-10_bilibili-shaoailun_sunyuchen-ai-era|孙宇晨]]"开图"——橘子把它产品化：**AI 做用户"不会的事"（教练）比做"会的事"（秘书）容错率高得多**。这直接回应了 Today 277 的"数字资产前提"：没数字资产的人需要的不是助理而是教练。
4. **"产品无壁垒+两周窗口+币圈玩法"是本周最冷峻的资本观察**：与 [[2026-10-11_xiaoyuzhou-crossing_yage-ai-strong|鸭哥]] Jev 三条件对照——鸭哥解释了为什么火（技术/需求/包装），橘子解释了火的后果（一个月全行业复现、领先一天的估值游戏）。**"爆款=两周融资窗口"应与梁琛奇"3 万个找 100 个"合并为 2026 创业方法论的两面**：快测快放弃 vs 快爆快收割。
5. **"老登资产"为判断力保值线补了资产端**：AK 的"签字权"、鸭哥的"表达力"是能力侧；橘子指出**流量/信任/渠道的所有权**是资产侧——资源 owner"连智能手机都不太会用、靠喝茶闻味道"恰是其不可替代性（线下 connection 是 AI 帮不上忙的）。这与 [[2026-10-09_xiaoyuzhou-tingdong-zhangsheng_father-son-money|冉总]]"敢要敢问就会有人给"（Warren 的资源积累）构成代际呼应。
6. **"一切终将开源"是 V95 AK 悲观论的技术加速版**：AI 破解 3A/复刻 Photoshop/cleanroom 重写——当"生成"的边际成本趋零，知识产权的执行成本成为唯一壁垒；橘子自己的应对（做脏活累活+垂直）恰是 [[2026-09-24_rss-wandian-latetalk_liangchenqi-ai-joy|梁琛奇]]"人难被替代五事"中"数据少/不好评估"的商业应用。

## 思考与追问

1. **我真正理解了什么？**这期的独特价值是**先行者的失败数据**——在所有人讲成功叙事时，"agent 协作使用率低得吓人/99% 没日历/程序员不用"这类负样本才是产品设计的最硬约束。而"教练式>秘书式"（做不会的事容错高）可能是个人 Agent 找到 PMF 的最简判据：**先问用户在这件事上是不是专家**。
2. **我还没搞懂什么？①ColaOS 转向后的垂直产品（本地生活商户运营）的具体形态与数据；②"接近免费下的新商业模式"（竞价排名/信息流广告进 agent）谁先跑通；③Next Token 播客的定位；④"mode"（roadmap 里被 Muse 先发的功能）是什么。
3. **下一步读什么/做什么？①把"教练式>秘书式"记入个人 Agent 观察卡（对照 Today 277 的四类 use case——长期目标型学习恰好是教练式的原型）；②追 ColaOS 垂直产品的发布（接本地生活线）；③Ben Thompson 那期原文（广告模型论）；④关注 Next Token 播客（橘子的新叙事阵地——先行者转向后的表达出口）。
