# 硅基立场 Vol.35 对话朱啸虎：Personal Agent 是个伪需求？

这是《硅基立场》主播骆轶航与金沙江创投主管合伙人[朱啸虎](../wiki/entities/zhu-xiaohu.md)在 **ACC 2026（AI 创造者嘉年华）开幕式主舞台**上的现场对谈，全长约 **22 分 40 秒**，发布于 2026-11-11。两人在 2025 年的 ACC 上就做过同题开场对话，本期是连续第二年。话题密度很高：开源模型凭什么赢、AI 应用什么叫"成了"、Personal Agent 有没有真需求、2026 年 AI 创业的壁垒、以及朱啸虎对"错过整波中国基座模型"的回应。

## ⚡ 速览

- 朱啸虎的两把尺子：开源模型看 **Token 消耗量**（必超闭源），AI 应用看**年化 10 亿美金收入**；他预测今年底明年初金沙江在海淀投的两家（LiblibAI、Tipsy Chat）会过线——注意这是利益相关方预测。
- Personal Agent 他判"伪需求"：没有高频场景（"你自己有秘书吗？"）、国内数据封在 App 里、90% 用户不用日历和邮件；"省时间"是大厂的机会，"消磨时间"（情绪价值/陪伴）才是创业公司的入口。
- 口播数字与独立核实基本对得上：DeepSeek 推理高毛利、"Anthropic 近期经营层面盈利"与招股书口径方向一致；但净亏损同样巨大——两个人各说了一个口径。

## 一、开源模型：Token 消耗量定胜负

朱啸虎给出的第一个判断标准是 **Token 消耗量**：彻底开源模型（他强调不只是"开放权重"，而是 DeepSeek 那种彻底开源）的 Token 消耗量必然超过闭源模型，理由是"99.9% 的日常工作根本不需要用到 frontier（顶级）模型"。他以自己为例：现在基本用 **WorkBuddy（腾讯云 CodeBuddy 出品的 AI Agent 办公工具）加 DeepSeek**，效果"超出期望值"。（转写中另有"前几个月 Claude 把我封掉了"一句，同场文字实录未收录，其后紧跟的一个词无法还原，标 [?]，本报告不据此展开。）

第二个判断标准是**收入**：AI 应用"成了"的标志是年化 10 亿美金收入，而不是拿了多少融资。美国已有两家——**Cursor 和 Higgsfield**；国内暂时都没有，但他预测"今年年底、明年年初"，金沙江在海淀投的两家——**LiblibAI** 和 **Tipsy Chat**——能过这条线，理由是"在收入榜上涨得太快，已经藏不住了"。[口播预测；两家均为其被投公司]

对美国这两家，他的评价是"经济模型不那么健康，都是健身房的模式，毛利可能基本都是负的"。"健身房模式"指用户付费但低使用、续费靠惰性。这一批评与第三方数据画像方向一致：Higgsfield 的 [10 亿美元 ARR 是"四周折算年化"口径](https://ffcap.cn/en/research/global-ai-company-revenue-top-100)，且作为多模型聚合的视频工具需要持续采购第三方模型（[月付约 400 万美元买模型的报道](https://lininn.cn/page/ai-daily-2026-10-04-daily)），成本结构确实不同于自有模型公司。[独立核实]

**分析与延伸：** "Token 消耗量"作为胜负标准的优点是可测量、不依赖榜单口径；陷阱是消耗量不等于收入——开源模型单价低，消耗量大反而可能掩盖单机价值。朱自己的框架里其实有回答：他不看模型公司的"影响力"而看应用公司的"年化收入"，消耗量之争最终被折算成谁能在应用层收到钱。这也是他连续两年判断的一致性所在（2025 年："所有 AI 应用都是套壳"，壁垒在应用之外；2026 年：壁垒=留存）。

## 二、模型经济学：推理很赚钱，研发才烧钱

模型侧的挑战是：开源模型给全世界 knowledge worker 贡献了大量产能，但 token 太便宜，利润很薄。朱啸虎用 DeepSeek 反驳"推理不赚钱"：**一块 GPU 一小时推理创造 38 美金收入，成本约 5 块钱**，即便按今天的低价仍有巨大降价空间——"不是推理本身不赚钱，是很赚钱；烧钱的是继续研发下一代模型的 R&D 成本"。[口播]

骆轶航随即抛出当天的热门数据："Anthropic 一年预计亏损 780 亿美元，把我吓到了。"朱啸虎的回应是："但它最近两个季度都是盈利的——包含研发成本、所有推理成本。所以今天基座模型公司并不是说没有毛利，它的毛利非常高。"他进一步比较：**今天价格下基座模型毛利至少 80% 以上**，远超当年云计算（美国 IDC 约百分之四五十毛利）。

这组对话可以用 Anthropic 招股书（2026-10-26 递交，草案数据 10-21 已在媒体流传）精确校准：**两个人各说了一个口径，且都成立。** [独立核实：[财新 10-27](https://www.caixin.com/2026-10-27/102497650.html)、[财新 11-03](https://www.caixin.com/2026-11-03/102500358.html)、[金融界 10-21](https://m.jrj.com.cn/madapter/usstock/2026/10/21075158798941.shtml)]

- 亏损侧：Anthropic 2025 年净亏损 420 亿美元，2026 上半年净亏损 807 亿美元（绝大部分为非现金/融资相关负债减值）。骆轶航的"一年 780 亿"接近 H1 净亏 807 亿的口径。
- 盈利侧：招股书同时显示算力/收入比在快速改善（2026 年二季度每 1 美元收入对应算力基础设施支出不足 50 美分），**二季度录得营业利润、经营性利润转正**；前三季度营业亏损同比收窄 75.9%。朱啸虎的"最近两个季度盈利（含研发与推理成本）"与营业利润口径方向一致。
- 代价侧：招股书披露的算力承诺支出高达数千亿美元量级——这正对应朱"研发下一代模型很烧钱"的另一半。

**分析与延伸：** 本期与本库[「美第奇的账本」（CAPEX 泡沫之辩）](../wiki/concepts/ai-capex-bubble-debate.md)形成互补而非矛盾：庄明浩看的是债务、折旧与"收入只够折旧"的系统性风险；朱啸虎看的是**单位经济**——单卡单小时的推理毛利。把两者拼起来才是完整账本：推理本身赚钱（朱），但支撑推理的算力承诺和下一代模型研发仍在吞噬现金（庄）。Anthropic 招股书恰好同时给两边提供了证据。

## 三、Personal Agent：高频场景之问

这是本期的标题议题。骆轶航的问题很直接：Muse 是大厂（Meta）做的，Instinct 是创业公司，国内过去一个月冒出至少十家做 Personal Agent 的公司（很多是明星创业者）——这到底是大厂的游戏还是创业公司的机会？

朱啸虎先给了一个历史坐标：Personal Agent 不是新概念，十年前海淀的**来也**就做过——那时 AI 不成熟，"全是真人在后面做你的 Personal Agent"，打到最后又去补贴打车、补贴外卖。结论是那句反问道破的判断：**"你有秘书吗？可能绝大部分人没有，也不需要。我自己有秘书，但也几乎没用了。"** 没有高频场景（他用美国 Muse 的使用结构举例：50% 场景是旅游，一年两三次），就很难成为可持续的大创业机会。[口播]

国内比美国更难：美国有很多独立网站开放给 agent 爬数据，**国内的数据都封在 App 里——包括微信**；而且 **90% 的用户不用日历、90% 的用户工作以外不用邮件**——"现在大部分时间都消耗在短剧这些娱乐产品上了，我需要 AI agent 干嘛呢？"[口播]

骆轶航提供了一个观察作缓冲：美国人实际把 Muse 当豆包用——不是"安排行程+读简报+提示午饭聊什么"的秘书形态，而是输入更方便的 chatbot，"我们老开玩笑 Gemini 是北美小豆包，今天发现 Muse 才是"。朱啸虎的回应：那就变成"竞争谁的输入更方便"的另外一个游戏，而创业公司在这个游戏里**没有数据壁垒**。

**分析与延伸（本库 Personal Agent 系列的第六块拼图）：** 朱啸虎的"90% 不用日历"与 [ColaOS 橘子期](2026-10-09_ximalaya-ailianjinshu_juzi-personal-agent.md)的"99% 没日历"几乎同构——而橘子正是做完 Personal Agent 半年复盘后"打了转向灯"的那个人，两位从不同位置得出了相近的谨慎。与之相对，创业者侧的回答已经形成谱系：[乱翻书 275](2026-09-21_xiaoyuzhou-luanfanshu_personal-agent-wars.md) 把赌注押在 Context 组织与委托权（详[概念页](../wiki/concepts/personal-agent-wars.md)）；[子皓（Ambi）](2026-10-12_xiaoyuzhou-42zhangjing_zihao-ambi.md)答"交互成本决定需求"，用硬件把在场成本压到两分钟；[张阔（硅谷101 E255）](2026-10-08_rss-guigu101_e255-zhangkuo.md)的"上云跑一周不挂"则绕开"高频"另走"长程可靠"。VC 问"有没有场景"，创业者答"把成本降到足够低场景自然出现"——本期是 VC 侧最完整的一次表述，适合作为这条辩论轴线的锚点报告。

## 四、壁垒：速度是入场券，留存才是壁垒

承接上一年以 Manus 为例的"速度+留存"框架，朱啸虎在 2026 年把话说得更狠：**速度只是入场券**——"今天在美国，2000 万美金收入以下的公司，一年增长小于 5 倍是没有投资人愿意看的；5 倍是及格线，10 倍才是优秀线。"他自己的两家被投公司"过去一年差不多每两个月翻一倍"。[口播]

为什么速度不再是壁垒？因为 Vibe Coding 和配套的 go-to-market 工具让产品迭代速度普惠化了，"大部分公司速度都不错，但留存做得好的很少"。**留存才是真的壁垒**，而留存回到产品定义：能不能站得住脚、到底给用户创造什么价值。他顺势再踩一脚 Muse："留存肯定会很差，场景不成立，不是高频场景"——和十年前来也最终退回补贴打车外卖同理，高频场景就那么几个，而且"肯定不能是帮你订外卖、订机票"，今天也没有投资人愿意再支持一场补贴大战。

对当下变相的补贴——**补 Token 大战、打折大战**——他的判断是"有点难，但有点机会"，逻辑是一条毛利改善曲线：国内 token 价格本身降得很快，只要给客户端的降价速度比模型厂 API 的降价速度**慢一点**，毛利就能持续改善、有机会转正；但前提是用户对价格不敏感、或者不愿意自己动手做麻烦事，"即使你比模型厂商的 API 贵那么一点点，他还愿意留下来"。

由此导出他更看好的方向：**情绪价值与陪伴**。"save time（帮用户节约时间）尤其在国内是大厂的场景，大厂做得很好，价格会卷得很厉害、很惨；但以后可能 99% 的人有大把时间，根本不需要节约时间，他需要消磨时间。消磨时间反而有很多百花齐放的机会，而且用户对价格不敏感，这是创业公司更好的机会。" 骆轶航随即以自己为例佐证"杀时间"的付费强度：他是重度游戏玩家，最近在玩 YC 上一届孵化的 AI 游戏 **Pax Historia**（在地图上推演架空历史），"（公司）说 ARR 1 亿美金我不信，直到发现我一个月在上面花了 2000 美金，我就信了"。朱啸虎补充国内同类《崇祯重生记》：重生到明朝末年，看你作为崇祯皇帝能不能拯救明朝。他总结："女性用户喜欢浪漫幻想，男性用户喜欢职业幻想，这里面都是有机会的。"

事实边界：Pax Historia 属实（[YC W26 批次](https://www.ycombinator.com/launches/PMu-pax-historia-user-ai-powered-gaming-platform)，2026 年 3 月报道约 35K DAU），但"ARR 1 亿美金、估值 3 亿美金"来自公司说法的转述，未见独立披露；《崇祯重生记》未找到独立来源，转写中另有"网易出品"字样，同场文字实录未收录，本报告不采用该归属。[口播/转述]

**分析与延伸：** "速度普惠化所以不再是壁垒"是对过去一年 AI 应用竞争最简洁的概括，但它和张阔 E255 的"乘法公式"（Agent=Model×Harness×Context）并不冲突：速度解决的是入场，留存靠的是 harness/context 的脏活累活。值得留意的是朱啸虎判断与持仓的一致性——"消磨时间+价格不敏感"恰好是其被投公司 Tipsy Chat（AI 陪伴出海）的画像，逻辑自洽与利益相关同时成立，阅读时应把这条作为"有仓位的观点"对待。

## 五、创业者画像：懂人性的工程师

骆轶航把话题落到海淀的现场语境：那两家被投公司的核心文化不是研究型文化、甚至不是工程师文化，而是极致的产品运营加对文化和人性的理解；但海淀的高校学生和工程师们更擅长研究与工程化。如果未来 80-90% 的 AI 创业需要的是极致运营和对人性的把握，这么多 engineer 创业该怎么办？

朱啸虎的答案是他重复多年的标准："按我们过去 20 年的经验，最好的创业者就是优秀的工程师，同时懂人性、懂商业。"他举张一鸣为例，"真的是百里挑一。中国最不缺的就是优秀工程师，聪明人太多了，但既是优秀工程师又懂商业和人性的，真的百里挑一，尤其是做 CEO 的人。"被问到 AI 时代是否要求更高时，他否认了时代差异："没有，一样的。互联网时代也是最优秀的工程师同时懂商业和人性。过去 20 年成功的几乎都是这个背景。"（"张一鸣"一例同场文字实录未收录，保留自转写。）

## 六、投资风格：终局、泡沫与安全边际

最后一个问题是"中国基座模型这波一个都没投，后悔吗"。朱啸虎的回应分三层：

1. **承认错过的机制**："我们也一直在反思——你如果一眼看到终局，可能就会错过当中的泡沫。"但一级市场和二级市场不同：二级市场看错今晚就能斩仓，一级市场"退出都是别人来买走的"，想卖的时候未必卖得出去。
2. **用港股解禁周期论证谨慎**："港股真正的价值发现是在解禁以后。过去 12 个月太明显：解禁以后从高点跌 80% 甚至 90%。我的投资假设是，从高点跌 80%、90% 以后你还能不能赚钱？对大部分投资人（的项目），哪怕上市了基本也等于 write-off。核心还是真正见到现金的时候还有多少投资回报。如果这个趋势越来越清晰，那我说实话也没什么可后悔的。"[口播]
3. **重申风格**：基座模型这种"进入估值就很贵、还需要很大 CapEx"的不是他的风格；"我们最喜欢的是在比较有安全边际的价格上放一点比较小的金额试错"——Tipsy Chat 第一笔只放了 100 万美金，跑出来后"一直追着它放钱"。重仓 all-in"会压力很大、满头白发，是我最不喜欢的"。对 all-in 型投资热，他的态度是基金必须有 portfolio，每个人回到自己熟悉的赛道——"我们就特别喜欢应用，对应用的判断比技术熟悉太多了"。

预测环节，他把上一年的"堂堂正正做一家中国公司做全球市场"接上了新证据：**明年中国至少会出现二三十家 ARR 5 亿美金以上的 AI 应用公司**——"门槛不高，Manus 已经过了 5 亿美金，商业化几个月做到大几千万美金的公司都有很多"——但前提"一定要面向全球市场，在国内市场要过这个门槛难度不小"。[口播预测] 骆轶航补充："很高兴看到 Manus 正在试图重新做一家真正的中国的、服务全球市场的 AI 创业公司，而它在海淀。"这与公开信息吻合：Manus 母公司蝴蝶效应 2026-10-08 宣布完成超 5 亿美元融资（博裕投资、IDG 资本领投，腾讯、红杉中国、真格基金跟投），估值 40 亿美元，招聘重心回到北京（[虎嗅](https://m.huxiu.com/article/4896151.html?type=text)、[财经网](https://m.caijing.com.cn/article/202610/447668)）。"ARR 过 5 亿美金"本身则未见独立披露，按口播口径处理。

## 思考与追问

1. **我真正理解了什么**：朱啸虎框架的自洽性——模型层看 Token 消耗量（供给端事实），应用层看年化收入（需求端事实），中间用"毛利结构"连接（C 端/陪伴/价格不敏感是好生意，程序员/B 端/价格敏感是坏生意）。Personal Agent 在这个框架里两头不占：没有高频场景（留存不成立），又撞在大厂"输入方便"的火力范围（数据壁垒不成立）。
