# 晚点聊 187：对话 LiberAI 刘松铭——Astra 来袭，00 后物理 AI 创始人看到的胜率

这是[晚点聊](../wiki/show-indexes/wandian-latetalk.md)程曼祺与 [LiberAI 创始人刘松铭](../wiki/entities/liu-songming.md)的长访谈，全长约 **2 小时 10 分**。刘松铭是"清华、世界模型、00 后小天才"这个 2026 上半年最火投资主题的完整体：清华特奖、RDT-1B 一作、博三创业、不到一年 6 轮融资（真格/红杉/顺为/龙珠等）。但本期的重心不是融资叙事，而是一个结构性问题：**当 Astra 冲击波（基模进场物理 AI）重估整个领域时，一家 Day 1 就选择全栈的创业公司凭什么活下来**。他的答案自成体系：基模会吃掉 System 2（规划调度），所以具身模型会"变薄"，LiberAI 把全部筹码押在与物理信息和场景相关的 System 1 及以下——并用手套数据经济学给出了到目前为止最硬的量化证据。

## ⚡ 速览

- **Astra 应对框架**：2025 年下半年创业前已判断基模"百分之百进场"（能力+算力双动机）；Astra 冲击只是"速度略超预期"。应对是 Day 1 全栈 + "硬件服务模型而非模型服务硬件"，技术方向刻意偏 System 1（动作执行、重试、物理反馈补偿）。
- **数据经济学（本期最硬的量化主张）**：**1 万小时手套数据 > 200 万小时互联网视频**；手套+25% 真机遥操 > 100% 真机遥操（可替代 75% 遥操）；真机遥操约上千元/小时，手套低一个数量级。
- **胜率判断**：OpenAI 做 AI 机器人"没有基因也没有动力"（同样精力投 coding 有 20 倍增长）；先进制造企业看量、耐心有限；**真正的对手是非标自动化公司**。理想分工：基模做 System 2，LiberAI 啃 System 1——"那部分钱对他们根本吃不饱"。
- **Liber-0 零样本成绩**（嘉宾称"我们可能是第一个"做系统性零样本测试，GPT-6 出 60 题）：抓取 60-70%、非抓取约 30%、四五步长程 >10%；Astra 单打强接触/"最后一毫米"会来回抽搐，LiberAI 模型成功率是其数倍。

## 一、Astra 冲击波与 System 分层

刘松铭的判断在创业前就已完成：2025 年下半年看到三个信号——视频模态在具身训练起作用（同门朱军团队 Vidar）、大规模 UMI 无本体数据效果媲美遥操、灵巧手走向成熟——人类数据路线就此清晰。同时他判断基模"百分之百"会进具身大脑的规划调度层（能力提升=有能力，算力/产能增加=有动机，叠加 OpenAI 招机器人人的传闻）。所以 Astra 来袭对他不是意外，"只是速度略超预期"。

他用三层结构组织这个问题：**System 2（规划调度）/ System 1（动作执行）/ System 0（物理反馈补偿）**。基模吃掉 System 2 后"具身模型会变薄"，因此 LiberAI 的技术方向从第一天起就刻意偏 System 1 及以下——重试（长程任务"靠 retry，人没有成功率之说"）、力觉触觉、运控、硬件。详见概念页[《具身智能的 System 2/1/0 分层》](../wiki/concepts/system-stack-embodied.md)。

**Astra 的边界（实测口径）**：Astra 单打（自兼 System 1）做不好强接触与形变控制，"最后一毫米"会来回抽搐尝试，LiberAI 模型零样本成功率是其好几倍；Astra 长于语义理解、任务拆解、规划与纠偏。对 GPT-7 的判断：除非补上接触/触觉/小模型，否则 reasoning 模式吃不掉直觉层。

## 二、全栈假设："硬件服务模型，而非模型服务硬件"

LiberAI 的全栈构成：世界模型 **Liber-0** + 数据采集手套 **LiberSense** + 自研本体 **LEO** + 数据管线；核心零部件与供应链依赖外部，自研只做"影响模型效果的部分"。LEO 的设计细节是"硬件服务模型"的最好注脚：腰 3 自由度、腕关节球形旋转（他对比 Optimus 二代腰仅 1 自由度）、细手臂——在拧转、弯腰捡拖鞋等任务上成功率超 90%，**比对比平台高 30%（百分点口径，主持人口述 Liber-0 报告数字的解读性定型）**；硬件构型与传感器选型对效果的影响"比预料更深"，且**无法靠训练配方解决**。

资源投入的排序很明确：算力+数据"毫无疑问"第一（含采集设备与人力），硬件重要性高但不吃资源——砸钱难加速，"十个孕妇也不能一个月生孩子"式的串行周期不可压缩。

## 三、数据经济学：手套 > 遥操

这是本期最具迁移价值的一组数字（均为嘉宾口述自报）：

| 主张 | 数字 | 含义 |
|---|---|---|
| 1 万小时手套 > 200 万小时互联网视频 | 200:1 | 互联网视频缺动作信息，手套补齐后"四两拨千斤" |
| 手套+25% 真机遥操 > 100% 真机遥操 | 替代 75% 遥操 | 混采优于纯遥操 |
| 遥操 ~1000 元/小时 vs 手套低一个数量级 | ~10× 成本差 | 数据成本的供给侧革命 |
| 220 万小时预训练数据 | 互联网视频（大头）+ ego 视频 + 真机遥操 + 跨本体真机 | 绝对量不如多样性与"是否带动作"重要 |

三阶段预训练："先看后做"、逐步提高带物理信息数据的比例、全程混互联网视频；本体作为条件注入模型。对比对象：Gen 1.5[?]（50 万小时、UMI 为主）、Dyna-2[?]（100 万小时、人类视频为主）——两个名字按转写原音保留存疑。不足也如实说：触觉还没采进来、RLHF 类任务无关提升探索不够；后训练（RL）是下一步。

**Liber-0 的验证设计**值得单独记：系统性零样本测试（嘉宾自称"可能是第一个"），用 GPT-6 出了 60 道题（20 抓取/20 非抓取/20 长程），成绩：抓取 60-70%、非抓取约 30%、四五步长程 >10%。全栈协同的量化：各部分约 30% 的贡献可撑起约 2 倍效果；模型能从手套数据学到没教过的技能。

## 四、胜率判断：谁是对手，钱在哪层

- **OpenAI**："没有这个基因也没有动力"——同样精力投 coding 有 20 倍增长，Sora 都关了且 Sora 比物理 AI 好赚钱。
- **先进制造企业**（特斯拉/华为类）：看量，一年一两百台的耐心有限。
- **真正的对手：非标自动化公司**——这是 LiberAI 视野里唯一在同一战场掘壕的玩家。
- **理想分工**：基模做 System 2 通用接口，LiberAI 啃 System 1 及以下（动作执行/力觉触觉/运控/硬件/部署），"那部分钱对他们根本吃不饱"。已与 **Kimi** 合作（方向一：基于其基座模型并缩短硬件周期；另有更长期的"以物理世界为接口"构想）。

商业路径从场景基础设施讲起：奶茶店演示（五分五十多秒无剪辑长程操作），按糖浆泵需要力觉/声音/手感兜底；坚持**不改造环境**（改造成本最低原则），公司在自建奶茶店打磨无人干预闭环。选场景四条件：相对标准化可复制、能靠模型解决且兜底越少越好、节拍/容错率匹配且有真实付费需求、过程中积累认知或数据资产；两到三年跑通标杆场景；全球化看好发达国家劳动力短缺的家庭照护/清洁与零售/服务/酒店。

## 五、创始人画像与组织

刘松铭的创业动机不是技术："从中学时就想创业，一直在寻找方向；技术本身不是目的，实现商业价值才是。"高中就想通"目标是为了做事就不必绕道获取资源"；清华创协/启创/星火计划，大一大二做在线教育推荐系统；2023 年 ChatGPT 时刻起判断要做与物理世界结合的应用。

组织三关键词：**品味**（taste，拆解问题与取舍）、**克制**（做减法、推崇极简）、**协作**（稀缺的"调解者"型管理者）；除他本人外全部中高层与重要技术员工由他亲自招募；决策"鼓励讨论，拍板我说了算"（权责对等）——组织设计的目的之一是"抵抗先入为主"：熟悉的事更容易跳步、依赖未验证假设。资本纪律口头禅："就是不该花钱的地方别花钱"；低谷应对=融到足够多的钱（"可以融的时候去融"）+储备三到五年；风险意识来自家里做传统生意。终局想象：碎片→集中必有"对标苹果的大公司"（"人类史上最伟大工业品之一"）；在思考利润分配问题——模型能吃哪层、哪些要硬件/infra 配合，"类比比亚迪提前布局电池"；LiberAI=Liber（自由），让人不再为琐事与繁重劳动困扰；终局是服务个人的机器人。

## 思考与追问

1. **我真正理解了什么**：刘松铭的体系是一个完整的"分层防守"——把 Astra 冲击翻译成 System 2/1/0 的塌缩问题，然后把公司所有资源（数据经济学、本体设计、场景选择）都对准"塌缩不到的那几层"。手套数据是这套防守里唯一可以外部检验的硬主张（200:1 与 75% 替代），如果成立，具身公司的数据资产估值逻辑会从"小时数"转向"动作信息密度"。
2. **我还没搞懂什么**（已汇入 [open-questions](../wiki/open-questions.md)）：
   - "手套 > 遥操"三组数字的可复现性：换一家公司/换任务族是否成立？设 2027 检验点——观察 LiberSense 类触觉/动作采集设备的行业采用率与其他具身公司的数据构成披露。
   - System 2/1/0 分层的稳定性：刘自己开了口子（"GPT-7 除非补接触/触觉"）——若基模真的补上小模型+触觉，分层的塌缩时间表是多久？这与 E256"谁先被 Astra 改写"是同一个赌局的两侧。
   - "真正对手是非标自动化公司"——该判断的可证伪形式：非标自动化头部（如先导、利元亨类）是否开始招具身算法团队/投资具身公司？
3. **下一步**：与[李飞飞 World Labs 期](2026-10-08_rss-kedaibiao-lizheng_lifeifei-worldlabs-robot.md)对读（世界模型路线 vs 全栈数据路线）；跟踪 Liber-0 后续公开评测与 Kimi 合作产出。
