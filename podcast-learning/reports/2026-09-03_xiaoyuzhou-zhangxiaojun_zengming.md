# 153. 和曾鸣聊产业史观：残酷的真相、会消亡的公司、优秀≠卓越

> 曾鸣是观察过互联网完整周期的战略研究者（前阿里总参谋长、长江/湖畔商学院创建参与者）。这期是他对 AI 新范式的完整思考，以"产业史观"框架展开：AI 产业化三阶段、模型公司的基础设施宿命、公司制度的衰亡、战略从规划变为生成。信息密度极高，且多为**非共识判断**。

## 一、概览

- **三阶段产业史观**：①技术被社会接受成为基础设施 → ②海量应用百花齐放 → ③原生应用阶段（需要更底层的方法运行新世界）。曾鸣判断：**2026 年第一阶段刚完成**（Token 成为标准度量衡是标志），第二阶段（智能体阶段）刚开场；类比互联网，"我们刚刚走到浏览器阶段，甚至比 Yahoo 还要早"。
- **残酷规律**：第一阶段的企业很难活到第二阶段，第二阶段很难活到第三阶段——所以"Anthropic、OpenAI 大概率不是原生应用阶段的大玩家、大赢家"。模型公司的终局是 **AI 云公司**，而公共基础设施只有一种成立的商业模式：**寡头垄断 + 政府强监管**。
- **公司会消亡**：科层制是工业革命的产物；AI 时代组织的基本单元从**岗位**变成**任务**，中层消亡，企业越来越像"全员合伙人"的球队；New Lab 是新组织形态的雏形。
- **战略生成**：战略规划已死（线性外推得不出 Anthropic 今年 80 倍的同比增长），替代物是"战略生成"——组织被设计成一个让洞察涌现的神经网络式生成系统，人和 AI 一起训练"组织的小模型"。
- **创造就是无中生有**：消化这场革命要一代人（20 年起步）；AI 时代可定义为**创造力时代**——所有可结构化的知识工作被 AI 接管，人被迫（也被解放）去开发"原创地定义复杂问题"的能力。

## 四、主要话题

### 1. 三阶段论与"我们在哪"

三阶段：技术成为社会基础设施 → 海量应用爆发 → 原生应用阶段（需要更底层方法运行新世界）。曾鸣用移动互联网校准：黑莓 2010 年仍占美国智能手机 40%+ 份额（iPhone 20%+），iPhone 4 后才真正领先；墨迹天气日活过亿但不代表未来；字节从内涵段子/今日头条（文字成熟）→推荐算法→带宽算力成熟→抖音=现象级原生应用。

当前定位的判断依据：2026 年初 **Token 成为共识度量衡**（黄仁勋"Token Factory"、Sam"OpenAI 核心就是卖 Token"）= 第一阶段完成标志，"如同一度电、一吨水、1GB 流量"；春节 OpenClaw（养龙虾）让人看到 Agent 独立完成任务的潜力 = 第二阶段开场。两年前他演讲说"让我们拥抱雅虎吧"，年初把判断前移为"还在等浏览器出来"——浏览器的两个功能（统一建站标准降低创造门槛 + 点击浏览把使用门槛降到零）带来供给端与需求端双爆发，Yahoo=目录=熵减，而"我完全没有看到雅虎的雏形"。

### 2. 基础设施宿命：寡头 + 强监管

模型公司类比 **AOL**（互联网基础接入服务商，让所有人接入互联网是巨大工程；大模型让所有人接入智能）。终局判断："模型公司说得直白一点就是 AI 云公司"。公共基础设施行业只有一种成立的商业模式——**寡头垄断加政府强监管**（水电费不能乱涨价），"我知道这个现实对很多现在创业的人很残酷"。

历史校准残酷规律：Yahoo 1995 年成立、5 年到 1200 亿美元（≈今天 1 万亿）；AOL 2000 年 2200 亿、收华纳后 3000 多亿；Google 1998 成立 2005 年 1000 亿；黑莓曾是最快到千亿的硬件公司——市值大不等于能跨阶段存活，"炼油厂 vs 化工、石油公司做不了汽车"。当前格局：Anthropic 领跑、OpenAI 跟上、Google 阶段性被甩、XAI/Meta 掉队；中国年底 3T 淘汰赛（K3 刚到 2.8T、Kimi 先交卷）。**做基础设施大模型的窗口已关闭**；寡头竞争 = 同质化（可替代）+ 差异化（有钱赚），"只要有同质化的供给，你就不可能获取高额利润，你就是一家不怎么值钱的公司"。

### 3. Agent 应用的反共识冰点与新平台

去年硅谷 demo day 全是 agent，但多是简单任务（"一场十个 demo 三五个做广告素材"）——**"越简单的活越容易被复杂的活给吞掉"**，做复杂任务才能建智能闭环："你要假定智能是完全够用的，今天的核心是干活，而且是干一个复杂的活"。Manus 抓住了 coding 溢出的机会窗，但今天再立足要 10 倍以上的切入点。Cursor 被判断为 coding 能力不足时探边界的**过渡品**，会被 fold into 模型迭代的养料。

投资人上轮受伤、认为"不就是模型的一个 skill 吗"→ 应用融资难——曾鸣判断这正是反共识阶段，"这才是应用阶段开始的真实标志"。电力史类比：电灯→1910 年电网覆盖美国主要城市、同年 2C 大应用（洗衣机电冰箱）→收音机→1925 空调→30 年代电视机；通用电气靠 2C 突破后繁荣 60 年。

新平台不来自旧平台："旧的平台做的是简单的信息匹配，新的平台要做的是能力跟需求的匹配，复杂度高了很多"。下一步看**谁把 Agent 的标准建立起来、谁抢住 Agent 的用户入口**，三年内可能出现入口——但信任问题（钱包/隐私敢不敢交给 Agent）需要独立第三方来解决，由此催生新型双边市场。

### 4. 公司消亡与组织革命

科层制公司 = 工业革命的制度创新，会衰亡——"这没有什么可以遗憾的，你说多少人现在去公司上班是开心的？"组织基本单元从**岗位**变为**任务**：招人变成任务发布+认领+deliver；层级消失（"未来是谁的能力强，谁被调用，传统意义上的中层肯定消亡了"）；硅基员工与碳基员工围绕任务流转。New Lab（OpenAI/Anthropic 是真正的第一批）是新组织雏形；曾鸣新书刻意通篇讲"组织"不用"公司"。

激励逻辑：贡献透明 → 奖励透明（top researcher 转会费高因为贡献透明，title 只剩"顶尖研究员"）；自驱 = high agency（"硅谷半年最流行词"）。一人公司不是方向（个人能力有限，一定要组织分工），但一人公司=六边形战士，再跟其他六边形战士合作。未来企业=合伙人企业（律所/咨询/投行式）。传统公司转型"不换脑袋就换人"。组织先于战略：CEO 自己重写公司运行体系（李志飞关三天写框架）vs 满足于飞书 AI 升级 = 分水岭；"原来的 ERP 就是固化的道路，神经网络的适应能力远远超过任何东西"。

### 5. 优秀 ≠ 卓越

卓越是**事后认定**的：克服一次次负反馈、所有人不认可、以巨大成功证明是时代先知；优秀则是持续正反馈的成长路径——"卓越一定来自反共识"，但反共识不一定成功（survival bias）。分野在 ego：ego 大 → 急证明自己 → 要短期反馈 → 先入为主 → 不真正感知真实世界。柯林斯两本书（《基业长青》《从优秀到卓越》）：卓越者把成功归于别人和运气，"是时代成就了你，你只不过是碰巧在合适的地方跟合适的人在一起做了合适的事情"。公司四层：机会驱动→战略驱动→远见驱动→使命驱动；使命"是发自内心的，不是你编出来写在墙上激励别人的"。曾鸣问创业者第一句："十年以后你会对怎样的自己满意"。

### 6. 战略生成系统

越不确定越需要战略，但"战略规划"已死：工业时代年增 5-8% → 线性外推 → 战略外包麦肯锡/BCG（80 年代到 2000 年井喷）；"线性外推就不可能得出 Anthropic 今年 80 倍的同比增长"。替代物是**战略生成**（"我特意创了这个词"）：组织设计=建生成系统=神经网络+任务流，人和 AI 接入，"人跟 AI 一起在训练一个组织的小模型"，核心是涌现与群体智慧演进；context not control 重新火（Netflix 案例五年前没人共鸣、今天都懂）。口诀"看十年想三年干一年，但大部分人记住了看十年干一年"——"想三年"才是创造力的部分（里程碑 1/2/3 + 短中长期动态张力，三维寻优）。战略四期：摸索期（一号位带头创新+降试错成本）/成型期/成熟期/执行期；"每个战略都要在当时那个时期有效才有效，它不是亘古不变的"。ARR 批判："ARR 虚幻"（当下外推 12 个月的增长幻觉）；"竞争一多，定价就从客户价值转向边际成本"。

### 7. 巨头审判（逐家点评）

跨时代存活："不是多不多的问题，是有没有的问题——基本没有。"IBM 一次、微软一次（错过移动互联网但保住搜索火苗+云+PC OS 垄断；但微软模型已出局、买不起 OpenAI）。Google=微软上一段，能成 AI 云公司但 2C 入口不确定。字节：模型国内第一梯队、很可能成 AI 云公司（Seedance 多模态世界一流），但豆包=第一代 AI 产品聊天机器人、没有行动力（"智能体的核心是独立完成任务"），不计成本砸豆包说明"不够那么未来"；上一代入口难成下一代入口。腾讯："作为最安全的为什么最近这么恐慌，就是因为也有可能不安全"——社交关系肯定重构；"QQ 过渡到了，但真正承接移动互联网时代的是微信"。XAI 掉队原因：战略不聚焦+组织问题（"XAI 肯定卡在组织上了"，研究员觉得 Elon 不懂大模型、自上而下给答案）。Meta：小扎出头早消耗早、研究员觉得他不懂模型→做不了重要决定。OpenAI/Anthropic 领跑原因：Sam+Ilya 好搭配；Anthropic 组织能力强+Dario 对 Mission/Vision 把握准。中国收敛慢：无先发酝酿期、快速跟进美国原型→百团大战。颠覆性框架：移动互联网对 PC=1.5 创新（延续性让头部 all in 成功）；**AI 颠覆的是工业革命（生产力革命），互联网本质是生产关系革命**——延续性弱，所以旧物种更难转型。"你别忘了，OpenAI 已经 11 年了。"

### 8. 创造力时代

德鲁克三阶段（生产力革命→管理革命→知识革命）延伸出第四段：AI 时代=**创造力时代**，"所有可以被结构化处理的知识类型的工作都会被 AI 接管"，人被逼着也被解放去开发潜能。创造力不是写歌画画，而是**原创地定义复杂问题的能力**（"无中生有"，已有的机器都知道）。消化这场革命要"一代人，20 年起步，因为他们才是原住民"。商学院"已经不行了，都在衰落"；教育系统是接下来最大的冲突（高中生知道按现在的方法毕业找不到工作，家长知道要新办法但不知道什么办法）。metaverse"方向没错，可能只是时间早了五年"。心态：从降低不确定性转向**拥抱不确定性**，"不确定性就是最大的机会"。曾鸣个人使命："做一个快乐的研究员"；快问快答里把"语言即世界"改写为"**你可能要改成智能体即世界**"。

## 思考与追问

1. **"寡头+强监管"与"收入只够折旧"的对撞**：曾鸣判模型公司终局=公用事业式 AI 云公司，而屠龙之术 2026H1 的核心议题是"收入将将覆盖折旧、26Q3 巨头自由现金流或转负"（[[2026-07-17_xiaoyuzhou-tulong-zhishu_2026h1-ai-review]]）——若两者同时成立，万亿估值的模型公司要靠什么撑到"强监管公用事业"的稳态？判别拐点的先行指标该看 API 毛利率、token 单价、还是监管动作（哪个司法辖区先动手）？
2. **Agent 入口的信任第三方会是什么形态**：曾鸣说三年内可能出现 Agent 入口，但钱包/隐私交给 Agent 需要独立第三方建信任——这对应今天生态里的谁（平台级 agent 客户端、开源技能/协议生态、还是评测/保险式新物种）？"谁建立 Agent 事实标准"的可观察信号是什么：MCP 类协议 adoption、agent 调用量分布、还是 agent 间的互操作网络效应？
3. **"组织=任务流+神经网络"的可证伪性**：公司消亡论的可观察证据链是什么——AI 公司员工结构（中层占比/人效）、New Lab 的研究员转会费曲线、还是"组织大脑"类 2B 产品的渗透？对个人（衔接 PROFILE 的"AI 时代水温下的工作方法调整"），"任务为基本单元 + high agency"落到日常，具体改写哪些工作习惯？
