# 卫诗婕89：阮良——AI 进组织的木桶真相

## ⚡ 速览

- 网易实测：工程师 AI 提效 300-500%，软件交付只从 20 天缩到 17 天——**短板是流程不是人**。
- 十年没写代码的 CEO 用 Claude Code 自建"CEO 系统"：审批自动化+跨系统找关联。
- 组织终局：中层减少、带 agent 的一线精英增多，分蜂结构。

## 概览

- **印刷术类比**：AI 把知识获取平权（教士解释圣经权→人人可得的定制化教育）；渗透一切毛细血管，且首次具备理解+意愿识别+执行。
- **CEO AI**：审批分三类（无风险全自动化/需溯源汇总/严审集中）；AI 帮老板在网状结构中发现机会风险（人脑受上下文限制）；省下的时间"可以刷短剧看风景"——状态好坏超过智商高低。
- **木桶效应（本集题眼）**：20 天→17 天的算术。三道坎：认知→个人短程任务→**改造流程（=改造组织，最难）**。周会改革：AI 接管"同步信息"（模板填写→知识库→聚焦带关联的 HTML 报告），决策只开专项会。
- **蒸馏 skills**：销售冠的动作/话术蒸馏分发；培训蒸馏的不是销售冠而是**客户**（历史交互训练 AI 模拟各类客户）；KA 销售配录音卡（CRM 被抵触、录音卡被接受）。
- **SaaS 未死**：进入关键流程的好 SaaS 会被海量 agent 调用，越用越牢；企业核心资产=私有知识库+对内部系统的调用编排。
- **token 经济学**：网易单月 token 顶去年一年但"不贵"（业务挣钱+人本来就贵）；**"token 断崖式领先的人，成果也断崖式领先"**（用得狠=在给自己造系统）；价值公式=质量比×节省时间×单位时间经济价值；先用最贵模型证明可行再切经济模式。
- **多 agent 红蓝军**：六个 agent 各配一家模型（Claude/GPT/Grok/智谱/Kimi/DeepSeek）互相 PK 出方案——独立进程保健壮性（挂三个还剩三个），"组织学的冗余"。

## 增量观点（polished 之外的连接与分析）

1. **AI 原生组织线四块拼图至此闭合**：[[2026-09-14_ximalaya-ailianjinshu_chenbin|鹿客陈彬]]（12 年硬件公司重写自己）+曾鸣（公司消亡预言）+[[2026-09-24_xiaoyuzhou-guiji-lichang_zhangfan-fde|张帆]]（FDE 批判）+本集（大厂内部一手数据）。四者共同指向：**AI Native 的瓶颈从来不是模型而是流程/组织的重构成本**——阮良的"换木桶"与陈彬的"重写成 AI 原生"是同一件事的两种表述（渐进改造 vs 推倒重写）。
2. **"20 天→17 天"是 E255 榜单断层的组织版**：[[2026-10-08_rss-guigu101_e255-zhangkuo|张阔]]的 61%（单 agent 全链路通过率）与阮良的 15%（组织效率提升）同构——**个人能力→系统交付之间的损耗，在 agent 侧叫 harness/context 缺口，在组织侧叫流程短板**。两个 15% 左右的数字互为印证。
3. **"token 断崖式领先"直接命中 EverAgent 实践**：阮良的统计规律（用得狠的人在给自己造系统）与 eacli 舰队的 token 纪律是同一枚硬币——**token 消耗结构是 agent 时代的工作质量代理指标**；他的"审计但不告诉"是温和版红线设计。
4. **红蓝军多模型 PK 是个人可复制的决策架构**：独立 harness（不同 agent×不同模型）→独立出方案→互 PK→中枢总结→人拍板——与 eacli 的多设备路由同构，但多了"对抗出方案"这一步；成本他明说"贵一点但值得"。
5. **中层消失论与 junior 困境的对账**：[[2026-10-09_xiaoyuzhou-zhixing-xiaojiuguan_e253-ai-good|知行 E253]]担心 junior 没法从基础工作长出判断力，阮良的回答是"新的技术性工作会诞生"——这是乐观派 vs 审慎派在本周报告里的正面对话；而"带 AI 团队入职谈判（为 AI 组织付溢价）"给出了个体突围的具体形态，与 [[2026-10-05_rss-kedaibiao-lizheng_codex-claude|216 期]]的"叙事主权"（把自己产品化给人和 AI 看）衔接。
6. **HTML 替代 PPT 的理由第三条最深刻**："对 AI 更友好——AI 读 Markdown/HTML 远深于 PPT，语料必须是 AI 第一道就能消化的格式"——这是**把组织文档从人读优先翻转为 agent 读优先**的具体信号，EverAgent 的 Markdown 知识库路线恰好押注同方向。

## 思考与追问

1. **我真正理解了什么？**"个人提效→组织提效"之间隔着流程重构，这解释了为什么 AI 热了三年而宏观数据不见生产率跃迁（also 知行 E253 的 83% 未用 AI 折叠世界）。**真正稀缺的不是会用 AI 的人，而是有权限"换木桶"的人**——所以一把手工程是必要条件。而"token 断崖式领先"给了一个可测量的代理指标：看一个人/团队的 token 结构就知道它在造系统还是在消费额度。
2. **我还没搞懂什么？①OpenCloud 到底是什么产品（手机操控电脑+登录各平台抓信息——与 Muse/Grok Bot 的关系）；②积分制的具体设计（有效代码量如何换算工作价值——AI 时代代码量还成立吗）；③"新的技术性工作会诞生"的具体例证；④网易智企任务选择器的模型适配规则。
3. **下一步读什么/做什么？①把"红蓝军 PK 出方案"试用于 EverAgent 的下一个重要决策（六模型独立出方案互评——正好用 eacli 多 provider 路由）；②对照 [[skills/report-writing/SKILL.md|自家 SKILL]] 把"HTML>PPT/AI 优先语料"原则记入 EverAgent 文档规范；③追踪 OpenCloud/WorkBuddy 的产品信息（接乱翻书 275 的个人 Agent 战争图谱）。
