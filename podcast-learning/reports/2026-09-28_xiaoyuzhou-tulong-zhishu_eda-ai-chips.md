# 当 AI 开始设计芯片：新思科技视角下的 EDA 与 AI 造芯真伪

> 庄明浩对谈新思科技近 20 年从业者。这期的价值是**EDA 双寡头视角的冷静剂**："全自动 AI 造芯从头到尾毫无人工参与的，其实还是没有出现。"与张托肯期（学术创业者说数字芯片渗透率 80-90%）构成同一问题的两种口径——都值得读，分歧本身就是信息。

## 一、概览

- **EDA 的体量与位置**：全球年产值约 129 亿美元（半导体 8000 亿里占比不到 2%），但芯片设计离不开它；新思市占率 40-50% 第一，双寡头格局。"EDA 像写文章的工具——流片后工具在那个层面消失；能不能拿诺贝尔奖看设计师。"
- **人人都自研的原因=经济账**：买芯片的钱超过自研成本就动念（扫地机主控芯片：设计+流片+团队需几亿美元）；训练用英伟达、推理分离后 ASIC 自研更省（电费+冷却才是大头）；"均码衣服能穿但不合身"。英伟达和 AMD 今年各收了一家推理芯片公司。
- **周期压缩**：芯片项目从 24-36 个月压到 12-15 个月；车载芯片已压到 7 个月；靠"买已流片成功的高速接口 IP+搭积木"提高一次成功率（3nm 一次流片光罩几千万美金[?]）。
- **AI 对 EDA 的真实水位**：软件行业 AI 替换率国内七八十、国外最高到九十，但即便 90% 也仍需要人；新思 2020 年就上了强化学习；**"agent 能替代一些人的工作，但离不开工具——工具是芯片行业多年积累的约束，容错率靠的就是这些约束，工具是 harness 的一部分"**。
- **硅基员工已落地**：新思已做 30 多个 agent、三十几个客户在试；"碳基员工 996 要睡觉，硅基员工 7×24"→商业模式之问开放：按席位还是 result as a service 还是按 token？国内开源模型本地部署收不到 token，FDE 更重要。
- **"全自动造芯"证伪清单**（本期最硬核）：三星×新思 3nm（2021，RL 参与非独立）、英伟达 ChipNeMo（辅助模型+工程师写验证脚本）、谷歌 AlphaChip（复现失败，公布权重后"没人跟他们玩了"）、中科院"启蒙一号"65nm（AI 全自动流程但 400 万逻辑门对标 40 万门的 486，"只是尝试性 demo"）、OpenAI Jalapeño（**后端全交给博通，只做了前端 RTL 生成**）。
- **人才观**：最对口集成电路专业；"目前没有"文科/创意型意外构成；期待跨界人才与"用自然语言向 AI 精确表达需求的能力"；为人设计的可视化工具未来会消失——"agent 对 agent 不需要可视化"。

## 二、章节地图（10 节）

新思与 EDA 是什么（129 亿/8000 亿、双寡头）→ 20 年前后对比（客户从专业芯片公司变系统厂商、周期腰斩）→ 人人自研的经济账 → 自研怎么开始（IP 搭积木+保姆式服务）→ AI 对 EDA 的影响（替换率/PPA/约束论）→ 硅基员工 Agent（30+ agent、计费之问）→ 认真算账（2026 起都在算 ROI、帕累托曲线）→ 当前系统瓶颈（散热/互连/收 Ansys 走向系统/老黄的铜线论）→ 几个人设计芯片（哲库 3000 人 vs 节俭车芯两三百人）+全自动造芯证伪清单 → 芯片人才。

## 四、主要话题

### 1. 工具=约束=harness 的一部分（本期核心论点）

"芯片行业容错率极低（流片失败≈公司破产），要得到容错率非常低的结果，又要利用 AI 的 productivity，怎么平衡？——我们容错率靠的就是这些约束（工具）。agent 能替代一些人的工作，但还是离不开工具，**因为工具其实就是 harness 的一部分**。" sign-off 签核离不开人："**agent 不会为你芯片的失败负责——人还是需要为芯片的结果负责。**"

### 2. 硅基员工的计费之问

新思 30+ agent 在客户处试。7×24 可用 → 工具使用频率变高 → 按席位/license？result as a service？按 token？"A 公司 agent 几百 token vs B 公司几万 token 怎么收费"；国内本地部署收不到 token → FDE 角色更重要（2023 年的 Copilot 承接 AE 问答，AE 腾出精力转 FDE）。

### 3. 全自动造芯证伪清单

（见概览末条）结论："从头到尾毫无人工参与的，其实还是没有出现……对这个行业还是有点信心的。"留活口：模型发展快，"未来三到六个月出现真实案例也不好做 forecast"。

### 4. 系统瓶颈：散热与互连

新思收购 Ansys 后"从 silicon 走向系统"（双 die 叠层发热→系统级仿真）；英伟达卖整套系统而非单芯片（标准系统插哪个数据中心都一样，所以敢兜折旧的底），本质是 CUDA+光+网络+存储的生态公司；老黄"限制 AI 的是铜线"→ CPO/硅光。

## 五、与库里叙事的接口（本期的独特价值：口径对照）

- **vs 张托肯期（渗透率张力）**：张说数字芯片 agent 渗透率 80-90%+（"几乎没有一行代码手写"，学术/demo 语境）；颜华说"全自动造芯从头到尾无人工的还没有出现"（量产语境）。**两人不矛盾但口径不同**：张托肯的"三天流片"正是颜华所说"新闻里讲、深挖执行细节就不太一样"的那类故事。一致的部分更重要：都认同数字芯片是 agent 最先打穿的场景、结果责任在人。
- **vs 硅谷101 E251**：买方视角互锁——"训练/推理分开→推理 ASIC 自研"=E251"训练看算力推理看带宽"的买方版；"英伟达/AMD 各收一家推理芯片公司"对应 E251 的 200 亿 acqui-hire Groq；Jalapeño 两期拼成完整图景（E251 讲 HBM4/暗硅/9 个月流片，本期讲"后端全交博通、只做 RTL"）。
- **vs 晚点 183**：主持提到的"GPT-6 操纵 Blender"正是 183 期 Astra 的病毒式 demo；"智谱 5.3 Flash 超级便宜、都在拉帕累托曲线"与 183 期"便宜和快"段完全互证（两期同一事件窗两侧）。

## 九、思考与追问

1. **"工具是 harness 的一部分"对 EverAgent 的直接映射**：颜华说芯片行业容错率靠工具的约束——这和张托肯"5 个 harness 分数无差异"是张力关系。差异可能在"约束是否带验证"：EDA 工具内嵌形式验证（绿灯机制），而 LLM harness 大多不带。**eacli/hermes 这类编排层要不要内嵌"签核"式验证器**（比如报告发出前的证据密度门禁、危险操作的双人复核）？
2. **硅基员工计费之问的个人版**："A 公司几百 token vs B 公司几万 token 怎么收费"——你自己的 tokenplan 是订阅制（包月），同一问题在个人版是"我的 agent 烧的 token 值不值这个订阅"。要不要给 eacli 的 tool invoke 加成本记录，月底回看哪些任务类型 ROI 最高？
3. **"为人设计的可视化工具会消失"**：颜华说 agent 对 agent 不需要可视化——这与津晶（319 期）"要人参与就给容易 review 的东西（HTML 可视化）"方向相反：一个是全机器链路，一个是人在回路。分界在哪？是不是"责任归属谁"决定界面形态（人负责→要可视化；机器负责→不需要）？
