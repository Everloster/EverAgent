# 孙宇晨×邵艾伦：搏击、开图与认知决定命运

## ⚡ 速览

- 孙宇晨的 AI 生活方式：全数据 Claude Code 化（饮食/训练/睡眠/MD 文档），"下一个 AI 直接读"。
- 核心概念"开图"：买房看 100 套、专业问 AI 看完 100 个——信息足够就不需要"做决定"。
- 立场宣言："百分百相信 AI"+ Small Ego + "一代版本一代神"——上版本的神不肯转弯，就是年轻人的机会。

## 概览

- **全 AI 化的一天**：每餐拍照→Claude 算卡路里+建议顺序；Oura Ring 睡眠数据→Claude Code 出日报；训练视频→AI 记组数重量；**所有数据 MD 文档本地，换 Codex 直接接手**。"90% 时间 AI 开飞机，我 10% 微调。"
- **搏击理论**（本集最大主题）：被嘲"头大四肢小"后与 Claude Code 深度对话被点醒——"你物质上是富人，身体上是穷人，练搏击就是领工资"。寿命 100 分=心肺 25+肌肉 25+其他 50；肌肉是战略储备资产（大病先扣肌肉）；有氧掉肌肉只拿 25 分，力量训练一箭双雕；巴菲特/马斯克反对健身=屁股决定脑袋（"巴菲特是自己走进餐厅还是被推进来的"）；马斯克打司美格鲁肽=double kill 掉肌肉。**"练搏击=维护你的碳基服务器"**（大脑被迫托管在碳基肉体上）。
- **给年轻人**：三大理论（孙学=认知升级+搏击=健康+黄毛=不在乎嘲笑）零成本安装；月入 <1000 也能全 AI 化（免费智谱/Kimi+白嫖 API 活动）；积累 2-4 个月数据→问三个顶尖模型→三选一。**开图理论**：先看 100 套房再买（秘书问题：前 3 套建 benchmark，4-6 套出现更好立刻买=黄金分割 0.618）；游戏版=先造斥候探图不闷头造兵，"AI 就是开图/开挂——有了足够信息就不需要做决定"。
- **看好方向**：数学（AI 抓全球思路，"高中生+AI 一步到位博士"；纽约大学教授 NS 方程思路被 OpenAI 700 万美元算力两天破解——"个人悲剧，人类进度条拖快了"）、天文学（数据没人处理）、生物制药、基因测序、数据标注、保险金融、**Crypto=把货币翻译成机器能听懂的语言**（SWIFT 是 1950 年代电报体系；Crypto 是可编程货币、天然适配 AI 的 API 级微计费）。
- **认知决定命运**：智商不存在，只存在信息多少（GPT-3 到 5.6 的跃升=灌信息；人的认知显化就是智商）；动机论批判（扒黑历史≠事情错——"看牙医不给钱"传闻 vs crypto 本身对错）；Small Ego（张一鸣 vs 百度）；**"一代版本一代神"**：地球 online 也更版本（"2017 版房地产砍 50%，AI 加 100%"），上版本的神 ego 大不肯转弯=年轻人的机会。
- **财富自由与人生**：先自由后财富（财富是副产品，螺旋上升）；主动健康管理（不生病去医院主动测指标——医生说他是第一个）；婚姻在摸索中，"体验大于结论"；"人生的意义就是体验的集合"；先上路比想清楚为什么上路重要。

## 增量观点（polished 之外的连接与分析）

1. **"全数据 MD 文档化+换 AI 直接接手"是 [[2026-10-05_rss-kedaibiao-lizheng_codex-claude|孙煜征 Document first]] 的生活版全量实现**：一日三餐/睡眠/训练全部进一个项目，"换 Codex 也能直接读"——**可移植文档作为人机接口**在一周内第三次出现（孙煜征→Today 的记忆→孙宇晨的生活流）。孙宇晨的激进版本（"百分百相信 AI，Cloud 说什么我执行"）是这条光谱的极值端，恰好与其争议风波构成天然对照组。
2. **"开图理论"是 [[2026-09-27_xiaoyuzhou-crossing_yuhong-sel|于红"画叉叉排除法"]]的游戏化镜像**：于红用两年面试排除法建 benchmark（"一半一半太好了我又能打个叉叉"），孙宇晨用"看 100 套房/前 3 套建 benchmark+黄金分割 4-6 套下手"——**同一决策论的三种表述**（信息充分→决策消失）。而"先造斥候不闷头造兵"几乎就是 [[2026-09-23_xiaoyuzhou-weishijie_ruanliang-ai-org|阮良"老板必须亲自用 AI 才知道边界"]]的战略版。
3. **"碳基服务器/硅基 AI"的资源分配框架接上 biology 线**："练搏击=维护碳基服务器"与 [[2026-07-13_xiaoyuzhou-mingjing-diandian_midlife-accounts|老钱"三本账"]]的肉身账完全同构——肌肉=退休储蓄；孙的"寿命 100 分=心肺 25+肌肉 25"给了可操作的分数化版本。**有氧掉肌肉论**与主流"力量+有氧兼修"有出入（Limitations 标注）。
4. **"动机论批判"在方法论上成立且有价值**：与 [[2026-10-08_xiaoyuzhou-daxiaoma-keji_v95-china-us|大小马 AK]]"名人情感无参考意义"、于红"论迹不论心"构成三连——**评价系统的去动机化**（看行为/结果/对错，不猜动机）是本周报告反复出现的独立收敛。
5. **"AI 没读到你的语料=从来没有发生过"是 EverAgent 存在主义的最佳注脚**：孙用 5000 万人的无名国家作喻——这与本仓的 Markdown 知识库哲学完全同构（AGENTS.md/报告/wiki=把个人学习翻译成机器可读）。孙宇晨奖（数学证明形式化为 Lean）的"证了机器读不懂=白证"是对 [[2026-09-22_xiaoyuzhou-tulong-zhishu_ai-production-stage|可靠性评测体系]]的数学界呼应。
6. **必须诚实记录的负面维度**：本集含大量不可核实且利益相关的断言（波场交易量、巴菲特对话、"人均诺贝尔奖"），以及与近期争议直接相关的自我辩护叙事（"百分百相信 AI"回应甩锅风波、搏击理论回应身材嘲讽）。**其结构价值在框架而非事实**——"三大理论+开图+版本论"是有传播力的心智模型，但每个数字和故事都应视为未经核实的个人宣传。
