# 路德维希·维特根斯坦（Ludwig Wittgenstein, 1889-1951）

## 身份

奥地利-英国哲学家，20 世纪哲学史**最具影响力**的两位思想家之一（另一位通常认为是海德格尔）。生于维也纳犹太钢铁工业家庭，1908 年入剑桥师从罗素，1914 年自愿入奥匈帝国军参加一战，1918 年 11 月在意军战俘营中完成《逻辑哲学论》(*Tractatus Logico-Philosophicus*)。1929 年重返剑桥做哲学，1951 年 4 月 29 日因前列腺癌在剑桥去世。

**前后期思想剧烈反转**:1921 年的《逻辑哲学论》建立"逻辑图像论 + 可说/不可说划界";1953 年身后出版的《哲学研究》(*Philosophische Investigations*)自我反转，提出"语言游戏"与"意义即使用"，把整部《逻辑哲学论》视为"读懂后须扔掉的阶梯"。这是 20 世纪哲学最显著的**作者自我反转**案例。

## 核心贡献

- **逻辑图像论（Logical Picture Theory）**：命题是事实的逻辑图像，命题与事态共享"逻辑形式"。这是 20 世纪语言哲学对"语言-世界关系"的最早系统化论述。来源：09_wittgenstein_tractatus_1921 §2.1-2.18
- **可说的与不可说的划界**：凡不能图示事态的命题皆为 *unsinnig*（无意义）。这是逻辑实证主义"拒斥形而上学"运动的文本基础。来源：09_wittgenstein_tractatus_1921 §4.003 / §7
- **真值函项理论**：一切命题（非逻辑命题）看作基本命题的真值函项，预示现代命题逻辑与组合性原则。来源：09_wittgenstein_tractatus_1921 §5
- **语言游戏（Sprachspiel）**：语言是嵌入在活动中的实践，意义不在"图示"而在"使用"。这是后期维特根斯坦的核心概念。来源：《哲学研究》§7 / §43
- **意义即使用**：*Die Bedeutung eines Wortes ist sein Gebrauch in der Sprache.*（《哲学研究》§43）—— 颠覆了弗雷格、罗素以来的"指称-意义"传统。
- **遵守规则悖论**：任何动作都可被解释为"遵守规则"，由此推出"私人语言不可能"。这是后期维特根斯坦的著名论证。来源：《哲学研究》§138-§242 / §243-§315
- **生活形式（Lebensform）**：语言游戏的最终锚点，是语言理解得以可能的社群-生物基础。来源：《哲学研究》§241

## 与其他人物的关系

- **老师**：**罗素**（B. Russell, 1911-1913 剑桥三一学院期间）—— 罗素是 1921 年英译本序言作者，但后来两人决裂（罗素不接受维特根斯坦后期思想）
- **影响自**：**弗雷格**（G. Frege）的意义/意谓理论；**罗素**的逻辑原子主义；**迈农**（A. Meinong）的对象论
- **平行人物**：
  - **海德格尔**（M. Heidegger）：同期德国哲学的反表象主义传统代表，与维特根斯坦对"语言"的看法根本对立（英美分析 vs 欧陆现象学）
  - **石里克/卡尔纳普**（M. Schlick / R. Carnap）：维也纳学圈直接继承《逻辑哲学论》
  - **奥斯汀/赖尔**（J.L. Austin / G. Ryle）：牛津日常语言学派继承《哲学研究》
- **自我反转**：维特根斯坦前期 vs 后期是同一人内部的根本对立，哲学史罕见

## 与 LLM 的当代相关性 [推论]

- 维特根斯坦前期思想与 LLM 的**形式语义能力**（真值条件、组合性）有深层对应（参见 09_wittgenstein_tractatus_1921 §11.A/B）
- 维特根斯坦后期"语言游戏"与 LLM 的**in-context learning / prompt engineering / 工具调用**在功能层面有强类比（参见 09_wittgenstein_tractatus_1921 §11.D）
- 维特根斯坦"可说的与不可说的"为审视 LLM **幻觉**与**对齐**（RLHF / Constitutional AI 的"沉默"策略）提供哲学框架（参见 09_wittgenstein_tractatus_1921 §11.C）
- **"理解"的判准争议**：维特根斯坦"理解是参与实践的能力" vs 塞尔"中文房间"——这是 LLM 是否"理解"的当代争论的哲学源头

## 开放问题

- 维特根斯坦后期对前期的反转究竟在哪些点上是**真反转**，哪些只是**发展**？学界未达成共识
- 维特根斯坦前后期是否在某些元层面（如"哲学的治疗性"目的）保持一致？这是 P.M.S. Hacker 与 Cora Diamond 等人的争论焦点
- 维特根斯坦与海德格尔的"语言哲学"在 21 世纪是否有融合可能？当代学者(例如 Stanley Cavell、Stephen Mulhall)有尝试
- 维特根斯坦的"语言游戏"对**机器意识**问题是否仍是**充分**的框架？这是 AI 哲学的前沿问题
