# 哲学文本深度分析

> 用于单篇哲学论文、著作或章节的论证分析。跨作者概念综述使用 `concept_deep_dive`。

## 路由

- 原文范围、引用和论证证据：读 [guide：文本证据要求](./references/guide.md#-文本证据要求)。
- 按文本选择背景、论证重构、概念、反驳或影响：读 [guide：分析维度](./references/guide.md#分析维度按研究取舍)。
- 只有需要选取分析视角时读取末尾哲学分支索引。

## 不变量

前提和推论忠实原文；补出的前提标 `[隐含前提]`；关键术语说明作者的特定用法；引文给出章节、页码或标准编号。
