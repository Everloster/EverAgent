# ai-learning — 领域协议

> AI/ML 论文、技术、行业与商业观察。公共报告流程和质量门由根级 Owner 维护。

## 按任务选一个入口

| 意图 | 按需读取 |
|---|---|
| 建立直觉、降低阅读门槛 | [科普讲解](./skills/科普讲解/SKILL.md) |
| 论文精读 | [paper_analysis](./skills/paper_analysis/SKILL.md) |
| 公式、机制、消融或工程落地 | [concept_deep_dive](./skills/concept_deep_dive/SKILL.md) |
| 书籍、长文或观点文章 | [拆书取景](./skills/拆书取景/SKILL.md) |
| 追问已有主题 | 定位原报告和相关原始材料，更新原文件 |

新建、续写或审计长期报告时同时使用根级 [`everagent-report`](../.agents/skills/everagent-report/SKILL.md)。不要并读多个体裁模板。

## 领域约束

- 公式逐符号解释；实验与消融数字保留单位、口径和出处。
- 技术史只写与当前机制有关的前驱和后续影响。
- 文章分析重构作者问题、回答与行动含义，并区分原文主张和自己的推断。
- 科普体报告交付后收一次学习反馈；只有明确反馈才写入 [FEEDBACK_LOG](./skills/科普讲解/FEEDBACK_LOG.md)。

需要既有覆盖时查询 eacli `knowledge.ai`；PROFILE、MAP 和 open-questions 按根协议条件读取。报告路径与命名约定由相应体裁 skill 负责。
