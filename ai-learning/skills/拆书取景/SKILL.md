# 拆书取景：x → f → f(x)

> 用于书籍、长文或观点文章的论证提炼。单篇实证论文用 `paper_analysis`；一句话摘要不使用本 playbook。

## 路由

- 判断材料是否足以支持拆解：读 [guide §1–§2](./references/guide.md#1-触发场景)。
- 重构 x、f 与 f(x)：读 [guide §3](./references/guide.md#3-核心流程)。
- 需要报告骨架或交稿检查时读取 [guide §4–§5](./references/guide.md#4-输出格式)。

## 不变量

x 必须是作者真正处理的问题；f 的各部分共同回答 x；f(x) 必须能从 f 推出并标明验证状态。材料不足时缩小结论范围，不用模型记忆补齐整本书。
