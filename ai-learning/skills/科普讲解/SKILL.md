# 科普讲解

根据当前问题选择例子、解释深度和结构。用户要公式推导、实验条件或工程参数时，按需转到 `paper_analysis` 或 `concept_deep_dive`。

公共表达、反馈和修订约定见 [REPORT_WORKFLOW](../../../docs/REPORT_WORKFLOW.md)。需要选择解释方法时读 [writing-guide](./references/writing-guide.md)；需要校准文风时按需选[阅读样例](../../../docs/WRITING_EXAMPLES.md)。

例子应说明真实机制中的对象、变化与关系；类比建立直觉后回到技术过程。中文译解仍需对照原文，明确翻译与概括的范围。

只有收到新反馈或需要追溯旧决定时才读写 [FEEDBACK_LOG](./FEEDBACK_LOG.md)，不将历史配方作为当前写作指令。
