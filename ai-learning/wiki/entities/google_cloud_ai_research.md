# Google Cloud AI Research

Google Cloud AI Research 是 Google Cloud 体系下的 AI 研究团队之一，SkillOS 论文的主要作者单位之一。

在 `SkillOS: Learning Skill Curation for Self-Evolving Agents` 中，Google Cloud AI Research 与 UIUC、MIT 合作，提出用强化学习训练 Skill Curator 管理外部 SkillRepo 的自进化 Agent 框架。

## 关联论文

- `SkillOS: Learning Skill Curation for Self-Evolving Agents`，arXiv:2605.06614，2026。

## 关联概念

- Skill Curation
- Self-Evolving Agents
- Procedural Memory
- Agent Orchestration
