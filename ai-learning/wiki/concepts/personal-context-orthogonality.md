# Personal Context 正交论（PC 与 AI 进步的正交性）

> 概念页 · 2026-10-10 · 来源：[PersonalContext正交论_PC构建指南](../../reports/knowledge_reports/PersonalContext正交论_PC构建指南_20261010.md)（用户 2026-10-10 今日思考的形式化与论证）

## 一句话
把个人积累目标从"会用 AI 的技巧"（过程性，随模型进步贬值）切换到 **Personal/Work Context**（事实性资产，随模型进步**升值**）——模型越强，同一份 context 兑现的价值越大；Context 是油，模型是越来越高效的炼油厂，巨头军备竞赛的每一分投入都在升值自持者的存量 context。

## 核心结构
- **两类 context 判别法**：下一代模型免费发布后，这条积累更值钱还是更不值钱？偏好/决策历史/判断对错（事实性）↑；prompt 技巧/工作流手感（过程性）↓
- **三个升值机制**：兑现（问答→执行）、Jevons（决策越便宜调用越频繁）、Bitter Lesson 个人版（随模型能力扩展的资产长期总赚）
- **三段链条**：积累事实性 context → memory 工程炼成画像 → 反复交付换委托信任（缺中段=豆包签证 bad case"有记忆不体贴"；缺末段=有油无炼油厂）
- **五层解剖**：L1 身份 / L2 事实 / L3 关系 / L4 程序（高贬值）/ L5 委托（终极资产，反向增长）；WC=PC 的 L2+L4 职业域投影，同一套分层不必两套系统
- **四条构建原则**：自持（油库在自己手里）/ 结构化（裸日志≠资产）/ provenance（资产防伪）/ 分层维护（按贬值速率区别投入）
