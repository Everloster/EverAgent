# Card Gallery：Agent 演义的自拟开发项目

项目包含前端、API 和集成测试，用于比较工作区、线程、预览、审查和任务组织。它由本次报告作者实现，不是 Claude、Codex 或任何产品的任务表现评测。

```sh
python3 -m unittest discover -s tests -v
python3 api/server.py --port 4188
```

打开 `http://127.0.0.1:4188`。只需要 Python 3 和浏览器，不需要模型、账户或第三方包。服务仅监听回环地址；数据是演示样本，没有用户信息。

功能合同：标题和描述做忽略大小写的字面匹配；支持中文；搜索和标签取交集；保留原始顺序；空查询显示全部；改变筛选重置到第一页；最新筛选结果优先；API 对非法分页返回 400。

适合作为独立演示仓使用：将本目录复制到临时目录并初始化 Git，再在 Orca 或 T3 中打开。不要把 EverAgent 整仓作为产品演示项目。设置项、会话和截图均应指向该演示目录。

可复走任务：扩展字段搜索并补测试；检查标签切换是否重置分页；在浏览器选择一张卡片并给出精确布局反馈；审查 API 与前端是否采用同一套搜索规则。任务脚本属于教学案例，报告没有运行付费模型或创建外部 PR。
