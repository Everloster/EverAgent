# AI 应用创业生死录

## 从 Evoken 三产品看「模型吞噬应用」时代的 survive 经济学

> 证据标签:`[实测]`=本次 opencli 官网实地所见 / `[自述]`=陈冕播客/图文原话 / `[外部]`=shownotes/公开报道 / `[评]`=分析判断 / `[待验证]`=未独立核实。
> 方法:三源交叉——播客完整版(2h08m 本地转写)+ 官方图文/shownotes + 三产品官网实地调研(2026-07-31)。

---

## 0. 执行摘要(TL;DR)

Evoken(演语科技)是这一代中国 AI 应用公司里估值/融资最高的前三名之一(`[外部]` 20 亿美元估值一笔融 3 亿、ARR>3 亿美元),也是争议最大的一家。它旗下三个产品——**Liblib(AI 图像平台)、Lovart(AI 设计 Agent)、LibTV(AI 视频工具)**——恰好构成一部"AI 应用创业生死录"的三个切片:

- **一个残酷前提**:创始人陈冕自己承认——**"现在还不是应用的时代,主叙事还在模型、甚至在 infra 上"**`[自述]`。今天属于应用的价值,明天可能被模型覆盖。所以这一代应用公司的第一要务不是增长,是 **survive**。
- **一套生存打法**:焦虑 + 速度 + 侵略性。用"逐鹿中原 vs 占领江东"的战略——**巨头争通用大市场时,应用公司抢垂类,以时间换空间→换资源→浇筑壁垒**。
- **一个可证伪的商业机制**:低毛利(≤30%)、积分制、按模型明码标价、"消耗率×续费率"定价——**本次官网实测(尤其 Lovart 定价页)完全印证了这套机制**,不是空谈。
- **一道悬顶之剑**:低毛利打法在 token 成本上涨时最先崩(Lovart 补贴战就是被算力缺卡"打穿"的),而"高 token 消耗产品的商业模式"陈冕明说**仍在探索、尚无答案**。

`[评]` 一句话:Evoken 是"在巨头脚下捡钢镚、且明知随时会被踩到"的极限生存样本。它的价值不在于是不是最"创新",而在于把**"应用层到底还剩什么、能撑多久"**这个全行业焦虑,用最激进的方式演给所有人看。

## 1. 三产品实地调研:一张"应用层价值栈"的活体切片

`[实测]` 2026-07-31 用 opencli browser 实地访问三个官网,所见如下:

| 产品 | 官网自我定位(原文) | 产品形态 | 模型策略(实测) | 商业模式(实测) |
|------|-------------------|---------|---------------|---------------|
| **Liblib**(liblib.art) | "中国领先的 AI 创作平台" | **工具 + 模型社区**:WebUI / ComfyUI / 训练 LoRA;首页聚合 100+ 图片/视频模型 | 全平台模型聚合:Seedream 5.0、Seedance 2.0、可灵 3.0、Happy Horse(阿里)、智能图片 V2… | 积分制(登录领 20 积分/天)、会员(3GB 云存储、约生图 40 张/视频 2 个)、**作者收益**(社区分成) |
| **Lovart**(lovart.ai) | **"全球首款 AI 设计智能体"** | **Agent**:自主"分析意图→搜参考→研究品牌→成套输出",强调"以系统思维设计品牌体系" | Seedance 2.0、Nano Banana 2、GPT Image 2、Kling O1… | **积分制 + 按模型明码标价**(见 §3) |
| **LibTV**(liblib.tv) | "专业视频创作工具 / 创作只需要一张画布" | **垂类视频**:短剧/漫剧/商业广告/影视/动漫 | Seedance(陈冕称"硬通货") | 3.9 折年包(见 §3,官网会员页需登录未取到,以播客实证为准) |

**`[评]` 三产品放一起,恰好画出"应用层价值栈"的三种活法:**

1. **Liblib = 聚合层 + 社区**:自己不做模型,把全世界最好的模型聚合起来 + UGC 模型社区(作者收益)。价值 = 聚合 + 社区网络效应。
2. **Lovart = Agent 层**:在模型之上叠"自主编排"——不是"给你一个模型",而是"给你一个会自己搜参考、定品牌体系的设计师"。价值 = 编排 + 判断。
3. **LibTV = 垂类场景层**:锁定短剧/广告等具体场景。价值 = 场景 know-how + 工作流。

这正是陈冕说的**"应用层所有的都是 leverage 在模型上的,我们本来就会卖模型,因为价值是在模型之上叠了一层"**`[自述]`。三产品是同一句话的三种叠法。

## 2. survive 战略:逐鹿中原 vs 占领江东

这是全场最锋利的框架,也是理解 Evoken 所有打法的钥匙。`[自述]` 陈冕用三国比喻:

> 天下大乱,袁绍与曹操在北方逐鹿中原(争通用大市场)。此时**江东(垂类)是巨头的低优先级**。所以:**巨头逐鹿中原时,你能不能一统江东?**
> 关键是"以时间换空间,再用空间换资源,再用资源浇筑壁垒(长江天险)"。**一蹴而就的壁垒都不是真壁垒。**
> **做通用,你就是河北——站在平原上,被平推概率很大。**

**拆解这套战略的三个内核 `[评]`:**

| 要素 | 陈冕原意 | 对应到 Evoken 实际 |
|------|---------|-------------------|
| **逐鹿中原者** | 字节等巨头,争通用 AI 大市场 | 即梦、豆包等大厂 C 端产品 |
| **江东(垂类)** | 巨头暂时看不上的高优先级缝隙 | AI 图像社区(Liblib)、垂类视频(LibTV) |
| **长江天险(壁垒)** | 需时间浇灌,非一蹴而就 | 模型聚合速度、社区(作者收益)、场景 know-how、用户消耗数据 |
| **时间差** | 巨头逐鹿中原→打完→才回头打江东 | Evoken 要在这个窗口内建起天险 |

**`[评]` 这个框架的锋利之处**:它把"打不过巨头"这个必死局,重构成"**在巨头注意力的时间差里偏安求生**"——不求赢,求**苟到应用时代真正到来**。

**但它有一个陈冕自己都没答的致命赌注**:整个战略押在"巨头的注意力窗口"上,而**这个窗口多长他无法估**(他承认"巨头逐鹿中原完之后会不会打江东、什么时候打,是动态变量")。而且他自己也说了——历史上**"偏安江东"最后都被大一统吞掉**。所以这套战略的真名不是"赢",是"**体面地拖延,换一个好的投降条件或等一个变数**"(他原话甚至提到"给你换一个好的投降条件,可能也是一个路")。`[自述]`

## 3. 商业机制:低毛利 + 消耗率定价(本次实测印证)

这是本报告最硬的一块——**播客里陈冕讲的定价哲学,在 Lovart 官网定价页得到了逐条实证 `[实测]`**。

### 3.1 陈冕的定价三原则 `[自述]`

1. **应用层早期不该有高毛利**:"存储/芯片/SOTA 模型都有七八成毛利,我还有七八成,it's not reasonable。" 目标毛利 **≤30% 且 >0**(不自爆、不负毛利,但也不追高——因为高毛利压制需求,而应用层最大的意义就是用户)。
2. **定价 = 消耗率假设 × 续费率假设的平衡**:成本(每张图/每条视频折算)→ 设计积分 → 价格带 → 对空耗假设 + 续费率假设 → 折算 LTV 周期 → 给一个低早期利润率。
3. **3.9 折的真相**:是**月费年包的 3.9 折**,不是 Seedance API 的 3.9 折;"我打的广告是对我的用户的,不是对懂 API 的创业者的"——大众误读成 API 补贴,才有了"补贴换增长"的指控。

### 3.2 Lovart 定价页实测:机制完全对上 `[实测]`

| 陈冕说的机制 | Lovart 官网实测证据 |
|-------------|-------------------|
| **积分制**(而非纯订阅) | 各档按"每月 X 积分"计:2,000 / 3,500 / 11,000 / 27,000 积分 |
| **按年折扣锁 LTV** | $16/月按年付 vs $19/月;Pro 首年 $468 次年 $888("锁定续费" ) |
| **按模型明码标价**(leverage 在模型上) | Seedance 2.0 **$0.040/秒**、Nano Banana 2 **$0.040/张**、GPT Image 2 **$0.008/张**——逐模型标价,且高档单价更低($0.017/秒) |
| **消耗率机制** | "积分消耗取决于功能/任务复杂度/图像尺寸质量";"Nano Banana 闲时半价"(削峰);充值九折 |
| **早期让利** | 低档单价高、高档单价低——用规模换单位成本,不追高毛利 |

**`[评]` 这套机制说明什么?** Evoken 的定价不是"拍脑袋低价补贴",而是一套**精算过的、把'模型成本'透明传导给用户 + 用积分制吸收消耗波动 + 用年包锁 LTV**的工程。它把自己定位成"模型的高效分销 + 消耗管理层",毛利薄但可控。这比"缺原创、靠补贴"的外界指控要精密得多。

### 3.3 但这套机制有个结构性风险 `[评]`

- **低毛利 = 无缓冲**。陈冕自述 Lovart 补贴战就是被"全球算力缺卡、后几代模型成本变高"**打穿**的(补了两个月就停,"再补马上被打穿")。
- **"高 token 消耗生产力产品的商业模式"陈冕明说仍在探索、无答案**。这意味着:**一旦进入真正的高 token 消耗时代(Agent 长任务、视频),现在这套薄毛利打法可能最先崩**——你把模型成本透明传导给用户,用户消耗一涨,你的薄毛利瞬间变负。
- 这与《Intelligence Curse》的洞察呼应:**应用层的价值高度依赖"模型成本-用户付费"这道剪刀差,而这道差是模型厂商单方面能压缩的。**

## 4. 三大争议的证据化复盘

| 争议 | 外界指控 | 陈冕回应 `[自述]` | 本报告判断 `[评]` |
|------|---------|-----------------|------------------|
| **爆雷** | 亏损严重、迟早爆雷 | 5-6 月现金流为正、账上钱越来越多 | 无法独立核实财务,但"现金流正"与"低毛利>0"自洽;`[待验证]` |
| **投流** | 靠投流换增长、字节最大代理商 | 投流占收入 3-4%、每月<100 万人民币;主流视频媒体不能开户"想投也投不了";代理商说法"一定程度没问题"(本就 leverage 在模型上) | "不能开户"是硬约束,指控与之矛盾;但"品牌投放花了不少"(shownotes 补充),口径有弹性 |
| **补贴/缺原创** | 3.9 折补贴、缺原创度 | 3.9 折是年包月费折非 API 折;真正补贴是 Lovart 海外补贴战(2 个月);"创新是有成本的,守不住做不好创新有啥意义" | 定价实测确为精算积分制而非无脑补贴;"缺原创"更像**战略选择**(聚合+跟进快)而非能力缺陷 |

**`[评]` 一个反直觉的结论**:很多针对 Evoken 的指控,本质是**用"上一代 SaaS 的高毛利/原创崇拜"去套一个"薄毛利、聚合、跟进"的 AI 应用公司**。陈冕的打法在他自己的框架里是自洽的——问题不在"是否道德/创新",而在"**这套框架能不能熬过时间**"。

## 5. 时代判断:idea is cheap,judgment 稀缺——但这道护城河牢吗?

`[自述]` 陈冕最凝练的时代判断:

> "**idea is cheap**,因为 vibe coding 让所有 idea 的实现变得特别容易;所以在浩如烟海的 idea 里找到那个正确的、那个 timing 的 best choice,才是人最大的意义——**judgment(判断力)变得更稀缺了**,这是创业公司最重要的杠杆。"

**`[评]` 这句话很动人,但和你知识库里两篇报告直接冲突,值得深挖:**

- 陈冕把"人的判断力"当作 AI 时代**永久的护城河**。
- 但 **Bitter Lesson × Harness** 指向:人工设计的"知识层/结构"终将被规模化方法碾平。
- 而 **《Intelligence Curse》** 更狠:AGI 会让"outlier 人才的判断力"也贬值——AI 造 idea、甚至 AI 做 timing 判断(VC 可直接跑几百个 AI 创业尝试)。

**所以核心张力是**:judgment 到底是"人类永久的高地",还是"**下一个待被模型爬升淹没的台阶**"?
- **短期(1-3 年)陈冕大概率对**:当前 AI 在长程判断、品味、局部知识上确实弱,人的 judgment 有真实溢价(这也是他"江东天险"的一部分)。
- **长期存疑**:如果 judgment 也能被 RL/搜索规模化(AlphaEvolve 式 meta-search 已在吃"设计 reward 和搜索空间"这一层),那么"人找对 idea"这道护城河,可能和 Evoken 的其他壁垒一样,是"**需要时间浇灌、但也可能被时间冲垮**"的。

`[评]` **这恰恰是整个"AI 应用创业生死录"的元问题**:陈冕赌的是"人的价值(judgment/品味/场景 know-how)能撑到应用时代到来"。这个赌注和《Intelligence Curse》"人类经济相关性会不会消失"是**同一个赌注的商业版**。

## 6. 结论:Evoken 是一个"高信息量的极限样本"

`[评]`

1. **它不是最'创新'的,但可能是最'诚实'的**——陈冕公开承认"现在不是应用的时代、我们最重要的是活着、我配不上这么多关注"。这种把"生存焦虑"摊开讲的坦诚,本身是这一代 AI 应用处境的最佳注脚。
2. **它的商业机制是精密的、可证伪的**——低毛利+积分制+按模型标价+消耗率定价,本次官网实测逐条印证,不是 PR 话术。它把自己工程化成"模型的高效分销与消耗管理层"。
3. **它的战略是"体面拖延"而非"必胜"**——"占领江东"的真名是在巨头注意力时间差里求生,换一个好的结局(被收购/偏安/等变数),不是击败巨头。
4. **它的生死手,系于两个它无法控制的外部变量**:① 模型 token 成本曲线(决定薄毛利何时崩);② 巨头注意力窗口(决定江东何时被打)。**这两者都掌握在模型厂商/巨头手里**——这正是"模型吞噬应用"最残酷的地方:**应用公司的生死,不完全由自己决定。**

> **一句话收尾**:Evoken 的"生死录",本质是在回答一个全行业问题——**当价值持续从应用层向模型层迁移,一家只握有"聚合+编排+场景+判断"的应用公司,能不能靠'比巨头快、比巨头专、在巨头看不上的地方扎根',苟到智能足够便宜、应用的春天真正到来的那一天?** 陈冕自己给的成功概率是"10%-20%-30%,但我愿意 bet 人类有没有价值"。

## 思考与追问(3 问)

1. **"江东天险"到底是什么,可量化吗?** 陈冕说壁垒是"聚合速度+社区+场景+消耗数据",但这些在巨头面前有多硬?**用什么指标能判断 Evoken 的"长江天险"正在变厚还是变薄**(如:模型上新到 Liblib 的时间差、作者社区留存、LibTV 场景复购)?这是判断它 survive 概率的关键。
2. **薄毛利定价的"打穿点"在哪?** 既然 Lovart 补贴被算力成本打穿过,而"高 token 消耗商业模式"无解——**能不能建一个简单模型:给定 token 成本上涨速率 + 用户消耗率 + 续费率,算出现在这套 3.9 折/积分制在什么条件下由正毛利翻负**?(这是可做的 B 类 demo,直接服务于判断)
3. **judgment 护城河的证伪信号**:如果"人找对 idea 的判断力"是 Evoken 的核心人力壁垒,那么**当 AI 开始能可靠地做"timing 判断/赛道选择"(而不只是执行),就是这道护城河被淹的信号**。有没有可观测的早期指标(如 AI VC、AI 选品、AI 定 roadmap 的成功率)能追踪这一点?(缝合 Bitter Lesson × Harness / Intelligence Curse)
