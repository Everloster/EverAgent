# Evoken 陈冕晚点访谈精读：一家 AI 应用公司如何在模型吞噬中求生

> 体裁：行业观察精读（ai-learning 扩边界后首篇）。
> 证据纪律：**本文全部数字（ARR/现金流/定价/用户量）均为创始人受访自述，晚点未做独立审计**，标 `[访谈]`；我的分析标 `[评]`；事实性背景标 `[背景]`。

---

## 0. 这家公司是谁

Evoken（演语科技），三年三个产品：**Liblib**（图像生成社区）→ **Lovart**(AI 设计 Agent)→ **LibTV**(AI 视频工具）。自述 ARR 超 3 亿美元、估值 20 亿美元、一笔融资 3 亿美元，2026 年 5 月起现金流转正 `[访谈]`。LibTV 贡献过半收入，月客单价"几百元"——"替代的是一个剧组的工作，客单价天然不是量级" `[访谈]`。

争议同体：缺少原创（LibTV 页面与更早的 PMF 产品相似）、激进定价换增长（3.9 折年费）、ARR 虚高、组织动荡（联创走一半、技术负责人走 4 个）`[访谈]`。

## 1. 核心命题：模型在进化，应用的安全区在坍塌

访谈的总纲是陈冕的"生存论"：**应用公司最大的机会和最大的危险来自同一个地方——模型能力与用户需求之间的空缺**。模型还在快速进化，今天属于应用的价值，明天可能被模型内化。

他自己撞上过一次：Liblib 时期探索一年的"节点式强控制工作流"，被 OpenAI GPT Image1 直接内化进模型——"完蛋了……我说不行，完蛋了，你让我想一想怎么办"。在回北京的飞机上想通转向：**做 Agent，把所有工具 combine 在一起 + context + agent 工作流**——这就是 Lovart `[访谈]`。

他的战略比喻是《三国》:**模型厂商在"逐鹿中原"，他趁江东不是主战场先统一江东，再修"长江天险"**——天险是什么，"修出来才知道是不是" `[访谈]`。

> [评] 这段和 ai-learning 库存的 Bitter Lesson × Harness 讨论（20260707 报告）是同一枚硬币的两面：**模型层每一次进步都收割一批脚手架**。"节点式工作流被内化"就是 Bitter Lesson 在商业上的即时显形。陈冕的应对不是修更高的脚手架，而是**把公司做成快速重新寻找空缺区的机器**——"一个方向坍塌，就再寻找下一个"。这是把 Bitter Lesson 从悲观命题改写成了组织节奏问题。

## 2. 商业模式拆解：健身房年卡 + 消耗率精算

围绕"3.9 折补贴"争议，陈冕给出了相当坦诚的定价模型 `[访谈]`:

- **不是补贴，是定价精算**：把图/视频成本折算成积分，设计价格带与积分数；**假设消耗率和续费率**，反推一个"早期利润率没那么高"下成立的价格。"用户买了 100 万积分，实际只用 20 万，剩下 80 万是我们的利润"——**健身房模式：赌办年卡的人不天天来**。
- **全用满必亏**："如果用户按原始定价全用满，那肯定是亏的呀，但怎么可能所有用户全用满？ChatGPT 都没有。"他援引传统工具的活跃度佐证：剪映/Adobe 稳定留存用户 LT30 也就 5 天左右——**工具产品本来就是周活不是日活**。
- **风险敞口他也认**：黑产把年费会员逆向成 API 会亏，"所以要治理"；Uber CEO 式警告（年付预收 ≠ 良性增长）他接住了——"是警惕年付带来的'不使用'，不是警惕年付本身"，要看留存和粘性。
- **毛利观**：短期不超 30%。"存储、芯片、SOTA 模型都有七八成毛利，应用还能有七八成，it's not reasonable"——智能从半导体向下游传导，应用层的价值是"对齐"（模型是单反，应用是听得懂需求的摄影师）。
- **下一代模式设想**："山姆模式"——会员卡保续费 + Token 实充实销，固定费用就是应用层价值。但比年包贵，现在切换会在竞争中被动。

> [评] 这套模型的脆弱点清晰可辨：**消耗率假设是全部的地基**。年包定价 = f（消耗率， 续费率）——若模型变便宜/变强导致用户消耗率上升（更好用→用更多），或黑产规模化，精算立刻翻转成失血。他赌的两个对冲：① token 成本长期下降（"SOTA 只有 SOTA 的时候最贵"）;② 工具产品的天然低消耗。这是一个**用互联网订阅制的壳，装按量计费的核**的过渡形态，他自己也知道，所以才有"山姆模式"的备胎。

## 3. 竞争观：PMF 先到先得 ≠ 赢家通吃

- **承认非首发**："LibTV 不是第一个拿到 PMF 的……但第一个发现 PMF 和最终赢得市场，差着十万八千里。"垂类 PMF 的 interface 最优解"极其趋同"——"手机现在都长一样，短视频就是上下滑"（ComfyUI 之于图像、Flora 之于视频）`[访谈]`。
- **关键决策是算账不是情绪**：做 LibTV 是因为"预测它的收入已经超过 Liblib，你还不去做，你在干嘛"。从想投资对方（被拒）到自己下场，只用了一个多月 `[访谈]`。
- **创新时效论**："工程上的创新时效性也就一个礼拜"——所以打法是**快上 + 一两个好单点 + 饱和式宣发**(LibTV 一个月烧 100 万美金宣发，自称 ROI 很高；投流只占收入 3-4%)"先 build attention，再 build ability" `[访谈]`。
- **后发难**："后发的主动权在别人手里，本质是等别人犯错……只要我们不犯错，后发很难。"

> [评] "先 build attention"是这篇访谈里最反直觉也最"字节系"的一招。在"模型季度迭代、创新保鲜一周"的环境里，**护城河不可能是功能本身，只能是注意力和组织速度**。这与 Bitter Lesson 的结构完全一致：当通用能力（模型）碾压专用功能（工程创新）时，唯一不可被模型内化的资产是用户关系。风险也同源——注意力资产的前提是"持续有下一个空缺可扑"，一旦模型进化放缓或公司扑错方向，高估值会立刻变成达摩克利斯之剑。

## 4. 组织与争议面（值得留档的反面教材）

- **title 草率**：早期"大家都可以叫联合创始人"，可能发过 10 个——"我没把 title 当回事，但公司有影响后大家会把它当认定"。反思：合伙人要有标准、要经受评判 `[访谈]`。
- **技术负责人换 4 个**："至少一半是出于无奈——公司都要倒闭了，发不出工资。" `[访谈]`
- **现金流惊悚时刻**:Liblib 与吐司（Tusi.Art）烧钱大战，账上只剩 4000 块；拒绝所有融资去打仗（"我要赢下来，不然就挂了"），战后只剩 600 万再疯狂见投资人 `[访谈]`。
- **打赢的账**：烧钱 300 万美金，**只补贴设计类作者**——"在生产力赛道，不是用户多谁赢，是谁掌握最高价值的生产谁赢"（剪映经验） `[访谈]`。

> [评] "高价值 token"论是全访谈含金量最高的一条常识非共识：当商业模式是从 token 产出中抽成，**低价值 token（泛娱乐内容）是负资产**——它消耗补贴和算力却不沉淀付费意愿。这条原则和"健身房模式"互为表里：一个管收入质量，一个管成本结构。

## 5. 留给我们的校验点

陈冕的自述内部自洽，但均为单方面口径 `[访谈]`：ARR 3 亿、现金流转正、投流仅占 3-4%、自然增长 90%、LibTV 过半收入。晚点的追问（年付预收占比 20-30%）已经戳到现金流质量的要害。这些数字在下一轮融资文件或后续报道（如暴雷/上市）出现时可对照验证——**本报告不采信也不质疑，只标记为"创始人声称"**。

## 思考与追问

1. **「消耗率精算」有没有公开可验证的样本？** 健身房模式成立与否全看真实消耗率分布——AI 工具类产品的公开留存/消耗数据（哪怕是别家的）能拼出这个假设的行业均值吗？（可深挖：Anthropic/OpenAI 官方或第三方分析的 usage pattern 研究）
2. **「模型吞噬应用」的边界在哪？** 节点式工作流被 GPT Image1 内化是实锤案例；但 ComfyUI 生态、Photoshop 这类工具为什么没被吞噬？吞噬发生的条件是什么——是"交互复杂度低于模型理解力"吗？（可接 Bitter Lesson × Harness 报告继续推演）
3. **陈冕的"应用时代 2-5 年后到来"用什么信号检验？** token 价格、模型能力、用户付费习惯三条曲线各自到什么刻度算"时代来了"？（可做成追踪型观察，半年回访一次）
