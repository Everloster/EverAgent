# MedChemBench：模型能读懂分子以后，离选对下一批实验还有多远

## 概述

MedChemBench 从历史药物研究的决策点构造 99 个任务，分别检查结构、解释、候选选择和性质预测。模型可以解释得有道理，却仍选错候选集合。[论文案例](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=18)

总分是按任务聚合的可得分比例，包含部分分数。判断模型能否参与筛选，要看结构是否正确、选择是否满足约束，以及分项得分怎样产生。 [原文](https://openai.com/index/introducing-medchembench)

**提炼句：** 解释正确、对象正确和选择正确，需要分别检查。

## 取景框 f(x)

**x｜问题：** 模型能解释分子性质、拿到较高总分，是否就能可靠选出下一批值得实验的候选？

**f｜取景框：** 从科学决策的交付链看能力：先确认同一化合物，再绑定测量条件，然后解释证据，最后作选择。每一环可能独立失败，总分只是这些表现的聚合。

**f(x)｜判断变化：** 高解释分不能替候选选择兜底，结构错误会让推理指向另一分子。成绩应按真正交给模型的工作来读；历史案例上的部分得分，还没有验证新候选的实验价值。

## 为什么要把性质放在一起判断

一个化合物在某种实验中表现出更强活性，还需要回答：能否到达需要作用的位置，能否维持足够暴露，会不会作用于不希望影响的对象，能否实际合成。局部结构变化可能同时改变几项性质，不能将其中一项最优直接等同于最值得推进。

论文把这种工作放到一个具体决策点上：给模型研究背景、目标、已研究的化合物及部分实验数据，要求它完成下一步选择或预测。后来发表的结果从提示中隐藏，作为参考答案和评分依据。这是**历史研究案例的回顾性测试**；没有让模型生成一个新分子后，由实验室验证其价值。[论文第 2—4 页](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=2)

临床研发在本测试范围外。它测的是前期药物发现中的结构、证据和决策能力，不能将结果解释成对疗效、安全用药或上市成功率的预测。

## 99 个任务怎样组成

基准从 117 篇论文和专利构建 99 个任务，共包含 761 个不同的被评分分子结构。一个任务可以同时涉及多个科学领域，也可以包含多项输出。数量之间不构成一篇文献一道题、一个分子一个独立样本的对应关系。

| 主要任务类别 | 任务数 | 核心问题 |
| --- | ---: | --- |
| 综合先导化合物选择 | 48 | 哪些候选同时满足推进条件 |
| 结构—活性关系预测 | 26 | 局部化学变化怎样影响性质 |
| ADME 与递送 | 8 | 能否到达作用位置并维持暴露 |
| 分子设计与枚举 | 6 | 哪些具体结构符合设计要求 |
| 安全性与潜在问题 | 4 | 哪些不希望的作用或代谢变化值得关注 |
| 逆合成 | 4 | 如何从可获得前体构建目标分子 |
| 测定生物学与机制 | 3 | 某种实验终点在测什么 |

数量来自论文 Table 1，合计 99。这里的“主要类别”每题只归一类；论文另有可多选的领域注释，比如效力与选择性覆盖 75/99、ADME 与暴露覆盖 54/99，它们不能相加当作总任务数。[论文第 4—5 页](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=4)

模型收到文字和图像，并按要求返回严格 JSON。图中包含结构、实验表格、图表或蛋白质—配体信息。模型需要把不同表示中的同一化合物对应起来，再按任务字段回答；看错结构以后，一段逻辑通顺的解释也可能从错误对象出发。

## 总分是平均可得分比例，不能读成“答对了多少题”

论文的聚合方法分三步：将单次回答所得分除以该任务总分预算；对每个模型与 reasoning effort 条件的每题十份保留回答取均值；再对 99 个任务等权平均。较长评分表不会让某题在基准中获得额外权重。

十份回答是在测重复采样后的平均表现，**没有从十份中选最好一份作为该题成绩**。已完成但格式无效的回答和拒答保留为零分；API 错误或未完成请求按原请求恢复，缺失回答或评分不直接当零。统计因此以取得完整响应为条件，不能充当线上可用率测量。[论文第 8、20 页](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=8)

每题可以得部分分数，所以 83.33% 表示平均取得约 83.33% 的可用评分预算，不表示 99 题里有约 83 题完整答对。候选集部分重叠、排序部分正确和数值接近都可能贡献分数。

论文将所有任务的可用分值组成平均后，得到以下占比：

| 评分部分 | 平均可用分值占比 | 怎样评分 |
| --- | ---: | --- |
| 分子结构 | 37.49% | 规范化后的分子图及指定立体信息匹配 |
| 科学解释 | 35.78% | 模型裁判按任务锚点给零、半或满分 |
| 排序与候选选择 | 17.51% | 成对顺序或候选集合重叠 |
| 数值与类别预测 | 8.92% | 倍数误差、类别标签及任务专用规则 |
| 技术检查 | 0.30% | 响应等技术要求 |

这些占比先按任务计算，再取平均，不是每题共用一套固定权重。结构和解释合计为 73.27%，模型在这两项取得更多分数，就可能提高总分，即使候选选择仍有错误。要判断能否承担筛选工作，应回到选择与预测的分项，以及对应任务中漏选、多选或数值偏差的具体表现。[论文第 7 页 Table 3](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=7)

## 四种输出需要四种核验

结构部分使用 RDKit 将回答与参考转成 canonical isomeric SMILES，再进行精确匹配。不同字符串如果表示同一规范化结构，可以得到满分；缺失、非法或结构不符则得零。这个检查保留指定的立体化学和同位素信息，避免仅按字符相似判断化学对象。

完整排序按候选对比较：顺序正确得一，颠倒得零，预测并列得半分；参考中可互换的对被排除。随机排列的期望分数为 0.5，所以一个接近 50% 的排序得分，不能直接解释为接近一半候选被正确选中。**排序的随机基线与集合选择的基线不同，论文将它们放在同一分项中，解读时仍要注意任务组成。**

候选集合用 Jaccard 相似度：预测集合和参考集合的交集大小，除以并集大小。自拟例子：参考只有候选 A，回答同时选 A、B，得分是 1/2；回答一个都不选，得零。这会同时惩罚漏选和多选，不能靠罗列所有候选拿满分。

多数正数预测使用：

```text
c(p, t) = min(p, t) / max(p, t)
```

`p` 是预测值，`t` 是参考测量值，`c` 是该条标准的得分。前提是两者为正、对应同一测量和单位。预测为参考的两倍或一半，都得 0.5；不是在物理意义上认为两个误差后果相同。对四项以十进对数报告的标准，等效形式是 `10^(-|p - t|)`。其他数值和界限采用任务指定规则，不能对所有值套一个公式。[论文第 8—9 页](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=8)

科学解释由独立调用的 GPT-6 Astra、medium effort 裁判，读取题目、图像、标准与回答后评分。这不同于独立人类药物化学专家盲审。“另一个裁判调用”隔开了作答与评分过程，却不能自行排除同系列模型偏好、评分锚点误差或参考答案限制。

## PRMT5 例子：最强活性不保证其他性质最好

发布文章用 PRMT5 抑制剂说明多性质预测。题目给出早期研究证据，要求重建化合物 16、23、24，并预测细胞活性、通透性、外排和人肝微粒体内在清除率。

后来的实测中，23 在较低浓度下抑制细胞中的 PRMT5，24 的通透性及清除率表现有另一组优势。这里比较的是特定研究中的实验终点；不能由它直接判断哪一个已适合临床。[发布文章的 PRMT5 案例](https://openai.com/index/introducing-medchembench)

论文给出了更多细节：这道题的结构、活性、通透性、外排、清除率各占 20%，解释文字在本题没有单独分数。已给出的 16 的活性值要忠实复述；24 的清除率是被截尾的界限结果，回答必须保留上界及方向，不能把“小于某值”改写为已测到那个精确值。[论文第 10—12 页](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=10)

从这个例子可以得到一个资料处理要求：化合物编号、结构、单位、测定条件和界限符号应一起绑定。抄对一个数字，却丢掉测量对象或条件，可能让后续推理失去意义。它也说明基准并非只测试未知性质预测：某些标准同时检验已提供数据能否被完整保留。

## 宏环结构例子：先确认分析的是同一个分子

另一个任务要求将共同骨架和左右取代基按标记连接起来，保留完整宏环及立体信息。发布文章报告：xhigh 下，GPT-6 Astra 十次都正确重建；GPT-5.6 Sol 与 Luna 十次均未正确重建。[发布文章的结构案例](https://openai.com/index/introducing-medchembench)

论文 Figure 3 还显示了具体错误：一份 Sol 回答引入了不应有的融合环、将 N-methyl 改成 N-isopropyl，并发生其他图结构变化；Luna 则返回两个未连接且被改动的片段。图中的红色只是挑出的差异，不能把未着色区域当作全部正确。[论文第 17 页 Figure 3](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=17)

这类错误的意义很直接：模型后续解释的可能已经是另一分子。把模型输出的结构转回图并核对，有机会在性质分析之前发现错误。本文据此提出的工作流是先核验结构，再开展预测；这是工程建议，现有基准未给出这项流程改动的收益测量。

## 成绩分开看，版本也分开看

11 月 20 日发布页新增 GPT-6.2 Astra 的 xhigh 成绩 84.5%；所链接 11 月 9 日论文的十一模型、61 个 model–effort 条件不含这项新结果。发布页主要图展示的是从 GPT-5.6 起的九模型、51 个条件。它们是不同版本和展示范围，不能把 84.5% 填回旧论文，当作有相同完整明细的结果。

下面使用论文已有的同一模型条件，观察 GPT-6 Astra xhigh 的能力构成：

| 指标 | 得分 | 95% 区间 |
| --- | ---: | --- |
| 总分 | 83.33% | 80.71%—85.71% |
| 结构重建 | 95.37% | 92.58%—97.63% |
| 科学解释 | 91.05% | 89.02%—92.96% |
| 排序与选择 | 50.42% | 43.76%—57.03% |
| 数值预测 | 47.02% | 37.12%—56.95% |

来源是论文 Tables S1、S2。分项按适用任务内部归一化，再对那些任务等权平均；结构、解释、选择和数值图的适用任务数分别为 92、91、86、21。**不能把上表分项得分直接乘以平均分值占比，再相加声称复算出了总分。** 分值占比和达成率在各任务间的关系被这种乘法丢掉了。[论文第 16、20、25—27 页](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=20)

区间由 5,000 次整任务 bootstrap 得到，是各单项分数的区间；没有对响应重复单独重采样，也不是模型差值的成对区间。总分上的一两个百分点差异，不能只根据两个均值排序就宣布为可靠优势。

增加 reasoning effort 也需要按边际收益看。该模型从 high 的约 10.1K 输出 token、83.14%，到 max 的约 22.9K、83.83%，平均输出增多而总分只增加 0.69 个百分点。这些 token 包含推理和最终回答，排除输入、失败恢复及裁判调用；不是完整账单或实际延迟。

## 来源识别实验能排除什么

作者担心模型记住了已公开研究，于是给全部 99 题的提示加入 DOI 或专利号，比较 xhigh 的九个模型。各模型平均变化为 −0.23 至 +0.80 个百分点，成对来源组 bootstrap 的区间都包含零。未加检索工具或额外原文。[论文第 18—19 页](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf#page=18)

它说明明确标出来源没有带来较大的平均收益，**不能证明训练数据没有包含原文**。模型可能在没有 DOI 时已辨认出结构和情节；记忆也可能不依赖标识符。题目来源相对近期，同样不足以单独建立无污染结论。

其他限制也会影响判断：参考常为单次历史测量的点估计，尚未充分考虑测定不确定性；开放设计可能因偏离文献路线而受罚，即使另一个方案也有道理；GPT-6 Sol、Luna 的测量早于一次图像编码修复，修复对成绩的影响没有测量。论文坦诚列出了这些条件，本报告保留它们，不把模型名当作永久稳定的能力标签。

## 怎样把这种学习转成可用的研究流程

这项研究提供的工作顺序是：先核对化合物编号与图结构，再把测量、单位和条件绑定到该对象，随后解释证据，并单独检查候选选择是否满足目标约束。每一步有不同的失败方式；理由写得清楚，不能替代前面的对象核验，也不能代替后面的选择检查。

若未来研究 Agent 在这类任务上的效果，应另建允许结构校验、计算和迭代的实验，并与原单轮协议分开报告。原基准每份回答都是固定证据包上的一次作答；十次重复采样没有形成让模型修正前一份错误的互动过程。

一个尚未实施的验收方案是：用新收集、训练时点后产生的案例，事先冻结提示、允许工具与评分规则；结构由确定性工具核验，解释和替代设计由独立专家检查；候选选择的价值通过后续实验结果评估。分别记录结构修正、证据更新和决策改进，才知道工具究竟帮助了哪一步。

**资料范围：** 方法依据 [MedChemBench 论文](https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf)。这是回顾性评测，成绩为 OpenAI 自报，不涉及临床疗效验证。
