# AI演义·28｜DDPM：用噪声预测计算反向生成步骤

[返回总览第 28 节](../AI演义_笔记分析与项目整合报告.md#paper-ddpm) · [上一章：早期扩散](AI演义_27_Diffusion2015_逐步加噪怎样学会生成_科普讲解_20261106.md)

2015年已有前向扰动、反向生成的扩散框架。2020年的DDPM改用网络预测受扰图中的累计噪声，再将预测换算为反向一步的均值，并结合简化损失、固定方差和带时间条件的U-Net，改善图像生成。

本章沿用*Denoising Diffusion Probabilistic Models*的2020-12-16 v2，首版为2020-06-19。[^paper] 花照继续作为教学示意，原论文没有本章的花卉实验。

<a id="what-changed"></a>

## 1. 在既有框架中选择参数化与目标

DDPM先规定每个时间步加多少噪声。网络接收带噪图像和时间步，预测其中的噪声；采样程序再用预测值计算反向一步的均值，方差采用预先规定的值。训练时，用预测噪声与实际加入噪声的平方误差更新网络。[^design]

“固定”指不学习，不是每步数值相同；强度和方差仍可随时间变化。U-Net又结合残差块、自注意力和时间条件，效果需要从这些选择的组合与消融理解。

<a id="training-example"></a>

## 2. 训练可直接构造任意噪声程度

从真实图取一张花照，假设随机选第600步。程序抽一份与图同尺寸的高斯噪声，按该步累计强度缩放原信号与噪声，直接混合出受扰图，再将它和时间步交给网络。网络输出噪声预测，与程序已知的实际噪声比较，更新参数。[^training]

第600步只是例子。原图参与构造样本，没有额外送给预测网络；目标由程序生成，无需人逐点标噪声。前向过程有直接采样形式，不必连续加噪600次才能得到该状态。

Algorithm 1在1到1000均匀抽时间步，反复训练同一网络，不为每步另建模型，也不在每次训练中反传整条千步生成链。

<a id="predicting-random-noise"></a>

## 3. 随机噪声为何能成为预测目标

模型不是无条件猜随机数，而是看到真实图与噪声的混合结果及混合程度。轮廓、颜色和背景的统计关系帮助它估计哪些部分属于结构、哪些属于扰动，所以噪声预测仍依赖学习图像规律。

噪声很重时，同一张受扰图可能由不同的原图和噪声组合得到。按平方误差训练，理想预测会接近这些可能噪声的平均值。因此，网络可以利用图像规律估计噪声，但不保证逐点还原某次实际抽样的结果。

直接构造时间步时，目标是原图到当前状态的累计扰动对应噪声，不是连续链最后一次新增的噪声。[^parameterization]

<a id="reverse-step"></a>

## 4. 原图估计与反向一步不同

噪声预测可以构造原图估计，采样却将它代入含时间系数的规则，得到反向一步均值，再按规定方差抽下一状态。[^sampling] 它包含信号缩放、预测系数和适量随机性，不是直接减掉全部预测噪声。

Algorithm 2除最后一步外会加入新高斯噪声。模型在新状态重新预测，让不确定结构逐步形成，而不将一次原图估计当成唯一正确答案。

```text
训练：真实图 + 已知扰动 → 随机噪声级别的样本 → 学会这一级别怎样预测
生成：新噪声 → 预测并走一步 → 重新预测并走一步 → …… → 新图片
```

固定起始噪声还不足以确定结果，中间随机选择也需固定才能讨论同次复现。减少生成步数属于后续研究，本篇噪声预测没有取消多步链。

<a id="loss-and-ablation"></a>

## 5. 预测对象与损失权重要一起看

噪声可换算为反向均值，单换输出形式不必改善效果。DDPM还去掉原变分目标对时间步误差的加权，直接优化噪声平方误差；在本篇日程下，相对降低轻微噪声、小时间步的训练分量。[^loss]

Table 2的无条件CIFAR-10消融为：[^ablation]

| 预测与训练设置 | FID ↓ |
|---|---:|
| 预测反向均值，原变分目标，固定方差 | 13.22 |
| 预测噪声，原变分目标，固定方差 | 13.51 |
| 预测噪声，简化目标，固定方差 | 3.17 |
| 预测均值并简单去掉损失权重 | 不稳定，无可用分数 |

前两行接近，噪声预测与简化目标结合才得到3.17。部分学习反向方差的配置也更差或不稳定，因此固定方差有此次实验依据，但不代表所有模型都不应学习方差。节目中的残差学习类比可帮助理解“预测调整量”，不能代替这些对照。

<a id="unet"></a>

## 6. U-Net计算逐位置预测

U-Net先缩小空间尺度取得较大范围表示，再恢复尺度，并通过对应层连接保留细节，适合输出与输入逐位置对应的噪声。它负责计算预测，扩散规则负责怎样将预测组成生成链。原始U-Net研究生物医学图像分割，并非专为边缘检测。[^unet]

DDPM具体骨架承接PixelCNN++／Wide ResNet，使用残差块、分组归一化，在16×16特征尺度加入自注意力。Transformer形式的正弦时间编码进入残差块，告知当前噪声阶段。[^architecture] 它不是完整Transformer替换U-Net，网络设计和概率过程各有职责。

<a id="results"></a>

## 7. 样本指标与概率指标的取舍

无条件CIFAR-10报告IS **9.46±0.11**、FID **3.17**，没有类别或文字引导。IS利用已有图像网络衡量可辨识性与总体类别分布，FID比较生成和参考图的特征统计，均非人类审美打分。[^results]

3.17以训练集为参考，换测试集为5.24。同表StyleGAN2+ADA v1的类别条件结果2.67，无条件为3.26，不能说DDPM超过全部方法或小差异已证实普遍优势。最终实验各训练一次，持续评价后报告训练中最低FID，CIFAR-10指标用50,000生成样本，IS的±也不能当多次独立训练波动。

| 同一噪声预测模型的目标 | FID | 测试负对数似然上界，bits/dim |
|---|---:|---:|
| 原变分目标 | 13.51 | ≤3.70 |
| 简化目标 | 3.17 | ≤3.75 |

bits/dim按一个像素的一个颜色通道计比特数，负对数似然越低越好。≤保留上界含义，不能称精确似然测量。简化目标改善样本指标，却未改善此概率指标，论文也承认似然弱于某些专用模型。

网络将0–255像素缩放至−1到1；评价时在每个离散值对应区间积分末步高斯密度，得到离散像素概率，可联系无损编码长度。[^discrete-decoder] 它与上一章连续密度的评价不只差一个负号，不能直接排名。

论文另展示256×256的LSUN等样本，说明可扩到较高分辨率，不等于任意文字条件与分辨率均已解决。以上指标也未独立证明无记忆、无偏差或细节全对。

<a id="progressive-decoding"></a>

## 8. 分数匹配、编码与插值

这里score指某个噪声程度下对数密度对图像取值的梯度，带有密度增大方向与强度，不是画质分数。噪声预测可换算为该梯度，论文据此连接去噪分数匹配与类似Langevin动力学的采样。[^score]

时间系数、随机项和前向日程共同定义过程，不是让样本都走向同一张最高概率图片，也不能把任意分数网络与采样器随意拼装视为等价。附录C专门讨论与NCSN的差异。

编码视角则观察逐步提供中间状态信息时，原图估计怎样改善。Figure 5给码率与重建误差，Figures 6–7呈现先大结构、后细节的行为。[^coding] 不必每步都对应可命名语义，许多编码比特花在几乎不可见细节，也解释像素概率与感官质量的目标差别。

论文用特殊逐坐标遮蔽过程连接自回归解码，不表示本篇高斯扩散逐词生成，也未交付性能领先的压缩软件。两张受扰图的中间状态插值后反向采样，可呈现姿态、发型连续变化，但眼镜等并不总平滑。[^interpolation] 这些状态仍与图片同维，不能因称为latent就等同下一章LDM的压缩空间。

<a id="cost-and-limits"></a>

## 9. 千步采样的实际成本

全部实验使用1000时间步。训练随机抽一步节约构造与学习开销，生成仍需连续计算。TPU v3-8上的批量采样为：[^cost]

| 任务 | 批量 | 整批耗时 |
|---|---:|---:|
| CIFAR-10，32×32 | 256图 | 17秒 |
| CelebA-HQ／LSUN，256×256 | 128图 | 300秒 |

这是当时实现的整批时间，不能直接当单请求延迟、当前电脑吞吐或实时视频能力。减少步数与压缩表示属于后续路线，尚非基本DDPM成果。

论文还讨论伪造与训练数据偏差，样本分数提升不自动解决输出真实性和使用条件。

<a id="people-and-history"></a>

## 10. 不同研究工具在此结合

DDPM沿用早期扩散框架，将噪声预测、目标权重与视觉网络结合，又联系分数匹配、随机动力学和渐进编码。GAN是重要对照，扩散内部也有失败配置，研究进步需按任务、指标和成本判断。

Jonathan Ho、Ajay Jain、Pieter Abbeel三位作者均署名UC Berkeley。Google TensorFlow Research Cloud在致谢中提供Cloud TPU，计算支持不改变作者机构。[^people] 节目提及的后续公司、榜单与任职不在本章核验范围。

<a id="mental-model"></a>

```text
训练时：
清楚的图 + 随机抽取的已知噪声 + 时间步
                    ↓
        直接构造这一噪声程度的图片
                    ↓
        同一个 U-Net 预测累计噪声
                    ↓
          比较已知噪声，更新参数

生成时：
新噪声 → 预测 → 按采样规则走一步 → 再预测 → …… → 新图片
```
