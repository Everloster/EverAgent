# AI演义·27｜早期扩散模型：用许多小步学习生成分布

[返回总览第 27 节](../AI演义_笔记分析与项目整合报告.md#paper-diffusion-2015) · [上一章：GAN](AI演义_26_GAN_两个模型怎样在对抗中学会生成_科普讲解_20261106.md)

将真实图片逐步扰动，直到接近简单噪声分布，再学习相反方向的小步变化，可以把复杂生成任务拆成可计算的训练问题。生成时从新噪声出发，依照学到的规律产生新样本，并非找回某张被破坏照片的唯一原件。

这是Jascha Sohl-Dickstein、Eric A. Weiss、Niru Maheswaranathan、Surya Ganguli的2015年论文*Deep Unsupervised Learning using Nonequilibrium Thermodynamics*的路线。首版为2015-03-12，本章沿用2015-11-18的v8。[^paper] 花照是节目提供的教学例子，不是原论文实验。[^lecture]

<a id="the-original-problem"></a>

## 1. 在表达能力与计算难度之间选择

简单分布容易计算，难以表达花形、颜色和背景等关系；灵活模型能表示复杂数据，训练、采样及计算数据概率却可能困难。论文关心怎样兼顾灵活性与可处理性。[^problem]

作者将许多小随机转移串成生成模型，每步简单、参数又依赖当前状态，使整体能表达复杂结构。节目用傅里叶方法类比“用易处理构件表达复杂对象”，这说明动机，但方法并非傅里叶变换或简单高斯函数相加。

<a id="forward-process"></a>

## 2. 前向过程构造受扰状态

原图记作x₀，下标表示步骤，每个状态仍是一整张图：

```text
花照 → 轻微受扰的花照 → 结构越来越难辨认 → 接近简单噪声分布
 x₀          x₁                    …                  xₜ
```

高斯设置每步适当缩小已有信号，再加入规定强度的正态噪声。重复后，整体数据分布接近选定的简单高斯。[^forward] 信号缩放使它区别于不断累加噪声、方差持续扩大的过程。

每步只依赖前一步状态，是马尔可夫链。训练程序掌握原图、转移规则和随机扰动，可自行构造不同噪声程度的状态，不必人工收集成对照片。这里无监督指不需要类别标注，真实数据和可计算目标仍然存在。

<a id="why-small-steps"></a>

## 3. 小步怎样降低反向建模难度

轻微扰动后，许多图像结构还在，预测相邻状态比一步从纯噪声构造完整图片容易组织。对于论文研究的过程，在步长趋近很小时，逆过程的小步可保持同样简单的分布形式，高斯扩散因而可用高斯反向条件分布描述。[^reverse]

条件是当前状态与时间步。强烈扰动可能混合许多差异很大的原状态，反向分布不再适合简单单一高斯，小步条件不可省略。

每步高斯也不意味着最终分布必然高斯：均值、协方差由当前状态和时间决定，变化方向随位置而变。许多状态相关的简单转移能组成复杂分布，区别于反复使用同一组固定参数。

<a id="what-is-learned"></a>

## 4. 学习反向分布的均值与协方差

2015年高斯模型预测每步均值和协方差，图像实验限制为对角协方差。均值确定变化的中心，协方差描述周围随机变化，不能直接改写成后来DDPM的噪声预测配方。[^reverse]

前向规则可计算，也不代表所有参数固定。高斯实验学习第二步至末步的加噪强度，第一步固定为小常数；同页脚注又说明近期实验中固定日程同样有效，学习日程不是扩散成立的必要条件。[^training]

训练取真实样本，按前向规则构造受扰状态，模型根据它和时间给出反向分布，再利用原图与已知规则计算目标并更新参数。训练可使用原图构造依据，生成时反向网络只看当前状态与时间，没有原件可偷看。

目标是最大化数据对数似然的变分下界，拆成各步条件分布比较，使反向转移接近训练依据。它为难直接优化的完整概率提供可计算目标，既无需共同训练真假判别器，也不是随意减掉一份噪声。

<a id="sampling-versus-restoration"></a>

## 5. 新样本与条件恢复

```text
新噪声 → 模型给出反向小步分布 → 抽取下一状态 → 再走一步 → 最终图像
```

生成从新抽噪声开始，每步还可随机采样，不是将训练时记录的扰动倒序扣除。高度受扰状态可与许多原图片相容，合理生成不能保证恢复某次信息丢失前的唯一历史。

给定受污染图片并保留其信息的去噪，则是条件推断。Figure 3分别展示条件去噪与自由生成，输入条件不同。[^conditional] 与GAN相比，两者都可从随机输入出发；基本GAN直接映射样本，扩散模型以多步随机链末端定义生成分布。

<a id="physics-and-architecture"></a>

## 6. 过程、目标和网络分别承担什么

非平衡统计物理提供逐步改变分布、逆过程与概率估计的思路，模型处理的是人为扰动后的数据，不模拟真实花朵运动。

扩散过程规定状态转移，训练目标使反向分布更能解释数据，神经网络预测这些分布的参数。CIFAR-10用多尺度卷积与全连接两路，MNIST只用全连接，再经时间相关读出产生均值和协方差。[^architecture] 主干共享，不是每个时间步独立训练完整网络，也非后来常见的U-Net方案。

实验步数随任务变化：图像通常1000步，树皮500步，二维卷曲分布40步，合成二值序列2000步。所谓“心跳”是长20、每隔5位置出现1的合成序列，不是临床心电图；二值扩散学习位翻转概率，不能直接套高斯图像形式。

更小变化便于近似逆过程，更多步骤增加执行成本。原文将成本写成参数函数计算量乘时间步数，单步好算不意味着整条链便宜。

<a id="probabilities"></a>

## 7. 可计算概率的范围

一步转移采用参数明确的简单分布，可以算密度；给定整条路径，可以把起点和每步条件概率相乘。仅求最终图片的边缘概率，却要汇总所有可能中间路径，原文指出直接积分不可行。[^probability]

作者利用前向轨迹、概率比与平均作估计，以变分下界训练。特殊理想极限下可精确，不代表任意有限网络和步数都能直接求精确图像概率。

“精确采样”也限定为按已定义的有限链模型逐步抽样，无须另等一条近似推断链混合到未知平衡；它不保证模型已精确等于真实数据分布。

<a id="inpainting"></a>

## 8. 根据已知区域修补图像

模型分布描述哪些图像合理，观测条件限定已知内容，两者组合可进行条件采样。一般组合仍依赖平滑扰动或可解析计算等条件，不能推成任意约束都能精确处理。[^conditional]

Figure 5将树皮中央100×100像素替换为噪声，再依据周围区域采样修补。作者指出裂缝等结构能延伸进入缺失区域，说明模型利用了空间联系。图示是一个条件样本，未证明还原真实被遮挡纹理，也不保证所有图和遮挡大小有效。

已知像素是具体观测条件，文字怎样可靠控制生成则需要另一套条件表示与训练，不能据此称已有成熟文生图系统。

<a id="experiments-and-limits"></a>

## 9. 似然评价与版本更正

实验包括二维卷曲分布、合成二值序列、MNIST、CIFAR-10、树皮和dead leaves。后者是不同大小圆片相互遮挡形成的统计图像，不是真实落叶照片。[^experiments]

相同dead leaves训练与测试数据下，扩散模型的对数似然下界K为1.489 bits/pixel，MCGSM对数似然为1.244。连续密度可以大于1，因此对数可为正；除二值任务外，原文先将数据缩放到方差1，再评价。这里对数似然越高越好，不能改成现代常见负对数似然越低越好，也不是画质打分。

扩散一项仍是下界。数值尺度与评价方式必须对齐，不能称已直接算出精确似然。

### MNIST的Parzen估计

作者使用GAN提供的Parzen窗代码，以生成样本估计平滑密度，再评价测试数据：[^evaluation]

| 方法 | MNIST对数似然估计，bits |
|---|---:|
| 扩散模型 | 317±2.7 |
| Adversarial net | 325±2.9 |
| 用训练数据样本作相同估计 | 349±3.3 |

最后一行在原表名为Perfect model，实际是直接拿训练样本做Parzen估计，不是已知真实分布的完美生成器。结果可称与近期方法相当，未证明全面超过GAN或感官质量更好。±按原表保留，不另推显著性；bits口径与上一章GAN的225等数值也不能不经处理直接比较。

### 去量化改变了CIFAR-10评价

v8说明早期更高的CIFAR-10下界包含模型学到8位像素量化的影响，修订后先加入均匀噪声去量化。[^dequantization] 这是作者自身更正，说明分数上升可能来自表示细节，而非语义或视觉质量同步提升，版本和预处理因此属于结果条件。

<a id="historical-position"></a>

## 10. 与GAN不同的训练信号

基本GAN学习真假判别器，再通过它更新生成器；早期扩散设计可计算的前向过程，训练反向各步分布。后者免去真假裁判的共同优化，仍要处理日程、概率估计、有限步近似和多步成本。

论文比较GAN并感谢Goodfellow提供评价代码，这是明确工具复用，不能推定GAN是扩散机制的直接来源。四位作者署名斯坦福与加州大学伯克利分校，物理、概率和神经网络的联系体现为实际建模选择。

节目有关作者后续职位与“沉寂五年”的叙事未在本章另行核实，也不代表期间无人研究。2015年的框架已有上述机制，2020年DDPM的贡献应在此基础上辨认。

<a id="mental-model"></a>

```text
训练所用的已知过程：
真实图片 ── 逐步扰动 ──► 简单噪声分布
              │
              └─ 提供各步可计算的学习依据
                            │
                            ▼
                学会反向小步的分布参数

生成时：
新的噪声 ── 学到的反向小步 × 多次 ──► 新样本
```

<a id="questions"></a>

[待验证] 在相同数据与预算下，减少步骤的损失可能来自单步近似、网络能力或训练设置，可固定条件分别检查。[下一章DDPM](AI演义_28_DDPM_预测噪声怎样学会生成图像_科普讲解_20261106.md)将研究怎样选择预测对象、损失和网络，改善扩散图像生成。
