# AI演义·29｜LDM：将反复去噪移到压缩表示中

[返回总览第 29 节](../AI演义_笔记分析与项目整合报告.md#paper-ldm) · [上一章：DDPM](AI演义_28_DDPM_预测噪声怎样学会生成图像_科普讲解_20261106.md)

高分辨率图像让每次去噪都很昂贵，多步采样又反复支付这笔成本。LDM先训练一个可重建图像的压缩表示，在较小网格上学习和运行扩散，最后解码为图片。表示与重建、生成分布由两个阶段分别承担，压缩也因此成为必须检查的质量限制。

本章采用*High-Resolution Image Synthesis with Latent Diffusion Models*的2022-04-13 v2，首版为2021-12-20。[^paper] 讲义将其放在Stable Diffusion标题下，这里按论文方法解释，下一章再讲v1.4具体模型。花照继续用作教学例子。

<a id="pixel-cost"></a>

## 1. 减少步数与降低每步成本

DDPM简化损失调整了不同去噪任务的权重，网络仍需处理完整像素网格。LDM原文引述当时前作：高质量像素扩散训练需150–1000个V100 GPU日，单A100生成50,000样本约5天。[^motivation] 这些是特定前作成本，不是所有模型的统一性能，也不是一天一张图。

可以少调用几次网络，也可以让每次调用处理更小表示。LDM主要研究后者，并用DDIM进行多种步数实验，压缩与减少采样步数可配合，潜空间本身不表示一步生成。

<a id="what-is-latent"></a>

## 2. 潜表示仍是有空间结构的数值网格

编码器输出较小的高、宽、通道数组，其中的数值不是直接显示的RGB，需要配套解码器变回图像。[^latent] 它既非“这是一朵花”的文字标签，也非普通缩略图。

仅按尺寸算，512×512图像高宽各缩4倍，得到128×128网格，位置数为原来的1/16。通道、网络宽度、注意力与编解码开销仍影响速度，不能由此断言整套系统快16倍。

论文用f表示每个空间方向的下采样倍数，比较f＝1、2、4、8、16、32等，潜通道数也随配置变化。表示保留了多少纹理和结构，需要重建实验判断。

<a id="learning-compression"></a>

## 3. 第一阶段学习表示与重建

```text
真实花照 → 编码器 → 较小的潜表示 → 解码器 → 重建花照
```

只用像素平均误差，可能将不确定细节折中成模糊颜色。压缩器结合感知损失和局部对抗目标：前者通过图像特征比较结构外观，后者让局部判别器区分真实与重建区域，鼓励真实纹理。[^compression] GAN的训练思想在压缩阶段继续使用，后续生成主过程则是扩散。

潜表示另有两种正则：

| 变体 | 约束 |
|---|---|
| KL | 小权重KL使编码分布接近标准正态，不要求严格相等 |
| VQ | 学习有限代码簿作向量量化；扩散用量化前表示，量化归入解码器 |

因此LDM不必预测离散代码编号，也不能将所有变体统称为同一VAE配置。第一阶段完成后冻结编解码器，再训练扩散，同一压缩器可复用于多个后续任务，首次训练成本仍应计入。

<a id="latent-training-and-generation"></a>

## 4. 在潜表示上训练扩散

训练图片先经过已经固定的编码器，得到较小的潜网格。程序随机选择一个时间步，按对应强度给网格加入已知噪声，再把受扰网格和时间交给去噪网络。网络预测这份噪声，用预测误差更新自己的参数，编解码器保持不变。[^ldm-training]

这沿用DDPM的训练方法，可以直接构造任意时间步的样本，无须每次训练跑完反向链。区别在于，网络反复处理的是潜网格，不再是整张像素图。

纯文本或无条件生成新图时则不需要输入真实照片：

```text
新的潜空间噪声 → 多步去噪 → 新的潜表示 → 解码一次 → 新图片
```

原文single pass指最后一次解码，前面仍反复去噪。编辑任务才可能另用输入图编码。任意潜向量也未必解码成好图，扩散需要学出与真实编码表示相符的分布。

<a id="compression-tradeoff"></a>

## 5. 压缩多少需要实验选择

压缩器承担一部分感知细节，扩散可在较小空间集中学习有用结构。[^tradeoff] 压得少，计算仍大；压得多，重要信息可能先丢失，后续去噪受表示与解码器限制。这支持具体分工，不支持“压缩必然产生智能”的概括。

§4.1在同型号单A100、相同步数和相近参数规模下比较，f＝4、8在样本质量与效率间较好，f＝32受到明显质量限制。批量、学习率和具体网络仍有差异，相同步数也不等于相同耗时；部分曲线只用5,000样本，不能与最终50,000样本结果混排。

附录另比较固定35个V100 GPU日，趋势相似。但A100时间换V100日使用2.2倍速度差假设，未把所有模型在两硬件各重测一遍。

VQ压缩器有时重建略逊于连续表示，后续扩散却生成更好，重建与生成目标并不完全一致。检查新任务应先看编解码保留多少细节，再看固定表示上生成的质量、速度和条件符合度。

<a id="text-conditioning"></a>

## 6. 交叉注意力将条件接入去噪

“窗边花瓶里的一朵红花”先经文本编码器形成表示。U-Net的图像特征提供查询Q，文本提供键K和值V，通过交叉注意力改变中间计算与本步噪声预测。[^conditioning] 这是生成过程中的条件读取，不是生成完贴标签，也不规定每词对应固定像素块。

训练使用图与条件配对，网络才有机会学习它们的关系。信息通道本身不保证计数、空间关系或关键词都正确。

所读LDM v2使用BERT tokenizer和与去噪网络联合训练的Transformer条件编码器。Tokenizer说明分词方式，不等于加载完整预训练BERT，更不是冻结CLIP。下一章Stable Diffusion v1.4才采用固定CLIP文本编码器。[^sd14]

类别与边界框布局可各自编码；低分辨率图、语义图等具有空间对齐关系的条件，还可与潜表示拼接。论文根据条件类型选择接口。

<a id="experiments"></a>

## 7. 按任务判断质量与效率

### 无条件生成

CelebA-HQ 256×256，LDM-4以500步DDIM得FID 5.11，优于Table 1所列对照；FFHQ 256×256则为4.98，弱于ProjectedGAN的3.08。[^unconditional] FID越低越好，不能从一套数据推断全面胜过GAN。

最终无条件结果用50,000生成样本与完整训练集统计。FID比较图像特征分布，非逐图真实证明或人类审美评分。

### 文本与类别条件

文本模型在LAION-400M训练，用MS-COCO的30,000验证样本评价，输出256×256、250步DDIM：[^text-results]

| 采样设置 | FID ↓ |
|---|---:|
| 无classifier-free guidance | 23.31 |
| 引导强度1.5 | 12.63 |

引导利用条件与无条件预测加强条件作用，细节下一章展开。该表GLIDE为12.24、Make-A-Scene为11.84，所以12.63不是最高表现；数据、规模和采样也不统一，不能仅归因于潜空间。

ImageNet类别条件的另一组实验，引导使FID由10.56到3.60，Recall却由0.62到0.48，质量指标改善可能伴随覆盖度下降。

### 修补效率

Table 6将像素LDM-1与VQ版LDM-4比较，所选LDM-4的“含注意力”指第一阶段压缩器：[^efficiency]

| 指标 | LDM-1 | LDM-4 |
|---|---:|---:|
| 训练吞吐，样本/秒 | 0.11 | 0.33 |
| 256×256采样，样本/秒 | 0.26 | 0.97 |
| 每轮训练及验证，小时 | 20.66 | 7.04 |
| 第6轮FID，2,000验证样本 | 24.74 | 14.99 |

修补模型在8张V100训练，吞吐受设备和批量影响，与前面单A100压缩率实验不同，也不能移作纯文本生成响应速度。它是在明确任务中同时改善效率与指标的证据，未证明按位置数量等比例提速。

<a id="more-than-text-to-image"></a>

## 8. 布局、超分与修补需要各自训练

论文为布局控制、低分辨率条件的超分、缺失区域修补等训练相应模型。[^tasks] 不能据共享潜空间方法，就推断一个文生图权重天然具有全部编辑能力。

超分中，LDM可以有更好的FID，SR3却有更高IS；简单图像回归在PSNR、SSIM更好。这些分别评价特征分布、分类器输出和与参考图的对应，目标不同。

Table 4的用户Task 2中，LDM相对像素扩散在超分获70.6%偏好，相对LaMa在修补获68.1%。受试者看到低清或待修补输入，3秒后在两结果中选较好者。[^user-study] 它不是满意度调查，也不同于Task 1的生成图与真实图比较。

合理纹理补全未必恢复原件细节。论文还展示较小分辨率模型以卷积方式生成更大空间条件图，达到约百万像素；效果受潜表示尺度、信噪比和高分辨率微调影响，部分修补模型也需额外微调，不能保证任意尺寸稳定。

<a id="history-and-limits"></a>

## 9. 不同方法承担不同部分

LDM组合扩散训练、自编码与感知压缩、压缩器对抗目标、U-Net和条件注意力。后续模型可替换文本编码器、数据和采样设置，不必重做整套方法。

作者为Robin Rombach、Andreas Blattmann、Dominik Lorenz、Patrick Esser、Björn Ommer，前两位共同一作。机构包括LMU Munich／IWR Heidelberg University与Runway ML，不能称全部来自同一实验室。[^people]

原文仍指出采样慢于GAN、压缩限制高精度重建、逼真内容的误导及数据偏差和隐私风险。[^limits] 压缩器、条件数据、后训练和评测也各有成本，资源改善需按任务检查。

<a id="mental-model"></a>

```text
先训练表示：
真实图 → 编码器 → 潜表示 → 解码器 → 重建图
                     以重建质量训练这一对部件

再训练生成：
真实图 → 固定编码器 → 潜表示 → 加已知噪声
                                   ↓
                    去噪网络学习预测噪声 ← 文本等条件

实际生成：
新潜空间噪声 → 多步去噪 → 新潜表示 → 固定解码器 → 新图
                   ↑
               文本等条件
```
