# AI演义·08｜GPT-1 与 BERT：把预训练网络用于不同任务

<a id="reading-route"></a>

[返回总览第 8 节](../AI演义_笔记分析与项目整合报告.md#paper-gpt1) · [上一章：GNMT 与 Transformer](./AI演义_07_GNMT与Transformer_从翻译系统到并行架构_科普讲解_20261105.md)

> The black cat is sleeping on the sofa. It ignores the noise outside.
>
> 黑猫正在沙发上睡觉。它没有理会外面的噪声。

同一段文字可以用于翻译、判断文本关系、回答位置问题，也可以接着续写。这些任务都需要词语、上下文、否定和指代等知识。若每项任务都从零训练，就会重复学习许多相通的东西。

2018 年的 GPT-1 与 BERT 先用大量文本训练网络，再用任务标注微调。它们采用不同的预训练题：GPT-1 根据前文预测下一词片，BERT 根据左右文恢复选中的词片，并判断两段文字是否相邻。[^gpt-framework][^bert-framework] 本章的黑猫句子和按词演示都是教学示意，真实模型使用词片。

<a id="beyond-word-vectors"></a>

## 1. 从复用词表到复用上下文网络

Word2Vec 为同一词条提供固定向量，后续模型还要处理它在具体句子中的关系。GPT-1 和 BERT 迁移的对象扩大为一整套上下文网络：先在大语料上训练参数，再将这些参数带到具体任务中继续训练。

预训练的题目可以从文本本身构造；监督微调仍需要任务答案。例如，“一只动物正在睡觉”能否由黑猫句子推出，这个关系标签需要由任务数据提供。

这种路线已有 Semi-supervised Sequence Learning、ULMFiT 等语言模型预训练与微调研究，也有 ELMo 等特征使用方法。GPT-1 明确承接了这些前驱，使用 Transformer 和较少的结构调整，将迁移用于更多语言理解任务。[^predecessors]

<a id="gpt-pretraining"></a>

## 2. GPT-1：预测接下来的词片

从原句可以直接构造训练题：

| 可使用的前文 | 预测目标 |
|---|---|
| The | black |
| The black | cat |
| The black cat is | sleeping |
| The black cat is sleeping on the | sofa |

真实单位是 token，一个英文词可能拆成多个词片。模型给词表候选分配概率，原文的下一 token 提供目标，反向传播据此更新参数。这通常称为自监督学习；GPT 原文使用“无监督预训练”的表述。[^gpt-framework]

想做好这道题，模型可能需要学习搭配、句法、主题和常见事实。它们是否能用于其他任务，还要由后面的实验检验。

GPT-1 使用解码器式 Transformer，自注意力带有因果遮罩。输入与预测目标错开一位，每个位置只能读取已有前缀，因此可以批量训练许多位置，又不把后续答案交给对应预测。与翻译 Transformer 相比，这里没有单独的源句编码器及交叉注意力。

模型为 **12 层、768 维、12 个注意力头**，包含前馈网络、残差和层归一化，并使用可学习位置表示。BooksCorpus 提供 **7,000 多本**未出版书籍，训练取连续 **512 token** 片段，BPE 进行了 **40,000 次合并**；合并次数不是精确词表大小。[^gpt-setup]

连续文本保留了跨句联系，如 It 与前面 cat 的关系。论文使用书籍中的长上下文，但并未据此单独证明书籍始终优于其他语料。

<a id="gpt-finetuning"></a>

## 3. 用预训练网络判断文本关系

将第一句作为前提，再输入 An animal is sleeping，任务可标为“可推出”；换成 No animal is sleeping 则矛盾；问房间的灯是否开着，前提没有提供答案。这是带监督标签的文本蕴含任务。

GPT-1 用特殊标记连接两段输入：

> 开始标记 → 前提 → 分隔标记 → 待判断文本 → 结束标记

末尾位置已经可以读取前面的整份输入，其表示接入小型分类层，预测关系标签。因果遮罩限制的是各个位置的可见范围，不妨碍末尾位置综合两段文本。[^gpt-inputs]

任务误差同时调整分类层和预训练网络。因此，同一个预训练起点可以分别微调成多个任务模型，微调后的参数通常不同。GPT-1 的主要结果并非冻结一份权重、只换提示就完成所有任务。

其他任务也通过输入组织复用网络。相似度任务将两句按两个先后顺序输入并合并表示；选择题把材料、问题和某个候选答案排在一起，逐个候选评分。结构调整较小，任务数据和训练仍然存在。

微调时还可加入辅助语言预测，与任务损失一同训练，它的收益取决于任务。

<a id="gpt-evidence"></a>

## 4. 预训练的收益怎样检验

GPT Table 5 的完整方法多任务平均分为 **74.7**，去掉预训练、直接用任务标注训练 Transformer 的版本为 **59.9**，相差 **14.8 分**。这是不同指标的无权重平均，不是统一准确率。[^gpt-ablation]

Figure 2 还逐步增加迁移过来的层数。只迁移词嵌入已经有用，继续迁移 Transformer 层，在 RACE 和 MultiNLI 验证集上总体继续受益；曲线有局部波动，不能向任意深度外推。[^gpt-layers]

具体任务的结果并不一致：

| 任务与评价 | GPT-1 微调后的成绩 | 论文列出的对照 |
|---|---:|---:|
| Story Cloze：选择故事结尾，准确率 | 86.5% | 77.6% |
| RACE：阅读选择题，整体准确率 | 59.0% | 53.3%，九模型集成 |
| RTE：文本蕴含，准确率 | 56.0% | 61.7%，多任务 BiLSTM 加注意力 |

前两项分别增加 **8.9、5.7 个百分点**，RTE 则未超过对照，该任务仅约 **2,490 条**训练样本。作者报告 12 个数据集中的 9 个刷新当时最好结果，显示较广的迁移能力，也保留了失败案例。[^gpt-results]

移除辅助语言预测后，Table 5 平均分为 **75.0**，略高于完整方法，但若干蕴含任务和 QQP 变差。它不是对所有任务都稳定增益的组件。

论文还探索了不微调的启发式方法，例如按材料和问题给候选答案的文本概率打分。Figure 2 右图显示其随预训练推进的变化，纵轴相对随机基线和当时最佳单模型归一化，不能直接读取为准确率。[^gpt-zero-shot] 这些探索与上面的监督微调成绩应分别理解。

<a id="bert-masking"></a>

## 5. BERT：用左右文恢复词片

GPT 中，cat 所在位置读不到后面的 is sleeping on the sofa；末尾分类位置虽然能综合全文，前面的表示仍受方向约束。答案抽取等逐位置任务，则可以直接利用每个位置两侧的线索。

BERT 使用编码器式 Transformer，让左右信息在每层共同处理。它不是两个单向网络算完后才拼接，也没有配一个逐步生成答案的解码器。[^bert-framework]

为了训练这种双向表示，BERT 将部分输入遮蔽。例如：

> The black cat is **[MASK]** on the sofa.

模型从左右文恢复原词，这叫遮蔽语言模型（MLM）。原始 BERT 选择的是 WordPiece 词片，按完整词展示仅为方便理解。

### 15% 的目标位置与 80／10／10

先选中约 **15% 的位置**作为预测目标，再决定怎样处理这些位置。若选中 100 个目标，平均分配如下：

| 在已选中的目标里 | 实际输入 | 预测目标 |
|---|---|---|
| 80% | 换成 `[MASK]` | 原词片 |
| 10% | 换成随机词片 | 原词片 |
| 10% | 保留原词片 | 原词片 |

MLM 损失只计算选中的目标，其他位置仍参与上下文计算。原样保留的 10% 也意味着部分预测位置会看到目标本身。随机替换和原样保留，是为了减轻预训练输入带有 `[MASK]`、实际任务通常没有它的差别。[^bert-mlm]

不同替换比例在微调和特征提取任务上各有影响，默认比例并非普适最优。[^bert-mask-ablation] 相比几乎每个位置都提供下一 token 目标的训练，MLM 直接预测的位置较少；附录观察到它收敛略慢，但任务收益超过相应训练代价。15% 是损失位置比例，不能解释为省下 85% 计算。[^bert-mlm-cost]

<a id="bert-nsp"></a>

## 6. 判断两段文字是否相邻

Next Sentence Prediction（NSP）是一道二分类题。给模型 A、B 两段，判断 B 是否来自原文紧接 A 的位置。实际相邻与随机抽取各占 **50%**，这里的 sentence 可以是一段连续文本。[^bert-nsp]

黑猫的两句话若在原文相邻，可组成正例；将第二段换成随机文本，得到另一类。标签来自取样关系，并不直接表示逻辑蕴含或所有可能续文的优劣。

输入组织为：

> `[CLS]` → A 段 → `[SEP]` → B 段 → `[SEP]`

`[SEP]` 标记边界，`[CLS]` 的最终表示用于 NSP 分类。每个位置的输入由词片、A／B 段标识和位置三份嵌入相加组成；被选中的位置同时承担 MLM，两项任务共同更新网络。[^bert-inputs]

原论文不把未经任务微调的 `[CLS]` 当作通用句向量。语义检索等用途仍需合适的训练和评估。

<a id="bert-finetuning"></a>

## 7. 分类、答案抽取和冻结特征

### 文本关系分类

将前提和待判断句放入 A、B 段，可以用 `[CLS]` 预测“可推出、相矛盾、信息不足”。这时需要对应任务标签，而非预训练时的相邻标签；主要微调方案会更新全部 BERT 参数。[^bert-finetune]

### 从段落选出答案

回答 Where is the cat sleeping? 时，把问题和段落一起输入，再为段落各位置计算答案起点、终点得分。候选必须组成合法片段，终点不能早于起点；原文将两端得分相加，选择最高分合法片段。例子中可以选中 **the sofa**。[^bert-qa]

这是 SQuAD 1.1 的抽取式问答，训练提供正确起止位置。SQuAD 2.0 增加无答案问题，例如问这只猫的名字。训练时，无答案的两端都标在 `[CLS]`；预测时比较最佳正文片段与无答案得分，只有差距超过验证集选出的阈值才返回片段。它学习的是给定材料是否包含答案，不是对所有未知问题作保证。

### 冻结后的表示也可以使用

原论文还冻结 BERT，用最后四层拼接特征训练双向 LSTM 做命名实体识别。验证 F1 为 **96.1**，全量微调 BERT Base 为 **96.4**。F1 同时衡量检出实体的准确性与覆盖，0.3 分差异只对应这一实验。[^bert-features]

冻结表示可预先计算，减少反复测试下游配置的成本；代价是 BERT 表示不能随新任务更新。冻结和微调各有适用情况。

<a id="comparison-conditions"></a>

## 8. 分数需要放回训练条件中

| 条件 | GPT-1 | 原始 BERT |
|---|---|---|
| 主干 | 12 层单向 Transformer | Base 12 层，Large 24 层双向 Transformer |
| 宽度与头数 | 768 维、12 头 | Base 768 维、12 头；Large 1024 维、16 头 |
| 预训练文本 | BooksCorpus，7,000 多本书 | BooksCorpus 约 8 亿词，英文 Wikipedia 约 25 亿词 |
| 预训练题 | 下一词片预测 | MLM 与 NSP |
| 主要任务结果 | 各任务监督微调 | 各任务监督微调 |

BERT Base 约 **1.1 亿参数**，Large 约 **3.4 亿参数**。“亿词”按原论文 words 统计，与分词后的 token 数不同。[^gpt-setup][^bert-setup]

原始 BERT 训练 **100 万步**，前 **90%** 使用长度 **128**，最后 **10%** 使用 **512**。Base 用 **4 个 Cloud TPU、16 枚芯片**，Large 用 **16 个 Cloud TPU、64 枚芯片**，各约 **4 天**。[^bert-training]

### 总榜与表内平均

官方 GLUE 综合分中，BERT Large 为 **80.5**，GPT 为 **72.8**，相差 **7.7 分**。训练数据、批次、特殊标记的训练阶段和微调学习率选择等也有变化，因此不能将全部差距归给双向表示。[^bert-glue]

BERT Table 1 的 **82.1** 是排除 WNLI 后的平均，同口径 GPT 为 **75.1**、BERT Base 为 **79.6**。这些综合分混合不同指标，需要与官方总分区分。

### 在相近条件下改变预训练目标

Table 5 使用相同 Base 规模、训练数据、微调与超参数，报告验证集结果：

| 预训练方法 | MNLI 准确率 | QNLI 准确率 | SQuAD 1.1 F1 |
|---|---:|---:|---:|
| 双向 MLM，加 NSP | 84.4 | 88.4 | 88.5 |
| 双向 MLM，去掉 NSP | 83.9 | 84.9 | 87.9 |
| 从左到右的语言模型，去掉 NSP | 82.1 | 84.3 | 77.8 |

前两行比较这套训练方案中 NSP 的作用，后两行都没有 NSP，更适合观察双向 MLM 与左到右语言预测的区别。方向约束与目标一起改变，仍需按整套方案理解。[^bert-ablation]

SQuAD 的 **87.9 对 77.8** 显示双向预训练对逐位置任务的价值。若到微调阶段才给单向模型加一个随机初始化双向 LSTM，F1 提高到 **84.9**，仍低于双向预训练。这个结论对应当前实验，并未证明 NSP 对以后所有模型必不可少，或双向模型适合所有生成任务。

### 结果的成本与稳定性

BERT Large 在小数据任务上可能需要多次随机重启，再按验证集选择模型。预训练提供了好起点，不保证任意一次微调都达到报告结果。[^bert-glue]

另一方面，小数据任务也不必只用小模型。Table 6 中，充分预训练的较大网络在一些标注较少的任务上仍有收益；其层数、宽度和头数共同改变，不能只解释为加层效果。[^bert-size]

SQuAD 1.1 的 **93.2 测试 F1** 来自额外使用 TriviaQA 微调的七模型集成，同样使用额外数据的单模型为 **91.8**。[^bert-qa-results] 数据、集成与测试设置都要和成绩一起记录。

<a id="different-interfaces"></a>

## 9. 输入可见范围决定使用方式

给定完整段落和问题，BERT 可以让每个候选位置读取左右线索，再选择答案片段。续写则面对尚未产生的后文，GPT 按已有前缀一步步预测，更直接地对应这种任务。

它们的用途不只一种：GPT-1 的主要实验就包括分类和选择题，BERT 也能提供冻结特征。应把训练目标、信息可见范围和输出接口一起看，而非只依据“单向”或“双向”判断能力。

OpenAI 的 **Alec Radford、Karthik Narasimhan、Tim Salimans、Ilya Sutskever** 将生成式预训练用于多种判别任务；Google AI Language 的 **Jacob Devlin、Ming-Wei Chang、Kenton Lee、Kristina Toutanova** 研究深层双向表示及任务适配。[^gpt-framework][^bert-framework] 这些工作承接词表示、序列建模和 Transformer 的积累，不能根据后来的结果倒推作者当时已经确定了全部发展路线。

这些方法的主要实验仍需要为每个任务准备标签并调整权重。[下一章 GPT-2 与 GPT-3](./AI演义_09_GPT2与GPT3_任务怎样进入上下文_科普讲解_20261105.md)会继续问：能否用输入本身表达任务？GPT-1 的候选打分探索已经提供了线索。

[^bert-framework]: BERT v2 [§3、图 1，PDF 第 3 页](https://arxiv.org/pdf/1810.04805v2#page=3)及[附录图 3，第 13 页](https://arxiv.org/pdf/1810.04805v2#page=13)：双向 Transformer encoder、不同任务共享预训练起点而分别微调；作者与机构见首页。
[^predecessors]: GPT-1 [§2，PDF 第 2 页](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf#page=2)及[官方研究介绍](https://openai.com/index/language-unsupervised/)明确列出 Dai 与 Le、Howard 与 Ruder、ELMo 等前驱关系；本文未另外完整精读这些前驱论文。
[^gpt-setup]: GPT-1 [§4.1，PDF 第 4–5 页](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf#page=4)：BooksCorpus、12 层、768 维、12 头、512 token 连续样本、BPE 40,000 merges、可学习位置表示。原文训练为批次 64、100 epochs；不将本配置推广到后续 GPT。
[^gpt-inputs]: GPT-1 [§3.2–3.3、图 1，PDF 第 3–4 页](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf#page=3)：分类输出层、任务输入转换、相似度双顺序与选择题候选分别评分。选择题正文顺序为材料、问题、分隔符、候选答案。
[^gpt-ablation]: GPT-1 [表 5、§5，PDF 第 8 页](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf#page=8)：完整配方 74.7，无预训练 59.9，无辅助 LM 75.0；该列为混合指标无权重平均，区别于官方 GLUE 综合分。
[^gpt-layers]: GPT-1 [图 2 左侧、§5，PDF 第 7 页](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf#page=7)：迁移层数与 RACE、MultiNLI 的训练／验证准确率；本文只解释趋势，不从曲线估取精确点值。
[^gpt-results]: GPT-1 [表 2–3、§4.2，PDF 第 5–6 页](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf#page=5)：Story Cloze、RACE、RTE 分数及 RTE 约 2,490 条训练样本；9／12 的总结见第 7 页。
[^gpt-zero-shot]: GPT-1 [图 2 右侧和 §5，PDF 第 7–8 页](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf#page=7)：未做监督微调的四类启发式方法，曲线按随机基线和当时最佳单模型归一化。
[^bert-mlm]: BERT v2 [§3.1，PDF 第 4 页](https://arxiv.org/pdf/1810.04805v2#page=4)：15% 目标位置、80／10／10 的条件比例、只预测选中目标及预训练／微调差别。
[^bert-mask-ablation]: BERT v2 [附录 C.2、表 8，PDF 第 16 页](https://arxiv.org/pdf/1810.04805v2#page=16)：不同替换比例在 MNLI、NER 微调和 NER 特征提取中的表现；正文没有把默认比例写成普适最优。
[^bert-mlm-cost]: BERT v2 [附录 A.1，第 12–13 页](https://arxiv.org/pdf/1810.04805v2#page=12)与[附录 C.1、图 5，第 16 页](https://arxiv.org/pdf/1810.04805v2#page=16)：只预测部分词片的训练代价，以及 MLM 与左到右预训练的收敛比较；这里不是按 15% 比例估算 FLOPs。
[^bert-nsp]: BERT v2 [§3.1 及脚注 5–6，PDF 第 4 页](https://arxiv.org/pdf/1810.04805v2#page=4)，[附录 A.1–A.2，第 12–13 页](https://arxiv.org/pdf/1810.04805v2#page=12)：NSP 二分类、50% 实际相邻／50% 随机文本；`[CLS]` 表示未经微调的用途限制。
[^bert-inputs]: BERT v2 [输入输出表示、图 2，PDF 第 4–5 页](https://arxiv.org/pdf/1810.04805v2#page=4)：WordPiece、特殊标记，以及 token、segment、position 三种表示相加。本文对图 2 采用可提取文字与正文核对，未据图估数。
[^bert-finetune]: BERT v2 [图 1、§3.2，PDF 第 3–5 页](https://arxiv.org/pdf/1810.04805v2#page=3)：各任务从预训练权重初始化，主要方案微调全部参数；句对、分类、标记任务使用不同输出形式。
[^bert-qa]: BERT v2 [§4.2–4.3，PDF 第 6–7 页](https://arxiv.org/pdf/1810.04805v2#page=6)：SQuAD 起止位置评分与训练，SQuAD 2.0 无答案机制。黑猫问答是本文教学示意。
[^bert-features]: BERT v2 [§5.3、表 7，PDF 第 9 页](https://arxiv.org/pdf/1810.04805v2#page=9)：冻结最后四层拼接特征，加两层双向 LSTM，CoNLL-2003 NER 验证 F1 为 96.1；Base 全微调验证 F1 为 96.4。
[^bert-setup]: BERT v2 [§3，第 3 页](https://arxiv.org/pdf/1810.04805v2#page=3)及[§3.1，第 5 页](https://arxiv.org/pdf/1810.04805v2#page=5)：Base／Large 配置，BooksCorpus 800M words、Wikipedia 2,500M words。
[^bert-training]: BERT v2 [附录 A.2，PDF 第 13 页](https://arxiv.org/pdf/1810.04805v2#page=13)：100 万步、批次 256、长度 128／512 的步数分配，以及 Cloud TPU／芯片数和约 4 天训练时间。
[^bert-glue]: BERT v2 [§4.1、表 1，PDF 第 6 页](https://arxiv.org/pdf/1810.04805v2#page=6)及[附录 A.4，第 14 页](https://arxiv.org/pdf/1810.04805v2#page=14)：官方分 80.5／72.8，去掉 WNLI 后的表内平均 82.1／75.1，Base 为 79.6；小数据随机重启与数据、批次等比较条件。
[^bert-size]: BERT v2 [§5.2、表 6，PDF 第 8–9 页](https://arxiv.org/pdf/1810.04805v2#page=8)：不同网络规模的验证集成绩，报告五次随机微调启动的平均；层数、宽度、注意力头同时变化。
[^bert-ablation]: BERT v2 [§5.1、表 5，PDF 第 8 页](https://arxiv.org/pdf/1810.04805v2#page=8)：Base 模型验证集，No NSP 与 LTR & No NSP 的对照；后加 BiLSTM 的 SQuAD F1 为 84.9。F1 是答案 token 重合的综合指标，不是整题完全答对比例。
[^bert-qa-results]: BERT v2 [§4.2、表 2，PDF 第 6–7 页](https://arxiv.org/pdf/1810.04805v2#page=6)：SQuAD 1.1 七模型集成加 TriviaQA 的测试 F1 为 93.2，单模型加 TriviaQA 为 91.8；没有混用验证集数值。
[^lecture]: [《AI演义》讲义，PDF 第 32、35–36 页](../../notes/终版：AI演义，36篇论文开启你的探索之旅.pdf#page=35)。正文保留其问题线索，并以论文补正“首次”“双向所以全面更强”等概括。
