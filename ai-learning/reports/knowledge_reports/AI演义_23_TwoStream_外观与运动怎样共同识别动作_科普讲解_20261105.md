# AI演义·23｜双流网络：分别学习外观与光流

[返回总览第 23 节](../AI演义_笔记分析与项目整合报告.md#paper-two-stream) · [上一章：DeepVideo](AI演义_22_DeepVideo_模型怎样利用视频时间信息_科普讲解_20261105.md)

拿着绳子站立与正在跳绳，定格画面可能很像。要分清动作，可以让网络从连续RGB帧学习变化，也可以先估计位移，再学习这些运动对应哪类动作。2014年，牛津的Karen Simonyan与Andrew Zisserman采用后一种分工，同时保留一条读取彩色帧的网络。[^paper]

在UCF-101第一个训练／测试划分中，从头训练的RGB多帧网络为56.4%，十组光流、减平均位移的时间网络为81.0%。[^ablation] 输入表示有明显影响，光流的预处理也带来额外成本。下面用跳绳场景作示意，解释两路输入。

<a id="why-separate-motion"></a>

## 1. 把一部分运动估计放到网络之前

直接输入RGB时，网络要从动作标签中学出前后对应、位移和动作关系，小数据会增加难度。DeepVideo的局部时间融合增益有限，双流论文以此为出发点，借用传统动作识别已在使用的光流，再由CNN学习运动特征。

这种分工没有取消学习，只为它提供更明确的输入。视觉双通路研究是架构启发，实验验证的是动作分类，不是复现人脑。

<a id="two-streams"></a>

| 路线 | 一次输入 | 输出 |
|---|---|---|
| 空间流 | 一张RGB帧 | 各动作类别分数 |
| 时间流 | 多时刻光流位移场 | 各动作类别分数 |

两路各有CNN，最后融合类别判断。[^architecture] 时间流就是读取光流的一路，没有额外第三条光流网络；也不同于DeepVideo的全景／中心空间分支。任务仍为分类，不要求数次数、定位时间或解释整段视频。

光流由现成算法预先计算，分类误差不会反向训练该算法，因此从视频到分类并非全部端到端学习。[^cost]

<a id="what-optical-flow-means"></a>

## 2. 光流是位移估计

若鞋尖在下一帧相对前一帧向右3像素、向上2像素，就可用水平、垂直两个数记录。对密集位置估计对应内容的位移，形成两张数值图，即稠密光流场。Figure 2用演奏画面展示了手与琴弓的运动分量。[^flow]

图片相减记录同一位置的颜色或亮度差，光流则估计内容移动到哪里，“相减留下影子”不能充当其定义。

估计依赖图像亮度、梯度在运动前后较稳定，以及位移场较平滑等假设。[推测] 光照突变、遮挡或难以对应的区域会影响可靠性，相机平移也产生大范围光流，位移不能直接等同物体真实运动。

<a id="stacking-flow"></a>

## 3. 从一对帧到一段运动

主要配置堆叠10组相邻帧光流，每组水平、垂直两分量，共20通道，需要对应的11张原始帧。网络可同时比较邻近位置及不同时间的位移。[^stacking] 作者对第一层滤波器的解释包括响应运动的空间变化与时间变化，后续运动描述由网络学习。

每组光流先减去全场平均位移，去掉一个共同运动分量，缓解相机平移干扰。[推测] 转动、缩放和不同景深的运动，未必能用一个平均向量补偿，论文也保留更精细相机处理作为后续方向。

作者还比较两种组织方式：沿估计轨迹移动取样位置，或在固定位置堆叠；同时使用前向、后向光流，或只用前向。双向对照保持总计10组、20通道，两方向各一半，不能把其结果当作输入量翻倍的收益。

<a id="learning-with-limited-data"></a>

## 4. 图片预训练与辅助视频数据

UCF-101约1.3万视频、101类，每划分约9,500训练视频；HMDB-51约6,800视频、51类，每划分约3,700训练视频。[^datasets] 空间流可借用ImageNet预训练，时间流输入变成光流，需要另寻小数据下的训练方法。

### 空间流

作者在ImageNet ILSVRC-2012预训练后，对UCF-101第一个划分比较：[^spatial]

| 方式 | Dropout | 准确率 |
|---|---:|---:|
| 从头训练 | 0.9 | 52.3% |
| 预训练后微调整网 | 0.9 | 72.8% |
| 冻结预训练网络，只训练末层 | 0.5 | 72.7% |

Dropout随机停用部分单元以正则化。最后两行比例不同，0.1个百分点差异不能说明全量微调必然无用；它们共同显示预训练图像表示在这里已经有效。后续采用只训练末层。此方案将Dropout由0.5增到0.9，准确率由72.7%降至59.9%，作者解释为过度正则化。

### 时间流

时间网络从头训练，Dropout为0.9，还尝试同时学习UCF-101与HMDB-51。前面共享特征网络，末端两个分类头分别处理不同标签集；来自哪个数据集的样本，就通过相应头产生误差，共同更新前层。[^multitask] 这样无需先将有交集但不相同的类别硬拼成一套。

HMDB-51第一个划分的时间流结果为：仅本数据46.6%；从UCF-101迁移49.0%；人工选入UCF-101的78个不重合类52.8%；多任务55.4%。收益包含额外数据与组织方式两方面。辅助数据使用完整集合，目标数据仍按自身训练／测试划分，不能省略辅助数据后称只用一个小数据集。

<a id="what-the-ablations-show"></a>

## 5. 输入表示的作用

以下均为UCF-101第一个划分、从头训练，三个光流配置均减去平均位移：[^ablation]

| 输入 | 准确率 |
|---|---:|
| 单张RGB空间网络 | 52.3% |
| 11张RGB的Slow Fusion | 56.4% |
| 1组光流 | 73.9% |
| 5组光流 | 80.4% |
| 10组光流 | 81.0% |

RGB多帧比单帧高4.1个百分点，十组光流比RGB多帧高24.6。显式位移在该数据与网络配置下很有效，但它已使用额外算法与计算，不是等总成本对照。

光流从1组到5组提高6.5个百分点，从5到10组只提高0.6。其他消融中，十组减均值由79.9%到81.0%；沿轨迹堆叠80.2%，不如固定位置；双向81.2%，比单向多0.2。原文未给这些小差异置信区间或多种子统计，不能据点估计推出普遍规律。

<a id="prediction-and-fusion"></a>

## 6. 视频聚合与两路融合

测试每视频等间距取25个位置，每处四角、中心及翻转共10个视角，平均类别分数。[^testing] 空间流因而也看多个时刻，时间流在各位置看光流窗口。固定这些输入，最后平均对排列顺序不敏感，局部时间表示不等于整段活动的长程顺序。

两路之间可直接平均，也可各做L2归一化，拼接类别分数后训练线性SVM。[^fusion] L2归一化按同一比例缩放一组分数至向量长度1，保留该路内部排序，SVM再学习怎样联合判断，输入并非原始像素和光流。

UCF-101第一个划分，普通单向时间流与空间流平均为85.9%；时间流改多任务后平均为86.2%，SVM融合为87.0%。相应空间单路72.7%、多任务时间单路81.5%，融合说明外观与运动在此互补。

较高层特征再加联合全连接层受到过拟合限制，未采用。单路略好的双向光流，平均融合后85.6%，却低于单向85.9%，模块分数提高未必改善整个系统。

<a id="results-and-mistakes"></a>

## 7. 三划分成绩与识别盲点

正式比较采用两个数据集各三个标准划分的平均准确率，不能与前面单划分消融混算：[^comparison]

| 方法 | UCF-101 | HMDB-51 |
|---|---:|---:|
| 改进稠密轨迹IDT | 85.9% | 57.2% |
| IDT＋高维编码 | 87.9% | 61.1% |
| IDT＋堆叠Fisher编码 | 未列 | 66.8% |
| DeepVideo Slow Fusion | 65.4% | 未列 |
| 空间流 | 73.0% | 40.5% |
| 时间流 | 83.7% | 54.6% |
| 双流平均融合 | 86.9% | 58.0% |
| 双流SVM融合 | 88.0% | 59.4% |

相对已有深度视频方法，双流明显进步；UCF-101的88.0%比表中最高的手工方法成绩87.9%高0.1个百分点，HMDB-51的59.4%仍低于61.1%和66.8%。原文“有竞争力”的定位符合这些结果，不能把节目“视频的AlexNet时刻”这一评价改写成全面超过手工方法。讲义第43页的“性能相当”更接近实验范围。

作者展示的敲锤Hammering，在UCF-101第一个划分中类别召回率最低，即该类真实样本被认对的比例最低。空间流易与头部按摩混淆，作者认为与人脸线索有关；时间流易与刷牙混淆，两者都有手反复上下移动。[^errors] 这是观察后的解释，未隔离变量证明因果，也表明不同动作可能共享外观与局部运动，融合仍会留下歧义。

<a id="cost-and-limits"></a>

## 8. 光流的时间与存储成本

OpenCV现成GPU光流每对帧约0.06秒，边训练边计算仍是瓶颈，作者选择预计算。UCF-101光流以浮点保存约1.5 TB，将两个分量线性映射至0–255后JPEG压缩、读取时映射回原范围，可降至27 GB。[^cost] 这是有损压缩的中间数据体积，不是权重大小。

时间网络在4张NVIDIA Titan上约训练一天，相对单卡加速3.2倍，均属当时实现。每对帧光流时间不能直接换成整套分类端到端帧率。

时间窗口仍短，最终平均缺少长程顺序；输入虽试过沿轨迹取值，后续空间池化未沿轨迹组织局部特征；相机补偿也较简化。[^limits] 论文将Sports-1M规模训练列为计划，不能把上一篇的百万视频训练算作双流已做的实验。
