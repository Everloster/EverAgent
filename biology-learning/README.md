# 生物学学习与研究

从时间生物学、睡眠、运动生理与内分泌代谢切入生命科学，积累论文精读和机制研究。既问“发生了什么”，也问通路、时间条件和个体差异如何影响结果。

## 几条阅读线索

- **昼夜节律与健康**：[Social Jetlag and Obesity](./reports/paper_analyses/P01_social_jetlag_obesity_2012.md)与[昼夜节律医学框架](./reports/paper_analyses/P04_roenneberg_circadian_health_2022.md)，区分关联、机制与干预证据。
- **睡眠与恢复**：[慢波睡眠和生长激素](./reports/paper_analyses/P08_sleep_onset_sws_gh_1988.md)与[睡眠和肌肉恢复](./reports/paper_analyses/P03_dattilo_sleep_muscle_2011.md)。
- **运动的时间条件**：[定时运动与时型](./reports/paper_analyses/P05_thomas_exercise_phase_chronotype_2020.md)及[个体化训练时间窗](./reports/concept_reports/运动时间生物学_个体化训练时间窗.md)。

研究结论应连同研究类型、样本和人群阅读；动物或体外结果不能直接外推到人类，群体平均结果也不自动成为个人医疗或训练建议。认知与行为问题可衔接[心理学](../psychology-learning/README.md)。
