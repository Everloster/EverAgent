# AI 实验分析

> 用于把实际运行的 notebook 或代码实验整理成可复核的教学笔记。纯理论解释或未运行的示例不使用本 playbook。

## 路由

- 需要实验笔记结构时读取 [guide：输出文件格式](./references/guide.md#输出文件格式)，只保留与实验有关的字段和章节。
- 处理数值、实验编号、notebook 映射或知识沉淀时读取 [guide：使用规则](./references/guide.md#使用规则)。

## 不变量

所有结果数值来自真实运行；记录环境、关键参数、命令和观察值；缩尺实验说明与真实规模的差异。wiki 与 CONTEXT 只在形成可复用知识或新增台账项时更新。
